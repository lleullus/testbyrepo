# systemd service 시작·종료가 timeout에서 멈춘 경우

## 입력값과 빠른 수집

실행 경로는 `운영자 Bash -> 승인 SSH endpoint -> machine/boot -> systemd job -> start-pre/start/start-post 또는 stop-sigterm/stop-sigkill -> ControlPID/MainPID -> dependency·kernel·storage`다. timeout은 경과 결과이며 어느 process나 dependency에서 대기했는지를 단독 확정하지 않는다.

| 종류 | 값 | 등록 기준 |
|---|---|---|
| 최초 입력 | `SSH_DEST`, `UNIT` | 승인 endpoint와 exact service |
| host 자동값 | unit Id·InvocationID·timeout 설정·MainPID/ControlPID·start ticks·namespace | fresh 원격 조회가 모두 성공한 뒤 등록 |
| 계산 후보값 | timeout phase와 대기 resource | bounded journal과 process 상태 확인 전 미확정 |
| 운영자 선택값 | expected machine/boot와 UTC 범위 | 자산·boot 목록·사건 시각으로 선택, refresh마다 재검증 |

```bash
unset INPUT_READY TARGET_READY TIME_READY SNAPSHOT_READY EVIDENCE_READY MUTATION_READY ROLLBACK_READY NORMALIZATION_READY MACHINE_ID BOOT_ID UNIT_ID INVOCATION_ID MAIN_PID MAIN_PID_START CONTROL_PID CONTROL_PID_START START_RFC3339 END_RFC3339
SSH_DEST='PASTE_APPROVED_SSH_DEST_HERE'
UNIT='PASTE_EXACT_SERVICE_UNIT_HERE'
INPUT_READY=false
if [[ "$SSH_DEST" =~ ^[A-Za-z0-9][A-Za-z0-9._-]*(@[A-Za-z0-9][A-Za-z0-9._-]*)?$ && "$UNIT" =~ ^[A-Za-z0-9_.@:-]+\.service$ ]] && command -v ssh >/dev/null && command -v date >/dev/null && command -v sed >/dev/null && command -v grep >/dev/null; then INPUT_READY=true; fi
printf 'INPUT_READY=%s ssh=%s unit=%s\n' "$INPUT_READY" "$SSH_DEST" "$UNIT"
```

### process·timeout refresh

refresh는 PID·InvocationID·time/evidence와 mutation·rollback·normalization READY를 먼저 폐기한다. PID 0은 허용하지만 process evidence는 등록하지 않으며, PID 교체는 이전 `/proc` 증거를 무효화한다.

```bash
refresh_timeout_target() {
  local out s e se ee
  unset TARGET_READY TIME_READY SNAPSHOT_READY EVIDENCE_READY MUTATION_READY ROLLBACK_READY NORMALIZATION_READY MACHINE_ID BOOT_ID UNIT_ID INVOCATION_ID MAIN_PID MAIN_PID_START MAIN_PID_STATE MAIN_PID_WCHAN MAIN_PID_PIDNS MAIN_PID_MNTNS CONTROL_PID CONTROL_PID_START CONTROL_PID_STATE CONTROL_PID_WCHAN CONTROL_PID_PIDNS CONTROL_PID_MNTNS START_RFC3339 END_RFC3339 START_EPOCH END_EPOCH
  TARGET_READY=false; TIME_READY=false; SNAPSHOT_READY=false; EVIDENCE_READY=false; MUTATION_READY=false; ROLLBACK_READY=false; NORMALIZATION_READY=false
  [[ "$INPUT_READY" == true && "$EXPECTED_MACHINE_ID_INPUT" =~ ^[0-9a-fA-F]{32}$ && "$EXPECTED_BOOT_ID_INPUT" =~ ^[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}$ ]] || { printf '%s\n' '중단: input/machine/boot gate 실패' >&2; return 1; }
  [[ "$START_INPUT" =~ ^[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}Z$ && "$END_INPUT" =~ ^[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}Z$ ]] || return 1
  s=$(date -u -d "$START_INPUT" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null) && e=$(date -u -d "$END_INPUT" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null) && [[ "$s" == "$START_INPUT" && "$e" == "$END_INPUT" ]] || { printf '%s\n' '중단: UTC round-trip 실패' >&2; return 1; }
  se=$(date -u -d "$s" +%s) && ee=$(date -u -d "$e" +%s) && (( se < ee && ee <= $(date -u +%s) && ee - se <= 86400 )) || { printf '%s\n' '중단: start<end/future/24h 범위 실패' >&2; return 1; }
  out=$(ssh -- "$SSH_DEST" bash -s -- "$EXPECTED_MACHINE_ID_INPUT" "$EXPECTED_BOOT_ID_INPUT" "$UNIT" <<'REMOTE'
set -eu
expected_machine=$1; expected_boot=$2; unit=$3
test "$(tr -d '\n' </etc/machine-id)" = "$expected_machine"; test "$(tr -d '\n' </proc/sys/kernel/random/boot_id)" = "$expected_boot"; pid1=$(ps -p 1 -o comm=); pid1=${pid1//[[:space:]]/}; test "$pid1" = systemd
printf 'machine-id=%s\nboot-id=%s\n' "$expected_machine" "$expected_boot"
systemctl show -p Id -p LoadState -p ActiveState -p SubState -p Result -p Type -p InvocationID -p MainPID -p ControlPID -p TimeoutStartUSec -p TimeoutStopUSec -p TimeoutAbortUSec -p JobTimeoutUSec -p KillMode -p Requires -p Requisite -p BindsTo -p FragmentPath -p DropInPaths -- "$unit"
for role in MainPID ControlPID; do pid=$(systemctl show --value -p "$role" -- "$unit"); if [[ "$pid" =~ ^[1-9][0-9]*$ && -r "/proc/$pid/stat" ]]; then stat=$(cat "/proc/$pid/stat"); rest=${stat##*) }; printf '%s-start=%s\n%s-state=%s\n%s-wchan=%s\n%s-pidns=%s\n%s-mntns=%s\n' "$role" "$(cut -d' ' -f20 <<<"$rest")" "$role" "${rest%% *}" "$role" "$(cat "/proc/$pid/wchan")" "$role" "$(readlink "/proc/$pid/ns/pid")" "$role" "$(readlink "/proc/$pid/ns/mnt")"; fi; done
REMOTE
  ) || { printf '%s\n' 'producer 실패: SSH/host/unit/process 조회' >&2; return 1; }
  grep -Fxq "machine-id=$EXPECTED_MACHINE_ID_INPUT" <<<"$out" && grep -Fxq "boot-id=$EXPECTED_BOOT_ID_INPUT" <<<"$out" && grep -Fxq "Id=$UNIT" <<<"$out" || { printf '%s\n' 'no match: current identity 불일치' >&2; return 1; }
  MACHINE_ID=$EXPECTED_MACHINE_ID_INPUT; BOOT_ID=$EXPECTED_BOOT_ID_INPUT; UNIT_ID=$UNIT; INVOCATION_ID=$(sed -n 's/^InvocationID=//p' <<<"$out")
  MAIN_PID=$(sed -n 's/^MainPID=//p' <<<"$out"); MAIN_PID_START=$(sed -n 's/^MainPID-start=//p' <<<"$out"); MAIN_PID_STATE=$(sed -n 's/^MainPID-state=//p' <<<"$out"); MAIN_PID_WCHAN=$(sed -n 's/^MainPID-wchan=//p' <<<"$out"); MAIN_PID_PIDNS=$(sed -n 's/^MainPID-pidns=//p' <<<"$out"); MAIN_PID_MNTNS=$(sed -n 's/^MainPID-mntns=//p' <<<"$out")
  CONTROL_PID=$(sed -n 's/^ControlPID=//p' <<<"$out"); CONTROL_PID_START=$(sed -n 's/^ControlPID-start=//p' <<<"$out"); CONTROL_PID_STATE=$(sed -n 's/^ControlPID-state=//p' <<<"$out"); CONTROL_PID_WCHAN=$(sed -n 's/^ControlPID-wchan=//p' <<<"$out"); CONTROL_PID_PIDNS=$(sed -n 's/^ControlPID-pidns=//p' <<<"$out"); CONTROL_PID_MNTNS=$(sed -n 's/^ControlPID-mntns=//p' <<<"$out")
  START_RFC3339=$s; END_RFC3339=$e; START_EPOCH=$se; END_EPOCH=$ee; TARGET_READY=true; TIME_READY=true; SNAPSHOT_READY=true
  printf 'TARGET_READY=true TIME_READY=true SNAPSHOT_READY=true machine=%s boot=%s unit=%s invocation=%s main=%s/%s control=%s/%s\n' "$MACHINE_ID" "$BOOT_ID" "$UNIT_ID" "${INVOCATION_ID:--}" "${MAIN_PID:-0}" "${MAIN_PID_START:--}" "${CONTROL_PID:-0}" "${CONTROL_PID_START:--}"
  printf '%s\n' "$out"
}
```

## bounded timeout evidence

먼저 `refresh_timeout_target`을 실행한다. 다음 명령은 원격 current identity를 다시 검사하고 journal producer와 filter 결과를 분리한다.

```bash
EVIDENCE_READY=false; if [[ "$SNAPSHOT_READY" == true && "$TIME_READY" == true ]]; then if ssh -- "$SSH_DEST" bash -s -- "$MACHINE_ID" "$BOOT_ID" "$UNIT_ID" "$INVOCATION_ID" "$MAIN_PID" "$MAIN_PID_START" "$CONTROL_PID" "$CONTROL_PID_START" "$START_RFC3339" "$END_RFC3339" <<'REMOTE'
set -u
expected_machine=$1; expected_boot=$2; unit=$3; expected_invocation=$4; expected_main=$5; expected_main_start=$6; expected_control=$7; expected_control_start=$8; start=$9; end=${10}
[[ "$(tr -d '\n' </etc/machine-id)" == "$expected_machine" && "$(tr -d '\n' </proc/sys/kernel/random/boot_id)" == "$expected_boot" ]] || exit 10
[[ "$(systemctl show --value -p Id -- "$unit")" == "$unit" ]] || exit 11
[[ "$(systemctl show --value -p InvocationID -- "$unit")" == "$expected_invocation" && "$(systemctl show --value -p MainPID -- "$unit")" == "$expected_main" && "$(systemctl show --value -p ControlPID -- "$unit")" == "$expected_control" ]] || exit 12
for pair in "$expected_main:$expected_main_start" "$expected_control:$expected_control_start"; do pid=${pair%%:*}; expected_start=${pair#*:}; if [[ "$pid" =~ ^[1-9][0-9]*$ ]]; then stat=$(cat "/proc/$pid/stat") || exit 13; rest=${stat##*) }; [[ "$(cut -d' ' -f20 <<<"$rest")" == "$expected_start" ]] || exit 14; fi; done
tmp=$(mktemp) || exit 12; trap 'rm -f "$tmp"' EXIT
journalctl --utc --boot="$expected_boot" -u "$unit" --since "$start" --until "$end" --no-pager -o short-iso-precise >"$tmp"; producer_rc=$?; printf 'producer_rc=%s\n' "$producer_rc"; (( producer_rc == 0 )) || exit 20
grep -E -i -C 3 'start operation timed out|stop operation timed out|jobtimeout|start-pre|start-post|stop-sigterm|stop-sigkill|control process|main process|dependency|watchdog|i/o error|read-only|oom|blocked task' "$tmp"; filter_rc=$?; printf 'filter_rc=%s\n' "$filter_rc"
case $filter_rc in 0) exit 0;; 1) printf '%s\n' 'no match: timeout 문자열 없음' >&2; exit 30;; *) printf '%s\n' 'filter 오류' >&2; exit 31;; esac
REMOTE
then EVIDENCE_READY=true; else printf '중단: timeout evidence 실패 rc=%s\n' "$?" >&2; fi; else printf '%s\n' '중단: fresh snapshot/time READY가 아니다.' >&2; fi; printf 'EVIDENCE_READY=%s\n' "$EVIDENCE_READY"
```

성공 gate는 `producer_rc=0`, `filter_rc=0`, 같은 unit/boot의 timeout phase와 해당 시각의 InvocationID/process 상태다. filter 무결과는 성공이 아니라 unit·boot·시간·retention 오류 후보다. `After`만으로 hard dependency를 확정하지 않는다.

| dependency job timeout | Requires/Requisite/BindsTo와 dependency 시각 | dependency 런북 | [[03. systemd unit dependency 실패로 service가 시작되지 않는 경우]] |

## process·resource 판정

PID·start ticks가 현재 `/proc`과 일치할 때만 state, wchan, namespace와 cgroup을 사용한다. `D` state나 I/O 문자열이 있으면 확인된 mount namespace에서 target/source/filesystem/major:minor를 연결한다. socket 대기는 network namespace, address·port·protocol, listener PID/start ticks가 필요하다. 현재 PID 소멸이나 교체는 정상화가 아니라 evidence 무효화다. argv/environment와 전체 stack은 기본 수집하지 않는다.

timeout 값을 늘리는 것은 원인 확정이 아니다. 적용된 `TimeoutStartUSec`, `TimeoutStopUSec`, `JobTimeoutUSec`와 실제 phase를 먼저 연결한다.

## 변경 경계와 정상화

진단 중 timeout 연장, stop/restart, kill, daemon-reload와 unit 편집을 실행하지 않는다. 별도 변경은 실행 직전에 refresh/evidence를 통과하고 fresh InvocationID·PID/start ticks, 원인 evidence, 승인 ID·권한·변경 창, dependency 가용성·quorum, 외부 side effect·멱등성, 중단 조건과 rollback 원본을 확인해야 한다. rollback도 current identity와 원본 checksum/revision을 재검증한다.

교체 process/unit/boot는 모든 READY를 폐기하고 입력부터 재등록한다. 정상화는 kernel/storage/dependency -> process 종료·기동 phase -> unit 의도 상태 -> 실제 client 요청·Job 산출물 순으로 새 canonical 창에서 검증한다. 같은 timeout이 재발하지 않아야 하며 `active`, PID 소멸 또는 빈 filter 하나는 성공이 아니다.

## 증거와 미검증

machine/boot, unit Id·InvocationID·timeout 설정, MainPID/ControlPID start ticks·state·wchan·namespace, canonical UTC와 producer/filter RC, 확인된 resource, 승인·rollback·실제 기능만 보존한다. argv/environment, credential과 전체 journal은 저장하지 않는다.
