# 호스트의 예상 IP가 없거나 duplicate address가 의심되는 경우

## 입력값과 빠른 수집

이 런북은 승인된 작업 PC 또는 bastion의 **같은 Bash**에서 실행한다. 경로는 `작업 PC의 Bash → 검증된 SSH host key → 대상 host의 machine-id·boot-id → host network namespace → 검증된 interface → address·local route·kernel journal`이다. `127.0.0.1`, Pod network namespace, VIP와 다른 host의 주소는 이 경로에 포함되지 않는다.

| 구분 | 값 | 출처와 gate |
|---|---|---|
| 최초 입력 | `INCIDENT_ID`, `SSH_TARGET`, `EXPECTED_MACHINE_ID`, `EXPECTED_IP` | 사건 기록과 승인된 inventory. 주소·host를 DNS나 naming convention으로 추측하지 않는다. |
| 시스템 확인 자동값 | `ACTUAL_MACHINE_ID`, `BOOT_ID`, `REMOTE_HOSTNAME`, `HOST_NETNS_INODE`, `IFINDEX` | 각 원격 명령이 다시 확인한다. boot 또는 interface가 바뀌면 stale 상태로 중단한다. |
| API 확인 자동값 | 없음 | Kubernetes API·CRI는 이 host identity와 workload endpoint 관계가 별도 확인되기 전 사용하지 않는다. |
| 계산 후보값 | `START_EPOCH`, `END_EPOCH`, 관측된 address 행 수 | 정규화된 UTC 창과 읽기 결과다. 빈 출력이나 필터 실패를 0·정상으로 바꾸지 않는다. |
| 운영자 선택값 | `IFACE`, 조건부 `TEST_DESTINATION` | 현재 host 출력과 승인된 실제 증상 endpoint에서 선택한다. |

각 `PASTE_..._HERE` 입력칸은 문서 전체에서 한 번만 나온다. 새 host로 바꾸거나 host가 재부팅되면 `register_host`부터 다시 실행한다.

### 1. Bash·도구·초기 입력

아래 블록은 retarget 시 machine identity, PID 시작점, mount, device, network namespace, interface, route, rule, time, argv 정규식과 모든 하위 `READY`를 먼저 폐기한다. 원격 명령은 문자열을 조립하거나 `eval`하지 않고 positional argument만 전달한다.

```bash
TOOLS_READY=false
MISSING_TOOLS=''
for TOOL in ssh date sed; do
  command -v "$TOOL" >/dev/null 2>&1 || MISSING_TOOLS="$MISSING_TOOLS $TOOL"
done
if [ -n "${BASH_VERSION:-}" ] && [ -z "$MISSING_TOOLS" ]; then
  TOOLS_READY=true
else
  printf '중단: Bash 또는 도구 누락:%s\n' "$MISSING_TOOLS" >&2
fi

clear_target_state() {
  unset ACTUAL_MACHINE_ID BOOT_ID REMOTE_HOSTNAME HOST_NETNS_INODE PID PID_START_TICKS MOUNT_ID DEVICE_ID DEVICE_IFINDEX NETNS_INODE IFACE IFINDEX ROUTE_FINGERPRINT RULE_FINGERPRINT START_RFC3339 END_RFC3339 START_EPOCH END_EPOCH ARGV_REGEX TEST_DESTINATION
  HOST_READY=false
  TIME_READY=false
  INTERFACE_READY=false
  EVIDENCE_READY=false
  NETWORK_READY=false
  MUTATION_READY=false
  ROLLBACK_READY=false
  NORMALIZATION_READY=false
}

register_host() {
  clear_target_state
  if [ "$TOOLS_READY" != true ]; then
    printf '%s\n' '중단: TOOLS_READY가 아니다.' >&2
    return 1
  fi
  if ! [[ "$SSH_TARGET" =~ ^([A-Za-z0-9._-]+@)?[A-Za-z0-9._-]+$ ]]; then
    printf '%s\n' '중단: SSH_TARGET 형식이 안전하지 않다.' >&2
    return 1
  fi
  if ! [[ "$EXPECTED_MACHINE_ID" =~ ^[0-9a-f]{32}$ ]]; then
    printf '%s\n' '중단: EXPECTED_MACHINE_ID는 소문자 32자리 hex여야 한다.' >&2
    return 1
  fi
  if ! [[ "$EXPECTED_IP" =~ ^[0-9A-Fa-f:.]+$ ]]; then
    printf '%s\n' '중단: EXPECTED_IP는 검증 가능한 숫자 IP여야 한다.' >&2
    return 1
  fi
  local RESULT RC
  RESULT="$(ssh -o BatchMode=yes -o StrictHostKeyChecking=yes -o ConnectTimeout=10 -- "$SSH_TARGET" bash -s -- "$EXPECTED_MACHINE_ID" <<'REMOTE'
set -uo pipefail
expected_machine_id=$1
actual_machine_id=$(< /etc/machine-id) || exit 20
boot_id=$(< /proc/sys/kernel/random/boot_id) || exit 20
host_netns=$(readlink /proc/1/ns/net) || exit 20
host_name=$(hostname) || exit 20
if [ "$actual_machine_id" != "$expected_machine_id" ]; then
  printf 'machine-id 불일치 expected=%s actual=%s\n' "$expected_machine_id" "$actual_machine_id" >&2
  exit 21
fi
printf '%s\t%s\t%s\t%s\n' "$actual_machine_id" "$boot_id" "$host_name" "$host_netns"
REMOTE
)"
  RC=$?
  if [ "$RC" -ne 0 ]; then
    clear_target_state
    printf '중단: host 등록 실패 rc=%s\n' "$RC" >&2
    return "$RC"
  fi
  IFS=$'\t' read -r ACTUAL_MACHINE_ID BOOT_ID REMOTE_HOSTNAME HOST_NETNS_INODE <<<"$RESULT"
  if [ -z "$ACTUAL_MACHINE_ID" ] || [ -z "$BOOT_ID" ] || [ -z "$HOST_NETNS_INODE" ]; then
    clear_target_state
    printf '%s\n' '중단: host identity 결과가 불완전하다.' >&2
    return 1
  fi
  HOST_READY=true
  printf 'HOST_READY=true host=%s machine-id=%s boot-id=%s host-netns=%s incident=%s\n' "$REMOTE_HOSTNAME" "$ACTUAL_MACHINE_ID" "$BOOT_ID" "$HOST_NETNS_INODE" "$INCIDENT_ID"
}

host_call() {
  if [ "${HOST_READY:-false}" != true ]; then
    printf '%s\n' '중단: HOST_READY가 아니다.' >&2
    return 1
  fi
  local OP=$1
  shift
  ssh -o BatchMode=yes -o StrictHostKeyChecking=yes -o ConnectTimeout=10 -- "$SSH_TARGET" bash -s -- "$EXPECTED_MACHINE_ID" "$BOOT_ID" "$OP" "$@" <<'REMOTE'
set -uo pipefail
expected_machine_id=$1
expected_boot_id=$2
op=$3
shift 3
actual_machine_id=$(< /etc/machine-id) || exit 20
actual_boot_id=$(< /proc/sys/kernel/random/boot_id) || exit 20
[ "$actual_machine_id" = "$expected_machine_id" ] || exit 21
[ "$actual_boot_id" = "$expected_boot_id" ] || exit 22
guard_interface() {
  iface=$1
  expected_ifindex=$2
  expected_netns=$3
  [[ "$iface" =~ ^[A-Za-z0-9_.:@-]{1,64}$ ]] || exit 30
  current_ifindex=$(< "/sys/class/net/$iface/ifindex") || exit 31
  current_netns=$(readlink /proc/1/ns/net) || exit 31
  [ "$current_ifindex" = "$expected_ifindex" ] || exit 32
  [ "$current_netns" = "$expected_netns" ] || exit 33
}
case "$op" in
  interface-identity)
    iface=$1
    [[ "$iface" =~ ^[A-Za-z0-9_.:@-]{1,64}$ ]] || exit 30
    ifindex=$(< "/sys/class/net/$iface/ifindex") || exit 31
    netns=$(readlink /proc/1/ns/net) || exit 31
    printf '%s\t%s\n' "$ifindex" "$netns"
    ;;
  address)
    guard_interface "$1" "$2" "$3"
    exec ip -details -statistics address show dev "$1"
    ;;
  local-route)
    guard_interface "$1" "$2" "$3"
    expected_ip=$4
    exec ip -j route show table local type local "$expected_ip"
    ;;
  route-get)
    guard_interface "$1" "$2" "$3"
    destination=$4
    exec ip -j route get "$destination"
    ;;
  neighbor)
    guard_interface "$1" "$2" "$3"
    destination=$4
    exec ip -j neighbor show to "$destination" dev "$1"
    ;;
  journal)
    guard_interface "$1" "$2" "$3"
    start=$4
    end=$5
    pattern=$6
    set +e
    journalctl -k --since "$start" --until "$end" --no-pager -n 300 | grep -E -i -C 3 -- "$pattern"
    status=("${PIPESTATUS[@]}")
    set -e
    [ "${status[0]}" -eq 0 ] || exit 60
    [ "${status[1]}" -eq 0 ] && exit 0
    [ "${status[1]}" -eq 1 ] && exit 61
    exit 62
    ;;
  ping)
    guard_interface "$1" "$2" "$3"
    destination=$4
    exec ping -n -I "$1" -c 3 -W 2 -- "$destination"
    ;;
  *)
    exit 64
    ;;
esac
REMOTE
}

INCIDENT_ID='PASTE_INCIDENT_ID_HERE'
SSH_TARGET='PASTE_SSH_TARGET_HERE'
EXPECTED_MACHINE_ID='PASTE_EXPECTED_MACHINE_ID_HERE'
EXPECTED_IP='PASTE_EXPECTED_IP_HERE'
clear_target_state
```

`EXPECTED_MACHINE_ID`는 SSH 접속으로 발견해 넣는 값이 아니라 승인된 inventory의 값이어야 한다. host key 검증 실패, machine-id 불일치, boot-id 변경은 우회하지 않는다.

```bash
register_host
```

성공 gate는 `HOST_READY=true`와 사건의 host·machine-id가 일치하는 것이다. 실패한 등록은 모든 파생값을 비운다.

### 2. 증거 시간창 등록

시간은 초 단위 UTC RFC3339만 허용한다. regex, GNU `date` round-trip, 순서와 최대 24시간 창을 모두 통과해야 journal을 읽을 수 있다.

```bash
START_RFC3339='PASTE_START_RFC3339_HERE'
END_RFC3339='PASTE_END_RFC3339_HERE'
TIME_READY=false
unset START_EPOCH END_EPOCH
RFC3339_RE='^[0-9]{4}-(0[1-9]|1[0-2])-([0-2][0-9]|3[01])T([01][0-9]|2[0-3]):[0-5][0-9]:[0-5][0-9]Z$'
if [ "${HOST_READY:-false}" != true ]; then
  printf '%s\n' '중단: HOST_READY가 아니다.' >&2
elif ! [[ "$START_RFC3339" =~ $RFC3339_RE ]] || ! [[ "$END_RFC3339" =~ $RFC3339_RE ]]; then
  printf '%s\n' '중단: 시간 형식은 YYYY-MM-DDTHH:MM:SSZ다.' >&2
elif [ "$(date -u -d "$START_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null)" != "$START_RFC3339" ] || [ "$(date -u -d "$END_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null)" != "$END_RFC3339" ]; then
  printf '%s\n' '중단: 존재하지 않거나 canonical하지 않은 시각이다.' >&2
else
  START_EPOCH=$(date -u -d "$START_RFC3339" +%s)
  END_EPOCH=$(date -u -d "$END_RFC3339" +%s)
  if (( START_EPOCH >= END_EPOCH || END_EPOCH - START_EPOCH > 86400 )); then
    unset START_EPOCH END_EPOCH
    printf '%s\n' '중단: 시작은 종료보다 앞서야 하고 창은 24시간 이하여야 한다.' >&2
  else
    TIME_READY=true
    printf 'TIME_READY=true start=%s end=%s seconds=%s\n' "$START_RFC3339" "$END_RFC3339" "$((END_EPOCH-START_EPOCH))"
  fi
fi
```

### 3. interface identity 등록

`IFACE`는 현재 host의 승인된 inventory 또는 콘솔 출력에서 선택한다. 이름만 보존하지 않고 host netns inode와 ifindex를 묶는다.

```bash
IFACE='PASTE_INTERFACE_HERE'
INTERFACE_READY=false
EVIDENCE_READY=false
NETWORK_READY=false
unset IFINDEX NETNS_INODE ROUTE_FINGERPRINT RULE_FINGERPRINT
if [ "${HOST_READY:-false}" != true ]; then
  printf '%s\n' '중단: HOST_READY가 아니다.' >&2
elif RESULT=$(host_call interface-identity "$IFACE"); then
  IFS=$'\t' read -r IFINDEX NETNS_INODE <<<"$RESULT"
  if [ -n "$IFINDEX" ] && [ "$NETNS_INODE" = "$HOST_NETNS_INODE" ]; then
    INTERFACE_READY=true
    printf 'INTERFACE_READY=true interface=%s ifindex=%s netns=%s\n' "$IFACE" "$IFINDEX" "$NETNS_INODE"
  else
    unset IFINDEX NETNS_INODE
    printf '%s\n' '중단: interface identity가 host netns와 맞지 않는다.' >&2
  fi
else
  unset IFINDEX NETNS_INODE
  printf '%s\n' '중단: interface 등록 실패' >&2
fi
```

## 진입 판단

| 구분 | 판단 기준 |
|---|---|
| 사용 | 승인된 `EXPECTED_IP`가 host netns에서 보이지 않거나, 같은 주소의 복수 local assignment, `tentative`·`dadfailed` 또는 exact conflict 메시지가 있는 경우 |
| 적용 | 같은 machine-id·boot-id·host netns·ifindex와 같은 증거 창을 유지할 수 있는 경우 |
| 제외 | Pod IP·CNI·Service·VIP·LoadBalancer 주소, 다른 host의 duplicate, DHCP·network manager 원인이 직접 관측되지 않은 경우 |

검색 문자열: `duplicate address`, `DAD`, `dadfailed`, `tentative`, `addrconf`, `conflict`, `RTNETLINK`.

## 관측별 진단 경로

| 지금 보이는 것 | 직접 증거 | 다음 분기 |
|---|---|---|
| address와 local route 모두 없음 | exact IP, interface identity, local table | authoritative address owner와 지속 설정 확인 |
| 같은 host에서 복수 assignment | 각 ifindex·prefix·scope·flag | local duplicate로 한정하고 remote duplicate와 분리 |
| `tentative`·`dadfailed` | address flag와 같은 창의 kernel message | IPv6 DAD·L2 owner |
| neighbor entry만 존재 | state·interface·관측 시각 | duplicate 증거로 쓰지 않고 L2 owner 확인 |
| address는 맞지만 실제 증상 지속 | route와 승인된 packet test | route·firewall·application 경로 |

## 읽기 전용 진단

각 호출은 machine-id, boot-id, host netns와 ifindex를 **직접 다시 검증**한다. 첫 명령 실패 뒤 다음 명령을 계속 실행하지 않는다.

```bash
if [ "${INTERFACE_READY:-false}" != true ]; then
  printf '%s\n' '중단: INTERFACE_READY가 아니다.' >&2
elif host_call address "$IFACE" "$IFINDEX" "$NETNS_INODE"; then
  if host_call local-route "$IFACE" "$IFINDEX" "$NETNS_INODE" "$EXPECTED_IP"; then
    EVIDENCE_READY=true
    printf '%s\n' 'EVIDENCE_READY=true'
  else
    EVIDENCE_READY=false
    printf '%s\n' '중단: local route 생산 명령 실패. 빈 결과와 실행 실패를 구분한다.' >&2
  fi
else
  EVIDENCE_READY=false
  printf '%s\n' '중단: address 조회 실패' >&2
fi
```

`ip address`에 exact address가 없으면 현재 이 host netns·ifindex에서 미관측인 것이다. DHCP 실패나 remote duplicate를 뜻하지 않는다. local route가 비어 있으면 정상으로 표시하지 말고 address 결과와 함께 `미관측`으로 기록한다.

```bash
if [ "${EVIDENCE_READY:-false}" != true ] || [ "${TIME_READY:-false}" != true ]; then
  printf '%s\n' '중단: EVIDENCE_READY와 TIME_READY가 필요하다.' >&2
else
  PATTERN="$(printf '%s' "$EXPECTED_IP" | sed 's/[][\\.^$*+?(){}|]/\\&/g')|duplicate address|DAD|dadfailed|tentative|addrconf|conflict|RTNETLINK"
  host_call journal "$IFACE" "$IFINDEX" "$NETNS_INODE" "$START_RFC3339" "$END_RFC3339" "$PATTERN"
  RC=$?
  case "$RC" in
    0) printf '%s\n' 'journal producer와 filter 성공' ;;
    60) printf '%s\n' '중단: journal producer 실패' >&2 ;;
    61) printf '%s\n' 'filter 일치 없음: 오류 부재가 아니라 이 창에 일치 행이 없음' >&2 ;;
    62) printf '%s\n' '중단: journal filter 실행 실패' >&2 ;;
    *) printf '중단: identity 또는 원격 실행 실패 rc=%s\n' "$RC" >&2 ;;
  esac
fi
```

`PATTERN`은 계산값이며 입력 문자열을 regex로 직접 실행하지 않는다. 전체 journal, MAC·neighbor 원문과 무관한 주소를 저장하지 않는다.

remote duplicate는 passive neighbor 결과로 확정하지 않는다. 조회 자체가 실패한 것과 빈 neighbor set도 구분한다.

```bash
if [ "${EVIDENCE_READY:-false}" != true ]; then
  printf '%s\n' '중단: EVIDENCE_READY가 아니다.' >&2
elif ! host_call neighbor "$IFACE" "$IFINDEX" "$NETNS_INODE" "$EXPECTED_IP"; then
  printf '%s\n' '중단: neighbor 조회 실패. 빈 정상으로 기록하지 않는다.' >&2
fi
```

## 제한된 packet 확인

`ping`은 duplicate 검출기가 아니다. 실제 장애가 IP packet 도달성이고 대상 owner가 3개 ICMP 요청을 승인한 경우에만 사용한다. 인터넷·다른 tenant·임의 private address를 선택하지 않는다.

```bash
TEST_DESTINATION='PASTE_APPROVED_TEST_DESTINATION_HERE'
NETWORK_READY=false
if [ "${EVIDENCE_READY:-false}" != true ] || ! [[ "$TEST_DESTINATION" =~ ^[0-9A-Fa-f:.]+$ ]]; then
  printf '%s\n' '중단: 증거와 승인된 실제 destination이 필요하다.' >&2
elif host_call route-get "$IFACE" "$IFINDEX" "$NETNS_INODE" "$TEST_DESTINATION"; then
  if host_call ping "$IFACE" "$IFINDEX" "$NETNS_INODE" "$TEST_DESTINATION"; then
    NETWORK_READY=true
    printf '%s\n' 'NETWORK_READY=true'
  else
    printf '%s\n' 'packet 확인 실패: route 성공과 packet 도달 실패를 분리한다.' >&2
  fi
else
  printf '%s\n' '중단: route lookup 실패' >&2
fi
```

성공한 `ping`은 TCP·TLS·업무 기능을 보장하지 않는다. 실패도 duplicate를 단독 확정하지 않는다. 실제 증상은 원래 client·protocol·endpoint에서 별도 승인된 요청으로 재검증한다.

## Kubernetes·CRI 경계

이 문서에는 `kubectl`, `crictl`, runtime socket 명령을 두지 않는다. 대상이 Kubernetes Node·Pod라면 먼저 별도 절차에서 Node 이름·UID·provider ID·InternalIP가 `EXPECTED_MACHINE_ID`의 inventory와 일치하고, Pod UID·`spec.nodeName`·container ID가 그 Node와 현재 runtime endpoint에 연결되는지 확인한다. 이 관계가 없으면 host address 결과를 Pod·Service 원인으로 승격하지 않는다.

## 변경 전 안전 gate

address add/delete, DHCP renew, manager reload, interface reset과 gratuitous ARP는 구현체·지속 설정·remote ownership을 모르면 안전한 공통 rollback을 만들 수 없어 이 런북에 실행 명령을 제공하지 않는다. 별도 변경 절차는 다음을 모두 만족해야 한다.

1. fresh `register_host`와 interface 재등록으로 machine-id·boot-id·host netns·ifindex를 다시 확인한다.
2. 변경 직전의 fresh address·local route·journal 증거가 같은 창에 있고 원인이 local missing 또는 local duplicate로 확정된다.
3. address/network owner의 승인 ID, 실행자, 시작·종료 시각과 가용성 기준이 있다.
4. persistent manager의 authoritative source를 확인하고 일회성 `ip` 상태와 충돌하지 않는다.
5. 조치의 멱등 조건과 이미 원하는 상태일 때의 no-op 조건이 정의된다.
6. 원래 prefix·scope·flags·route·manager 원본과 실제 rollback 절차를 사전 검증한다.
7. 다른 interface·Node, 새 DAD/conflict, packet loss 또는 업무 오류 증가 시 즉시 중단한다.
8. 교체·재부팅·interface 재생성이 있으면 모든 변수를 폐기하고 replacement state를 `register_host`부터 다시 등록한다.

## 정상화 검증

변경이 없었더라도 정상화 시점에는 최신 identity와 새 증거 창을 등록한다. 이전 `READY`나 이전 boot의 결과를 재사용하지 않는다.

```bash
clear_target_state
register_host
printf '%s\n' '다음: 새 UTC 창과 현재 interface를 다시 입력·등록한 뒤 read-only 진단과 승인된 packet 확인을 반복한다.'
```

정상화는 다음을 모두 만족해야 한다.

- 승인된 exact IP가 의도한 host netns·ifindex·prefix·scope·flags로 한 번 존재하고 local route와 맞는다.
- 새 관찰 창에 DAD·duplicate·conflict가 재발하지 않는다. filter 일치 없음은 producer 성공과 창 보존을 함께 기록한다.
- 승인된 route lookup과 packet 확인이 성공하고, 원래 protocol의 실제 connectivity·업무 증상이 회복된다.
- Kubernetes가 관련되면 fresh Node·Pod identity relation을 다시 등록하고 Node condition, endpoint와 실제 서비스 기능을 별도 확인한다.
- 완화와 remote duplicate·지속 설정의 근본 원인 해결을 분리해 기록한다.

## 증거 보존과 완료 기준

보존: 사건 ID, SSH host key 확인 경로, machine-id·boot-id·hostname, host netns inode, interface·ifindex, expected IP의 승인 출처, prefix·scope·flags, local route, canonical UTC 창, journal producer/filter 상태, 제한된 packet 결과, 승인·이관·정상화 결과.

저장 금지: 전체 address·neighbor·journal 원문, MAC·tenant 주소, credential·token·개인키·개인정보. 필요한 행도 공유 전에 비식별화한다.

완료 결론은 `host-local missing`, `host-local duplicate`, `DAD conflict`, `remote duplicate 미확정`, `다른 계층`, `증거 부족` 중 하나로 쓴다. 빈 출력, Node Ready, ping 한 번만으로 `정상`을 선택하지 않는다.
