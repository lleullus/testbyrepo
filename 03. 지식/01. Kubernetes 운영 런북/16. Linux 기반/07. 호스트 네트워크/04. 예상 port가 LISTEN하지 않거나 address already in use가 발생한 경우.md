# 예상 port가 LISTEN하지 않거나 address already in use가 발생한 경우

## 입력값과 빠른 수집

실행 경로는 `승인된 작업 PC/Bash → 검증된 SSH host key → machine-id·boot-id → host netns 또는 확인된 process netns → protocol·bind address·port socket → PID·start ticks·cgroup·argv match → unit → application endpoint`다. TCP `LISTEN`, UDP socket, process 생존과 application 성공은 서로 다른 gate다.

| 구분 | 값 | 출처와 gate |
|---|---|---|
| 최초 입력 | `INCIDENT_ID`, `SSH_TARGET`, `EXPECTED_MACHINE_ID`, `PROTOCOL`, `PORT` | 오류 원문과 승인 inventory. protocol은 `tcp` 또는 `udp`, port는 1–65535다. |
| 시스템 확인 자동값 | `BOOT_ID`, `HOST_NETNS_INODE`, `SOCKET_FINGERPRINT`, 조건부 `PID_START_TICKS`, `PROCESS_NETNS_INODE`, `CGROUP_HASH`, `COMM` | 원격 호출마다 lifecycle을 다시 확인한다. |
| API 확인 자동값 | 없음 | Kubernetes/CRI는 Node↔machine, Pod UID↔node↔container endpoint가 별도 확정된 경우만 전문 런북에서 사용한다. |
| 계산 후보값 | canonical UTC epoch, `ARGV_REGEX_B64`, socket state | 입력 regex를 전송용 base64로 만들지만 원문 argv는 출력하지 않는다. |
| 운영자 선택값 | `PID_INPUT`, `ARGV_REGEX`, `SERVICE_UNIT`, `CONNECT_ADDRESS` | 현재 `ss`, service inventory와 실제 application 계약에서 선택한다. listener가 없으면 PID를 억지로 만들지 않는다. |

각 입력칸은 한 번만 나온다. 새 PID, unit restart, socket replacement, netns 변경 또는 host reboot가 있으면 모든 하위 상태를 폐기한다.

### 1. 실행 계약과 host 등록

```bash
TOOLS_READY=false
MISSING_TOOLS=''
for TOOL in ssh date base64 mktemp; do
  command -v "$TOOL" >/dev/null 2>&1 || MISSING_TOOLS="$MISSING_TOOLS $TOOL"
done
if [ -n "${BASH_VERSION:-}" ] && [ -z "$MISSING_TOOLS" ]; then TOOLS_READY=true; else printf '중단: Bash 또는 도구 누락:%s\n' "$MISSING_TOOLS" >&2; fi

clear_target_state() {
  unset ACTUAL_MACHINE_ID BOOT_ID REMOTE_HOSTNAME HOST_NETNS_INODE PID PID_INPUT PID_START_TICKS MOUNT_ID DEVICE_ID DEVICE_IFINDEX NETNS_INODE IFACE IFINDEX ROUTE_FINGERPRINT RULE_FINGERPRINT START_RFC3339 END_RFC3339 START_EPOCH END_EPOCH ARGV_REGEX ARGV_REGEX_B64 SOCKET_FINGERPRINT SOCKET_STATE PROCESS_NETNS_INODE CGROUP_HASH COMM SERVICE_UNIT UNIT_FINGERPRINT UNIT_MAIN_PID UNIT_ACTIVE UNIT_SUB UNIT_START_MONO
  HOST_READY=false
  TIME_READY=false
  SOCKET_READY=false
  PROCESS_READY=false
  UNIT_READY=false
  EVIDENCE_READY=false
  NETWORK_READY=false
  MUTATION_READY=false
  ROLLBACK_READY=false
  NORMALIZATION_READY=false
}

register_host() {
  clear_target_state
  if [ "$TOOLS_READY" != true ] || ! [[ "$SSH_TARGET" =~ ^([A-Za-z0-9._-]+@)?[A-Za-z0-9._-]+$ ]] || ! [[ "$EXPECTED_MACHINE_ID" =~ ^[0-9a-f]{32}$ ]]; then printf '%s\n' '중단: host 초기 입력 오류' >&2; return 1; fi
  local RESULT RC
  RESULT="$(ssh -o BatchMode=yes -o StrictHostKeyChecking=yes -o ConnectTimeout=10 -- "$SSH_TARGET" bash -s -- "$EXPECTED_MACHINE_ID" <<'REMOTE'
set -uo pipefail
expected=$1
actual=$(< /etc/machine-id) || exit 20
boot=$(< /proc/sys/kernel/random/boot_id) || exit 20
netns=$(readlink /proc/1/ns/net) || exit 20
name=$(hostname) || exit 20
[ "$actual" = "$expected" ] || exit 21
printf '%s\t%s\t%s\t%s\n' "$actual" "$boot" "$name" "$netns"
REMOTE
)"
  RC=$?
  if [ "$RC" -ne 0 ]; then clear_target_state; printf '중단: host 등록 실패 rc=%s\n' "$RC" >&2; return "$RC"; fi
  IFS=$'\t' read -r ACTUAL_MACHINE_ID BOOT_ID REMOTE_HOSTNAME HOST_NETNS_INODE <<<"$RESULT"
  if [ -z "$BOOT_ID" ] || [ -z "$HOST_NETNS_INODE" ]; then clear_target_state; return 1; fi
  HOST_READY=true
  printf 'HOST_READY=true host=%s machine-id=%s boot-id=%s host-netns=%s incident=%s\n' "$REMOTE_HOSTNAME" "$ACTUAL_MACHINE_ID" "$BOOT_ID" "$HOST_NETNS_INODE" "$INCIDENT_ID"
}

host_call() {
  [ "${HOST_READY:-false}" = true ] || { printf '%s\n' '중단: HOST_READY가 아니다.' >&2; return 1; }
  local OP=$1
  shift
  ssh -o BatchMode=yes -o StrictHostKeyChecking=yes -o ConnectTimeout=10 -- "$SSH_TARGET" bash -s -- "$EXPECTED_MACHINE_ID" "$BOOT_ID" "$OP" "$@" <<'REMOTE'
set -uo pipefail
expected_machine=$1; expected_boot=$2; op=$3; shift 3
[ "$(< /etc/machine-id)" = "$expected_machine" ] || exit 21
[ "$(< /proc/sys/kernel/random/boot_id)" = "$expected_boot" ] || exit 22
validate_socket_input() {
  protocol=$1; port=$2
  [ "$protocol" = tcp ] || [ "$protocol" = udp ] || exit 30
  [[ "$port" =~ ^[0-9]+$ ]] && (( port >= 1 && port <= 65535 )) || exit 30
}
socket_snapshot() {
  protocol=$1; port=$2
  validate_socket_input "$protocol" "$port"
  if [ "$protocol" = tcp ]; then ss -H -ltnp "sport = :$port"; else ss -H -lunp "sport = :$port"; fi
}
socket_fingerprint() {
  protocol=$1; port=$2
  tmp=$(mktemp) || exit 40
  socket_snapshot "$protocol" "$port" >"$tmp" || { rm -f "$tmp"; exit 41; }
  if [ -s "$tmp" ]; then state=present; else state=absent; fi
  digest=$(sha256sum "$tmp") || { rm -f "$tmp"; exit 42; }
  rm -f "$tmp"
  printf '%s\t%s\n' "$state" "${digest%% *}"
}
process_start_ticks() {
  pid=$1
  stat=$(< "/proc/$pid/stat") || exit 50
  rest=${stat#*) }
  set -- $rest
  printf '%s\n' "${20}"
}
guard_process() {
  pid=$1; expected_start=$2; expected_netns=$3; expected_cgroup_hash=$4; argv_b64=$5
  [[ "$pid" =~ ^[1-9][0-9]*$ ]] || exit 50
  [ "$(process_start_ticks "$pid")" = "$expected_start" ] || exit 51
  [ "$(readlink "/proc/$pid/ns/net")" = "$expected_netns" ] || exit 52
  current_hash=$(sha256sum "/proc/$pid/cgroup") || exit 53
  [ "${current_hash%% *}" = "$expected_cgroup_hash" ] || exit 54
  regex_file=$(mktemp) || exit 55
  argv_file=$(mktemp) || { rm -f "$regex_file"; exit 55; }
  printf '%s' "$argv_b64" | base64 -d >"$regex_file"
  decode_status=("${PIPESTATUS[@]}")
  if [ "${decode_status[0]}" -ne 0 ] || [ "${decode_status[1]}" -ne 0 ]; then rm -f "$regex_file" "$argv_file"; exit 56; fi
  tr '\0' ' ' <"/proc/$pid/cmdline" >"$argv_file" || { rm -f "$regex_file" "$argv_file"; exit 57; }
  grep -E -q -f "$regex_file" "$argv_file"
  filter_rc=$?
  rm -f "$regex_file" "$argv_file"
  [ "$filter_rc" -eq 0 ] || exit 58
}
guard_socket() {
  protocol=$1; port=$2; expected_state=$3; expected_fingerprint=$4
  current=$(socket_fingerprint "$protocol" "$port") || return
  IFS=$'\t' read -r state fingerprint <<<"$current"
  [ "$state" = "$expected_state" ] && [ "$fingerprint" = "$expected_fingerprint" ] || exit 43
}
guard_socket_owner() {
  protocol=$1; port=$2; expected_state=$3; expected_fingerprint=$4; pid=$5
  guard_socket "$protocol" "$port" "$expected_state" "$expected_fingerprint"
  [ "$expected_state" = present ] || exit 44
  snapshot=$(socket_snapshot "$protocol" "$port") || exit 41
  case "$snapshot" in *"pid=$pid,"*) ;; *) exit 44 ;; esac
}
unit_data() {
  unit=$1
  [[ "$unit" =~ ^[A-Za-z0-9_.@-]+\.service$ ]] || exit 70
  active=$(systemctl show "$unit" --property=ActiveState --value --no-pager) || exit 71
  sub=$(systemctl show "$unit" --property=SubState --value --no-pager) || exit 71
  main_pid=$(systemctl show "$unit" --property=MainPID --value --no-pager) || exit 71
  start_mono=$(systemctl show "$unit" --property=ExecMainStartTimestampMonotonic --value --no-pager) || exit 71
  fingerprint_input=$(printf '%s\n%s\n%s\n%s\n%s\n' "$unit" "$active" "$sub" "$main_pid" "$start_mono") || exit 71
  digest=$(sha256sum <<<"$fingerprint_input") || exit 71
  printf '%s\t%s\t%s\t%s\t%s\n' "${digest%% *}" "$active" "$sub" "$main_pid" "$start_mono"
}
guard_unit() {
  current=$(unit_data "$1") || return
  IFS=$'\t' read -r fingerprint active sub main_pid start_mono <<<"$current"
  [ "$fingerprint" = "$2" ] || exit 72
}
case "$op" in
  socket-fingerprint) socket_fingerprint "$1" "$2" ;;
  socket-read)
    guard_socket "$1" "$2" "$3" "$4"
    socket_snapshot "$1" "$2"
    ;;
  process-identity)
    guard_socket_owner "$1" "$2" "$3" "$4" "$5"
    pid=$5; argv_b64=$6
    [[ "$pid" =~ ^[1-9][0-9]*$ ]] || exit 50
    start=$(process_start_ticks "$pid") || exit 50
    netns=$(readlink "/proc/$pid/ns/net") || exit 50
    cgroup=$(sha256sum "/proc/$pid/cgroup") || exit 50
    comm=$(< "/proc/$pid/comm") || exit 50
    guard_process "$pid" "$start" "$netns" "${cgroup%% *}" "$argv_b64" || exit
    printf '%s\t%s\t%s\t%s\n' "$start" "$netns" "${cgroup%% *}" "$comm"
    ;;
  process-read)
    guard_socket_owner "$1" "$2" "$3" "$4" "$5"
    guard_process "$5" "$6" "$7" "$8" "$9"
    ps -o pid=,ppid=,comm=,user=,etime=,lstart= -p "$5"
    ;;
  unit-register)
    guard_socket "$1" "$2" "$3" "$4"
    if [ "$5" != NONE ]; then
      guard_socket_owner "$1" "$2" "$3" "$4" "$5"
      guard_process "$5" "$6" "$7" "$8" "$9"
    elif [ "$3" != absent ]; then
      exit 74
    fi
    unit=${10}
    result=$(unit_data "$unit") || exit
    IFS=$'\t' read -r fingerprint active sub main_pid start_mono <<<"$result"
    if [ "$5" != NONE ] && [ "$main_pid" != "$5" ]; then exit 73; fi
    printf '%s\n' "$result"
    ;;
  journal)
    guard_socket "$1" "$2" "$3" "$4"
    if [ "$5" != NONE ]; then
      guard_socket_owner "$1" "$2" "$3" "$4" "$5"
      guard_process "$5" "$6" "$7" "$8" "$9"
    elif [ "$3" != absent ]; then
      exit 74
    fi
    unit=${10}; unit_fingerprint=${11}; start=${12}; end=${13}
    guard_unit "$unit" "$unit_fingerprint"
    set +e
    journalctl -u "$unit" --since "$start" --until "$end" --no-pager -n 300 | grep -E -i -C 3 -- 'LISTEN|bind|address already in use|EADDRINUSE|start|stop|exit|failed|timeout'
    status=("${PIPESTATUS[@]}")
    set -e
    [ "${status[0]}" -eq 0 ] || exit 60
    [ "${status[1]}" -eq 0 ] && exit 0
    [ "${status[1]}" -eq 1 ] && exit 61
    exit 62
    ;;
  tcp-connect)
    guard_socket "$1" "$2" "$3" "$4"
    guard_process "$5" "$6" "$7" "$8" "$9"
    address=${10}
    [[ "$address" =~ ^[0-9A-Fa-f:.]+$ ]] || exit 80
    timeout 5 bash -c 'exec 3<>/dev/tcp/"$1"/"$2"' _ "$address" "$2"
    ;;
  *) exit 64 ;;
esac
REMOTE
}

INCIDENT_ID='PASTE_INCIDENT_ID_HERE'
SSH_TARGET='PASTE_SSH_TARGET_HERE'
EXPECTED_MACHINE_ID='PASTE_EXPECTED_MACHINE_ID_HERE'
PROTOCOL='PASTE_TCP_OR_UDP_HERE'
PORT='PASTE_PORT_HERE'
clear_target_state
```

원격 인자는 whitelist를 통과한 값 또는 base64만 전달한다. `eval`, process environment 출력, raw argv 저장은 금지한다.

```bash
register_host
```

### 2. canonical UTC 증거 창

```bash
START_RFC3339='PASTE_START_RFC3339_HERE'
END_RFC3339='PASTE_END_RFC3339_HERE'
TIME_READY=false
unset START_EPOCH END_EPOCH
RFC3339_RE='^[0-9]{4}-(0[1-9]|1[0-2])-([0-2][0-9]|3[01])T([01][0-9]|2[0-3]):[0-5][0-9]:[0-5][0-9]Z$'
if [ "${HOST_READY:-false}" != true ]; then printf '%s\n' '중단: HOST_READY가 아니다.' >&2
elif ! [[ "$START_RFC3339" =~ $RFC3339_RE ]] || ! [[ "$END_RFC3339" =~ $RFC3339_RE ]]; then printf '%s\n' '중단: UTC RFC3339 형식 오류' >&2
elif [ "$(date -u -d "$START_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null)" != "$START_RFC3339" ] || [ "$(date -u -d "$END_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null)" != "$END_RFC3339" ]; then printf '%s\n' '중단: date round-trip 실패' >&2
else START_EPOCH=$(date -u -d "$START_RFC3339" +%s); END_EPOCH=$(date -u -d "$END_RFC3339" +%s); if (( START_EPOCH >= END_EPOCH || END_EPOCH - START_EPOCH > 86400 )); then unset START_EPOCH END_EPOCH; printf '%s\n' '중단: 순서 오류 또는 24시간 초과' >&2; else TIME_READY=true; printf 'TIME_READY=true seconds=%s\n' "$((END_EPOCH-START_EPOCH))"; fi; fi
```

### 3. socket state 등록

```bash
SOCKET_READY=false
PROCESS_READY=false
EVIDENCE_READY=false
unset SOCKET_STATE SOCKET_FINGERPRINT PID PID_START_TICKS PROCESS_NETNS_INODE CGROUP_HASH COMM
if [ "${HOST_READY:-false}" != true ] || { [ "$PROTOCOL" != tcp ] && [ "$PROTOCOL" != udp ]; } || ! [[ "$PORT" =~ ^[0-9]+$ ]] || (( PORT < 1 || PORT > 65535 )); then
  printf '%s\n' '중단: host/protocol/port 입력 오류' >&2
elif RESULT=$(host_call socket-fingerprint "$PROTOCOL" "$PORT"); then
  IFS=$'\t' read -r SOCKET_STATE SOCKET_FINGERPRINT <<<"$RESULT"
  if { [ "$SOCKET_STATE" = present ] || [ "$SOCKET_STATE" = absent ]; } && [[ "$SOCKET_FINGERPRINT" =~ ^[0-9a-f]{64}$ ]]; then
    SOCKET_READY=true
    printf 'SOCKET_READY=true protocol=%s port=%s state=%s fingerprint=%s\n' "$PROTOCOL" "$PORT" "$SOCKET_STATE" "$SOCKET_FINGERPRINT"
  else
    unset SOCKET_STATE SOCKET_FINGERPRINT
    printf '%s\n' '중단: socket 결과 불완전' >&2
  fi
else
  unset SOCKET_STATE SOCKET_FINGERPRINT
  printf '%s\n' '중단: ss producer 실패' >&2
fi
```

`absent`는 `ss` producer 성공 후 exact protocol/port 결과가 비었다는 명시적 관측이다. `정상`이 아니다. `present`도 올바른 bind address·owner·application을 보장하지 않는다.

```bash
if [ "${SOCKET_READY:-false}" != true ]; then printf '%s\n' '중단: SOCKET_READY가 아니다.' >&2
elif host_call socket-read "$PROTOCOL" "$PORT" "$SOCKET_STATE" "$SOCKET_FINGERPRINT"; then EVIDENCE_READY=true; printf '%s\n' 'EVIDENCE_READY=true'
else EVIDENCE_READY=false; printf '%s\n' '중단: socket replacement 또는 read 실패' >&2; fi
```

### 4. 현재 owner process 등록

`PID_INPUT`은 `ss`가 현재 표시한 owner PID다. listener가 없거나 권한 때문에 owner가 보이지 않으면 `NONE`을 입력하고 process 분기로 진행하지 않는다. regex는 승인된 executable/고정 인수만 최소 매칭하며 secret·token을 포함하지 않는다. socket activation 환경도 현재 listener process를 직접 소유한 `.service`를 등록하며 `.socket`만으로 process 관계를 추측하지 않는다.

```bash
PID_INPUT='PASTE_OWNER_PID_OR_NONE_HERE'
ARGV_REGEX='PASTE_NON_SECRET_ARGV_REGEX_HERE'
PROCESS_READY=false
unset PID PID_START_TICKS PROCESS_NETNS_INODE CGROUP_HASH COMM ARGV_REGEX_B64
if [ "${SOCKET_READY:-false}" != true ]; then
  printf '%s\n' '중단: SOCKET_READY가 아니다.' >&2
elif [ "$PID_INPUT" = NONE ]; then
  printf '%s\n' 'PROCESS_READY=false: 현재 owner PID 미등록'
elif ! [[ "$PID_INPUT" =~ ^[1-9][0-9]*$ ]] || [ -z "$ARGV_REGEX" ]; then
  printf '%s\n' '중단: PID 또는 non-secret argv regex 오류' >&2
else
  TMP=$(mktemp)
  printf '%s' "$ARGV_REGEX" >"$TMP"
  ARGV_REGEX_B64=$(base64 -w0 "$TMP")
  ENCODE_RC=$?
  rm -f "$TMP"
  if [ "$ENCODE_RC" -ne 0 ] || ! [[ "$ARGV_REGEX_B64" =~ ^[A-Za-z0-9+/=]+$ ]]; then
    unset ARGV_REGEX_B64
    printf '%s\n' '중단: regex encoding 실패' >&2
  elif RESULT=$(host_call process-identity "$PROTOCOL" "$PORT" "$SOCKET_STATE" "$SOCKET_FINGERPRINT" "$PID_INPUT" "$ARGV_REGEX_B64"); then
    IFS=$'\t' read -r PID_START_TICKS PROCESS_NETNS_INODE CGROUP_HASH COMM <<<"$RESULT"
    PID=$PID_INPUT
    if [ -n "$PID_START_TICKS" ] && [[ "$CGROUP_HASH" =~ ^[0-9a-f]{64}$ ]]; then PROCESS_READY=true; printf 'PROCESS_READY=true pid=%s start-ticks=%s netns=%s cgroup-hash=%s comm=%s\n' "$PID" "$PID_START_TICKS" "$PROCESS_NETNS_INODE" "$CGROUP_HASH" "$COMM"; else unset PID PID_START_TICKS PROCESS_NETNS_INODE CGROUP_HASH COMM; fi
  else
    unset PID PID_START_TICKS PROCESS_NETNS_INODE CGROUP_HASH COMM
    printf '%s\n' '중단: PID 종료·재사용, argv 불일치 또는 process read 실패' >&2
  fi
fi
```

## 진입 판단과 분기

| 관측 | 직접 gate | 다음 행동 |
|---|---|---|
| `SOCKET_STATE=absent` | ss producer 성공·protocol·port | unit journal과 실제 process lifecycle. PID를 추측하지 않는다. |
| `present`, PID 없음 | 권한·netns·socket type | 권한 owner 또는 확인된 netns로 이관 |
| `present`, process 등록 성공 | PID start·netns·cgroup hash·argv match | bind address, unit MainPID, application 확인 |
| `EADDRINUSE`, 현재 absent | 오류 창의 unit journal | transient overlap·이미 종료된 owner 후보 |
| socket fingerprint 변경 | 같은 boot에서 socket replacement | 모든 process/unit READY 폐기 후 재등록 |

검색 문자열: `LISTEN`, `UNCONN`, `address already in use`, `EADDRINUSE`, `bind`, `MainPID`, `exited`.

## process·unit·journal 증거

```bash
if [ "${PROCESS_READY:-false}" != true ]; then
  printf '%s\n' '중단: current PID identity가 없다.' >&2
elif ! host_call process-read "$PROTOCOL" "$PORT" "$SOCKET_STATE" "$SOCKET_FINGERPRINT" "$PID" "$PID_START_TICKS" "$PROCESS_NETNS_INODE" "$CGROUP_HASH" "$ARGV_REGEX_B64"; then
  PROCESS_READY=false
  printf '%s\n' '중단: socket/PID lifecycle 변경 또는 process producer 실패' >&2
fi
```

출력은 PID·PPID·comm·user·elapsed·start만 포함한다. argv, environment와 cgroup 원문은 출력·저장하지 않는다.

```bash
SERVICE_UNIT='PASTE_CONFIRMED_SERVICE_UNIT_HERE'
UNIT_READY=false
unset UNIT_FINGERPRINT UNIT_ACTIVE UNIT_SUB UNIT_MAIN_PID UNIT_START_MONO
if [ "${SOCKET_READY:-false}" != true ]; then
  printf '%s\n' '중단: SOCKET_READY가 아니다.' >&2
elif [ "$PID_INPUT" != NONE ] && [ "${PROCESS_READY:-false}" != true ]; then
  printf '%s\n' '중단: PID를 선택한 경로는 PROCESS_READY가 필요하다.' >&2
elif [ "$PID_INPUT" = NONE ] && [ "$SOCKET_STATE" != absent ]; then
  printf '%s\n' '중단: socket이 present인데 owner PID가 없으면 unit을 임의 연결하지 않고 권한 owner에게 이관한다.' >&2
elif ! [[ "$SERVICE_UNIT" =~ ^[A-Za-z0-9_.@-]+\.service$ ]]; then
  printf '%s\n' '중단: 확인된 unit 이름 형식 오류' >&2
else
  UNIT_PID=${PID:-NONE}; UNIT_START=${PID_START_TICKS:--}; UNIT_NETNS=${PROCESS_NETNS_INODE:--}; UNIT_CGROUP=${CGROUP_HASH:--}; UNIT_ARGV=${ARGV_REGEX_B64:--}
  if RESULT=$(host_call unit-register "$PROTOCOL" "$PORT" "$SOCKET_STATE" "$SOCKET_FINGERPRINT" "$UNIT_PID" "$UNIT_START" "$UNIT_NETNS" "$UNIT_CGROUP" "$UNIT_ARGV" "$SERVICE_UNIT"); then
    IFS=$'\t' read -r UNIT_FINGERPRINT UNIT_ACTIVE UNIT_SUB UNIT_MAIN_PID UNIT_START_MONO <<<"$RESULT"
    if [[ "$UNIT_FINGERPRINT" =~ ^[0-9a-f]{64}$ ]] && [[ "$UNIT_MAIN_PID" =~ ^[0-9]+$ ]]; then
      UNIT_READY=true
      printf 'UNIT_READY=true unit=%s active=%s sub=%s main-pid=%s start-mono=%s fingerprint=%s\n' "$SERVICE_UNIT" "$UNIT_ACTIVE" "$UNIT_SUB" "$UNIT_MAIN_PID" "$UNIT_START_MONO" "$UNIT_FINGERPRINT"
    else
      unset UNIT_FINGERPRINT UNIT_ACTIVE UNIT_SUB UNIT_MAIN_PID UNIT_START_MONO
      printf '%s\n' '중단: unit identity 결과 불완전' >&2
    fi
  else
    printf '%s\n' '중단: unit 또는 socket/process identity 불일치' >&2
  fi
  unset UNIT_PID UNIT_START UNIT_NETNS UNIT_CGROUP UNIT_ARGV
fi
```

`PID_INPUT=NONE`이면 현재 socket 부재·owner 미표시 상태와 unit lifecycle을 독립적으로 등록한다. PID가 있으면 socket owner와 unit MainPID가 모두 같은 current PID여야 한다. socket activation이면 `.socket`과 실제 process를 소유한 `.service` lifecycle을 별도로 기록한다.

```bash
if [ "${UNIT_READY:-false}" != true ] || [ "${TIME_READY:-false}" != true ]; then
  printf '%s\n' '중단: UNIT_READY와 TIME_READY가 필요하다.' >&2
else
  UNIT_PID=${PID:-NONE}; UNIT_START=${PID_START_TICKS:--}; UNIT_NETNS=${PROCESS_NETNS_INODE:--}; UNIT_CGROUP=${CGROUP_HASH:--}; UNIT_ARGV=${ARGV_REGEX_B64:--}
  host_call journal "$PROTOCOL" "$PORT" "$SOCKET_STATE" "$SOCKET_FINGERPRINT" "$UNIT_PID" "$UNIT_START" "$UNIT_NETNS" "$UNIT_CGROUP" "$UNIT_ARGV" "$SERVICE_UNIT" "$UNIT_FINGERPRINT" "$START_RFC3339" "$END_RFC3339"
  RC=$?
  unset UNIT_PID UNIT_START UNIT_NETNS UNIT_CGROUP UNIT_ARGV
  case "$RC" in
    0) printf '%s\n' 'journal producer/filter 성공' ;;
    60) printf '%s\n' '중단: journal producer 실패' >&2 ;;
    61) printf '%s\n' 'filter 일치 없음: 오류 부재가 아니라 이 창에 일치 행 없음' >&2 ;;
    62) printf '%s\n' '중단: journal filter 실패' >&2 ;;
    *) printf '중단: socket/unit guard 실패 rc=%s\n' "$RC" >&2 ;;
  esac
fi
```

## 실제 connectivity 확인

TCP이고 현재 process identity·socket이 유지되며, 해당 bind address로 한 번의 connect가 승인된 경우에만 사용한다. UDP와 application request에는 이 명령을 사용하지 않는다.

```bash
CONNECT_ADDRESS='PASTE_APPROVED_CONNECT_ADDRESS_HERE'
NETWORK_READY=false
if [ "$PROTOCOL" != tcp ] || [ "${PROCESS_READY:-false}" != true ] || ! [[ "$CONNECT_ADDRESS" =~ ^[0-9A-Fa-f:.]+$ ]]; then
  printf '%s\n' '중단: TCP/process/승인 address gate가 필요하다.' >&2
elif host_call tcp-connect "$PROTOCOL" "$PORT" "$SOCKET_STATE" "$SOCKET_FINGERPRINT" "$PID" "$PID_START_TICKS" "$PROCESS_NETNS_INODE" "$CGROUP_HASH" "$ARGV_REGEX_B64" "$CONNECT_ADDRESS"; then
  NETWORK_READY=true
  printf '%s\n' 'NETWORK_READY=true'
else
  printf '%s\n' 'TCP connect 실패: listener 표시와 실제 connect 결과를 분리한다.' >&2
fi
```

TCP connect 성공은 TLS·HTTP·gRPC·업무 기능을 보장하지 않는다. 실제 protocol의 read-only health 또는 제품 요청을 같은 endpoint에서 별도 승인해 확인한다.

## 변경 전 안전 gate

generic kill, port 강제 해제, service restart는 안전한 공통 rollback이 없어 명령을 제공하지 않는다. 별도 변경은 fresh host/socket/process/unit identity, 오류 창의 직접 증거, approval ID·window, 대체 replica/PDB/quorum·connection drain 가용성, 이미 desired 상태일 때 no-op인 멱등 조건, unit/config rollback, 중단 조건을 가져야 한다. PID나 socket이 교체되면 이전 PID start/netns/cgroup/argv와 모든 `READY`를 폐기하고 replacement state를 다시 등록한다.

금지: 확인되지 않은 PID `kill`, broad `pkill`, socket/runtime 파일 삭제, port 변경, 무근거 restart, Kubernetes Pod 삭제. 민감한 argv/environment를 증거에 남기지 않는다.

## 정상화 검증

```bash
clear_target_state
register_host
printf '%s\n' '다음: 새 UTC 창에서 protocol/port socket, 새 PID start/netns/cgroup/argv, unit을 다시 등록하고 connectivity와 실제 application 증상을 확인한다.'
```

정상화는 의도한 protocol·bind address·netns에서 올바른 PID lifecycle과 unit MainPID가 안정되고, 새 창에 EADDRINUSE·bind 실패·반복 종료가 없으며, TCP/UDP 실제 packet 경로와 application 기능이 회복된 상태다. rollback 후에도 replacement identity를 새로 등록한다. `ss` 한 행, process 생존, TCP connect 한 번, Pod Running만으로 닫지 않는다.

## 증거·완료

보존: 사건 ID, machine/boot/netns, protocol·port·bind address, socket state/fingerprint, PID/start ticks/comm/netns/cgroup hash/argv match 결과, unit/MainPID/start monotonic, canonical 창, producer/filter 상태, connectivity·application 결과, 승인·rollback.

저장 금지: raw argv, environment, cgroup 원문, 전체 socket/process/journal, credential·token·개인정보. 결론은 `listener absent`, `wrong protocol/address/netns`, `EADDRINUSE lifecycle`, `wrong owner`, `application layer`, `증거 부족` 중 하나다.
