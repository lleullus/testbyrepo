# route·default gateway가 기대 경로와 다른 경우

## 입력값과 빠른 수집

실행 경로는 `승인된 작업 PC/Bash → 검증된 SSH host key → machine-id·boot-id → host network namespace → ifindex → source·destination·rule priority·table → kernel route lookup`이다. host namespace의 default route를 Pod·VRF·다른 netns의 경로로 재사용하지 않는다.

| 구분 | 값 | 출처와 유효성 |
|---|---|---|
| 최초 입력 | `INCIDENT_ID`, `SSH_TARGET`, `EXPECTED_MACHINE_ID`, `SOURCE_IP`, `DESTINATION_IP` | 실제 실패 flow와 승인된 inventory에서 가져온다. DNS 결과·Node InternalIP를 추측해 넣지 않는다. |
| 시스템 확인 자동값 | `BOOT_ID`, `HOST_NETNS_INODE`, `IFINDEX` | 원격 호출마다 machine-id와 함께 재검증한다. |
| API 확인 자동값 | 없음 | Kubernetes/CRI endpoint는 Node UID·machine identity와 Pod UID·nodeName 관계가 별도 확정된 뒤에만 다른 런북에서 조회한다. |
| 계산 후보값 | `ROUTE_FINGERPRINT`, `START_EPOCH`, `END_EPOCH` | 같은 rule/table/lookup snapshot의 SHA-256과 canonical UTC 창이다. route가 바뀌면 stale로 중단한다. |
| 운영자 선택값 | `IFACE`, `TABLE_ID`, `RULE_PRIORITY` | 현재 `ip` 출력과 승인된 설계에서 선택한다. 이름·번호를 관례로 만들지 않는다. |

각 입력칸은 한 번만 입력한다. address family는 `SOURCE_IP`와 `DESTINATION_IP`가 같은 family인지 등록 단계에서 확인한다.

### 1. 실행 계약과 host 등록

```bash
TOOLS_READY=false
MISSING_TOOLS=''
for TOOL in ssh date; do
  command -v "$TOOL" >/dev/null 2>&1 || MISSING_TOOLS="$MISSING_TOOLS $TOOL"
done
if [ -n "${BASH_VERSION:-}" ] && [ -z "$MISSING_TOOLS" ]; then TOOLS_READY=true; else printf '중단: Bash 또는 도구 누락:%s\n' "$MISSING_TOOLS" >&2; fi

clear_target_state() {
  unset ACTUAL_MACHINE_ID BOOT_ID REMOTE_HOSTNAME HOST_NETNS_INODE PID PID_START_TICKS MOUNT_ID DEVICE_ID DEVICE_IFINDEX NETNS_INODE IFACE IFINDEX ROUTE_FINGERPRINT RULE_FINGERPRINT START_RFC3339 END_RFC3339 START_EPOCH END_EPOCH ARGV_REGEX TABLE_ID RULE_PRIORITY
  HOST_READY=false
  TIME_READY=false
  INTERFACE_READY=false
  ROUTE_READY=false
  EVIDENCE_READY=false
  NETWORK_READY=false
  MUTATION_READY=false
  ROLLBACK_READY=false
  NORMALIZATION_READY=false
}

register_host() {
  clear_target_state
  if [ "$TOOLS_READY" != true ] || ! [[ "$SSH_TARGET" =~ ^([A-Za-z0-9._-]+@)?[A-Za-z0-9._-]+$ ]] || ! [[ "$EXPECTED_MACHINE_ID" =~ ^[0-9a-f]{32}$ ]]; then
    printf '%s\n' '중단: 도구 또는 host 초기 입력이 유효하지 않다.' >&2
    return 1
  fi
  local RESULT RC
  RESULT="$(ssh -o BatchMode=yes -o StrictHostKeyChecking=yes -o ConnectTimeout=10 -- "$SSH_TARGET" bash -s -- "$EXPECTED_MACHINE_ID" <<'REMOTE'
set -uo pipefail
expected=$1
actual=$(< /etc/machine-id) || exit 20
boot=$(< /proc/sys/kernel/random/boot_id) || exit 20
netns=$(readlink /proc/1/ns/net) || exit 20
name=$(hostname) || exit 20
[ "$actual" = "$expected" ] || exit 21
printf '%s\t%s\t%s\t%s\n' "$actual" "$boot" "$name" "$netns"
REMOTE
)"
  RC=$?
  if [ "$RC" -ne 0 ]; then clear_target_state; printf '중단: host 등록 실패 rc=%s\n' "$RC" >&2; return "$RC"; fi
  IFS=$'\t' read -r ACTUAL_MACHINE_ID BOOT_ID REMOTE_HOSTNAME HOST_NETNS_INODE <<<"$RESULT"
  if [ -z "$BOOT_ID" ] || [ -z "$HOST_NETNS_INODE" ]; then clear_target_state; return 1; fi
  HOST_READY=true
  printf 'HOST_READY=true host=%s machine-id=%s boot-id=%s netns=%s incident=%s\n' "$REMOTE_HOSTNAME" "$ACTUAL_MACHINE_ID" "$BOOT_ID" "$HOST_NETNS_INODE" "$INCIDENT_ID"
}

host_call() {
  [ "${HOST_READY:-false}" = true ] || { printf '%s\n' '중단: HOST_READY가 아니다.' >&2; return 1; }
  local OP=$1
  shift
  ssh -o BatchMode=yes -o StrictHostKeyChecking=yes -o ConnectTimeout=10 -- "$SSH_TARGET" bash -s -- "$EXPECTED_MACHINE_ID" "$BOOT_ID" "$OP" "$@" <<'REMOTE'
set -uo pipefail
expected_machine=$1
expected_boot=$2
op=$3
shift 3
[ "$(< /etc/machine-id)" = "$expected_machine" ] || exit 21
[ "$(< /proc/sys/kernel/random/boot_id)" = "$expected_boot" ] || exit 22
guard_interface() {
  iface=$1; expected_ifindex=$2; expected_netns=$3
  [[ "$iface" =~ ^[A-Za-z0-9_.:@-]{1,64}$ ]] || exit 30
  [ "$(< "/sys/class/net/$iface/ifindex")" = "$expected_ifindex" ] || exit 31
  [ "$(readlink /proc/1/ns/net)" = "$expected_netns" ] || exit 32
}
family_flag() {
  if [[ "$1" == *.* && "$1" != *:* && "$2" == *.* && "$2" != *:* ]]; then
    printf '%s' '-4'
  elif [[ "$1" == *:* && "$2" == *:* && "$1" != *.* && "$2" != *.* ]]; then
    printf '%s' '-6'
  else
    exit 35
  fi
}
route_fingerprint() {
  iface=$1; ifindex=$2; netns=$3; source=$4; destination=$5; table=$6; priority=$7
  guard_interface "$iface" "$ifindex" "$netns"
  [[ "$source" =~ ^[0-9A-Fa-f:.]+$ ]] || exit 36
  [[ "$destination" =~ ^[0-9A-Fa-f:.]+$ ]] || exit 36
  [[ "$table" =~ ^[A-Za-z0-9_.-]+$ ]] || exit 36
  [[ "$priority" =~ ^[0-9]+$ ]] || exit 36
  family=$(family_flag "$source" "$destination") || exit 35
  tmp=$(mktemp) || exit 40
  ip "$family" -j rule show pref "$priority" >"$tmp" || { rm -f "$tmp"; exit 41; }
  ip "$family" -j route get "$destination" from "$source" >>"$tmp" || { rm -f "$tmp"; exit 43; }
  digest=$(sha256sum "$tmp") || { rm -f "$tmp"; exit 44; }
  rm -f "$tmp"
  printf '%s\n' "${digest%% *}"
}
guard_route() {
  expected_fingerprint=$8
  current=$(route_fingerprint "$1" "$2" "$3" "$4" "$5" "$6" "$7") || return
  [ "$current" = "$expected_fingerprint" ] || exit 45
}
case "$op" in
  interface-identity)
    iface=$1
    [[ "$iface" =~ ^[A-Za-z0-9_.:@-]{1,64}$ ]] || exit 30
    printf '%s\t%s\n' "$(< "/sys/class/net/$iface/ifindex")" "$(readlink /proc/1/ns/net)"
    ;;
  fingerprint)
    route_fingerprint "$@"
    ;;
  snapshot)
    guard_route "$@"
    iface=$1; source=$4; destination=$5; table=$6; priority=$7
    family=$(family_flag "$source" "$destination") || exit 35
    printf '%s\n' '=== rule ==='
    ip "$family" -j rule show pref "$priority" || exit 41
    printf '%s\n' '=== lookup ==='
    ip "$family" -j route get "$destination" from "$source" || exit 43
    ;;
  journal)
    guard_route "${@:1:8}"
    start=$9; end=${10}
    set +e
    journalctl -k --since "$start" --until "$end" --no-pager -n 300 | grep -E -i -C 3 -- 'no route|unreachable|prohibit|blackhole|throw|martian|redirect|RTNETLINK|network is unreachable'
    status=("${PIPESTATUS[@]}")
    set -e
    [ "${status[0]}" -eq 0 ] || exit 60
    [ "${status[1]}" -eq 0 ] && exit 0
    [ "${status[1]}" -eq 1 ] && exit 61
    exit 62
    ;;
  ping)
    guard_route "${@:1:8}"
    source=$4; destination=$5
    exec ping -n -I "$source" -c 3 -W 2 -- "$destination"
    ;;
  *) exit 64 ;;
esac
REMOTE
}

INCIDENT_ID='PASTE_INCIDENT_ID_HERE'
SSH_TARGET='PASTE_SSH_TARGET_HERE'
EXPECTED_MACHINE_ID='PASTE_EXPECTED_MACHINE_ID_HERE'
SOURCE_IP='PASTE_ACTUAL_SOURCE_IP_HERE'
DESTINATION_IP='PASTE_ACTUAL_DESTINATION_IP_HERE'
clear_target_state
```

SSH target와 원격 positional argument는 허용 문자로 검증한다. space, shell metacharacter, option 형태의 입력은 전달하지 않으며 `eval`은 사용하지 않는다.

```bash
register_host
```

### 2. UTC 증거 창

```bash
START_RFC3339='PASTE_START_RFC3339_HERE'
END_RFC3339='PASTE_END_RFC3339_HERE'
TIME_READY=false
unset START_EPOCH END_EPOCH
RFC3339_RE='^[0-9]{4}-(0[1-9]|1[0-2])-([0-2][0-9]|3[01])T([01][0-9]|2[0-3]):[0-5][0-9]:[0-5][0-9]Z$'
if [ "${HOST_READY:-false}" != true ]; then
  printf '%s\n' '중단: HOST_READY가 아니다.' >&2
elif ! [[ "$START_RFC3339" =~ $RFC3339_RE ]] || ! [[ "$END_RFC3339" =~ $RFC3339_RE ]]; then
  printf '%s\n' '중단: canonical UTC RFC3339 형식이 아니다.' >&2
elif [ "$(date -u -d "$START_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null)" != "$START_RFC3339" ] || [ "$(date -u -d "$END_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null)" != "$END_RFC3339" ]; then
  printf '%s\n' '중단: date round-trip 실패' >&2
else
  START_EPOCH=$(date -u -d "$START_RFC3339" +%s)
  END_EPOCH=$(date -u -d "$END_RFC3339" +%s)
  if (( START_EPOCH >= END_EPOCH || END_EPOCH - START_EPOCH > 86400 )); then unset START_EPOCH END_EPOCH; printf '%s\n' '중단: 순서 오류 또는 24시간 초과' >&2; else TIME_READY=true; printf 'TIME_READY=true seconds=%s\n' "$((END_EPOCH-START_EPOCH))"; fi
fi
```

### 3. interface·route·rule identity 등록

```bash
IFACE='PASTE_INTERFACE_HERE'
TABLE_ID='PASTE_ROUTE_TABLE_HERE'
RULE_PRIORITY='PASTE_RULE_PRIORITY_HERE'
INTERFACE_READY=false
ROUTE_READY=false
EVIDENCE_READY=false
unset IFINDEX NETNS_INODE ROUTE_FINGERPRINT RULE_FINGERPRINT
if [ "${HOST_READY:-false}" != true ]; then
  printf '%s\n' '중단: HOST_READY가 아니다.' >&2
elif ! [[ "$SOURCE_IP" =~ ^[0-9A-Fa-f:.]+$ ]] || ! [[ "$DESTINATION_IP" =~ ^[0-9A-Fa-f:.]+$ ]] || ! [[ "$TABLE_ID" =~ ^[A-Za-z0-9_.-]+$ ]] || ! [[ "$RULE_PRIORITY" =~ ^[0-9]+$ ]]; then
  printf '%s\n' '중단: route 입력 형식 오류' >&2
elif RESULT=$(host_call interface-identity "$IFACE"); then
  IFS=$'\t' read -r IFINDEX NETNS_INODE <<<"$RESULT"
  if [ -n "$IFINDEX" ] && [ "$NETNS_INODE" = "$HOST_NETNS_INODE" ]; then
    INTERFACE_READY=true
    if ROUTE_FINGERPRINT=$(host_call fingerprint "$IFACE" "$IFINDEX" "$NETNS_INODE" "$SOURCE_IP" "$DESTINATION_IP" "$TABLE_ID" "$RULE_PRIORITY") && [[ "$ROUTE_FINGERPRINT" =~ ^[0-9a-f]{64}$ ]]; then
      RULE_FINGERPRINT="$RULE_PRIORITY:$TABLE_ID"
      ROUTE_READY=true
      printf 'ROUTE_READY=true interface=%s ifindex=%s netns=%s rule=%s table=%s fingerprint=%s\n' "$IFACE" "$IFINDEX" "$NETNS_INODE" "$RULE_PRIORITY" "$TABLE_ID" "$ROUTE_FINGERPRINT"
    else
      unset ROUTE_FINGERPRINT RULE_FINGERPRINT
      printf '%s\n' '중단: route/rule snapshot 등록 실패 또는 빈 결과' >&2
    fi
  fi
else
  unset IFINDEX NETNS_INODE ROUTE_FINGERPRINT RULE_FINGERPRINT
  printf '%s\n' '중단: interface 등록 실패' >&2
fi
```

등록 성공은 route가 올바르다는 뜻이 아니다. 현재 rule·table·lookup 세 결과가 하나의 lifecycle fingerprint로 고정됐다는 뜻이다.

## 진입 판단

| 구분 | 판단 기준 |
|---|---|
| 사용 | 실제 source·destination flow의 선택 route가 승인 설계와 다르거나 `unreachable`·`blackhole`·잘못된 `via/dev/src/table`이 보이는 경우 |
| 적용 | machine·boot·host netns·ifindex·family·source·destination·rule·table이 모두 고정된 경우 |
| 제외 | Pod netns, VRF, fwmark, ingress interface 등 실제 packet 조건이 이 등록과 다른 경우. 해당 namespace/owner 경로로 이동한다. |

검색 문자열: `default via`, `ip route get`, `ip rule`, `lookup`, `unreachable`, `blackhole`, `throw`, `No route to host`.

## 관측별 진단 경로

| 관측 | 직접 확인 | 의미와 다음 행동 |
|---|---|---|
| rule 결과가 비어 있음 | producer 성공과 exact priority | priority 선택 오류 또는 rule 부재. 정상 default로 간주하지 않는다. |
| table은 있으나 lookup 실패 | destination prefix·route type·source | policy selection 또는 source/address owner |
| lookup의 `dev/src/via`가 설계와 다름 | same family/source/destination fingerprint | route owner에게 exact tuple 이관 |
| snapshot 중 fingerprint 변경 | boot는 같고 route만 변화 | route churn; 모든 하위 READY 폐기 후 재등록 |
| route는 맞고 packet 실패 | 승인된 실제 packet·application check | firewall·MTU·remote listener로 이동 |

## 읽기 전용 route 증거

모든 원격 read/journal/network 호출은 machine-id·boot-id·netns·ifindex와 **현재 route fingerprint를 직접 다시 확인**한다.

```bash
if [ "${ROUTE_READY:-false}" != true ]; then
  printf '%s\n' '중단: ROUTE_READY가 아니다.' >&2
elif host_call snapshot "$IFACE" "$IFINDEX" "$NETNS_INODE" "$SOURCE_IP" "$DESTINATION_IP" "$TABLE_ID" "$RULE_PRIORITY" "$ROUTE_FINGERPRINT"; then
  EVIDENCE_READY=true
  printf '%s\n' 'EVIDENCE_READY=true'
else
  EVIDENCE_READY=false
  printf '%s\n' '중단: identity 변경, route churn 또는 producer 실패. 빈 정상으로 기록하지 않는다.' >&2
fi
```

출력에서 rule priority·selector·lookup table과 lookup의 실제 route type·metric·`dev/src/via`를 본다. 전체 route table·rule 목록, tenant 주소와 mark는 조회·저장하지 않는다.

```bash
if [ "${EVIDENCE_READY:-false}" != true ] || [ "${TIME_READY:-false}" != true ]; then
  printf '%s\n' '중단: EVIDENCE_READY와 TIME_READY가 필요하다.' >&2
else
  host_call journal "$IFACE" "$IFINDEX" "$NETNS_INODE" "$SOURCE_IP" "$DESTINATION_IP" "$TABLE_ID" "$RULE_PRIORITY" "$ROUTE_FINGERPRINT" "$START_RFC3339" "$END_RFC3339"
  RC=$?
  case "$RC" in
    0) printf '%s\n' 'journal producer/filter 성공' ;;
    60) printf '%s\n' '중단: journal producer 실패' >&2 ;;
    61) printf '%s\n' 'filter 일치 없음: 오류 없음이 아니라 이 창에 일치 행 없음' >&2 ;;
    62) printf '%s\n' '중단: filter 실행 실패' >&2 ;;
    *) printf '중단: identity/route guard 실패 rc=%s\n' "$RC" >&2 ;;
  esac
fi
```

## 제한된 실제 packet 확인

실제 destination owner가 ICMP 3회를 승인하고 ICMP가 원래 증상의 유효한 보조 경로일 때만 실행한다. 성공은 TCP/TLS/업무 기능을 보장하지 않는다.

```bash
NETWORK_READY=false
if [ "${EVIDENCE_READY:-false}" != true ]; then
  printf '%s\n' '중단: EVIDENCE_READY가 아니다.' >&2
elif host_call ping "$IFACE" "$IFINDEX" "$NETNS_INODE" "$SOURCE_IP" "$DESTINATION_IP" "$TABLE_ID" "$RULE_PRIORITY" "$ROUTE_FINGERPRINT"; then
  NETWORK_READY=true
  printf '%s\n' 'NETWORK_READY=true'
else
  printf '%s\n' 'packet check 실패: route lookup 성공과 packet 도달 실패를 분리한다.' >&2
fi
```

원래 증상은 같은 source namespace·protocol·destination endpoint에서 승인된 실제 요청으로 확인한다. 임의 endpoint, health-changing request, credential 포함 URL을 사용하지 않는다.

## Kubernetes·CRI·namespace 경계

Kubernetes Node의 `InternalIP`는 이 flow의 source나 gateway가 아니다. Kubernetes/CRI 명령은 Node UID·provider ID·machine inventory가 현재 machine-id에 연결되고 Pod UID·`spec.nodeName`·container ID·runtime endpoint가 같은 lifecycle로 확인된 경우에만 해당 전문 런북에서 실행한다. netns 또는 VRF가 다르면 이 host fingerprint를 폐기하고 그 namespace에서 독립 등록한다.

## 변경 전 안전 gate

route/rule/default gateway 변경은 network manager와 지속 설정을 모르면 공통 rollback이 성립하지 않으므로 이 문서에 mutation 명령을 두지 않는다. 별도 절차는 fresh host·interface·route fingerprint, 같은 창의 직접 증거, 승인 ID·변경 창, 대체 경로와 가용성, 원하는 상태일 때 no-op인 멱등 조건, persistent source, 검증된 rollback, 중단 조건을 모두 가져야 한다. route/rule 교체·host 재부팅·netns/interface 재생성 후에는 기존 fingerprint와 모든 `READY`를 폐기하고 replacement state를 처음부터 등록한다.

금지: `ip route flush`, broad rule delete, 추측한 default route add, manager restart, interface reset, Node/Pod 재시작. metric이나 한 번의 lookup만으로 승인하지 않는다.

## 정상화 검증

```bash
clear_target_state
register_host
printf '%s\n' '다음: 새 UTC 창, interface, table, rule priority를 다시 등록하고 snapshot·journal·packet·실제 업무 요청을 반복한다.'
```

정상화 조건:

- 새 lifecycle에서 same family·source·destination·rule·table lookup이 승인 설계의 type·via·dev·src와 맞고 관찰 창 동안 churn이 없다.
- packet 확인과 원래 protocol의 실제 connectivity·업무 증상이 모두 회복된다.
- firewall·conntrack·MTU·remote listener가 원인이면 해당 런북의 identity와 정상화 증거를 별도로 갖는다.
- 변경을 되돌렸다면 rollback 후에도 새 fingerprint를 등록하고 실제 packet·업무 증상을 재검증한다.
- 빈 rule/table 결과, ping 한 번, Node Ready만으로 정상화하지 않는다.

## 증거·완료

보존: 사건 ID, machine-id·boot-id, host netns·ifindex, family·source/destination 출처, exact rule priority·table, route fingerprint, 필요한 route 행, canonical UTC 창, producer/filter status, packet·실제 기능 결과, 승인·rollback·이관 결과.

저장 금지: 전체 route/rule 목록, tenant 주소·mark·credential·token·개인정보. 완료 결론은 `rule selection`, `table route`, `source selection`, `namespace/VRF 경계`, `route 외 계층`, `증거 부족` 중 하나로 쓴다.
