# filesystem corruption 오류가 관측된 경우

## 입력값과 빠른 수집

실행 hop은 `승인된 작업 PC/bastion → Kubernetes Node UID·machineID → SSH host hostname·machine-id → bounded kernel evidence → block device identity → filesystem·mount ID → consumer process namespace → application`이다. filesystem 종류를 오류 문구로 추측하지 않으며 CRI socket이나 Prometheus metric을 corruption 직접 증거로 사용하지 않는다.

| 구분 | 값 | 출처와 gate |
|---|---|---|
| 최초 입력 | context·Node·SSH host, observed literal, UTC evidence window | incident 원문과 승인된 접근 기록 |
| API 확인 자동값 | Node UID·API machineID | 현재 API와 remote machine-id exact match |
| 계산 후보값 | escaped Node regex, KNAME·major:minor·mount ID | 실제 device/mount 출력에서 계산 |
| 운영자 선택값 | device source, mount target, consumer PID·unit·argv regex | bounded evidence와 owner inventory 뒤 선택 |

### 1. 전체 초기화·입력

`TOOLS_READY=false; MISSING=''; for T in kubectl jq ssh date grep sed; do command -v "$T" >/dev/null 2>&1 || MISSING="$MISSING $T"; done; if [ -n "${BASH_VERSION:-}" ] && [ -z "$MISSING" ]; then TOOLS_READY=true; else printf '중단: Bash 또는 도구가 없음:%s\n' "$MISSING" >&2; fi`

`invalidate_all(){ unset HOST_READY TIME_READY EVIDENCE_READY DEVICE_READY MOUNT_READY PROCESS_READY CONTAIN_READY CHANGE_READY RECOVERY_READY NODE_UID API_MACHINE_ID REMOTE_HOSTNAME REMOTE_MACHINE_ID NODE_RE START_CANONICAL END_CANONICAL START_EPOCH END_EPOCH DEVICE_SOURCE KNAME MAJOR_MINOR DEVICE_SYSFS DEVICE_SIZE MOUNT_TARGET MOUNT_ID MOUNT_SOURCE MOUNT_FSTYPE MOUNT_OPTIONS PID PID_START CGROUP_NS NET_NS MNT_NS ARGV_RE CONSUMER_UNIT OBSERVED_LITERAL PRODUCER_RC FILTER_RC EVIDENCE_AT CHANGE_APPLIED; HOST_READY=false; TIME_READY=false; EVIDENCE_READY=false; DEVICE_READY=false; MOUNT_READY=false; PROCESS_READY=false; CONTAIN_READY=false; CHANGE_READY=false; RECOVERY_READY=false; }; invalidate_all; CTX='PASTE_CONTEXT_HERE'; NODE='PASTE_NODE_HERE'; NODE_HOST='PASTE_NODE_HOST_HERE'; OBSERVED_LITERAL='PASTE_OBSERVED_KERNEL_LITERAL_HERE'; START_RFC3339='PASTE_START_RFC3339_HERE'; END_RFC3339='PASTE_END_RFC3339_HERE'; INPUT_READY=false; if [ "$TOOLS_READY" != true ] || [[ "$CTX" == PASTE_* ]] || [[ "$NODE" == PASTE_* ]] || [[ "$NODE_HOST" == PASTE_* ]] || [[ "$OBSERVED_LITERAL" == PASTE_* ]] || [[ ! "$NODE_HOST" =~ ^[A-Za-z0-9._:-]+$ ]] || [ -z "$OBSERVED_LITERAL" ]; then printf '%s\n' '중단: 승인된 대상과 실제 kernel literal이 필요하다.' >&2; elif kubectl --context "$CTX" get node "$NODE" -o name >/dev/null 2>&1; then INPUT_READY=true; export CTX NODE NODE_HOST OBSERVED_LITERAL; printf 'INPUT_READY=true context=%s node=%s host=%s literal-length=%s\n' "$CTX" "$NODE" "$NODE_HOST" "${#OBSERVED_LITERAL}"; else printf '%s\n' '중단: exact-name Node 조회 실패' >&2; fi`

host identity refresh나 실패는 machine identity, PID start, mount/device, cgroup/netns, time 파생값, argv regex와 모든 downstream gate를 무효화한다.

### 2. host identity·current guard

`refresh_host(){ local j r rh rm; invalidate_all; [ "$INPUT_READY" = true ] || return 1; j="$(kubectl --context "$CTX" get node "$NODE" -o json)" || return 1; NODE_UID="$(jq -er '.metadata.uid' <<<"$j")" || return 1; API_MACHINE_ID="$(jq -er '.status.nodeInfo.machineID' <<<"$j")" || return 1; jq -e --arg h "$NODE_HOST" --arg n "$NODE" '(.metadata.name==$n) and (($h==$n) or any(.status.addresses[]?;.address==$h))' <<<"$j" >/dev/null || { invalidate_all; return 1; }; r="$(ssh -o BatchMode=yes -o ConnectTimeout=10 -- "$NODE_HOST" bash -s <<< 'set -u; hostname -s; cat /etc/machine-id')" || { invalidate_all; return 1; }; rh="${r%%$'\n'*}"; rm="${r#*$'\n'}"; rm="${rm%%$'\n'*}"; jq -e --arg h "$rh" --arg n "$NODE" '($h==$n) or any(.status.addresses[]?;.address==$h)' <<<"$j" >/dev/null && [ "$rm" = "$API_MACHINE_ID" ] || { invalidate_all; return 1; }; REMOTE_HOSTNAME="$rh"; REMOTE_MACHINE_ID="$rm"; NODE_RE="$(printf '%s' "$NODE" | sed 's/[][\\.^$*+?(){}|]/\\&/g')"; HOST_READY=true; export NODE_UID API_MACHINE_ID REMOTE_HOSTNAME REMOTE_MACHINE_ID NODE_RE; printf 'HOST_READY=true node=%s uid=%s machine-id=%s remote=%s\n' "$NODE" "$NODE_UID" "$API_MACHINE_ID" "$REMOTE_HOSTNAME"; }; refresh_host`

`guard_host(){ local j r rh rm; [ "$HOST_READY" = true ] || return 1; j="$(kubectl --context "$CTX" get node "$NODE" -o json)" || { invalidate_all; return 1; }; [ "$(jq -r '.metadata.uid // empty' <<<"$j")" = "$NODE_UID" ] && [ "$(jq -r '.status.nodeInfo.machineID // empty' <<<"$j")" = "$API_MACHINE_ID" ] || { invalidate_all; return 1; }; r="$(ssh -o BatchMode=yes -o ConnectTimeout=10 -- "$NODE_HOST" bash -s <<< 'set -u; hostname -s; cat /etc/machine-id')" || { invalidate_all; return 1; }; rh="${r%%$'\n'*}"; rm="${r#*$'\n'}"; rm="${rm%%$'\n'*}"; [ "$rh" = "$REMOTE_HOSTNAME" ] && [ "$rm" = "$REMOTE_MACHINE_ID" ] || { invalidate_all; return 1; }; }`

`TIME_READY=false; EVIDENCE_READY=false; DEVICE_READY=false; MOUNT_READY=false; PROCESS_READY=false; CHANGE_READY=false; unset START_CANONICAL END_CANONICAL START_EPOCH END_EPOCH; if ! guard_host; then printf '%s\n' '중단: current host guard 실패' >&2; elif [[ "$START_RFC3339" =~ ^[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}Z$ ]] && [[ "$END_RFC3339" =~ ^[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}Z$ ]] && START_CANONICAL="$(date -u -d "$START_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null)" && END_CANONICAL="$(date -u -d "$END_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null)" && [ "$START_CANONICAL" = "$START_RFC3339" ] && [ "$END_CANONICAL" = "$END_RFC3339" ] && START_EPOCH="$(date -u -d "$START_RFC3339" +%s)" && END_EPOCH="$(date -u -d "$END_RFC3339" +%s)" && [ "$START_EPOCH" -lt "$END_EPOCH" ]; then TIME_READY=true; export START_RFC3339 END_RFC3339 START_EPOCH END_EPOCH; printf 'TIME_READY=true start=%s end=%s\n' "$START_RFC3339" "$END_RFC3339"; else printf '%s\n' '중단: strict UTC round-trip 또는 start<end 실패' >&2; fi`

## 진입 판단

| 구분 | 판단 기준 |
|---|---|
| 사용 | exact kernel literal이 같은 host·UTC window에 재확인됨 |
| 적용 | literal을 actual device/source·mount·consumer에 연결하거나 연결 실패를 증거로 남김 |
| 제외 | application 로그만 있으면 application owner, `FailedMount`/CSI면 [[25. Pod 이벤트에 FailedMount·FailedAttachVolume이 기록된 경우]], mapping 소실이면 [[09. block device가 사라지거나 device mapping이 바뀐 경우]] |

검색 문자열: `I/O error`, `corrupt`, `metadata`, `journal`, `read-only`, `remount`, `wrong fs type`.

| repair 뒤 mount만 `rw` | 새 device·mount·process와 실제 data 기능 | 재발 관찰과 application 검증 | [[#정상화·증거\|정상화]] |

## bounded kernel evidence

`EVIDENCE_READY=false; if [ "$TIME_READY" != true ] || ! guard_host; then printf '%s\n' '중단: current host/time gate 실패' >&2; else RAW="$(ssh -o BatchMode=yes -o ConnectTimeout=10 -- "$NODE_HOST" bash -s -- "$START_RFC3339" "$END_RFC3339" <<< 'set -u; command -v journalctl >/dev/null || exit 127; sudo -n journalctl -k --since "$1" --until "$2" -o short-iso-precise --no-pager')"; PRODUCER_RC=$?; if [ "$PRODUCER_RC" -ne 0 ]; then printf 'journal producer 실패 rc=%s\n' "$PRODUCER_RC" >&2; else MATCH="$(grep -F -C 5 -- "$OBSERVED_LITERAL" <<<"$RAW")"; FILTER_RC=$?; if [ "$FILTER_RC" -eq 0 ]; then EVIDENCE_AT="$(date -u '+%Y-%m-%dT%H:%M:%SZ')"; EVIDENCE_READY=true; printf '%s\n' "$MATCH" | sed -n '1,80p'; printf 'EVIDENCE_READY=true at=%s literal-length=%s\n' "$EVIDENCE_AT" "${#OBSERVED_LITERAL}"; elif [ "$FILTER_RC" -eq 1 ]; then printf '%s\n' 'literal 불일치; corruption 부재가 아니라 evidence 부재/시간·host 불일치' >&2; else printf 'grep filter 실패 rc=%s\n' "$FILTER_RC" >&2; fi; fi; unset RAW MATCH; fi`

전체 journal, pstore, block metadata, 파일 내용은 출력하지 않는다. 결정적 행에 credential·tenant path·개인정보가 있으면 저장을 중단하고 timestamp·device token·오류 종류만 비식별화해 기록한다.

## exact device·mount·process identity

`DEVICE_SOURCE='PASTE_DEVICE_SOURCE_HERE'; MOUNT_TARGET='PASTE_MOUNT_TARGET_HERE'; DEVICE_READY=false; MOUNT_READY=false; if [ "$EVIDENCE_READY" != true ] || ! guard_host || [[ ! "$DEVICE_SOURCE" =~ ^/dev/[A-Za-z0-9._/+:-]+$ ]] || [[ ! "$MOUNT_TARGET" =~ ^/[A-Za-z0-9._/-]+$ ]]; then printf '%s\n' '중단: evidence와 실제 block source·target이 필요하다.' >&2; else DF="$(ssh -o BatchMode=yes -o ConnectTimeout=10 -- "$NODE_HOST" bash -s -- "$DEVICE_SOURCE" "$MOUNT_TARGET" <<< 'set -u; d="$1"; t="$2"; test -b "$d" || exit 3; k="$(lsblk -dn -o KNAME "$d")" || exit 4; printf "%s %s %s %s\n" "$k" "$(lsblk -dn -o MAJ:MIN "$d")" "$(readlink -f "/sys/class/block/$k")" "$(cat "/sys/class/block/$k/size")"; findmnt -rn -T "$t" -o ID,SOURCE,FSTYPE,MAJ:MIN,OPTIONS')"; PRODUCER_RC=$?; if [ "$PRODUCER_RC" -eq 0 ]; then DEV_LINE="${DF%%$'\n'*}"; MNT_LINE="${DF#*$'\n'}"; read -r KNAME MAJOR_MINOR DEVICE_SYSFS DEVICE_SIZE <<<"$DEV_LINE"; read -r MOUNT_ID MOUNT_SOURCE MOUNT_FSTYPE MOUNT_MAJOR_MINOR MOUNT_OPTIONS <<<"$MNT_LINE"; if [[ "$MOUNT_ID" =~ ^[0-9]+$ ]] && [ "$MOUNT_SOURCE" = "$DEVICE_SOURCE" ] && [ "$MOUNT_MAJOR_MINOR" = "$MAJOR_MINOR" ]; then DEVICE_READY=true; MOUNT_READY=true; export DEVICE_SOURCE MOUNT_TARGET KNAME MAJOR_MINOR DEVICE_SYSFS DEVICE_SIZE MOUNT_ID MOUNT_SOURCE MOUNT_FSTYPE MOUNT_MAJOR_MINOR MOUNT_OPTIONS; printf 'MOUNT_READY=true device=%s kname=%s major-minor=%s sysfs=%s sectors=%s mount-id=%s target=%s fstype=%s options=%s\n' "$DEVICE_SOURCE" "$KNAME" "$MAJOR_MINOR" "$DEVICE_SYSFS" "$DEVICE_SIZE" "$MOUNT_ID" "$MOUNT_TARGET" "$MOUNT_FSTYPE" "$MOUNT_OPTIONS"; else printf '%s\n' '중단: device와 exact mount identity 불일치' >&2; fi; else printf 'device/mount producer 실패 rc=%s\n' "$PRODUCER_RC" >&2; fi; unset DF DEV_LINE MNT_LINE; fi`

`guard_mount(){ local f dl ml k mm sy sz id src fs mmm opt; guard_host || return 1; [ "$DEVICE_READY" = true ] && [ "$MOUNT_READY" = true ] || return 1; f="$(ssh -o BatchMode=yes -o ConnectTimeout=10 -- "$NODE_HOST" bash -s -- "$DEVICE_SOURCE" "$MOUNT_TARGET" <<< 'set -u; d="$1"; t="$2"; test -b "$d" || exit 3; k="$(lsblk -dn -o KNAME "$d")"; printf "%s %s %s %s\n" "$k" "$(lsblk -dn -o MAJ:MIN "$d")" "$(readlink -f "/sys/class/block/$k")" "$(cat "/sys/class/block/$k/size")"; findmnt -rn -T "$t" -o ID,SOURCE,FSTYPE,MAJ:MIN,OPTIONS')" || { DEVICE_READY=false; MOUNT_READY=false; PROCESS_READY=false; CHANGE_READY=false; return 1; }; dl="${f%%$'\n'*}"; ml="${f#*$'\n'}"; read -r k mm sy sz <<<"$dl"; read -r id src fs mmm opt <<<"$ml"; [ "$k" = "$KNAME" ] && [ "$mm" = "$MAJOR_MINOR" ] && [ "$sy" = "$DEVICE_SYSFS" ] && [ "$sz" = "$DEVICE_SIZE" ] && [ "$id" = "$MOUNT_ID" ] && [ "$src" = "$MOUNT_SOURCE" ] && [ "$fs" = "$MOUNT_FSTYPE" ] && [ "$mmm" = "$MOUNT_MAJOR_MINOR" ] && [ "$opt" = "$MOUNT_OPTIONS" ] || { DEVICE_READY=false; MOUNT_READY=false; PROCESS_READY=false; CHANGE_READY=false; return 1; }; }`

`PID='PASTE_PID_HERE'; ARGV_RE='PASTE_ARGV_REGEX_HERE'; CONSUMER_UNIT='PASTE_CONSUMER_UNIT_HERE'; PROCESS_READY=false; if ! guard_mount || ! [[ "$PID" =~ ^[1-9][0-9]*$ ]] || [[ "$ARGV_RE" == PASTE_* ]] || [[ ! "$CONSUMER_UNIT" =~ ^[A-Za-z0-9_.@-]+\.service$ ]]; then printf '%s\n' '중단: current mount와 실제 PID·argv regex·unit이 필요하다.' >&2; elif grep -E -- "$ARGV_RE" </dev/null >/dev/null 2>&1 || [ "$?" -eq 1 ]; then PF="$(ssh -o BatchMode=yes -o ConnectTimeout=10 -- "$NODE_HOST" bash -s -- "$PID" "$ARGV_RE" "$CONSUMER_UNIT" <<< 'set -u; p="$1"; re="$2"; unit="$3"; s="$(cat "/proc/$p/stat")" || exit 3; r="${s##*) }"; set -- $r; tr "\0" "\n" < "/proc/$p/cmdline" | grep -Eq -- "$re" || exit 4; test "$(sudo -n systemctl show "$unit" --property=MainPID --value --no-pager)" = "$p" || exit 5; printf "%s %s %s %s\n" "${20}" "$(readlink "/proc/$p/ns/cgroup")" "$(readlink "/proc/$p/ns/net")" "$(readlink "/proc/$p/ns/mnt")"')"; PRODUCER_RC=$?; if [ "$PRODUCER_RC" -eq 0 ] && read -r PID_START CGROUP_NS NET_NS MNT_NS <<<"$PF"; then PROCESS_READY=true; export PID ARGV_RE CONSUMER_UNIT PID_START CGROUP_NS NET_NS MNT_NS; printf 'PROCESS_READY=true pid=%s start=%s unit=%s cgroup-ns=%s netns=%s mntns=%s\n' "$PID" "$PID_START" "$CONSUMER_UNIT" "$CGROUP_NS" "$NET_NS" "$MNT_NS"; else printf 'process identity 실패 rc=%s\n' "$PRODUCER_RC" >&2; fi; unset PF; else printf '%s\n' '중단: invalid argv regex' >&2; fi`

`guard_process(){ local f st cg nn mn; guard_mount || return 1; [ "$PROCESS_READY" = true ] || return 1; f="$(ssh -o BatchMode=yes -o ConnectTimeout=10 -- "$NODE_HOST" bash -s -- "$PID" "$ARGV_RE" "$CONSUMER_UNIT" <<< 'set -u; p="$1"; re="$2"; unit="$3"; s="$(cat "/proc/$p/stat")" || exit 3; r="${s##*) }"; set -- $r; tr "\0" "\n" < "/proc/$p/cmdline" | grep -Eq -- "$re" || exit 4; test "$(sudo -n systemctl show "$unit" --property=MainPID --value --no-pager)" = "$p" || exit 5; printf "%s %s %s %s\n" "${20}" "$(readlink "/proc/$p/ns/cgroup")" "$(readlink "/proc/$p/ns/net")" "$(readlink "/proc/$p/ns/mnt")"')" || { PROCESS_READY=false; CHANGE_READY=false; return 1; }; read -r st cg nn mn <<<"$f"; [ "$st" = "$PID_START" ] && [ "$cg" = "$CGROUP_NS" ] && [ "$nn" = "$NET_NS" ] && [ "$mn" = "$MNT_NS" ] || { PROCESS_READY=false; CHANGE_READY=false; return 1; }; }`

현재 `ro`는 보호성 전환의 결과일 수 있다. `rw` remount, `fsck`, filesystem-specific repair, format, device reset·detach를 진단 명령으로 실행하지 않는다. Kubernetes consumer가 확인되면 Pod UID·node·PVC/PV/VolumeAttachment lifecycle을 별도 storage 런북에서 exact하게 등록한다.

## containment·repair 안전 경계

이 문서는 service stop/start, `rw` remount, `fsck`, filesystem-specific repair, format, unmount, device reset·detach 명령을 제공하지 않는다. consumer 정지 containment와 repair는 fresh host·device·mount·process identity, 15분 이내의 bounded corruption evidence, application quorum·availability, backup/snapshot, 승인 ID·window, idempotence, 중단 조건과 rollback 원본을 별도 변경 절차에서 직접 재검증한 경우에만 수행한다.

repair·device replacement 뒤에는 `refresh_host`부터 다시 수행하고 replacement device의 KNAME·major:minor·sysfs·size, 새 mount ID·source·fstype·options를 등록한다. replacement PID의 start tick·cgroup/netns/mntns·argv regex를 새로 등록하고, 실제 read/write·data integrity·application 요청을 확인한다. mount가 `rw`이거나 journal이 빈 것만으로 recovery를 선언하지 않는다.

## 정상화·증거

정상화 순서는 `새 kernel corruption/I/O 부재 → replacement device identity → filesystem 검사 결과 → exact mount → replacement process namespace → 실제 데이터 기능`이다. producer 실패와 filter no-match를 분리하고, observation window가 비면 성공으로 닫지 않는다.

Node UID/machineID, remote machine-id, literal hash/길이와 결정적 timestamp, evidence window, producer/filter rc, device·mount·process identity, filesystem owner의 repair 결과, 승인·rollback·기능 검증을 보존한다. literal 원문의 민감 부분, argv, 파일 내용, 전체 journal·pstore·dump는 보존하지 않는다.
