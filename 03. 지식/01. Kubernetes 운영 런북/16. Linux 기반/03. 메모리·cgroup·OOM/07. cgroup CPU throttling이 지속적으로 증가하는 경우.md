# cgroup CPU throttling이 지속적으로 증가하는 경우

## 입력값과 빠른 수집

실행 경로는 `운영자 Bash -> 직접 SSH -> 대상 host -> 확인된 cgroup -> 확인된 process`다. ProxyJump·ProxyCommand를 사용하지 않으며 bastion이 필요하면 bastion에서 이 절을 새로 시작한다. 다른 host로 바꾸거나 명령 하나라도 실패하면 host·boot ID, cgroup mount/dev/inode, PID/start time, netns, 시간 창과 모든 `*_READY` 값을 먼저 무효화한다.

| 구분 | 값 | 계약 |
|---|---|---|
| 최초 입력 | `SSH_TARGET`, `EXPECTED_MACHINE_ID_SHA256` | 승인 기록의 SSH endpoint와 `/etc/machine-id` 파일 SHA-256 |
| system-auto | `HOSTNAME_ACTUAL`, `BOOT_ID` | 대상 host에서 매번 재확인 |
| 운영자 선택 | `CGROUP_PATH`, `ARGV_REGEX`, `TARGET_PID`, `START_RFC3339`, `END_RFC3339` | 후보 출력과 사건 기록을 보고 선택 |
| system-auto | `CGROUP_KEY`, `CGROUP_MOUNT_KEY`, `PID_START_TICKS`, `NETNS_INODE` | 선택 직후 등록하고 매 후속 명령에서 재검증 |
| 계산값 | `WINDOW_SECONDS`, counter delta | 엄격한 UTC 시간과 같은 identity의 두 snapshot에서 계산 |

### 1. 최초 입력과 초기화

`SSH_TARGET`은 `user@host` 한 hop만 허용한다. machine-id 원문은 출력·저장하지 않고 승인된 SHA-256과 비교한다.

```bash
unset HOST_READY CGROUP_READY PROCESS_READY TIME_READY DOWNSTREAM_READY HOSTNAME_ACTUAL BOOT_ID CGROUP_PATH CGROUP_KEY CGROUP_MOUNT_KEY ARGV_REGEX TARGET_PID PID_START_TICKS NETNS_INODE START_RFC3339 END_RFC3339 WINDOW_SECONDS; SSH_TARGET='PASTE_SSH_TARGET_HERE'; EXPECTED_MACHINE_ID_SHA256='PASTE_MACHINE_ID_SHA256_HERE'; HOST_READY=false; if [ -z "${BASH_VERSION:-}" ] || ! command -v ssh >/dev/null 2>&1 || ! command -v date >/dev/null 2>&1 || ! [[ "$SSH_TARGET" =~ ^[A-Za-z0-9._-]+@([A-Za-z0-9._-]+|\[[0-9A-Fa-f:]+\])$ ]] || ! [[ "$EXPECTED_MACHINE_ID_SHA256" =~ ^[0-9a-f]{64}$ ]]; then printf '%s\n' '중단: Bash, ssh, date, SSH_TARGET 또는 machine-id SHA-256 입력을 확인한다.' >&2; else printf '초기 입력 확인 target=%s direct-hop-only=true\n' "$SSH_TARGET"; fi
```

```bash
unset HOSTNAME_ACTUAL BOOT_ID CGROUP_PATH CGROUP_KEY CGROUP_MOUNT_KEY ARGV_REGEX TARGET_PID PID_START_TICKS NETNS_INODE START_RFC3339 END_RFC3339 WINDOW_SECONDS; HOST_READY=false; CGROUP_READY=false; PROCESS_READY=false; TIME_READY=false; DOWNSTREAM_READY=false; if OUT="$(ssh -o BatchMode=yes -o ConnectTimeout=10 -o ProxyCommand=none -o ProxyJump=none -- "$SSH_TARGET" 'set -euo pipefail; expected=$1; sum=$(sha256sum /etc/machine-id); actual=${sum%% *}; [ "$actual" = "$expected" ] || { printf "%s\n" "machine-id mismatch" >&2; exit 70; }; printf "%s\n%s\n" "$(hostname --fqdn 2>/dev/null || hostname)" "$(cat /proc/sys/kernel/random/boot_id)"' bash "$EXPECTED_MACHINE_ID_SHA256")"; then mapfile -t HOST_META <<<"$OUT"; [ "${#HOST_META[@]}" -eq 2 ] || { printf '%s\n' '중단: host metadata 형식 오류' >&2; exit 1; }; HOSTNAME_ACTUAL=${HOST_META[0]}; BOOT_ID=${HOST_META[1]}; HOST_READY=true; printf 'HOST_READY=true host=%s boot_id=%s\n' "$HOSTNAME_ACTUAL" "$BOOT_ID"; else unset HOSTNAME_ACTUAL BOOT_ID; printf '%s\n' '중단: SSH 또는 machine identity gate 실패' >&2; fi
```

성공 gate는 `HOST_READY=true`다. 이 값만 믿지 않고 아래 모든 원격 명령이 machine-id와 boot ID를 다시 검사한다.

### 2. cgroup과 process 등록

`CGROUP_PATH`는 runtime inspect, systemd `ControlGroup`, 또는 node owner가 확인한 절대 경로만 사용한다. 이름을 조합해 만들지 않는다.

```bash
unset CGROUP_KEY CGROUP_MOUNT_KEY ARGV_REGEX TARGET_PID PID_START_TICKS NETNS_INODE START_RFC3339 END_RFC3339 WINDOW_SECONDS; CGROUP_READY=false; PROCESS_READY=false; TIME_READY=false; DOWNSTREAM_READY=false; CGROUP_PATH='PASTE_CGROUP_PATH_HERE'; if [ "$HOST_READY" != true ] || [ -z "$CGROUP_PATH" ] || [ "${CGROUP_PATH#/}" = "$CGROUP_PATH" ]; then printf '%s\n' '중단: host gate와 절대 cgroup 경로를 확인한다.' >&2; elif OUT="$(ssh -o BatchMode=yes -o ConnectTimeout=10 -o ProxyCommand=none -o ProxyJump=none -- "$SSH_TARGET" 'set -euo pipefail; expected=$1; boot=$2; path=$3; sum=$(sha256sum /etc/machine-id); [ "${sum%% *}" = "$expected" ] && [ "$(cat /proc/sys/kernel/random/boot_id)" = "$boot" ] || exit 70; [ -d "$path" ] && [ -r "$path/cpu.stat" ] || exit 71; key=$(stat -Lc "%d:%i" -- "$path"); mount=$(findmnt -T "$path" -n -o MAJ:MIN,TARGET,FSTYPE); printf "%s\n%s\n" "$key" "$mount"' bash "$EXPECTED_MACHINE_ID_SHA256" "$BOOT_ID" "$CGROUP_PATH")"; then mapfile -t CG_META <<<"$OUT"; [ "${#CG_META[@]}" -eq 2 ] || { printf '%s\n' '중단: cgroup metadata 형식 오류' >&2; exit 1; }; CGROUP_KEY=${CG_META[0]}; CGROUP_MOUNT_KEY=${CG_META[1]}; CGROUP_READY=true; printf 'CGROUP_READY=true path=%s key=%s mount=%s\n' "$CGROUP_PATH" "$CGROUP_KEY" "$CGROUP_MOUNT_KEY"; else unset CGROUP_KEY CGROUP_MOUNT_KEY; printf '%s\n' '중단: cgroup 등록 실패' >&2; fi
```

process가 있는 cgroup이면 argv의 비민감한 고정 문자열로 후보를 제한한다. 정규식은 원격 positional argument로 전달하며 `eval`하지 않는다.

```bash
unset TARGET_PID PID_START_TICKS NETNS_INODE; PROCESS_READY=false; DOWNSTREAM_READY=false; ARGV_REGEX='PASTE_ARGV_REGEX_HERE'; if [ "$CGROUP_READY" != true ] || [ -z "$ARGV_REGEX" ] || [[ "$ARGV_REGEX" == *$'\n'* ]]; then printf '%s\n' '중단: cgroup gate 또는 argv regex를 확인한다.' >&2; else ssh -o BatchMode=yes -o ConnectTimeout=10 -o ProxyCommand=none -o ProxyJump=none -- "$SSH_TARGET" 'set -euo pipefail; expected=$1; boot=$2; path=$3; key=$4; regex=$5; sum=$(sha256sum /etc/machine-id); [ "${sum%% *}" = "$expected" ] && [ "$(cat /proc/sys/kernel/random/boot_id)" = "$boot" ] && [ "$(stat -Lc "%d:%i" -- "$path")" = "$key" ] || exit 70; while IFS= read -r pid; do [[ "$pid" =~ ^[0-9]+$ ]] || continue; [ -r "/proc/$pid/stat" ] || continue; argv=$(tr "\0" " " <"/proc/$pid/cmdline"); if printf "%s\n" "$argv" | grep -Eq -- "$regex"; then filter_rc=0; else filter_rc=$?; fi; [ "$filter_rc" -eq 0 ] || { [ "$filter_rc" -eq 1 ] && continue; printf "grep failed rc=%s\n" "$filter_rc" >&2; exit "$filter_rc"; }; start=$(cut -d" " -f22 "/proc/$pid/stat"); netns=$(stat -Lc "%i" "/proc/$pid/ns/net"); printf "pid=%s start_ticks=%s netns_inode=%s argv=%.*s\n" "$pid" "$start" "$netns" 160 "$argv"; done <"$path/cgroup.procs"' bash "$EXPECTED_MACHINE_ID_SHA256" "$BOOT_ID" "$CGROUP_PATH" "$CGROUP_KEY" "$ARGV_REGEX"; fi
```

빈 출력은 process 부재, regex 불일치 또는 짧은 수명의 process일 수 있다. producer 실패와 `grep`의 no-match(rc=1)를 오류 없음으로 합치지 않는다.

```bash
unset PID_START_TICKS NETNS_INODE; PROCESS_READY=false; DOWNSTREAM_READY=false; TARGET_PID='PASTE_PID_HERE'; if [ "$CGROUP_READY" != true ] || ! [[ "$TARGET_PID" =~ ^[0-9]+$ ]]; then printf '%s\n' '중단: cgroup gate와 PID 선택을 확인한다.' >&2; elif OUT="$(ssh -o BatchMode=yes -o ConnectTimeout=10 -o ProxyCommand=none -o ProxyJump=none -- "$SSH_TARGET" 'set -euo pipefail; expected=$1; boot=$2; path=$3; key=$4; pid=$5; regex=$6; sum=$(sha256sum /etc/machine-id); [ "${sum%% *}" = "$expected" ] && [ "$(cat /proc/sys/kernel/random/boot_id)" = "$boot" ] && [ "$(stat -Lc "%d:%i" -- "$path")" = "$key" ] || exit 70; grep -Fxq -- "$pid" "$path/cgroup.procs" || exit 72; argv=$(tr "\0" " " <"/proc/$pid/cmdline"); printf "%s\n" "$argv" | grep -Eq -- "$regex" || exit 73; printf "%s\n%s\n" "$(cut -d" " -f22 "/proc/$pid/stat")" "$(stat -Lc "%i" "/proc/$pid/ns/net")"' bash "$EXPECTED_MACHINE_ID_SHA256" "$BOOT_ID" "$CGROUP_PATH" "$CGROUP_KEY" "$TARGET_PID" "$ARGV_REGEX")"; then mapfile -t PID_META <<<"$OUT"; PID_START_TICKS=${PID_META[0]}; NETNS_INODE=${PID_META[1]}; PROCESS_READY=true; printf 'PROCESS_READY=true pid=%s start_ticks=%s netns_inode=%s\n' "$TARGET_PID" "$PID_START_TICKS" "$NETNS_INODE"; else unset PID_START_TICKS NETNS_INODE; printf '%s\n' '중단: PID가 재사용·종료·이동했거나 argv가 달라짐' >&2; fi
```

### 3. 시간 창 등록

```bash
unset WINDOW_SECONDS; TIME_READY=false; DOWNSTREAM_READY=false; START_RFC3339='PASTE_START_RFC3339_HERE'; END_RFC3339='PASTE_END_RFC3339_HERE'; if START_CANON=$(date -u -d "$START_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null) && END_CANON=$(date -u -d "$END_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null) && [ "$START_CANON" = "$START_RFC3339" ] && [ "$END_CANON" = "$END_RFC3339" ]; then START_EPOCH=$(date -u -d "$START_RFC3339" +%s); END_EPOCH=$(date -u -d "$END_RFC3339" +%s); if [ "$START_EPOCH" -lt "$END_EPOCH" ]; then WINDOW_SECONDS=$((END_EPOCH-START_EPOCH)); TIME_READY=true; printf 'TIME_READY=true start=%s end=%s seconds=%s\n' "$START_RFC3339" "$END_RFC3339" "$WINDOW_SECONDS"; else printf '%s\n' '중단: start는 end보다 빨라야 한다.' >&2; fi; else printf '%s\n' '중단: UTC RFC3339 초 단위 roundtrip 실패' >&2; fi
```

## 진입 판단

| 구분 | 판단 기준 |
|---|---|
| 사용 | 같은 cgroup identity에서 `nr_throttled`와 throttled time의 delta가 증가하고 실제 latency 증상과 시간상 겹침 |
| 적용 | cgroup v1/v2, quota/period, process identity와 host pressure를 같은 창에서 비교 가능 |
| 제외 | snapshot 하나뿐이거나 cgroup controller 자체가 불명확하면 [[08. cgroup controller가 활성화되지 않거나 제한이 적용되지 않는 경우]] |

검색 문자열: `cpu.stat`, `nr_periods`, `nr_throttled`, `throttled_usec`, `throttled_time`, `cpu.max`, `cpu.cfs_quota_us`, `cpu.pressure`.

## 관측별 진단 경로

| 지금 보이는 것 | 먼저 볼 것 | 다음 판단 |
|---|---|---|
| 유한 quota와 throttling delta 증가 | quota/period와 같은 cgroup의 `cpu.stat` | cgroup quota boundary |
| host PSI·runnable도 증가 | host `/proc/pressure/cpu`, load | host contention과 quota를 분리 |
| process 또는 cgroup identity 변경 | PID start/netns, cgroup dev:inode | 이전 증거 폐기 후 재등록 |
| counter는 크지만 delta 없음 | process·boot 원점 | 과거 사건 또는 현재 미재현 |

## 직접 진단

다음 명령은 두 번 실행해 각 출력의 UTC 시각과 동일 identity를 보존한다. 중간에 boot ID, cgroup dev:inode, PID start time, netns 또는 argv가 바뀌면 두 snapshot을 비교하지 않는다.

```bash
if [ "$CGROUP_READY" != true ] || [ "$PROCESS_READY" != true ] || [ "$TIME_READY" != true ]; then printf '%s\n' '중단: cgroup/process/time gate가 완전하지 않다.' >&2; exit 1; fi; ssh -o BatchMode=yes -o ConnectTimeout=10 -o ProxyCommand=none -o ProxyJump=none -- "$SSH_TARGET" 'set -euo pipefail; expected=$1; boot=$2; path=$3; key=$4; pid=$5; start=$6; netns=$7; regex=$8; sum=$(sha256sum /etc/machine-id); [ "${sum%% *}" = "$expected" ] && [ "$(cat /proc/sys/kernel/random/boot_id)" = "$boot" ] && [ "$(stat -Lc "%d:%i" -- "$path")" = "$key" ] && [ "$(cut -d" " -f22 "/proc/$pid/stat")" = "$start" ] && [ "$(stat -Lc "%i" "/proc/$pid/ns/net")" = "$netns" ] || exit 70; argv=$(tr "\0" " " <"/proc/$pid/cmdline"); printf "%s\n" "$argv" | grep -Eq -- "$regex" || exit 73; printf "observed_at=%s host=%s boot=%s cgroup=%s pid=%s\n" "$(date -u +%Y-%m-%dT%H:%M:%SZ)" "$(hostname)" "$boot" "$key" "$pid"; cat "$path/cpu.stat"; if [ -r "$path/cpu.max" ]; then printf "version=v2 cpu.max="; cat "$path/cpu.max"; [ -r "$path/cpu.weight" ] && { printf "cpu.weight="; cat "$path/cpu.weight"; }; elif [ -r "$path/cpu.cfs_quota_us" ] && [ -r "$path/cpu.cfs_period_us" ]; then printf "version=v1 quota="; cat "$path/cpu.cfs_quota_us"; printf "period="; cat "$path/cpu.cfs_period_us"; else printf "%s\n" "중단: cgroup CPU interface 불명" >&2; exit 74; fi; printf "%s\n" "host_cpu_pressure:"; cat /proc/pressure/cpu; printf "%s\n" "host_load:"; cat /proc/loadavg' bash "$EXPECTED_MACHINE_ID_SHA256" "$BOOT_ID" "$CGROUP_PATH" "$CGROUP_KEY" "$TARGET_PID" "$PID_START_TICKS" "$NETNS_INODE" "$ARGV_REGEX"
```

`nr_periods`, `nr_throttled`, throttled time은 누적 counter다. 같은 원점의 두 snapshot에서만 delta를 계산한다. v2 `throttled_usec`과 v1 `throttled_time`의 단위를 섞지 않는다. local quota가 `max`/`-1`이어도 ancestor quota 부재를 보장하지 않으며, host PSI가 낮다고 실제 서비스 지연이 없다는 뜻도 아니다.

## 복구 전 안전 gate

이 문서는 상태 변경 명령을 제공하지 않는다. quota/period·weight·CPU limit 변경, process/container/Pod restart·kill, cgroup 이동과 부하 생성은 별도 변경 절차로 이관한다. 변경 절차는 실행 직전에 machine-id, boot ID, cgroup mount/dev/inode, PID/start/netns/argv, 증거 창을 다시 확인하고 실패 전에 모든 downstream gate를 무효화해야 한다. trigger, 승인 ID, maintenance window, 가용 capacity, 영향 범위, 멱등성, 중단 조건, 검증된 rollback/보상 절차가 하나라도 없으면 실행하지 않는다. 재생성된 process나 cgroup은 새 identity로 등록한다.

## 정상화 검증

승인된 외부 조치 후 위 직접 진단 명령을 새 UTC 창에서 다시 두 번 실행한다. 새 identity라면 과거 counter와 직접 빼지 않는다. throttle delta·host pressure·latency가 승인 기준 안에서 안정되고, 영향 서비스의 기존 health check·실제 요청 또는 batch 산출물이 정상이며 관찰 창 동안 재발하지 않아야 한다. `nr_throttled`가 잠시 멈추거나 process가 살아 있는 것만으로 정상화하지 않는다.

## 증거 보존과 완료 보고

host·boot ID, machine-id hash 검증 성공 여부, cgroup path와 mount/dev/inode, PID/start/netns와 비민감 argv 요약, 엄격한 UTC 창, v1/v2 interface, 두 snapshot과 delta, host PSI/load, 실제 기능 결과를 보존한다. machine-id 원문, 전체 argv, 환경변수, Secret·token·개인키·개인정보는 저장하지 않는다. Linux kernel/cgroup 배치, SSH 접근, workload-runtime mapping과 실제 서비스 검증은 환경별 미검증이다.
