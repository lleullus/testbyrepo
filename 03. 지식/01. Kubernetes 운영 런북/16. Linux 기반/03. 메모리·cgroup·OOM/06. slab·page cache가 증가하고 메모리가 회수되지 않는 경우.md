# slab·page cache가 증가하고 메모리가 회수되지 않는 경우

## 입력값과 빠른 수집

| 구분 | 값 | 출처와 gate |
|---|---|---|
| 최초 입력 | approved SSH host, canonical UTC start/end | 한 번만 입력 |
| 시스템 자동값 | machine/boot/kernel/namespace, meminfo/vmstat/PSI | 실제 host에서 fresh 수집 |
| 계산 후보값 | counter delta, field/instance regex | bounded 출력과 escape 뒤 사용 |
| 운영자 선택값 | exact mount/device 또는 PID/cgroup, metrics provider | 직접 evidence가 해당 branch를 요구할 때만 선택 |

경로는 `operator Bash -> SSH -> host namespaces -> meminfo/vmstat/PSI -> slab 또는 page-cache/writeback -> 필요 시 exact mount/device/process`다. Kubernetes 객체는 이 Linux 원인 판정에 필요하지 않으므로 조회하지 않는다.

SSH는 allowlist host와 고정 script만 사용하며 검증된 hex·UUID·정규식·canonical UTC를 위치 인자로 전달한다. `eval`이나 동적 remote command를 쓰지 않는다.

## 진입 판단

| 구분 | 판단 기준 |
|---|---|
| 사용 | same host·boot에서 slab/page cache 증가와 reclaim·pressure 비회복이 함께 관측됨 |
| 적용 | slab 하위, cache/dirty/writeback, counter delta, PSI를 분리 가능 |
| 제외 | 단일 현재값만 큼, 직접 global/memcg OOM 또는 block I/O error가 우선임 |

검색 문자열: `SReclaimable`, `SUnreclaim`, `KReclaimable`, `Cached`, `Dirty`, `Writeback`, `pgscan`, `pgsteal`.

## 관측별 진단 경로

| 지금 보이는 것 | 먼저 볼 것 | 다음 판단 | 상세 절 |
|---|---|---|---|
| slab 증가 | reclaimable/unreclaimable delta | kernel memory 후보 | [[#1. bounded memory samples]] |
| cache + dirty/writeback 증가 | exact backing I/O·PSI | writeback 경로 | [[#2. mount·device·process branch]] |
| scan·allocstall·PSI 증가 | steal 효율과 OOM journal | pressure 경로 | [[#3. bounded journal]] |
| 현재 정상, 과거 peak | provider retention/boot | evidence gap | [[#4. safe metrics query]] |

## 1. bounded memory samples

```bash
SAMPLE_READY=false; TARGET_READY=false; PROCESS_READY=false; SELECTION_READY=false; EVIDENCE_READY=false; QUERY_READY=false; MUTATION_READY=false; ROLLBACK_READY=false; NORMALIZATION_READY=false; unset TARGET_PID PID_START PID_EXE CGROUP_PATH TARGET_MOUNT MOUNT_SOURCE MOUNT_MAJMIN DEVICE_ID MOUNT_RELATION_ID PROCESS_RELATION_ID APPROVED_METRICS_PROVIDER INSTANCE INSTANCE_RE METRICS_RELATION_ID; if [ "$HOST_READY" != true ]; then printf '%s\n' '중단: HOST_READY가 아니다.' >&2; else ssh "${SSH_OPTS[@]}" -- "$APPROVED_HOST" bash -s -- "$MACHINE_ID" "$BOOT_ID" "$MOUNT_ID" "$MEM_RE" "$VM_RE" <<'REMOTE'
set -euo pipefail
[ "$(cat /etc/machine-id)" = "$1" ] && [ "$(cat /proc/sys/kernel/random/boot_id)" = "$2" ] && [ "$(stat -Lc %i /proc/1/ns/mnt)" = "$3" ] || exit 40
for n in 1 2; do for key in MemAvailable Cached Slab SReclaimable SUnreclaim Dirty Writeback; do grep -q "^$key:" /proc/meminfo || exit 41; done; grep -q '^pgscan' /proc/vmstat && grep -q '^pgsteal' /proc/vmstat && grep -q '^allocstall' /proc/vmstat || exit 42; date -u '+sample=%Y-%m-%dT%H:%M:%SZ'; grep -E "$4" /proc/meminfo; grep -E "$5" /proc/vmstat; if [ -r /proc/pressure/memory ]; then sed -n '1,4p' /proc/pressure/memory; else printf '%s\n' 'memory-PSI=unavailable'; fi; if [ -r /proc/pressure/io ]; then sed -n '1,4p' /proc/pressure/io; else printf '%s\n' 'io-PSI=unavailable'; fi; [ "$n" -eq 1 ] && sleep 5; done
REMOTE
rc=$?; if [ "$rc" -eq 0 ]; then SAMPLE_READY=true; printf '%s\n' 'SAMPLE_READY=true'; else unset TARGET_PID PID_START PID_EXE CGROUP_PATH TARGET_MOUNT MOUNT_SOURCE MOUNT_MAJMIN DEVICE_ID RELATION_ID; SAMPLE_READY=false; TARGET_READY=false; printf '중단: sample 실패 rc=%s\n' "$rc" >&2; fi; fi
```

모든 필수 field가 두 timestamp에 있어야 delta를 계산한다. 없는 field는 0이 아니다. `SReclaimable`이 커도 즉시 회수 가능함을 보장하지 않는다. `SUnreclaim` 증가만으로 leak owner를 특정하지 않는다. `Cached`와 `Dirty/Writeback`, 낮은 steal/scan, allocstall·PSI를 같은 창에서 연결한다.

## 2. mount·device·process branch

writeback/I/O 증거가 있을 때만 exact mount를 선택한다. 공백 없는 canonical absolute path만 원격 인자로 허용하며 broad filesystem scan을 하지 않는다.

`TARGET_READY=false; PROCESS_READY=false; SELECTION_READY=false; EVIDENCE_READY=false; QUERY_READY=false; MUTATION_READY=false; ROLLBACK_READY=false; NORMALIZATION_READY=false; unset TARGET_MOUNT MOUNT_SOURCE MOUNT_MAJMIN DEVICE_ID MOUNT_RELATION_ID TARGET_PID PID_START PID_EXE CGROUP_PATH PROCESS_RELATION_ID APPROVED_METRICS_PROVIDER INSTANCE INSTANCE_RE METRICS_RELATION_ID; read -r -p 'evidence가 가리키는 exact mount path(해당 branch만): ' TARGET_MOUNT; read -r -p 'mount와 사건 evidence의 승인 relation ID: ' MOUNT_RELATION_ID; if [ "$HOST_READY" = true ] && [ "$SAMPLE_READY" = true ] && [[ "$TARGET_MOUNT" =~ ^/[A-Za-z0-9_./:@-]+$ ]] && [ -n "$MOUNT_RELATION_ID" ]; then SELECTION_READY=true; TARGET_READY=true; printf 'SELECTION_READY=true TARGET_READY=true mount=%s relation=%s\n' "$TARGET_MOUNT" "$MOUNT_RELATION_ID"; else unset TARGET_MOUNT MOUNT_RELATION_ID; printf '%s\n' '중단: current sample/mount/relation gate 오류' >&2; fi`

```bash
if [ "$HOST_READY" != true ] || [ "$SAMPLE_READY" != true ] || [ "$SELECTION_READY" != true ] || [ "$TARGET_READY" != true ]; then printf '%s\n' '중단: current host/sample/selection/target gate가 아니다.' >&2; else ssh "${SSH_OPTS[@]}" -- "$APPROVED_HOST" bash -s -- "$MACHINE_ID" "$BOOT_ID" "$MOUNT_ID" "$TARGET_MOUNT" <<'REMOTE'
set -euo pipefail
[ "$(cat /etc/machine-id)" = "$1" ] && [ "$(cat /proc/sys/kernel/random/boot_id)" = "$2" ] && [ "$(stat -Lc %i /proc/1/ns/mnt)" = "$3" ] || exit 40
findmnt -T "$4" -o TARGET,SOURCE,FSTYPE,OPTIONS,MAJ:MIN -n
src=$(findmnt -T "$4" -o SOURCE -n); [ -n "$src" ] || exit 42
if [ -b "$src" ]; then lsblk -dn -o NAME,TYPE,MAJ:MIN,SIZE,ROTA,MODEL,SERIAL,WWN -- "$src"; else printf 'source=%s non-block-or-mapped; owner relation required\n' "$src"; fi

```

mount source, `MAJ:MIN`, stable device ID와 storage telemetry label의 관계가 있어야 device latency를 연결한다. overlay/network/mapped source는 하위 backing을 추측하지 않는다.

특정 process가 cache/cgroup 원인 후보일 때만 exact PID를 선택한다. 현재 PID의 start tick과 namespaces를 기록하며 이름 일치만으로 과거 process와 연결하지 않는다.

```bash
pid=$4; [ -r "/proc/$pid/stat" ] || exit 43

```

## 3. bounded journal

```bash
JOURNAL_READY=false; if [ "$HOST_READY" != true ] || [ "$START_EPOCH" -ge "$END_EPOCH" ]; then printf '%s\n' '중단: host/time gate 실패' >&2; else ssh "${SSH_OPTS[@]}" -- "$APPROVED_HOST" bash -s -- "$MACHINE_ID" "$BOOT_ID" "$MOUNT_ID" "$START_RFC3339" "$END_RFC3339" <<'REMOTE'
set -euo pipefail
[ "$(cat /etc/machine-id)" = "$1" ] && [ "$(cat /proc/sys/kernel/random/boot_id)" = "$2" ] && [ "$(stat -Lc %i /proc/1/ns/mnt)" = "$3" ] || exit 40
tmp=$(mktemp); trap 'rm -f "$tmp"' EXIT
journalctl -k --since "$4" --until "$5" --utc --no-pager >"$tmp"
if grep -E -i -C 3 'oom-kill|out of memory|page allocation failure|reclaim|writeback|I/O error|read-only' "$tmp"; then :; else grc=$?; [ "$grc" -eq 1 ] || exit "$grc"; printf '%s\n' 'FILTER_MATCH=none; producer 성공, 문자열 없음'; tail -n 50 "$tmp"; fi
REMOTE
rc=$?; if [ "$rc" -eq 0 ]; then JOURNAL_READY=true; printf '%s\n' 'JOURNAL_READY=true'; else unset JOURNAL_READY; JOURNAL_READY=false; printf '중단: journal producer 실패 rc=%s\n' "$rc" >&2; fi; fi
```

pipeline producer와 filter 상태를 분리했다. no-match는 정상화가 아니다. 민감정보는 저장하지 않는다.

## 4. safe metrics query

`QUERY_READY=false; MUTATION_READY=false; ROLLBACK_READY=false; NORMALIZATION_READY=false; unset APPROVED_METRICS_PROVIDER INSTANCE INSTANCE_RE METRICS_RELATION_ID; read -r -p '승인 metrics provider: ' APPROVED_METRICS_PROVIDER; read -r -p 'exact instance label: ' INSTANCE; read -r -p 'instance와 current machine-id의 승인 relation ID: ' METRICS_RELATION_ID; if [ "$HOST_READY" = true ] && [ "$SAMPLE_READY" = true ] && [ -n "$APPROVED_METRICS_PROVIDER" ] && [[ "$INSTANCE" =~ ^[A-Za-z0-9._:/-]+$ ]] && [ -n "$METRICS_RELATION_ID" ]; then INSTANCE_RE="$(printf '%s' "$INSTANCE" | sed 's/[][\\.^$*+?(){}|]/\\&/g')"; QUERY_READY=true; printf 'QUERY_READY=true provider=%s machine=%s relation=%s instance=^%s$\n' "$APPROVED_METRICS_PROVIDER" "$MACHINE_ID" "$METRICS_RELATION_ID" "$INSTANCE_RE"; else unset APPROVED_METRICS_PROVIDER INSTANCE INSTANCE_RE METRICS_RELATION_ID; printf '%s\n' '중단: current host/sample/provider/instance relation 미확정' >&2; fi`

parser/API 성공, non-empty series, instance-machine relation, scrape timestamp가 필요하다. missing metric·retention 밖·label mismatch는 0이나 정상 상태가 아니다.

## 변경 분리·정상화·증거

`drop_caches`, sysctl, swap, limit, kill/restart, file 삭제를 실행하지 않는다. 별도 변경마다 fresh host/target identity, direct evidence, 승인 ID, canonical UTC window, quorum·대체 capacity, idempotence, 중단·rollback을 독립 확인한다.

reboot/process/device replacement면 새 identity를 완전히 등록하고 old->new relation을 남긴다. bounded 창에서 `SUnreclaim`, dirty/writeback, reclaim/PSI와 OOM/I/O 오류가 재발하지 않고 실제 서비스 request/read/write가 회복되어야 한다. 한 번의 cache 감소는 충분하지 않다.

보존: machine/boot/kernel/namespaces, UTC 창, 두 sample, exact mount/device 또는 PID/start/cgroup relation, journal producer/filter, provider/query timestamp, 승인·rollback·실제 기능. infrastructure 명령은 작성 중 실행하지 않았다.
