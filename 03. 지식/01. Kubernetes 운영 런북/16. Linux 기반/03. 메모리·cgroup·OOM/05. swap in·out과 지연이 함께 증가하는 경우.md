# swap in·out과 지연이 함께 증가하는 경우

## 입력값과 빠른 수집

| 구분 | 값 | 출처와 gate |
|---|---|---|
| 최초 입력 | approved SSH host, canonical UTC start/end | 한 번만 입력 |
| 시스템 자동값 | machine/boot/kernel/namespace, swap source·device identity | 실제 host에서 수집 |
| 계산 후보값 | epoch, counter delta, escaped instance regex | 두 sample·bounded 출력 전 미확정 |
| 운영자 선택값 | exact swap source, backing relation ID, metrics provider·instance relation | 출력과 승인 관계 확인 뒤 선택 |

경로는 `operator Bash -> SSH -> host namespaces -> /proc/vmstat·PSI -> /proc/swaps -> exact block/file backing -> storage latency`다. Pod 내부 `/proc`는 node 증거가 아니다. Kubernetes swap 해석이 필요할 때만 active kubelet effective config를 확인하며, 이 증상에는 CRI 조회가 필요하지 않다.

## 진입 판단

| 구분 | 판단 기준 |
|---|---|
| 사용 | 같은 host·boot·창에서 `pswpin/pswpout` delta와 memory/application/storage 지연이 함께 증가 |
| 적용 | counter 두 sample, page size, PSI, exact swap backing identity와 latency source를 연결 가능 |
| 제외 | delta 없이 과거 누적값만 큼, 직접 OOM 또는 filesystem I/O error가 우선인 경우 |

검색 문자열: `pswpin`, `pswpout`, `SwapCached`, `some`, `full`, `await`, `I/O error`, `swap`.

## 1. fresh counter와 pressure sample

```bash
SAMPLE_READY=false; DEVICE_CANDIDATES_READY=false; SELECTION_READY=false; EVIDENCE_READY=false; DEVICE_READY=false; QUERY_READY=false; MUTATION_READY=false; ROLLBACK_READY=false; NORMALIZATION_READY=false; unset SWAP_SOURCE SWAP_TYPE DEVICE_MAJMIN DEVICE_WWN FILE_MOUNT_ID BACKING_RELATION_ID APPROVED_METRICS_PROVIDER INSTANCE INSTANCE_RE METRICS_RELATION_ID; if [ "$HOST_READY" != true ]; then printf '%s\n' '중단: HOST_READY가 아니다.' >&2; else ssh "${SSH_OPTS[@]}" -- "$APPROVED_HOST" bash -s -- "$MACHINE_ID" "$BOOT_ID" "$MOUNT_ID" <<'REMOTE'
set -euo pipefail
[ "$(cat /etc/machine-id)" = "$1" ] && [ "$(cat /proc/sys/kernel/random/boot_id)" = "$2" ] && [ "$(stat -Lc %i /proc/1/ns/mnt)" = "$3" ] || exit 40
page_size=$(getconf PAGESIZE); [[ "$page_size" =~ ^[1-9][0-9]*$ ]] || exit 41; printf 'page_size=%s\n' "$page_size"
for n in 1 2; do for key in pswpin pswpout; do grep -q "^$key " /proc/vmstat || exit 42; done; for key in MemAvailable SwapTotal SwapFree; do grep -q "^$key:" /proc/meminfo || exit 43; done; date -u '+sample=%Y-%m-%dT%H:%M:%SZ'; grep -E '^(pswpin|pswpout|pgscan|pgsteal|allocstall) ' /proc/vmstat; grep -E '^(MemAvailable|SwapTotal|SwapFree|SwapCached):' /proc/meminfo; if [ -r /proc/pressure/memory ]; then sed -n '1,4p' /proc/pressure/memory; else printf '%s\n' 'memory-PSI=unavailable'; fi; if [ -r /proc/pressure/io ]; then sed -n '1,4p' /proc/pressure/io; else printf '%s\n' 'io-PSI=unavailable'; fi; [ "$n" -eq 1 ] && sleep 5; done
REMOTE
rc=$?; if [ "$rc" -eq 0 ]; then SAMPLE_READY=true; printf '%s\n' 'SAMPLE_READY=true'; else unset SWAP_SOURCE SWAP_TYPE DEVICE_MAJMIN DEVICE_WWN FILE_MOUNT_ID; SAMPLE_READY=false; DEVICE_READY=false; printf '중단: sample 실패 rc=%s\n' "$rc" >&2; fi; fi
```

성공 gate는 같은 boot에서 두 timestamp와 동일 counter key가 모두 존재하는 것이다. `pswpin/pswpout` 절대값은 boot 누적이다. delta를 bytes로 바꿀 때만 출력된 page size를 사용한다. PSI avg와 total은 swap page counter와 단위가 다르다. 빈 PSI는 0이 아니다.

## 2. swap backing identity

```bash
DEVICE_CANDIDATES_READY=false; SELECTION_READY=false; EVIDENCE_READY=false; DEVICE_READY=false; QUERY_READY=false; MUTATION_READY=false; ROLLBACK_READY=false; NORMALIZATION_READY=false; unset SWAP_SOURCE SWAP_TYPE DEVICE_MAJMIN DEVICE_WWN FILE_MOUNT_ID BACKING_RELATION_ID APPROVED_METRICS_PROVIDER INSTANCE INSTANCE_RE METRICS_RELATION_ID; if [ "$HOST_READY" != true ] || [ "$SAMPLE_READY" != true ]; then printf '%s\n' '중단: current HOST/SAMPLE READY가 아니다.' >&2; else ssh "${SSH_OPTS[@]}" -- "$APPROVED_HOST" bash -s -- "$MACHINE_ID" "$BOOT_ID" "$MOUNT_ID" <<'REMOTE'
set -euo pipefail
[ "$(cat /etc/machine-id)" = "$1" ] && [ "$(cat /proc/sys/kernel/random/boot_id)" = "$2" ] && [ "$(stat -Lc %i /proc/1/ns/mnt)" = "$3" ] || exit 40
date -u '+observed=%Y-%m-%dT%H:%M:%SZ'
if [ ! -r /proc/swaps ]; then exit 41; fi
sed -n '1,40p' /proc/swaps
while read -r name type size used priority; do [ "$name" = Filename ] && continue; printf '\n=== source=%s type=%s ===\n' "$name" "$type"; if [ "$type" = partition ]; then lsblk -dn -o NAME,TYPE,MAJ:MIN,SIZE,ROTA,MODEL,SERIAL,WWN -- "$name"; else findmnt -T "$name" -o TARGET,SOURCE,FSTYPE,OPTIONS,MAJ:MIN -n; stat -Lc 'file-device=%d inode=%i' "$name"; fi; done </proc/swaps
REMOTE
rc=$?; if [ "$rc" -eq 0 ]; then DEVICE_CANDIDATES_READY=true; printf '%s\n' 'DEVICE_CANDIDATES_READY=true'; else unset SWAP_SOURCE SWAP_TYPE DEVICE_MAJMIN DEVICE_WWN FILE_MOUNT_ID BACKING_RELATION_ID; DEVICE_CANDIDATES_READY=false; printf '중단: swap 후보 수집 실패 rc=%s\n' "$rc" >&2; fi; fi
```

후보 출력에서 사건과 연결할 exact source 하나와 storage telemetry까지의 승인 relation을 선택한다.

`SELECTION_READY=false; EVIDENCE_READY=false; DEVICE_READY=false; QUERY_READY=false; MUTATION_READY=false; ROLLBACK_READY=false; NORMALIZATION_READY=false; unset SWAP_SOURCE BACKING_RELATION_ID; read -r -p 'exact swap source: ' SWAP_SOURCE; read -r -p 'backing과 storage telemetry의 승인 relation ID: ' BACKING_RELATION_ID; if [ "$HOST_READY" = true ] && [ "$SAMPLE_READY" = true ] && [ "$DEVICE_CANDIDATES_READY" = true ] && [[ "$SWAP_SOURCE" =~ ^/[A-Za-z0-9_./:@+-]+$ ]] && [ -n "$BACKING_RELATION_ID" ]; then SELECTION_READY=true; printf 'SELECTION_READY=true source=%s relation=%s\n' "$SWAP_SOURCE" "$BACKING_RELATION_ID"; else unset SWAP_SOURCE BACKING_RELATION_ID; printf '%s\n' '중단: current 후보/source/relation gate 오류' >&2; fi`

```bash
DEVICE_READY=false; EVIDENCE_READY=false; QUERY_READY=false; MUTATION_READY=false; ROLLBACK_READY=false; NORMALIZATION_READY=false; unset SWAP_TYPE DEVICE_MAJMIN DEVICE_WWN FILE_MOUNT_ID; if [ "$HOST_READY" != true ] || [ "$SAMPLE_READY" != true ] || [ "$DEVICE_CANDIDATES_READY" != true ] || [ "$SELECTION_READY" != true ]; then printf '%s\n' '중단: current host/sample/candidate/selection gate가 아니다.' >&2; else ssh "${SSH_OPTS[@]}" -- "$APPROVED_HOST" bash -s -- "$MACHINE_ID" "$BOOT_ID" "$MOUNT_ID" "$SWAP_SOURCE" <<'REMOTE'
set -euo pipefail
[ "$(cat /etc/machine-id)" = "$1" ] && [ "$(cat /proc/sys/kernel/random/boot_id)" = "$2" ] && [ "$(stat -Lc %i /proc/1/ns/mnt)" = "$3" ] || exit 40
record=$(awk -v source="$4" '$1==source {count++; type=$2} END {if(count!=1) exit 42; printf "%s\t%s\n", source, type}' /proc/swaps)
IFS=$'\t' read -r source type <<<"$record"
printf 'source=%s type=%s\n' "$source" "$type"
if [ -b "$source" ]; then lsblk -dn -o NAME,TYPE,MAJ:MIN,SIZE,ROTA,MODEL,SERIAL,WWN -- "$source"; else findmnt -T "$source" -o TARGET,SOURCE,FSTYPE,OPTIONS,MAJ:MIN -n; stat -Lc 'file-device=%d inode=%i mountns=%n' "$source"; fi
REMOTE
rc=$?; if [ "$rc" -eq 0 ]; then DEVICE_READY=true; EVIDENCE_READY=true; printf 'DEVICE_READY=true EVIDENCE_READY=true source=%s relation=%s\n' "$SWAP_SOURCE" "$BACKING_RELATION_ID"; else unset SWAP_SOURCE SWAP_TYPE DEVICE_MAJMIN DEVICE_WWN FILE_MOUNT_ID BACKING_RELATION_ID; SELECTION_READY=false; EVIDENCE_READY=false; DEVICE_READY=false; printf '중단: exact swap identity 실패 rc=%s\n' "$rc" >&2; fi; fi
```

각 swap source의 partition/file 유형, `MAJ:MIN`, stable WWN/serial 또는 file mount/device/inode 관계를 기록한다. zram/zswap·encrypted mapping·LVM이면 실제 계층을 owner가 확인한다. `lsblk`/`findmnt` 빈 결과는 device 정상이나 없음이 아니라 identity 미확정이다. latency query의 device label이 이 exact backing과 연결되지 않으면 swap 때문에 storage가 느리다고 확정하지 않는다.

## 3. 조건부 kubelet 경계

Kubernetes node일 때만 실행한다. active kubelet PID·start와 argv를 fresh 확인한다. argv에 값이 없으면 active `--config`가 가리키는 절대경로 regular readable file에서 effective `failSwapOn`과 memory swap behavior를 읽기 전용으로 확인한다.

```bash
KUBELET_READY=false; unset KUBELET_PID KUBELET_PID_START; if [ "$HOST_READY" != true ]; then printf '%s\n' '중단: HOST_READY가 아니다.' >&2; else KUBELET_OUTPUT="$(ssh "${SSH_OPTS[@]}" -- "$APPROVED_HOST" bash -s -- "$MACHINE_ID" "$BOOT_ID" "$MOUNT_ID" "$KUBELET_ARGV_RE" <<'REMOTE'
set -euo pipefail
[ "$(cat /etc/machine-id)" = "$1" ] && [ "$(cat /proc/sys/kernel/random/boot_id)" = "$2" ] && [ "$(stat -Lc %i /proc/1/ns/mnt)" = "$3" ] || exit 40
pid=$(systemctl show kubelet.service -p MainPID --value 2>/dev/null || true); [[ "$pid" =~ ^[1-9][0-9]*$ ]] && [ -r "/proc/$pid/stat" ] || exit 41
printf 'KUBELET_ACTIVE pid=%s start_ticks=%s\n' "$pid" "$(cut -d ' ' -f 22 "/proc/$pid/stat")"
mapfile -d '' -t argv <"/proc/$pid/cmdline"; matches=0; for arg in "${argv[@]}"; do if [[ "$arg" =~ $4 ]]; then printf 'argv=%s\n' "$arg"; matches=$((matches+1)); fi; done; if [ "$matches" -eq 0 ]; then printf '%s\n' 'relevant argv=none; strict effective config 확인 필요'; fi
REMOTE
 )"; rc=$?; if [ "$rc" -eq 0 ] && [[ "$KUBELET_OUTPUT" == KUBELET_ACTIVE* ]]; then printf '%s\n' "$KUBELET_OUTPUT"; KUBELET_READY=true; printf '%s\n' 'KUBELET_READY=true; effective config는 active PID와 함께 기록'; else unset KUBELET_OUTPUT KUBELET_PID KUBELET_PID_START; KUBELET_READY=false; printf '중단: active kubelet gate 실패 rc=%s\n' "$rc" >&2; fi; fi
```

host swap 활성화는 workload swap 허용을 보장하지 않는다. Kubernetes 1.26의 workload swap은 `NodeSwap` alpha feature gate와 `failSwapOn=false` 등 실제 effective kubelet 설정이 모두 확인된 경우에만 해석하며, 설정 파일은 active `--config`가 가리키는 절대경로 regular readable file만 사용한다.

## 변경 분리·정상화·증거

`swapoff/swapon`, limit·sysctl, cache, kubelet/runtime/process를 변경하지 않는다. 외부 변경은 매 항목마다 fresh machine/boot/device/kubelet identity, 직접 evidence, 승인 ID, UTC window, quorum·대체 capacity, idempotence, 중단·rollback을 독립 gate로 확인한다.

reboot/device/workload replacement면 모든 identity를 재등록하고 old->new relation을 남긴다. 새 창에서 swap delta·memory/I/O PSI·exact device latency·application latency가 함께 안정되고 OOM/eviction이 재발하지 않으며 실제 request/read/write가 회복되어야 한다.

보존: machine/boot/namespaces, UTC 창, counter samples/page size, PSI, exact backing identity, active kubelet PID/start/effective swap setting(적용 시), provider query·timestamp, 승인·rollback·실제 기능. infrastructure 명령은 작성 중 실행하지 않았다.
