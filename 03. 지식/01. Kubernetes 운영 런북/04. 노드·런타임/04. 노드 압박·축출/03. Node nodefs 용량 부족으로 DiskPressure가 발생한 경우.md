# Node nodefs 용량 부족으로 DiskPressure가 발생한 경우

## 입력값과 빠른 수집

실행 hop은 `승인된 작업 PC/Bastion → Kubernetes API → 승인된 SSH host → kubelet signal → 실제 nodefs path/mount/source → Linux filesystem`이다. 같은 Bash를 유지하고 `eval`은 사용하지 않는다.

| 종류 | 값 | 확정 방법 |
|---|---|---|
| 최초 입력 | `NODE` | 승인된 Node exact name |
| API 확인 자동값 | `NODE_UID`, `NODE_RV`, runtime provider, Pod UID/owner | 매 단계 fresh API |
| 계산 후보값 | escaped node regex, path가 속한 mount | regex/mount relation 확인 전 미확정 |
| 운영자 선택값 | `START_RFC3339`, `END_RFC3339`, `SSH_HOST`, `NODEFS_PATH` | 사건 시각과 kubelet 설정·signal 근거로 선택 |

`TOOLS_READY=false; MISSING=''; for T in kubectl jq grep sed date ssh; do command -v "$T" >/dev/null 2>&1 || MISSING="$MISSING $T"; done; if [ -z "${BASH_VERSION:-}" ] || [ -n "$MISSING" ]; then printf '중단: Bash/도구 gate 실패%s\n' "$MISSING" >&2; elif kubectl auth whoami >/dev/null 2>&1 && kubectl auth can-i get nodes | grep -Fxq yes && kubectl auth can-i list pods --all-namespaces | grep -Fxq yes; then TOOLS_READY=true; kubectl auth whoami; else printf '%s\n' '중단: 현재 주체/RBAC 실패' >&2; fi`

`unset INPUT_READY AUTO_READY HOST_READY TIME_READY KUBELET_READY STORAGE_READY EVIDENCE_READY MUTATION_READY REPLACEMENT_READY NORMALIZATION_READY DOWNSTREAM_READY NODE_UID NODE_RV POD_UID OWNER_KIND OWNER_NAME OWNER_UID CONTAINER_ID RUNTIME_VERSION RUNTIME_PROVIDER SSH_HOST HOST_IDENTITY KUBELET_UNIT NODEFS_PATH NODEFS_TARGET NODEFS_SOURCE NODEFS_FSTYPE START_RFC3339 END_RFC3339 START_EPOCH END_EPOCH START_CANON END_CANON NODE_RE; SSH_ARGS=(); NODE='PASTE_NODE_HERE'; INPUT_READY=false; if [ "$TOOLS_READY" = true ] && J="$(kubectl get node "$NODE" -o json)" && [ "$(jq -r '.metadata.name' <<<"$J")" = "$NODE" ]; then INPUT_READY=true; printf 'INPUT_READY=true node=%s\n' "$NODE"; else printf '%s\n' '중단: Node exact-name 조회 실패' >&2; fi`

`unset AUTO_READY HOST_READY TIME_READY KUBELET_READY STORAGE_READY EVIDENCE_READY MUTATION_READY REPLACEMENT_READY NORMALIZATION_READY NODE_UID NODE_RV RUNTIME_VERSION RUNTIME_PROVIDER SSH_HOST HOST_IDENTITY KUBELET_UNIT NODEFS_PATH NODEFS_TARGET NODEFS_SOURCE NODEFS_FSTYPE START_RFC3339 END_RFC3339 START_EPOCH END_EPOCH START_CANON END_CANON NODE_RE DOWNSTREAM_READY; SSH_ARGS=(); AUTO_READY=false; if [ "$INPUT_READY" = true ] && J="$(kubectl get node "$NODE" -o json)"; then NODE_UID="$(jq -r '.metadata.uid // empty' <<<"$J")"; NODE_RV="$(jq -r '.metadata.resourceVersion // empty' <<<"$J")"; RUNTIME_VERSION="$(jq -r '.status.nodeInfo.containerRuntimeVersion // empty' <<<"$J")"; case "$RUNTIME_VERSION" in containerd://*) RUNTIME_PROVIDER=containerd;; cri-o://*) RUNTIME_PROVIDER=cri-o;; *) RUNTIME_PROVIDER='';; esac; if [ -n "$NODE_UID" ] && [ -n "$NODE_RV" ] && [ -n "$RUNTIME_PROVIDER" ]; then AUTO_READY=true; jq -r '"Node/UID/RV: \(.metadata.name) \(.metadata.uid) \(.metadata.resourceVersion)\nRuntime: \(.status.nodeInfo.containerRuntimeVersion)\nEphemeral allocatable: \(.status.allocatable["ephemeral-storage"] // "-")\n" + ([.status.conditions[] | "\(.type)=\(.status) reason=\(.reason) transition=\(.lastTransitionTime) message=\(.message)"]|join("\n"))' <<<"$J"; else printf '%s\n' '중단: identity/runtime 등록 실패' >&2; fi; else printf '%s\n' '중단: fresh Node API 실패' >&2; fi`

`fresh_node(){ local j; unset CURRENT_NODE_RV; j="$(kubectl get node "$NODE" -o json)" || return 1; [ "$(jq -r '.metadata.uid' <<<"$j")" = "$NODE_UID" ] || return 1; CURRENT_NODE_RV="$(jq -r '.metadata.resourceVersion // empty' <<<"$j")"; [ -n "$CURRENT_NODE_RV" ]; }`

재등록 전 UID/RV/owner/containerID/node/host/storage relation/time/regex와 downstream `READY`를 unset/false로 만든다. 실패한 값은 재사용하지 않는다.

## 진입 판단

| 구분 | 판단 기준 |
|---|---|
| 사용 | `DiskPressure`와 `nodefs.available` bytes signal이 같은 사건 창에 있음 |
| 적용 | 실제 nodefs path→mount/source와 bytes·inode, kubelet signal을 대조 가능 |
| 제외 | inode-only, imagefs/GC, PVC/CSI, read-only/I/O corruption은 각각 inode/imagefs/storage/Linux 런북으로 이관 |

검색 문자열: `DiskPressure`, `nodefs.available`, `nodefs.inodesFree`, `imagefs.available`, `EvictionThresholdMet`, `ephemeral-storage`, `no space left on device`, `read-only file system`.

## 최초 확인·영향

`fresh_node && kubectl get pods -A --field-selector "spec.nodeName=$NODE" -o json | jq -r '.items[] | "\n=== \(.metadata.namespace)/\(.metadata.name) ===\nUID: \(.metadata.uid)\nOwner: \(.metadata.ownerReferences[0].kind // "-")/\(.metadata.ownerReferences[0].name // "-") UID=\(.metadata.ownerReferences[0].uid // "-")\nPhase: \(.status.phase) Ready=\([.status.containerStatuses[]?.ready]|join(",")) Restarts=\([.status.containerStatuses[]?.restartCount]|join(","))\nEphemeral request/limit: \([.spec.containers[] | "\(.name)=\(.resources.requests["ephemeral-storage"] // "-")/\(.resources.limits["ephemeral-storage"] // "-")"]|join(";"))"'`

request/limit은 실제 nodefs 사용량이 아니다. 빈 목록은 API/RBAC/실제 empty node를 구분한다. replacement는 UID·owner UID로 분리한다.

## 시간·host gate

`START_RFC3339='PASTE_START_RFC3339_HERE'; END_RFC3339='PASTE_END_RFC3339_HERE'; unset TIME_READY KUBELET_READY STORAGE_READY EVIDENCE_READY START_EPOCH END_EPOCH START_CANON END_CANON DOWNSTREAM_READY; TIME_READY=false; if [[ "$START_RFC3339" =~ ^[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}Z$ ]] && [[ "$END_RFC3339" =~ ^[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}Z$ ]] && START_EPOCH="$(date -u -d "$START_RFC3339" +%s 2>/dev/null)" && END_EPOCH="$(date -u -d "$END_RFC3339" +%s 2>/dev/null)"; then START_CANON="$(date -u -d "@$START_EPOCH" '+%Y-%m-%dT%H:%M:%SZ')"; END_CANON="$(date -u -d "@$END_EPOCH" '+%Y-%m-%dT%H:%M:%SZ')"; if [ "$START_RFC3339" = "$START_CANON" ] && [ "$END_RFC3339" = "$END_CANON" ] && [ "$START_EPOCH" -lt "$END_EPOCH" ]; then TIME_READY=true; printf 'TIME_READY=true %s < %s\n' "$START_CANON" "$END_CANON"; else printf '%s\n' '중단: canonical round-trip/start<end 실패' >&2; fi; else printf '%s\n' '중단: strict UTC RFC3339 regex/parse 실패' >&2; fi`

`SSH_HOST='PASTE_APPROVED_SSH_HOST_HERE'; unset HOST_READY KUBELET_READY STORAGE_READY EVIDENCE_READY HOST_IDENTITY DOWNSTREAM_READY; SSH_ARGS=(); HOST_READY=false; if fresh_node && [[ "$SSH_HOST" =~ ^[A-Za-z0-9_.@:-]+$ ]] && [[ "$SSH_HOST" != -* ]]; then SSH_ARGS=(-o BatchMode=yes -o StrictHostKeyChecking=yes -o ClearAllForwardings=yes -o ConnectTimeout=10 "$SSH_HOST"); REMOTE_ID="$(ssh "${SSH_ARGS[@]}" -- 'printf "hostname=%s machine_id=%s boot_id=%s\n" "$(hostname -f 2>/dev/null || hostname)" "$(cat /etc/machine-id 2>/dev/null)" "$(cat /proc/sys/kernel/random/boot_id 2>/dev/null)"')"; SSH_RC=$?; printf '%s\n' "$REMOTE_ID"; read -r -p 'CMDB에서 이 host가 대상 Node임을 확인했으면 Node 이름 입력: ' HOST_CONFIRM; if [ "$SSH_RC" -eq 0 ] && [ "$HOST_CONFIRM" = "$NODE" ] && [[ "$REMOTE_ID" =~ ^hostname=[^[:space:]]+[[:space:]]machine_id=[0-9a-fA-F-]+[[:space:]]boot_id=[0-9a-fA-F-]+$ ]]; then HOST_IDENTITY="$REMOTE_ID"; HOST_READY=true; printf 'HOST_READY=true host=%s node=%s uid=%s rv=%s\n' "$SSH_HOST" "$NODE" "$NODE_UID" "$CURRENT_NODE_RV"; else printf '%s\n' '중단: 원격 host identity/CMDB 승인 실패' >&2; fi; else printf '%s\n' '중단: fresh Node/SSH host 형식 실패' >&2; fi`

`host_guard(){ local now; HOST_READY=false; fresh_node || return 1; now="$(ssh "${SSH_ARGS[@]}" -- 'printf "hostname=%s machine_id=%s boot_id=%s\n" "$(hostname -f 2>/dev/null || hostname)" "$(cat /etc/machine-id 2>/dev/null)" "$(cat /proc/sys/kernel/random/boot_id 2>/dev/null)"')" || return 1; [ "$now" = "$HOST_IDENTITY" ] || return 1; HOST_READY=true; }`

모든 node 명령은 작업 PC에서 `host_guard`를 직접 호출하고 검증된 canonical 시각·절대경로를 SSH positional argument로 전달한다. 작업 PC 변수가 원격 shell에 자동 전달된다고 가정하지 않는다.

## 관측별 진단 경로

| 지금 보이는 것 | 먼저 볼 것 | 그다음 어디를 볼지 | 상세 절 |
|---|---|---|---|
| `nodefs.available` | 실제 path/mount bytes | 제한된 소비 경로·owner | [[#kubelet signal과 storage relation]] |
| `nodefs.inodesFree` | 같은 mount inode | inode 런북 | [[#kubelet signal과 storage relation]] |
| `imagefs.*` | runtime image store mount | imagefs 런북 | [[#kubelet signal과 storage relation]] |
| read-only/I/O/corruption | kernel과 mount source | Linux/filesystem owner | [[#Linux 경계]] |

## kubelet signal과 storage relation

`unset KUBELET_READY KUBELET_UNIT EVIDENCE_READY DOWNSTREAM_READY; KUBELET_READY=false; host_guard || exit 1; UNIT_OUTPUT="$(ssh "${SSH_ARGS[@]}" -- systemctl list-units --type=service --all --no-legend)"; PRODUCER_RC=$?; if [ "$PRODUCER_RC" -eq 0 ]; then mapfile -t KU < <(grep -E '(^|[[:space:]])kubelet\.service([[:space:]]|$)' <<<"$UNIT_OUTPUT" | sed -E 's/^[[:space:]]*([^[:space:]]+).*/\1/'); FILTER_RC=$?; else FILTER_RC=99; fi; if [ "$PRODUCER_RC" -eq 0 ] && [ "$FILTER_RC" -eq 0 ] && [ "${#KU[@]}" -eq 1 ] && ssh "${SSH_ARGS[@]}" -- sudo systemctl is-active --quiet "${KU[0]}"; then KUBELET_UNIT="${KU[0]}"; KUBELET_READY=true; printf 'KUBELET_READY=true unit=%s\n' "$KUBELET_UNIT"; else printf '중단: kubelet producer=%s filter=%s candidates=%s\n' "$PRODUCER_RC" "$FILTER_RC" "${#KU[@]}" >&2; fi`

`host_guard || exit 1; [ "$KUBELET_READY" = true ] && [ "$TIME_READY" = true ] || exit 1; TMP="$(mktemp)" || exit 1; ssh "${SSH_ARGS[@]}" -- sudo journalctl -u "$KUBELET_UNIT" --since "$START_CANON" --until "$END_CANON" --no-pager >"$TMP"; PRODUCER_RC=$?; if [ "$PRODUCER_RC" -eq 0 ]; then grep -E -i -C 3 'DiskPressure|nodefs\.available|nodefs\.inodesFree|imagefs\.available|imagefs\.inodesFree|ephemeral-storage|EvictionThresholdMet|no space left on device|read-only file system' "$TMP"; FILTER_RC=$?; else FILTER_RC=99; fi; rm -f "$TMP"; printf 'producer_rc=%s filter_rc=%s\n' "$PRODUCER_RC" "$FILTER_RC"; [ "$PRODUCER_RC" -eq 0 ] && { [ "$FILTER_RC" -eq 0 ] || [ "$FILTER_RC" -eq 1 ]; }`

`NODEFS_PATH='PASTE_CONFIRMED_NODEFS_PATH_HERE'; unset STORAGE_READY NODEFS_TARGET NODEFS_SOURCE NODEFS_FSTYPE DOWNSTREAM_READY; STORAGE_READY=false; if host_guard && [[ "$NODEFS_PATH" =~ ^/[-A-Za-z0-9._/]+$ ]]; then MAP="$(ssh "${SSH_ARGS[@]}" -- findmnt -T "$NODEFS_PATH" -rn -o TARGET,SOURCE,FSTYPE)"; PRODUCER_RC=$?; if [ "$PRODUCER_RC" -eq 0 ] && [ "$(wc -l <<<"$MAP")" -eq 1 ]; then read -r NODEFS_TARGET NODEFS_SOURCE NODEFS_FSTYPE <<<"$MAP"; fi; if [ -n "$NODEFS_TARGET" ] && [ -n "$NODEFS_SOURCE" ] && [ -n "$NODEFS_FSTYPE" ]; then STORAGE_READY=true; printf 'STORAGE_READY=true path=%s target=%s source=%s fstype=%s\n' "$NODEFS_PATH" "$NODEFS_TARGET" "$NODEFS_SOURCE" "$NODEFS_FSTYPE"; else printf '중단: findmnt producer=%s 또는 exact-one relation 실패\n' "$PRODUCER_RC" >&2; fi; else printf '%s\n' '중단: fresh host/안전한 absolute path 실패' >&2; fi`

`host_guard || exit 1; CURRENT_MAP="$(ssh "${SSH_ARGS[@]}" -- findmnt -T "$NODEFS_PATH" -rn -o TARGET,SOURCE,FSTYPE)"; [ "$STORAGE_READY" = true ] && [ "$CURRENT_MAP" = "$MAP" ] && ssh "${SSH_ARGS[@]}" -- df -hT -- "$NODEFS_PATH"`

`host_guard || exit 1; CURRENT_MAP="$(ssh "${SSH_ARGS[@]}" -- findmnt -T "$NODEFS_PATH" -rn -o TARGET,SOURCE,FSTYPE)"; [ "$STORAGE_READY" = true ] && [ "$CURRENT_MAP" = "$MAP" ] && ssh "${SSH_ARGS[@]}" -- df -iT -- "$NODEFS_PATH"`

`nodefs.available`와 bytes 부족, 실제 mount relation, 사건 시간이 모두 맞아야 nodefs bytes 원인이다. inode-only는 inode 런북, imagefs-only는 imagefs 런북으로 이동한다. 현재 `df`는 과거 peak를 보장하지 않는다. kubelet configz/proxy는 `kubectl auth can-i get nodes/proxy`와 승인된 endpoint를 fresh 확인한 경우만 사용하고, 기본 threshold를 추측하지 않는다.

## Linux 경계

`host_guard || exit 1; [ "$STORAGE_READY" = true ] && [ "$TIME_READY" = true ] || exit 1; TMP="$(mktemp)" || exit 1; ssh "${SSH_ARGS[@]}" -- sudo journalctl -k --since "$START_CANON" --until "$END_CANON" --no-pager >"$TMP"; PRODUCER_RC=$?; if [ "$PRODUCER_RC" -eq 0 ]; then grep -E -i -C 3 'I/O error|read-only|filesystem|remount|ext4|xfs|overlay|no space left on device|corrupt' "$TMP"; FILTER_RC=$?; else FILTER_RC=99; fi; rm -f "$TMP"; printf 'producer_rc=%s filter_rc=%s\n' "$PRODUCER_RC" "$FILTER_RC"; [ "$PRODUCER_RC" -eq 0 ] && { [ "$FILTER_RC" -eq 0 ] || [ "$FILTER_RC" -eq 1 ]; }`

producer/filter RC와 `start <= signal/error <= end`를 분리 기록한다. `filter_rc=1`은 오류 부재가 아니다. read-only/I/O/corruption이면 삭제·정리로 진행하지 않고 Linux/filesystem owner에게 이관한다. PVC/CSI mount는 nodefs와 합치지 않는다.

## 보안·변경·정상화

Secret/token/key, 파일 내용·전체 목록, args/env, 전체 journal을 저장하지 않는다. 정확한 RBAC과 audit 최소 필드는 별도 승인 경로로 확인한다.

이 문서는 삭제/정리 명령을 제공하지 않는다. `rm`, truncate, 광범위 `du/find`, image prune, Pod/PVC/emptyDir 삭제, restart/reboot/cordon/drain은 금지한다. 별도 변경은 fresh evidence, 승인/window, owner, PDB/quorum, 대체 capacity, idempotence·외부 write, rollback/비가역 중단 계획을 요구한다.

이 문서 안에서는 `MUTATION_READY=false`를 유지한다. 별도 변경 절차가 실제 명령을 제공할 때 그 명령 자체가 fresh Node UID/RV·host identity·path→mount/source/fstype·evidence window·승인 ID·owner·PDB/quorum·멱등성·rollback 또는 비가역 중단 조건을 다시 검사해야 한다.

실제 조치는 승인된 owner 절차에서만 수행한다. replacement는 새 Pod UID/RV·owner UID·node·container ID를 재등록하고 Ready 전 downstream을 금지한다.

`NORMALIZATION_READY=false; CURRENT_MAP=''; if fresh_node && host_guard && J="$(kubectl get node "$NODE" -o json)" && CURRENT_MAP="$(ssh "${SSH_ARGS[@]}" -- findmnt -T "$NODEFS_PATH" -rn -o TARGET,SOURCE,FSTYPE)" && [ "$(jq -r '[.status.conditions[]|select(.type=="DiskPressure")|.status][0]' <<<"$J")" = False ] && [ "$STORAGE_READY" = true ] && [ "$CURRENT_MAP" = "$MAP" ]; then NORMALIZATION_READY=true; printf 'NORMALIZATION_READY=true node_uid=%s rv=%s mount=%s\n' "$NODE_UID" "$CURRENT_NODE_RV" "$NODEFS_TARGET"; else printf '%s\n' '중단: condition/remote identity/mount fresh 정상화 gate 실패' >&2; fi`

정상화는 bytes와 inode 안정, 새 nodefs signal/write 오류 부재, replacement Ready/restart 안정, owner desired=Ready, EndpointSlice `ready=true`, 실제 요청 또는 Job 산출물까지 확인해야 한다.

## Prometheus 빠른 관측

`fresh_node || exit 1; host_guard || exit 1; CURRENT_MAP="$(ssh "${SSH_ARGS[@]}" -- findmnt -T "$NODEFS_PATH" -rn -o TARGET,SOURCE,FSTYPE)"; [ "$STORAGE_READY" = true ] && [ "$CURRENT_MAP" = "$MAP" ] || exit 1; NODE_RE="$(printf '%s' "$NODE" | sed 's/[][\\.^$*+?(){}|]/\\&/g')"; MOUNT_RE="$(printf '%s' "$NODEFS_TARGET" | sed 's/[][\\.^$*+?(){}|]/\\&/g')"; printf '100*(1-node_filesystem_avail_bytes{nodename=~"^%s$",mountpoint=~"^%s$",fstype!~"tmpfs|overlay"}/node_filesystem_size_bytes{nodename=~"^%s$",mountpoint=~"^%s$",fstype!~"tmpfs|overlay"})\n' "$NODE_RE" "$MOUNT_RE" "$NODE_RE" "$MOUNT_RE"`

완성 쿼리만 UI에 붙이며 metric/label/mount relabel 미확인이나 빈 결과를 정상으로 보지 않는다.

## 증거·환경 미검증

Node UID/RV, Pod UID/owner, canonical 시간, remote identity, kubelet producer/filter RC, path→mount/source/fstype relation, bytes/inode, 승인·replacement·정상화를 보존한다. threshold source, nodefs mapping, SSH/NTP/audit/metrics/filesystem 구현은 환경별 미검증이다. 실제 인프라에는 실행하지 않았다.
