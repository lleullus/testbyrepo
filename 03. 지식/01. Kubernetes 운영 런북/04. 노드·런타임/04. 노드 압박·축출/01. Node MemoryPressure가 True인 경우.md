# Node MemoryPressure가 True인 경우

## 입력값과 빠른 수집

실행 hop은 `승인된 작업 PC/Bastion → Kubernetes API → 승인된 SSH host → 실제 Node/Linux memory·kubelet`이다. 같은 Bash를 유지하고 `eval`은 사용하지 않는다.

| 종류 | 값 | 확정 방법 |
|---|---|---|
| 최초 입력 | `NODE` | 승인된 Node exact name |
| API 확인 자동값 | `NODE_UID`, `NODE_RV`, condition·runtime version, same-node Pod UID/owner | 매 조회 직전 API 재확인 |
| 계산 후보값 | condition 시각 기반 관측 창, PromQL의 escaped node regex | canonical/escape 검증 전 미확정 |
| 운영자 선택값 | `START_RFC3339`, `END_RFC3339`, `SSH_HOST`, 실제 `KUBELET_UNIT` | 사건·CMDB·systemd 근거로 선택 |

`TOOLS_READY=false; MISSING=''; for T in kubectl jq grep sed date ssh; do command -v "$T" >/dev/null 2>&1 || MISSING="$MISSING $T"; done; if [ -z "${BASH_VERSION:-}" ] || [ -n "$MISSING" ]; then printf '중단: Bash/도구 gate 실패%s\n' "$MISSING" >&2; elif kubectl auth whoami >/dev/null 2>&1 && kubectl auth can-i get nodes | grep -Fxq yes && kubectl auth can-i list pods --all-namespaces | grep -Fxq yes; then TOOLS_READY=true; kubectl auth whoami; else printf '%s\n' '중단: 현재 주체 또는 get nodes/list pods RBAC 실패' >&2; fi`

`unset INPUT_READY AUTO_READY HOST_READY TIME_READY KUBELET_READY EVIDENCE_READY MUTATION_READY REPLACEMENT_READY NORMALIZATION_READY DOWNSTREAM_READY NODE_UID NODE_RV OWNER_KIND OWNER_NAME OWNER_UID CONTAINER_ID POD_UID RUNTIME_VERSION RUNTIME_PROVIDER SSH_HOST HOST_IDENTITY KUBELET_UNIT START_RFC3339 END_RFC3339 START_EPOCH END_EPOCH START_CANON END_CANON NODE_RE; SSH_ARGS=(); NODE='PASTE_NODE_HERE'; INPUT_READY=false; if [ "$TOOLS_READY" = true ] && J="$(kubectl get node "$NODE" -o json)" && [ "$(jq -r '.metadata.name' <<<"$J")" = "$NODE" ]; then INPUT_READY=true; printf 'INPUT_READY=true node=%s\n' "$NODE"; else printf '%s\n' '중단: Node exact-name 조회 실패' >&2; fi`

`unset AUTO_READY HOST_READY TIME_READY KUBELET_READY EVIDENCE_READY MUTATION_READY REPLACEMENT_READY NORMALIZATION_READY NODE_UID NODE_RV RUNTIME_VERSION RUNTIME_PROVIDER SSH_HOST HOST_IDENTITY KUBELET_UNIT START_RFC3339 END_RFC3339 START_EPOCH END_EPOCH START_CANON END_CANON NODE_RE DOWNSTREAM_READY; SSH_ARGS=(); AUTO_READY=false; if [ "$INPUT_READY" = true ] && J="$(kubectl get node "$NODE" -o json)"; then NODE_UID="$(jq -r '.metadata.uid // empty' <<<"$J")"; NODE_RV="$(jq -r '.metadata.resourceVersion // empty' <<<"$J")"; RUNTIME_VERSION="$(jq -r '.status.nodeInfo.containerRuntimeVersion // empty' <<<"$J")"; case "$RUNTIME_VERSION" in containerd://*) RUNTIME_PROVIDER=containerd;; cri-o://*) RUNTIME_PROVIDER=cri-o;; *) RUNTIME_PROVIDER='';; esac; if [ -n "$NODE_UID" ] && [ -n "$NODE_RV" ] && [ -n "$RUNTIME_PROVIDER" ]; then AUTO_READY=true; jq -r '"=== Node ===\n이름/UID/RV: \(.metadata.name) \(.metadata.uid) \(.metadata.resourceVersion)\nRuntime: \(.status.nodeInfo.containerRuntimeVersion)\nMemory: allocatable=\(.status.allocatable.memory) capacity=\(.status.capacity.memory)\n" + ([.status.conditions[] | "Condition: \(.type)=\(.status) reason=\(.reason) heartbeat=\(.lastHeartbeatTime) transition=\(.lastTransitionTime)"] | join("\n"))' <<<"$J"; else printf '%s\n' '중단: Node identity/runtime provider 자동 등록 실패' >&2; fi; else printf '%s\n' '중단: fresh Node API 실패' >&2; fi`

`fresh_node(){ local j; unset CURRENT_NODE_RV; j="$(kubectl get node "$NODE" -o json)" || return 1; [ "$(jq -r '.metadata.uid' <<<"$j")" = "$NODE_UID" ] || return 1; CURRENT_NODE_RV="$(jq -r '.metadata.resourceVersion // empty' <<<"$j")"; [ -n "$CURRENT_NODE_RV" ]; }`

재등록 전에는 UID/RV/owner/containerID/node/host/relation/time/argv-regex와 모든 downstream `READY`를 unset/false로 만든다. 실패 뒤 과거 값은 사용하지 않는다.

## 진입 판단

| 구분 | 판단 기준 |
|---|---|
| 사용 | 현재 또는 사건 기록의 `MemoryPressure=True` |
| 적용 | Node UID/RV, condition 시각, kubelet `memory.available`, Linux memory와 same-node 영향의 시간 관계를 확인 가능 |
| 제외 | 단일 cgroup `OOMKilled`, 단일 `Evicted`, system OOM 다중 종료, Disk/PID pressure는 각각 해당 런북으로 이관 |

검색 문자열: `MemoryPressure`, `NodeHasMemoryPressure`, `EvictionThresholdMet`, `memory.available`, `must evict`, `oom-kill`, `Killed process`.

## 최초 확인과 영향 범위

`fresh_node && kubectl get node "$NODE" -o json | jq -r '"UID/RV: \(.metadata.uid) \(.metadata.resourceVersion)\n" + ([.status.conditions[] | "\(.type)=\(.status) reason=\(.reason) message=\(.message) heartbeat=\(.lastHeartbeatTime) transition=\(.lastTransitionTime)"]|join("\n"))'`

`fresh_node && kubectl get pods -A --field-selector "spec.nodeName=$NODE" -o json | jq -r '.items[] | "\n=== \(.metadata.namespace)/\(.metadata.name) ===\nUID: \(.metadata.uid)\nOwner: \(.metadata.ownerReferences[0].kind // "-")/\(.metadata.ownerReferences[0].name // "-") UID=\(.metadata.ownerReferences[0].uid // "-")\nPhase: \(.status.phase)\nReady: \([.status.containerStatuses[]?.ready]|join(","))\nRestarts: \([.status.containerStatuses[]?.restartCount]|join(","))\nLast reason/time: \([.status.containerStatuses[]? | "\(.lastState.terminated.reason // "-")@\(.lastState.terminated.finishedAt // "-")"]|join(","))"'`

빈 Pod 목록은 정상으로 보지 않는다. API 실패, RBAC, 실제 empty node를 구분한다. Pod UID·owner UID와 종료 시각을 묶어 기록하며 replacement 이름만 비교하지 않는다.

## 시간과 host gate

`START_RFC3339='PASTE_START_RFC3339_HERE'; END_RFC3339='PASTE_END_RFC3339_HERE'; unset TIME_READY KUBELET_READY EVIDENCE_READY START_EPOCH END_EPOCH START_CANON END_CANON DOWNSTREAM_READY; TIME_READY=false; if [[ "$START_RFC3339" =~ ^[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}Z$ ]] && [[ "$END_RFC3339" =~ ^[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}Z$ ]] && START_EPOCH="$(date -u -d "$START_RFC3339" +%s 2>/dev/null)" && END_EPOCH="$(date -u -d "$END_RFC3339" +%s 2>/dev/null)"; then START_CANON="$(date -u -d "@$START_EPOCH" '+%Y-%m-%dT%H:%M:%SZ')"; END_CANON="$(date -u -d "@$END_EPOCH" '+%Y-%m-%dT%H:%M:%SZ')"; if [ "$START_RFC3339" = "$START_CANON" ] && [ "$END_RFC3339" = "$END_CANON" ] && [ "$START_EPOCH" -lt "$END_EPOCH" ]; then TIME_READY=true; printf 'TIME_READY=true %s < %s\n' "$START_CANON" "$END_CANON"; else printf '%s\n' '중단: RFC3339 canonical round-trip/start<end 실패' >&2; fi; else printf '%s\n' '중단: strict UTC RFC3339 regex/parse 실패' >&2; fi`

`SSH_HOST='PASTE_APPROVED_SSH_HOST_HERE'; unset HOST_READY KUBELET_READY EVIDENCE_READY HOST_IDENTITY DOWNSTREAM_READY; SSH_ARGS=(); HOST_READY=false; if fresh_node && [[ "$SSH_HOST" =~ ^[A-Za-z0-9_.@:-]+$ ]] && [[ "$SSH_HOST" != -* ]]; then SSH_ARGS=(-o BatchMode=yes -o StrictHostKeyChecking=yes -o ClearAllForwardings=yes -o ConnectTimeout=10 "$SSH_HOST"); REMOTE_ID="$(ssh "${SSH_ARGS[@]}" -- 'printf "hostname=%s machine_id=%s boot_id=%s\n" "$(hostname -f 2>/dev/null || hostname)" "$(cat /etc/machine-id 2>/dev/null)" "$(cat /proc/sys/kernel/random/boot_id 2>/dev/null)"')"; SSH_RC=$?; printf '%s\n' "$REMOTE_ID"; read -r -p 'CMDB에서 이 host가 대상 Node임을 확인했으면 Node 이름 입력: ' HOST_CONFIRM; if [ "$SSH_RC" -eq 0 ] && [ "$HOST_CONFIRM" = "$NODE" ] && [[ "$REMOTE_ID" =~ ^hostname=[^[:space:]]+[[:space:]]machine_id=[0-9a-fA-F-]+[[:space:]]boot_id=[0-9a-fA-F-]+$ ]]; then HOST_IDENTITY="$REMOTE_ID"; HOST_READY=true; printf 'HOST_READY=true host=%s node=%s uid=%s rv=%s\n' "$SSH_HOST" "$NODE" "$NODE_UID" "$CURRENT_NODE_RV"; else printf '%s\n' '중단: 원격 host identity/CMDB 승인 실패' >&2; fi; else printf '%s\n' '중단: fresh Node/SSH host 형식 실패' >&2; fi`

`host_guard(){ local now; HOST_READY=false; fresh_node || return 1; now="$(ssh "${SSH_ARGS[@]}" -- 'printf "hostname=%s machine_id=%s boot_id=%s\n" "$(hostname -f 2>/dev/null || hostname)" "$(cat /etc/machine-id 2>/dev/null)" "$(cat /proc/sys/kernel/random/boot_id 2>/dev/null)"')" || return 1; [ "$now" = "$HOST_IDENTITY" ] || return 1; HOST_READY=true; }`

모든 node 명령은 작업 PC에서 `host_guard`를 직접 호출하고 검증된 값을 SSH positional argument로 전달한다. 작업 PC 변수가 원격 shell에 자동 전달된다고 가정하지 않으며, `127.0.0.1`은 해당 원격 host의 network namespace다.

## 관측별 진단 경로

| 지금 보이는 것 | 먼저 볼 것 | 그다음 어디를 볼지 | 상세 절 |
|---|---|---|---|
| `MemoryPressure=True` | condition transition과 kubelet signal | Linux `MemAvailable`·PSI | [[#kubelet과 Linux 증거]] |
| 여러 owner가 동시에 restart/Evicted | UID별 종료 시각 | system OOM 또는 eviction 분리 | [[#kubelet과 Linux 증거]] |
| 현재 메모리는 정상 | 사건 창의 journal/metrics | 과거 peak 미검증으로 유지 | [[#kubelet과 Linux 증거]] |

## kubelet과 Linux 증거

원격에서 실제 unit을 확인하고 active unit 하나만 선택한다.

`unset KUBELET_READY KUBELET_UNIT EVIDENCE_READY DOWNSTREAM_READY; KUBELET_READY=false; host_guard || exit 1; UNIT_OUTPUT="$(ssh "${SSH_ARGS[@]}" -- systemctl list-units --type=service --all --no-legend)"; PRODUCER_RC=$?; if [ "$PRODUCER_RC" -eq 0 ]; then mapfile -t KU < <(grep -E '(^|[[:space:]])kubelet\.service([[:space:]]|$)' <<<"$UNIT_OUTPUT" | sed -E 's/^[[:space:]]*([^[:space:]]+).*/\1/'); FILTER_RC=$?; else FILTER_RC=99; fi; if [ "$PRODUCER_RC" -eq 0 ] && [ "$FILTER_RC" -eq 0 ] && [ "${#KU[@]}" -eq 1 ] && ssh "${SSH_ARGS[@]}" -- sudo systemctl is-active --quiet "${KU[0]}"; then KUBELET_UNIT="${KU[0]}"; KUBELET_READY=true; printf 'KUBELET_READY=true unit=%s\n' "$KUBELET_UNIT"; else printf '중단: kubelet producer=%s filter=%s candidates=%s\n' "$PRODUCER_RC" "$FILTER_RC" "${#KU[@]}" >&2; fi`

`host_guard || exit 1; [ "$KUBELET_READY" = true ] && [ "$TIME_READY" = true ] || exit 1; TMP="$(mktemp)" || exit 1; ssh "${SSH_ARGS[@]}" -- sudo journalctl -u "$KUBELET_UNIT" --since "$START_CANON" --until "$END_CANON" --no-pager >"$TMP"; PRODUCER_RC=$?; if [ "$PRODUCER_RC" -eq 0 ]; then grep -E -i -C 3 'eviction manager|must evict|EvictionThresholdMet|memory\.available|memory pressure|threshold|evict|oom' "$TMP"; FILTER_RC=$?; else FILTER_RC=99; fi; rm -f "$TMP"; printf 'producer_rc=%s filter_rc=%s\n' "$PRODUCER_RC" "$FILTER_RC"; [ "$PRODUCER_RC" -eq 0 ] && { [ "$FILTER_RC" -eq 0 ] || [ "$FILTER_RC" -eq 1 ]; }`

`host_guard || exit 1; printf '%s\n' '=== current Linux memory; 과거 peak 아님 ==='; ssh "${SSH_ARGS[@]}" -- free -h; host_guard || exit 1; ssh "${SSH_ARGS[@]}" -- grep -E '^(MemTotal|MemFree|MemAvailable|SwapTotal|SwapFree|Dirty|Slab|SReclaimable):' /proc/meminfo; host_guard || exit 1; ssh "${SSH_ARGS[@]}" -- cat /proc/pressure/memory`

`host_guard || exit 1; [ "$TIME_READY" = true ] || exit 1; TMP="$(mktemp)" || exit 1; ssh "${SSH_ARGS[@]}" -- sudo journalctl -k --since "$START_CANON" --until "$END_CANON" --no-pager >"$TMP"; PRODUCER_RC=$?; if [ "$PRODUCER_RC" -eq 0 ]; then grep -E -i -C 3 'oom-kill|out of memory|killed process|task_memcg|memory cgroup|page allocation failure|invoked oom-killer' "$TMP"; FILTER_RC=$?; else FILTER_RC=99; fi; rm -f "$TMP"; printf 'producer_rc=%s filter_rc=%s\n' "$PRODUCER_RC" "$FILTER_RC"; [ "$PRODUCER_RC" -eq 0 ] && { [ "$FILTER_RC" -eq 0 ] || [ "$FILTER_RC" -eq 1 ]; }`

`producer_rc!=0`은 조회 실패, `filter_rc=1`은 일치 없음, `filter_rc>1`은 filter 실패다. 빈 결과를 오류 없음으로 기록하지 않는다. condition transition, Pod finishedAt, kubelet signal, kernel 행은 canonical UTC에서 `start <= evidence <= end`인지 대조한다. host clock 관계가 확인되지 않으면 시간 상관은 미확정이다.

`MemoryPressure=True + memory.available threshold + same-node 영향`은 node pressure를 지지한다. `CONSTRAINT_NONE` global OOM과 다중 종료면 system OOM 런북으로, 특정 memcg와 단일 container면 Pod OOM 런북으로, `must evict`와 `Evicted`면 eviction 런북으로 이동한다. 현재 `free` 정상은 과거 pressure를 반증하지 않는다.

## 보안·변경·정상화

현재 주체의 정확한 RBAC은 사용한 verb/resource 범위로 확인한다. Node proxy가 필요하면 `kubectl auth can-i get nodes/proxy`를 별도로 확인하고, 거부되면 우회하지 않는다. audit은 승인된 backend owner에게 최소 필드만 요청한다. Secret/token/private key, 전체 process cmdline·환경, 전체 journal은 저장하지 않는다.

이 문서는 mutation 명령을 제공하지 않는다. limit 상향, Pod 삭제, kill, drop_caches, swap 변경, kubelet/runtime restart, cordon/drain/reboot는 fresh evidence·승인·window·PDB/quorum·대체 capacity·멱등성/외부 write·rollback 또는 비가역 중단 계획이 모두 확인되기 전 금지한다.

이 문서 안에서는 `MUTATION_READY=false`를 유지한다. 별도 변경 절차가 실제 명령을 제공할 때 그 명령 자체가 fresh Node UID/RV·host identity·evidence window·승인 ID·PDB/quorum·대체 capacity·멱등성·rollback 또는 비가역 중단 조건을 다시 검사해야 한다.

실제 변경은 승인된 별도 절차에서만 수행한다. replacement가 생기면 이름이 아니라 새 Pod UID/RV·owner UID·node·container ID를 재등록하고, 후보가 0/복수면 `REPLACEMENT_READY=false`로 중단한다.

`NORMALIZATION_READY=false; if fresh_node && J="$(kubectl get node "$NODE" -o json)" && [ "$(jq -r '[.status.conditions[]|select(.type=="MemoryPressure")|.status][0]' <<<"$J")" = False ]; then NORMALIZATION_READY=true; printf 'NORMALIZATION_READY=true node_uid=%s rv=%s\n' "$NODE_UID" "$CURRENT_NODE_RV"; else printf '%s\n' '중단: MemoryPressure=False fresh gate 실패' >&2; fi`

이 gate만으로 정상화하지 않는다. 관찰 window 동안 새 kubelet memory signal·kernel OOM·Evicted/restart가 없고 Linux memory/PSI가 안정되며, 영향 owner의 desired=Ready, EndpointSlice `ready=true`, 실제 요청 또는 Job 산출물이 정상이어야 한다. 실패하면 추가 변경을 중단한다.

## Prometheus 빠른 관측

`fresh_node || exit 1; NODE_RE="$(printf '%s' "$NODE" | sed 's/[][\\.^$*+?(){}|]/\\&/g')"; printf 'kube_node_status_condition{node=~"^%s$",condition="MemoryPressure",status="true"} == 1\n' "$NODE_RE"; printf '100 * node_memory_MemAvailable_bytes{nodename=~"^%s$"} / node_memory_MemTotal_bytes{nodename=~"^%s$"}\n' "$NODE_RE" "$NODE_RE"`

완성 쿼리 출력만 승인된 UI에 붙인다. `nodename` label과 metric 수집 여부를 먼저 확인하며 빈 결과는 정상/0이 아니다.

## 증거·환경 미검증

Node UID/RV, condition·시각, same-node Pod UID/owner, 원격 host/machine-id, canonical 시간, producer/filter RC와 결정적 행, 승인·변경·replacement·정상화 결과를 보존한다. cgroup 버전, kubelet threshold source, Linux 배포판, SSH mapping, NTP, audit, metrics label은 환경별 미검증이다. 실제 인프라 명령은 실행하지 않았다.
