# Node imagefs 용량 부족·image garbage collection이 실패한 경우

## 입력값과 빠른 수집

실행 hop은 `승인된 작업 PC/Bastion → Kubernetes API → 승인된 SSH host → active kubelet → 실제 CRI provider/runtime image store → imagefs mount`이다. 같은 Bash를 유지하고 `eval`은 사용하지 않는다.

| 종류 | 값 | 확정 방법 |
|---|---|---|
| 최초 입력 | `NODE` | 승인된 Node exact name |
| API 확인 자동값 | `NODE_UID`, `NODE_RV`, `RUNTIME_PROVIDER`, 영향 Pod UID/owner | fresh API |
| 계산 후보값 | kubelet argv의 `CRI_ENDPOINT`, runtime image path의 mount, escaped regex | exact-one/provider/mount 대조 전 미확정 |
| 운영자 선택값 | `START_RFC3339`, `END_RFC3339`, `SSH_HOST`, 실제 `RUNTIME_DATA_PATH` | 사건·CMDB·runtime config 근거로 선택 |

`TOOLS_READY=false; MISSING=''; for T in kubectl jq grep sed date ssh; do command -v "$T" >/dev/null 2>&1 || MISSING="$MISSING $T"; done; if [ -z "${BASH_VERSION:-}" ] || [ -n "$MISSING" ]; then printf '중단: Bash/도구 gate 실패%s\n' "$MISSING" >&2; elif kubectl auth whoami >/dev/null 2>&1 && kubectl auth can-i get nodes | grep -Fxq yes && kubectl auth can-i list pods --all-namespaces | grep -Fxq yes; then TOOLS_READY=true; kubectl auth whoami; else printf '%s\n' '중단: 현재 주체/RBAC 실패' >&2; fi`

`unset INPUT_READY AUTO_READY HOST_READY TIME_READY KUBELET_READY CRI_READY STORAGE_READY EVIDENCE_READY MUTATION_READY REPLACEMENT_READY NORMALIZATION_READY DOWNSTREAM_READY NODE_UID NODE_RV POD_UID OWNER_KIND OWNER_NAME OWNER_UID CONTAINER_ID RUNTIME_VERSION RUNTIME_PROVIDER SSH_HOST HOST_IDENTITY KUBELET_UNIT RUNTIME_UNIT RUNTIME_MAIN_PID CRI_ENDPOINT CRI_SOCKET RUNTIME_DATA_PATH IMAGEFS_TARGET IMAGEFS_SOURCE IMAGEFS_FSTYPE START_RFC3339 END_RFC3339 START_EPOCH END_EPOCH START_CANON END_CANON ARGV_RE NODE_RE; SSH_ARGS=(); NODE='PASTE_NODE_HERE'; INPUT_READY=false; if [ "$TOOLS_READY" = true ] && J="$(kubectl get node "$NODE" -o json)" && [ "$(jq -r '.metadata.name' <<<"$J")" = "$NODE" ]; then INPUT_READY=true; printf 'INPUT_READY=true node=%s\n' "$NODE"; else printf '%s\n' '중단: Node exact-name 조회 실패' >&2; fi`

`unset AUTO_READY HOST_READY TIME_READY KUBELET_READY CRI_READY STORAGE_READY EVIDENCE_READY MUTATION_READY REPLACEMENT_READY NORMALIZATION_READY NODE_UID NODE_RV RUNTIME_VERSION RUNTIME_PROVIDER SSH_HOST HOST_IDENTITY KUBELET_UNIT RUNTIME_UNIT RUNTIME_MAIN_PID CRI_ENDPOINT CRI_SOCKET RUNTIME_DATA_PATH IMAGEFS_TARGET IMAGEFS_SOURCE IMAGEFS_FSTYPE START_RFC3339 END_RFC3339 START_EPOCH END_EPOCH START_CANON END_CANON ARGV_RE NODE_RE DOWNSTREAM_READY; SSH_ARGS=(); AUTO_READY=false; if [ "$INPUT_READY" = true ] && J="$(kubectl get node "$NODE" -o json)"; then NODE_UID="$(jq -r '.metadata.uid // empty' <<<"$J")"; NODE_RV="$(jq -r '.metadata.resourceVersion // empty' <<<"$J")"; RUNTIME_VERSION="$(jq -r '.status.nodeInfo.containerRuntimeVersion // empty' <<<"$J")"; case "$RUNTIME_VERSION" in containerd://*) RUNTIME_PROVIDER=containerd;; cri-o://*) RUNTIME_PROVIDER=cri-o;; *) RUNTIME_PROVIDER='';; esac; if [ -n "$NODE_UID" ] && [ -n "$NODE_RV" ] && [ -n "$RUNTIME_PROVIDER" ]; then AUTO_READY=true; jq -r '"Node/UID/RV: \(.metadata.name) \(.metadata.uid) \(.metadata.resourceVersion)\nRuntime: \(.status.nodeInfo.containerRuntimeVersion)\n" + ([.status.conditions[] | "\(.type)=\(.status) reason=\(.reason) transition=\(.lastTransitionTime) message=\(.message)"]|join("\n"))' <<<"$J"; else printf '%s\n' '중단: identity/runtime provider 등록 실패' >&2; fi; else printf '%s\n' '중단: fresh Node API 실패' >&2; fi`

`fresh_node(){ local j; unset CURRENT_NODE_RV; j="$(kubectl get node "$NODE" -o json)" || return 1; [ "$(jq -r '.metadata.uid' <<<"$j")" = "$NODE_UID" ] || return 1; CURRENT_NODE_RV="$(jq -r '.metadata.resourceVersion // empty' <<<"$j")"; [ -n "$CURRENT_NODE_RV" ]; }`

재등록 전에 UID/RV/owner/containerID/node/host/storage/runtime relation/time/argv-regex와 downstream `READY`를 unset/false로 만든다. stale 값으로 GC나 filesystem 명령을 실행하지 않는다.

## 진입 판단

| 구분 | 판단 기준 |
|---|---|
| 사용 | `imagefs.*` signal 또는 실제 image store의 GC/write/no-space 오류 |
| 적용 | provider·CRI endpoint·runtime unit/data path·mount를 같은 사건 창에서 대조 가능 |
| 제외 | nodefs bytes, inode-only, registry 인증/TLS/network, PVC/CSI는 각각 담당 런북으로 이관 |

검색 문자열: `DiskPressure`, `imagefs.available`, `imagefs.inodesFree`, `image garbage collection failed`, `no space left on device`, `unpack`, `containerd`, `crio`.

## 최초 확인·영향

`fresh_node && kubectl get pods -A --field-selector "spec.nodeName=$NODE" -o json | jq -r '.items[] | "\n=== \(.metadata.namespace)/\(.metadata.name) ===\nUID: \(.metadata.uid)\nOwner: \(.metadata.ownerReferences[0].kind // "-")/\(.metadata.ownerReferences[0].name // "-") UID=\(.metadata.ownerReferences[0].uid // "-")\nPhase: \(.status.phase) Ready=\([.status.containerStatuses[]?.ready]|join(",")) Restarts=\([.status.containerStatuses[]?.restartCount]|join(","))\nWaiting: \([.status.containerStatuses[]? | .state.waiting.reason // empty]|join(","))"'`

`ImagePullBackOff`의 `unauthorized|denied|x509|timeout`은 imagefs가 아니라 registry 경로다. replacement는 Pod UID/owner UID로 구분한다.

## 시간·host gate

`START_RFC3339='PASTE_START_RFC3339_HERE'; END_RFC3339='PASTE_END_RFC3339_HERE'; unset TIME_READY KUBELET_READY CRI_READY STORAGE_READY EVIDENCE_READY START_EPOCH END_EPOCH START_CANON END_CANON DOWNSTREAM_READY; TIME_READY=false; if [[ "$START_RFC3339" =~ ^[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}Z$ ]] && [[ "$END_RFC3339" =~ ^[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}Z$ ]] && START_EPOCH="$(date -u -d "$START_RFC3339" +%s 2>/dev/null)" && END_EPOCH="$(date -u -d "$END_RFC3339" +%s 2>/dev/null)"; then START_CANON="$(date -u -d "@$START_EPOCH" '+%Y-%m-%dT%H:%M:%SZ')"; END_CANON="$(date -u -d "@$END_EPOCH" '+%Y-%m-%dT%H:%M:%SZ')"; if [ "$START_RFC3339" = "$START_CANON" ] && [ "$END_RFC3339" = "$END_CANON" ] && [ "$START_EPOCH" -lt "$END_EPOCH" ]; then TIME_READY=true; printf 'TIME_READY=true %s < %s\n' "$START_CANON" "$END_CANON"; else printf '%s\n' '중단: canonical round-trip/start<end 실패' >&2; fi; else printf '%s\n' '중단: strict UTC RFC3339 regex/parse 실패' >&2; fi`

`SSH_HOST='PASTE_APPROVED_SSH_HOST_HERE'; unset HOST_READY KUBELET_READY CRI_READY STORAGE_READY EVIDENCE_READY HOST_IDENTITY DOWNSTREAM_READY; SSH_ARGS=(); HOST_READY=false; if fresh_node && [[ "$SSH_HOST" =~ ^[A-Za-z0-9_.@:-]+$ ]] && [[ "$SSH_HOST" != -* ]]; then SSH_ARGS=(-o BatchMode=yes -o StrictHostKeyChecking=yes -o ClearAllForwardings=yes -o ConnectTimeout=10 "$SSH_HOST"); REMOTE_ID="$(ssh "${SSH_ARGS[@]}" -- 'printf "hostname=%s machine_id=%s boot_id=%s\n" "$(hostname -f 2>/dev/null || hostname)" "$(cat /etc/machine-id 2>/dev/null)" "$(cat /proc/sys/kernel/random/boot_id 2>/dev/null)"')"; SSH_RC=$?; printf '%s\n' "$REMOTE_ID"; read -r -p 'CMDB에서 이 host가 대상 Node임을 확인했으면 Node 이름 입력: ' HOST_CONFIRM; if [ "$SSH_RC" -eq 0 ] && [ "$HOST_CONFIRM" = "$NODE" ] && [[ "$REMOTE_ID" =~ ^hostname=[^[:space:]]+[[:space:]]machine_id=[0-9a-fA-F-]+[[:space:]]boot_id=[0-9a-fA-F-]+$ ]]; then HOST_IDENTITY="$REMOTE_ID"; HOST_READY=true; printf 'HOST_READY=true host=%s node=%s uid=%s rv=%s\n' "$SSH_HOST" "$NODE" "$NODE_UID" "$CURRENT_NODE_RV"; else printf '%s\n' '중단: 원격 host identity/CMDB 승인 실패' >&2; fi; else printf '%s\n' '중단: fresh Node/SSH host 형식 실패' >&2; fi`

`host_guard(){ local now; HOST_READY=false; fresh_node || return 1; now="$(ssh "${SSH_ARGS[@]}" -- 'printf "hostname=%s machine_id=%s boot_id=%s\n" "$(hostname -f 2>/dev/null || hostname)" "$(cat /etc/machine-id 2>/dev/null)" "$(cat /proc/sys/kernel/random/boot_id 2>/dev/null)"')" || return 1; [ "$now" = "$HOST_IDENTITY" ] || return 1; HOST_READY=true; }`

모든 node/CRI 명령은 작업 PC에서 `host_guard`를 직접 호출하고 검증된 값만 SSH positional argument로 전달한다. 작업 PC 변수가 원격 shell에 자동 전달된다고 가정하지 않는다.

## runtime·CRI·storage relation

`unset KUBELET_READY KUBELET_UNIT CRI_READY CRI_ENDPOINT CRI_SOCKET RUNTIME_UNIT RUNTIME_MAIN_PID EVIDENCE_READY DOWNSTREAM_READY; KUBELET_READY=false; CRI_READY=false; host_guard || exit 1; UNIT_OUTPUT="$(ssh "${SSH_ARGS[@]}" -- systemctl list-units --type=service --all --no-legend)"; argv에 endpoint가 없거나 여러 개면 기본 socket을 쓰지 않는다. fallback은 active argv의 `--config` 절대경로가 exact-one이고 regular readable file이며 top-level `containerRuntimeEndpoint` key가 정확히 하나, nonempty 지원 형식인지 확인한 뒤 같은 MainPID/socket 관계를 다시 검증한다.

## journal 증거

`host_guard || exit 1; [ "$KUBELET_READY" = true ] && [ "$TIME_READY" = true ] || exit 1; TMP="$(mktemp)" || exit 1; ssh "${SSH_ARGS[@]}" -- sudo journalctl -u "$KUBELET_UNIT" --since "$START_CANON" --until "$END_CANON" --no-pager >"$TMP"; PRODUCER_RC=$?; if [ "$PRODUCER_RC" -eq 0 ]; then grep -E -i -C 3 'imagefs|image garbage collection|no space left on device|nodefs\.available|DiskPressure|eviction|failed|write' "$TMP"; FILTER_RC=$?; else FILTER_RC=99; fi; rm -f "$TMP"; printf 'producer_rc=%s filter_rc=%s\n' "$PRODUCER_RC" "$FILTER_RC"; [ "$PRODUCER_RC" -eq 0 ] && { [ "$FILTER_RC" -eq 0 ] || [ "$FILTER_RC" -eq 1 ]; }`

`host_guard || exit 1; [ "$CRI_READY" = true ] && [ "$TIME_READY" = true ] || exit 1; TMP="$(mktemp)" || exit 1; ssh "${SSH_ARGS[@]}" -- sudo journalctl -u "$RUNTIME_UNIT" --since "$START_CANON" --until "$END_CANON" --no-pager >"$TMP"; PRODUCER_RC=$?; if [ "$PRODUCER_RC" -eq 0 ]; then grep -E -i -C 3 'image garbage collection|imagefs|no space left on device|unpack|write|failed|error|unauthorized|denied|x509|timeout' "$TMP"; FILTER_RC=$?; else FILTER_RC=99; fi; rm -f "$TMP"; printf 'producer_rc=%s filter_rc=%s\n' "$PRODUCER_RC" "$FILTER_RC"; [ "$PRODUCER_RC" -eq 0 ] && { [ "$FILTER_RC" -eq 0 ] || [ "$FILTER_RC" -eq 1 ]; }`

producer/filter RC를 분리한다. 빈 결과는 정상 아님이다. `imagefs.*`, mount bytes/inode, GC/write 오류가 `start <= evidence <= end`에서 맞아야 imagefs 원인이다. auth/TLS/network 오류는 registry, inode-only는 inode, nodefs signal은 nodefs로 이관한다.

## 보안·변경·정상화

정확한 RBAC/audit은 사용 verb/subresource와 최소 필드로 확인한다. image reference에 credential이 있거나 journal에 token/key/개인정보가 보이면 저장을 중단한다.

이 문서는 image prune/rm, file/log 삭제·truncate, threshold 변경, Pod 삭제, runtime/kubelet restart, reboot/cordon/drain 명령을 제공하지 않는다. 별도 변경은 fresh evidence, 승인/window, workload/PDB/quorum, registry 재pull 영향, idempotence, rollback 또는 비가역 중단 계획을 요구한다.

이 문서 안에서는 `MUTATION_READY=false`를 유지한다. 별도 변경 절차가 실제 명령을 제공할 때 그 명령 자체가 fresh Node UID/RV·host identity·CRI provider/MainPID/socket·image path→mount/source/fstype·evidence window·승인 ID·PDB/quorum·registry 재pull 영향·멱등성·rollback 또는 비가역 중단 조건을 다시 검사해야 한다.

실제 변경은 승인된 runtime owner 절차만 사용한다. replacement는 새 Pod UID/RV·owner UID·node·container ID를 재등록하고 Ready 전 downstream을 금지한다.

`NORMALIZATION_READY=false; CURRENT_MAP=''; if fresh_node && host_guard && J="$(kubectl get node "$NODE" -o json)" && CURRENT_MAP="$(ssh "${SSH_ARGS[@]}" -- findmnt -T "$RUNTIME_DATA_PATH" -rn -o TARGET,SOURCE,FSTYPE)" && [ "$(jq -r '[.status.conditions[]|select(.type=="DiskPressure")|.status][0]' <<<"$J")" = False ] && [ "$STORAGE_READY" = true ] && [ "$CURRENT_MAP" = "$MAP" ]; then NORMALIZATION_READY=true; printf 'NORMALIZATION_READY=true node_uid=%s rv=%s mount=%s\n' "$NODE_UID" "$CURRENT_NODE_RV" "$IMAGEFS_TARGET"; else printf '%s\n' '중단: condition/remote identity/mount 정상화 gate 실패' >&2; fi`

정상화는 bytes/inode 안정, 새 GC/write warning 부재, DiskPressure/taint 해소, replacement Ready/restart 안정, owner desired=Ready, EndpointSlice `ready=true`, 실제 요청 성공까지 확인한다.

## Prometheus 빠른 관측

`fresh_node || exit 1; host_guard || exit 1; CURRENT_MAP="$(ssh "${SSH_ARGS[@]}" -- findmnt -T "$RUNTIME_DATA_PATH" -rn -o TARGET,SOURCE,FSTYPE)"; [ "$CRI_READY" = true ] && [ "$STORAGE_READY" = true ] && [ "$CURRENT_MAP" = "$MAP" ] || exit 1; NODE_RE="$(printf '%s' "$NODE" | sed 's/[][\\.^$*+?(){}|]/\\&/g')"; MOUNT_RE="$(printf '%s' "$IMAGEFS_TARGET" | sed 's/[][\\.^$*+?(){}|]/\\&/g')"; printf '100*(1-node_filesystem_avail_bytes{nodename=~"^%s$",mountpoint=~"^%s$"}/node_filesystem_size_bytes{nodename=~"^%s$",mountpoint=~"^%s$"})\n' "$NODE_RE" "$MOUNT_RE" "$NODE_RE" "$MOUNT_RE"; printf 'sum by(operation_type)(rate(kubelet_runtime_operations_errors_total{node=~"^%s$",operation_type=~"pull_image|remove_image|image_status"}[5m]))\n' "$NODE_RE"`

완성 쿼리만 UI에 붙인다. metric/label/operation type 미확인과 빈 결과를 정상으로 보지 않는다.

## 증거·환경 미검증

Node UID/RV, Pod UID/owner, remote identity, canonical 시간, endpoint/socket/provider/unit, runtime path→mount/source, producer/filter RC, 승인·replacement·정상화를 보존한다. kubelet config, runtime path/unit, imagefs reporting, SSH/NTP/audit/metrics는 환경별 미검증이다. 실제 인프라에는 실행하지 않았다.
