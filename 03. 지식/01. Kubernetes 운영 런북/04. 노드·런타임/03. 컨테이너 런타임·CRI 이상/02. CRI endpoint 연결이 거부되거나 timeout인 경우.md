# CRI endpoint 연결이 거부되거나 timeout인 경우

## 입력값과 빠른 수집

실행 hop은 `승인된 작업 PC의 Bash → Kubernetes API`와 `작업 PC → SSH 주소 → Node host namespace → active kubelet process → kubelet이 실제 사용 중인 단일 Unix endpoint → socket provider runtime`이다. Node 이름, Node UID, SSH 주소와 Linux hostname을 같은 identity로 취급하지 않는다. SSH에는 positional argument만 전달하고 `eval`과 원격 command 문자열 보간을 금지한다.

| 구분 | 값 | 유효성 |
|---|---|---|
| 최초 입력 | `NODE_NAME`, `SSH_HOST` | exact Node와 승인된 SSH 목적지 |
| API 자동값 | `NODE_UID`, `NODE_RV`, `EXPECTED_HOSTNAME`, `RUNTIME_VERSION` | 한 API 응답이 모두 제공할 때만 유효 |
| 계산 후보 | `RUNTIME_KIND`, `CRI_SOCKET`, journal regex | exact endpoint·runtime 검증 전 미확정 |
| 운영자 선택 | active `KUBELET_UNIT`, `RUNTIME_UNIT`, `CRI_ENDPOINT`, UTC start/evidence/end | host 후보와 최초 오류를 확인한 뒤 선택 |

**도구와 최초 입력**

`TOOLS_READY=false; MISSING=''; [ -n "${BASH_VERSION:-}" ] || MISSING="$MISSING bash"; for T in kubectl jq ssh date grep mktemp; do command -v "$T" >/dev/null 2>&1 || MISSING="$MISSING $T"; done; [ -z "$MISSING" ] && TOOLS_READY=true || printf '중단: 없는 도구=%s\n' "$MISSING" >&2; unset INPUT_READY API_READY HOST_READY TIME_READY ENDPOINT_READY CRI_ATTEMPTED EVIDENCE_READY NORMAL_READY NODE_UID NODE_RV EXPECTED_HOSTNAME RUNTIME_VERSION RUNTIME_KIND KUBELET_UNIT RUNTIME_UNIT CRI_ENDPOINT CRI_SOCKET START_RFC3339 END_RFC3339 EVIDENCE_RFC3339 OWNER_UID SELECTOR REVISION SPEC_HASH IMAGE_DIGEST CONTAINER_ID RELATION_ID ARGV_RE; NODE_NAME='PASTE_NODE_NAME_HERE'; SSH_HOST='PASTE_SSH_HOST_HERE'; INPUT_READY=false; if [ "$TOOLS_READY" = true ] && [ -n "$NODE_NAME" ] && [ -n "$SSH_HOST" ]; then INPUT_READY=true; printf 'INPUT_READY=true node=%s ssh-host=%s\n' "$NODE_NAME" "$SSH_HOST"; else printf '%s\n' '중단: 최초 입력 실패' >&2; fi`

**Node API 자동값 수집**

`unset API_READY HOST_READY TIME_READY ENDPOINT_READY CRI_ATTEMPTED EVIDENCE_READY NORMAL_READY NODE_UID NODE_RV EXPECTED_HOSTNAME RUNTIME_VERSION RUNTIME_KIND CRI_SOCKET CONTAINER_ID RELATION_ID ARGV_RE; API_READY=false; if [ "$INPUT_READY" != true ]; then printf '%s\n' '중단: INPUT_READY가 아니다.' >&2; elif J="$(kubectl get node "$NODE_NAME" -o json)" && U="$(jq -er '.metadata.uid|select(length>0)' <<<"$J")" && R="$(jq -er '.metadata.resourceVersion|select(length>0)' <<<"$J")" && H="$(jq -er '[.status.addresses[]?|select(.type=="Hostname")|.address]|unique|if length==1 then .[0] else error("hostname") end' <<<"$J")" && V="$(jq -er '.status.nodeInfo.containerRuntimeVersion|select(length>0)' <<<"$J")"; then NODE_UID="$U"; NODE_RV="$R"; EXPECTED_HOSTNAME="$H"; RUNTIME_VERSION="$V"; RUNTIME_KIND="${V%%:*}"; API_READY=true; export NODE_NAME SSH_HOST NODE_UID NODE_RV EXPECTED_HOSTNAME RUNTIME_VERSION RUNTIME_KIND; printf 'API_READY=true node=%s uid=%s rv=%s hostname=%s runtime=%s observed=%s\n' "$NODE_NAME" "$NODE_UID" "$NODE_RV" "$EXPECTED_HOSTNAME" "$RUNTIME_VERSION" "$(date -u '+%Y-%m-%dT%H:%M:%SZ')"; else printf '%s\n' '중단: API 실패; 모든 파생 identity와 READY 폐기' >&2; fi`

`API_READY` 실패를 빈 Node로 해석하지 않는다. `kubectl auth can-i get nodes`는 RBAC preflight이며 exact 요청·context·audit 성공 증거가 아니다. audit가 필요하면 승인된 backend에서 user/groups, verb, request URI, response code, `auditID`만 다루고 credential과 request body는 저장하지 않는다.

## 진입 판단

| 구분 | 판단 기준 |
|---|---|
| 사용 | active kubelet의 실제 endpoint에 `connection refused`, `context deadline exceeded`, `i/o timeout`이 같은 증거 창에 있음 |
| 적용 | endpoint identity, socket listener/provider, service와 host pressure를 분리할 수 있음 |
| 제외 | endpoint 증거 없이 `RuntimeReady=false`만 있으면 [[01. kubelet에 Container runtime is down이 기록된 경우]], Pod별 sandbox/create/start 오류면 해당 런북 |

검색 문자열: `dial unix`, `connection refused`, `context deadline exceeded`, `i/o timeout`, `permission denied`, `listen`, `bind`.

## 준비 gate

**원격 active unit 후보**

`if [ "$API_READY" != true ]; then printf '%s\n' '중단: API_READY가 아니다.' >&2; else ssh -- "$SSH_HOST" bash -s -- "$EXPECTED_HOSTNAME" <<'REMOTE'
expected=$1; [ "$(hostname)" = "$expected" ] || { printf '%s\n' '중단: remote hostname 불일치' >&2; exit 10; }
tmp=$(mktemp); trap 'rm -f "$tmp"' EXIT
systemctl list-units --type=service --state=active --no-legend --no-pager >"$tmp"; producer_rc=$?; [ "$producer_rc" -eq 0 ] || exit 11
case "$filter_rc" in 0) ;; 1) printf '%s\n' '중단: 후보 없음' >&2; exit 12 ;; *) exit 13 ;; esac
REMOTE
fi`

**선택과 UTC round-trip**

`unset HOST_READY TIME_READY ENDPOINT_READY CRI_ATTEMPTED EVIDENCE_READY NORMAL_READY CRI_SOCKET ARGV_RE; KUBELET_UNIT='PASTE_KUBELET_UNIT_HERE'; RUNTIME_UNIT='PASTE_RUNTIME_UNIT_HERE'; CRI_ENDPOINT='PASTE_CRI_ENDPOINT_HERE'; START_RFC3339='PASTE_START_RFC3339_HERE'; END_RFC3339='PASTE_END_RFC3339_HERE'; EVIDENCE_RFC3339='PASTE_EVIDENCE_RFC3339_HERE'; HOST_READY=false; TIME_READY=false; if [ "$API_READY" = true ] && [[ "$KUBELET_UNIT" =~ ^[A-Za-z0-9_.@:-]+\.service$ ]] && [[ "$RUNTIME_UNIT" =~ ^[A-Za-z0-9_.@:-]+\.service$ ]] && [[ "$CRI_ENDPOINT" == unix:///* ]]; then HOST_READY=true; SC="$(date -u -d "$START_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null)"; EC="$(date -u -d "$END_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null)"; XC="$(date -u -d "$EVIDENCE_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null)"; SE="$(date -u -d "$START_RFC3339" +%s 2>/dev/null)"; EE="$(date -u -d "$END_RFC3339" +%s 2>/dev/null)"; XE="$(date -u -d "$EVIDENCE_RFC3339" +%s 2>/dev/null)"; if [ "$SC" = "$START_RFC3339" ] && [ "$EC" = "$END_RFC3339" ] && [ "$XC" = "$EVIDENCE_RFC3339" ] && [ "$SE" -lt "$EE" ] && [ "$SE" -le "$XE" ] && [ "$XE" -le "$EE" ]; then TIME_READY=true; fi; fi; if [ "$HOST_READY" = true ] && [ "$TIME_READY" = true ]; then printf 'HOST_READY=true TIME_READY=true\n'; else HOST_READY=false; TIME_READY=false; printf '%s\n' '중단: 선택값 또는 canonical UTC start<end/evidence 불일치' >&2; fi`

`MACHINE_READY=false; NODE_NOW="$(kubectl get node "$NODE_NAME" -o json)"; API_RC=$?; if [ "$HOST_READY" = true ] && [ "$API_RC" -eq 0 ] && [ "$(jq -r '.metadata.uid // empty' <<<"$NODE_NOW")" = "$NODE_UID" ] && NODE_MACHINE_ID="$(jq -er '.status.nodeInfo.machineID|select(length>0)' <<<"$NODE_NOW")" && REMOTE_MACHINE_ID="$(ssh -- "$SSH_HOST" 'test -r /etc/machine-id && tr -d "\n" </etc/machine-id')" && [ "$REMOTE_MACHINE_ID" = "$NODE_MACHINE_ID" ]; then MACHINE_READY=true; printf 'MACHINE_READY=true nodeUID=%s machineID=%s\n' "$NODE_UID" "$NODE_MACHINE_ID"; else HOST_READY=false; unset NODE_MACHINE_ID REMOTE_MACHINE_ID; printf '%s\n' '중단: current Node UID/machineID와 원격 /etc/machine-id 불일치' >&2; fi`

**active kubelet 단일 endpoint와 provider exact 검증**

`if [ "$HOST_READY" != true ] || [ "$MACHINE_READY" != true ] || [ "$TIME_READY" != true ]; then printf '%s\n' '중단: HOST_READY/MACHINE_READY/TIME_READY가 아니다.' >&2; else ENDPOINT_READY=false; if ssh -- "$SSH_HOST" bash -s -- "$EXPECTED_HOSTNAME" "$KUBELET_UNIT" "$RUNTIME_UNIT" "$CRI_ENDPOINT" "$RUNTIME_KIND" <<'REMOTE'
host=$1; ku=$2; ru=$3; endpoint=$4; kind=$5
[ "$(hostname)" = "$host" ] || exit 20
[ "$(systemctl is-active "$ku")" = active ] || exit 21
kpid=$(systemctl show "$ku" -p MainPID --value); [ "$kpid" -gt 1 ] 2>/dev/null || exit 22
mapfile -d '' -t argv < "/proc/$kpid/cmdline" || exit 23
values=(); config=''; for arg in "${argv[@]}"; do case "$arg" in --container-runtime-endpoint=*) values+=("${arg#*=}");; --config=*) config=${arg#*=};; esac; done
if [ -n "$config" ]; then [ -r "$config" ] || exit 24; while IFS= read -r v; do values+=("$v"); done < <(sed -n 's/^[[:space:]]*containerRuntimeEndpoint:[[:space:]]*["'"']\{0,1\}\([^"'"'[:space:]]*\)["'"']\{0,1\}[[:space:]]*$/\1/p' "$config"); fi
mapfile -t unique < <(printf '%s\n' "${values[@]}" | sed '/^$/d' | sort -u)
[ "${#unique[@]}" -eq 1 ] && [ "${unique[0]}" = "$endpoint" ] || { printf '중단: endpoint count/exact mismatch count=%s\n' "${#unique[@]}" >&2; exit 25; }
socket=${endpoint#unix://}; [ "$socket" != "$endpoint" ] && [ -S "$socket" ] || exit 26
[ "$(systemctl is-active "$ru")" = active ] || exit 27
rpid=$(systemctl show "$ru" -p MainPID --value); [ "$rpid" -gt 1 ] 2>/dev/null || exit 28
tmp=$(mktemp); trap 'rm -f "$tmp"' EXIT; sudo ss -xlpn >"$tmp"; producer_rc=$?; [ "$producer_rc" -eq 0 ] || exit 29
grep -F -- "$socket" "$tmp" | grep -F -- "pid=$rpid,"; socket_rc=${PIPESTATUS[0]}; provider_rc=${PIPESTATUS[1]}; [ "$socket_rc" -eq 0 ] && [ "$provider_rc" -eq 0 ] || exit 30
case "$kind" in containerd|cri-o|docker) ;; *) exit 31 ;; esac
printf 'verified endpoint=%s socket=%s kubelet-pid=%s runtime-unit=%s provider-pid=%s\n' "$endpoint" "$socket" "$kpid" "$ru" "$rpid"
REMOTE
then CRI_SOCKET="${CRI_ENDPOINT#unix://}"; ENDPOINT_READY=true; export KUBELET_UNIT RUNTIME_UNIT CRI_ENDPOINT CRI_SOCKET START_RFC3339 END_RFC3339 EVIDENCE_RFC3339; printf 'ENDPOINT_READY=true socket=%s\n' "$CRI_SOCKET"; else unset CRI_SOCKET; printf '%s\n' '중단: endpoint/provider 검증 실패' >&2; fi; fi`

## refused·timeout 분리

**journal producer와 filter rc 분리**

`if [ "$ENDPOINT_READY" != true ]; then printf '%s\n' '중단: ENDPOINT_READY가 아니다.' >&2; else EVIDENCE_READY=false; if ssh -- "$SSH_HOST" bash -s -- "$EXPECTED_HOSTNAME" "$KUBELET_UNIT" "$RUNTIME_UNIT" "$CRI_SOCKET" "$START_RFC3339" "$END_RFC3339" <<'REMOTE'
host=$1; ku=$2; ru=$3; socket=$4; start=$5; end=$6; [ "$(hostname)" = "$host" ] || exit 40
for unit in "$ku" "$ru"; do tmp=$(mktemp); sudo journalctl -u "$unit" --since "$start" --until "$end" --output=short-iso --no-pager >"$tmp"; producer_rc=$?; if [ "$producer_rc" -ne 0 ]; then rm -f "$tmp"; printf 'producer 실패 unit=%s rc=%s\n' "$unit" "$producer_rc" >&2; exit 41; fi; grep -F -C 3 -- "$socket" "$tmp"; path_rc=$?; grep -E -i -C 3 'connection refused|context deadline exceeded|i/o timeout|permission denied|listen|bind|no space|read-only|I/O error|oom' "$tmp"; filter_rc=$?; rm -f "$tmp"; printf 'unit=%s path-filter-rc=%s symptom-filter-rc=%s\n' "$unit" "$path_rc" "$filter_rc"; [ "$path_rc" -le 1 ] && [ "$filter_rc" -le 1 ] || exit 42; done
REMOTE
then EVIDENCE_READY=true; printf 'EVIDENCE_READY=true evidence=%s node-uid=%s\n' "$EVIDENCE_RFC3339" "$NODE_UID"; else printf '%s\n' '중단: journal producer/filter 실패' >&2; fi; fi`

판정:

- `connection refused`와 listener 부재 또는 runtime inactive가 같은 시각이면 bind/service 경로다. refused만으로 firewall을 확정하지 않는다.
- timeout이면서 listener/provider가 유지되면 runtime 처리 정체, host CPU·memory·I/O pressure를 같은 창에서 확인한다. timeout만으로 service down을 확정하지 않는다.
- `permission denied`는 실행 주체와 socket mode/LSM 경계다. `chmod`, `chown`, LSM 완화로 우회하지 않는다.
- filter rc 1은 해당 문자열 미발견이며 producer 성공과 다르다. 증거 부재를 정상으로 기록하지 않는다.

**검증된 endpoint에서만 crictl**

`if [ "$ENDPOINT_READY" != true ] || [ "$EVIDENCE_READY" != true ]; then printf '%s\n' '중단: endpoint/evidence gate가 아니다.' >&2; else CRI_ATTEMPTED=false; if ssh -- "$SSH_HOST" bash -s -- "$EXPECTED_HOSTNAME" "$CRI_ENDPOINT" <<'REMOTE'
host=$1; endpoint=$2; [ "$(hostname)" = "$host" ] || exit 50; command -v crictl >/dev/null 2>&1 || exit 51; sudo crictl --runtime-endpoint="$endpoint" info | jq -c '{conditions:.status.conditions}'
REMOTE
then CRI_ATTEMPTED=true; printf 'CRI_ATTEMPTED=true endpoint=%s\n' "$CRI_ENDPOINT"; else printf '%s\n' 'crictl 실패: 원격 stderr의 refused/timeout/permission/도구 실패를 서로 구분한다.' >&2; fi; fi`

`info`의 명령 성공과 `RuntimeReady=true`는 별개다. 성공해도 kubelet 보고, Pod sandbox/create/start와 실제 서비스 정상은 보장하지 않는다. 출력 전체 대신 conditions와 비민감 오류만 보존한다.

## 변경 경계와 정상화

진단 중 runtime/kubelet restart, endpoint 수정, socket 삭제·권한 완화, reboot, Pod 삭제를 실행하지 않는다. 별도 변경 직전 fresh Node UID/RV, owner UID·selector·revision·spec hash·image digest, 현재 containerID, unit/MainPID·endpoint/provider, 직접 증거, 승인 ID·창, PDB/quorum, 외부 작업 멱등성과 rollback gate를 재등록한다. 변경되거나 비면 중단한다. replacement는 새 UID·owner relation·revision·digest·node·containerID로 재등록한다.

정상화는 API 재수집으로 기존 READY를 모두 폐기한 뒤 다음을 확인한다.

- 동일 active kubelet의 동일 endpoint와 동일 provider가 반복 검증되고 refused/timeout이 재발하지 않는다.
- `RuntimeReady=true`, Node Ready/Lease, sandbox→image→create→start→Ready가 수렴한다.
- owner desired/Ready, EndpointSlice 재등록과 실제 요청·핵심 기능 또는 Job 결과·중복 없음이 정상이다.
- 완화와 근본 원인 제거를 분리 기록한다.

## Prometheus 빠른 관측

`if [ "$API_READY" != true ]; then printf '%s\n' '중단: API_READY가 아니다.' >&2; else PROM_LABEL='PASTE_PROM_LABEL_HERE'; PROM_VALUE='PASTE_PROM_VALUE_HERE'; if [[ "$PROM_LABEL" =~ ^[A-Za-z_][A-Za-z0-9_]*$ ]]; then Q="$(jq -Rn --arg v "$PROM_VALUE" '$v')"; printf 'histogram_quantile(0.99,sum by(le,operation_type)(rate(kubelet_runtime_operations_duration_seconds_bucket{%s=%s}[5m])))\n' "$PROM_LABEL" "$Q"; printf 'sum by(operation_type)(rate(kubelet_runtime_operations_errors_total{%s=%s}[5m]))\n' "$PROM_LABEL" "$Q"; printf 'up{%s=%s}\n' "$PROM_LABEL" "$Q"; else printf '%s\n' '중단: label 이름 오류' >&2; fi; fi`

생성 출력만 UI에 붙여 넣는다. duration/error가 비면 metric 미노출·scrape 실패·label mismatch·조회 창을 `up`과 label browser로 분기한다. `up`도 비면 target 부재/선택 오류이고, `up=0`이면 scrape 실패다. 빈 결과를 0 또는 endpoint 회복으로 해석하지 않는다.

## 증거·미검증

Node UID/RV, runtimeVersion, 원격 hostname, unit/MainPID, active kubelet argv/config의 단일 endpoint, socket/provider, canonical UTC와 증거 관계, producer/filter rc, CRI conditions, 승인·기능 검증을 보존한다. 전체 argv/config/journal·credential·개인정보는 저장하지 않는다.

Kubernetes 1.26 기준이다. SSH, systemd, runtime·socket, journald, Linux pressure, Prometheus metric/label은 환경별 미검증이다.
