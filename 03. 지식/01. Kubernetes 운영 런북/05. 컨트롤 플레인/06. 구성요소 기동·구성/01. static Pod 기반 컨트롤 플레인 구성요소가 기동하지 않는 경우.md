# static Pod 기반 컨트롤 플레인 구성요소가 기동하지 않는 경우

## 입력값과 빠른 수집

연결 경로는 `작업 PC → API server의 mirror Pod`와 `작업 PC → SSH → 승인 node → active kubelet argv/config → staticPodPath manifest → active CRI socket provider → exact container`다. API 조회 실패와 mirror Pod 0개를 구분한다.

| 종류 | 변수 | 출처·gate |
|---|---|---|
| 최초 입력 | `NODE`, `ROLE` | inventory의 Node 이름과 static Pod container 이름 |
| API 자동값 | `NODE_UID`, `NODE_MACHINE_ID`, mirror namespace/name/UID/RV, current `CONTAINER_ID`, runtime provider | exact API 조회가 모두 성공해야 등록 |
| 계산 후보 | `MANIFEST_PATH`, `CRI_ENDPOINT` | active kubelet PID의 argv 또는 엄격히 검증한 `--config`에서 계산 |
| 운영자 선택 | SSH target·remote hostname·kubelet/runtime unit, UTC 창 | 승인 inventory와 최초 오류 증거 |

**Bash·로컬 도구와 stale 상태 초기화:** `unset INPUT_READY AUTO_READY WINDOW_READY REMOTE_READY MANIFEST_READY ENDPOINT_READY CRI_READY NODE_UID NODE_MACHINE_ID MIRROR_NS MIRROR_POD MIRROR_UID MIRROR_RV OWNER_REL CONTAINER_ID RUNTIME_PROVIDER SSH_TARGET EXPECTED_REMOTE_HOST KUBELET_UNIT RUNTIME_UNIT KUBELET_PID KUBELET_START MANIFEST_PATH CRI_ENDPOINT START_RFC3339 END_RFC3339 EVIDENCE_RFC3339 START_EPOCH END_EPOCH EVIDENCE_EPOCH NODE_JSON MIRROR_JSON; TOOLS_READY=false; MISSING=''; for T in kubectl jq date grep ssh; do command -v "$T" >/dev/null 2>&1 || MISSING="$MISSING $T"; done; if [ -z "${BASH_VERSION:-}" ] || [ -n "$MISSING" ]; then printf '중단: Bash/도구 gate 실패:%s\n' "$MISSING" >&2; else TOOLS_READY=true; fi`

**최초 입력:** `NODE='PASTE_NODE_HERE'; ROLE='PASTE_COMPONENT_CONTAINER_HERE'; INPUT_READY=false; [ "$TOOLS_READY" = true ] && [ -n "$NODE" ] && [ -n "$ROLE" ] && INPUT_READY=true || printf '%s\n' '중단: 최초 입력 불완전' >&2`

**Node·mirror 자동 등록:** `AUTO_READY=false; unset NODE_UID NODE_MACHINE_ID MIRROR_NS MIRROR_POD MIRROR_UID MIRROR_RV OWNER_REL CONTAINER_ID RUNTIME_PROVIDER NODE_JSON MIRROR_JSON; if [ "$INPUT_READY" != true ]; **current target gate 등록:** `refresh_target(){ local nj nu nm rp pj count mj mu mr cid; AUTO_READY=false; nj=$(kubectl get node "$NODE" -o json) || return 1; nu=$(jq -er '.metadata.uid' <<<"$nj") || return 1; nm=$(jq -er '.status.nodeInfo.machineID|select(length>0)' <<<"$nj") || return 1; rp=$(jq -er '.status.nodeInfo.containerRuntimeVersion|split(":")[0]' <<<"$nj") || return 1; [ "$nu" = "$NODE_UID" ] && [ "$nm" = "$NODE_MACHINE_ID" ] && [ "$rp" = "$RUNTIME_PROVIDER" ] || { printf '%s\n' '중단: Node identity/runtime 변경' >&2; return 1; }; pj=$(kubectl get pods -A --field-selector "spec.nodeName=$NODE" -o json) || return 1; count=$(jq -er --arg role "$ROLE" '[.items[]|select(.metadata.annotations["kubernetes.io/config.mirror"]!=null and any(.spec.containers[]?;.name==$role))]|length' <<<"$pj") || return 1; if [ -n "${MIRROR_UID:-}" ]; then [ "$count" -eq 1 ] || return 1; mj=$(jq -cer --arg uid "$MIRROR_UID" '.items[]|select(.metadata.uid==$uid)' <<<"$pj") || return 1; mu=$(jq -er '.metadata.uid' <<<"$mj") || return 1; mr=$(jq -er '.metadata.resourceVersion' <<<"$mj") || return 1; cid=$(jq -r --arg role "$ROLE" '[.status.containerStatuses[]?|select(.name==$role)|.containerID][0]//""' <<<"$mj"); [ "$mu" = "$MIRROR_UID" ] && [ "$cid" = "$CONTAINER_ID" ] || { printf '%s\n' '중단: mirror/container lifecycle 변경; 전체 재등록' >&2; return 1; }; MIRROR_JSON=$mj; MIRROR_RV=$mr; else [ "$count" -eq 0 ] || { printf '%s\n' '중단: 새 mirror가 생김; 전체 재등록' >&2; return 1; }; fi; NODE_JSON=$nj; AUTO_READY=true; }`

`AUTO_READY=true`가 아니면 이후 명령을 실행하지 않는다. mirror가 있으면 container kind/name/current containerID를 함께 보존하며, containerID가 비어 있으면 CRI inspect 절은 열지 않는다.

## 최초 확인과 시간 gate

**현재 요약:** `refresh_target || exit $?; jq -r '"=== Node ===\nUID: \(.metadata.uid)\nmachineID: \(.status.nodeInfo.machineID)\nReady: \([.status.conditions[]|select(.type=="Ready")][0].status)\nRuntime: \(.status.nodeInfo.containerRuntimeVersion)"' <<<"$NODE_JSON"; if [ -n "${MIRROR_JSON:-}" ]; then jq -r --arg role "$ROLE" '"=== mirror ===\nNamespace/Pod: \(.metadata.namespace)/\(.metadata.name)\nUID/RV: \(.metadata.uid)/\(.metadata.resourceVersion)\nCreated: \(.metadata.creationTimestamp)\nPhase: \(.status.phase)\n"+([.status.containerStatuses[]?|select(.name==$role)|"Container: \(.name) id=\(.containerID//"none") waiting=\(.state.waiting.reason//"none") terminated=\(.state.terminated.reason//"none")"]|join("\n"))' <<<"$MIRROR_JSON"; else printf '%s\n' 'mirror=0 (API 성공 범위의 부재 후보)'; fi`

**엄격한 UTC 창:** `unset WINDOW_READY START_EPOCH END_EPOCH EVIDENCE_EPOCH; START_RFC3339='PASTE_START_RFC3339_HERE'; END_RFC3339='PASTE_END_RFC3339_HERE'; EVIDENCE_RFC3339='PASTE_EVIDENCE_RFC3339_HERE'; RFC3339_RE='^[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}Z$'; WINDOW_READY=false; if [[ "$START_RFC3339" =~ $RFC3339_RE ]] && [[ "$END_RFC3339" =~ $RFC3339_RE ]] && [[ "$EVIDENCE_RFC3339" =~ $RFC3339_RE ]]; then START_EPOCH=$(date -u -d "$START_RFC3339" +%s 2>/dev/null) && END_EPOCH=$(date -u -d "$END_RFC3339" +%s 2>/dev/null) && EVIDENCE_EPOCH=$(date -u -d "$EVIDENCE_RFC3339" +%s 2>/dev/null) || true; fi; if [ -n "${START_EPOCH:-}" ] && [ "$(date -u -d "@$START_EPOCH" '+%Y-%m-%dT%H:%M:%SZ')" = "$START_RFC3339" ] && [ "$(date -u -d "@$END_EPOCH" '+%Y-%m-%dT%H:%M:%SZ')" = "$END_RFC3339" ] && [ "$(date -u -d "@$EVIDENCE_EPOCH" '+%Y-%m-%dT%H:%M:%SZ')" = "$EVIDENCE_RFC3339" ] && [ "$START_EPOCH" -lt "$END_EPOCH" ] && [ "$START_EPOCH" -le "$EVIDENCE_EPOCH" ] && [ "$EVIDENCE_EPOCH" -lt "$END_EPOCH" ]; then WINDOW_READY=true; else unset START_EPOCH END_EPOCH EVIDENCE_EPOCH; printf '%s\n' '중단: canonical UTC 또는 start<=evidence<end 위반' >&2; fi`

## 관측별 진단 경로

| 지금 보이는 것 | 먼저 볼 것 | 다음 gate |

### 1. 승인 node·active kubelet·manifest

**SSH와 unit 선택:** `unset REMOTE_READY SSH_TARGET EXPECTED_REMOTE_HOST KUBELET_UNIT RUNTIME_UNIT; SSH_TARGET='PASTE_SSH_TARGET_HERE'; EXPECTED_REMOTE_HOST='PASTE_EXPECTED_REMOTE_HOST_HERE'; KUBELET_UNIT='PASTE_KUBELET_UNIT_HERE'; RUNTIME_UNIT='PASTE_RUNTIME_UNIT_HERE'; run_remote(){ local script=$1 arg q cmd='bash -s --'; shift; for arg in "$@"; do printf -v q '%q' "$arg"; cmd+=" $q"; done; ssh -- "$SSH_TARGET" "$cmd" <<<"$script"; }; REMOTE_READY=false; [ -n "$SSH_TARGET" ] && [ -n "$EXPECTED_REMOTE_HOST" ] && [ -n "$KUBELET_UNIT" ] && [ -n "$RUNTIME_UNIT" ] && REMOTE_READY=true || printf '%s\n' '중단: SSH/unit 선택 불완전' >&2`

다음 원격 helper는 active kubelet PID의 `/proc/PID/cmdline`을 NUL 단위 argv로 읽는다. `--config` fallback은 절대경로 regular readable file이며 요청 key가 정확히 한 번인 경우만 허용한다.

**manifest path 자동 등록:** `refresh_target || exit $?; [ "$REMOTE_READY" = true ] || exit 1; OUT=$(run_remote 'expected=$1; expected_mid=$2; unit=$3; role=$4; actual=$(hostname -f 2>/dev/null || hostname) || exit 20; mid=$(cat /etc/machine-id) || exit 21; [ "$actual" = "$expected" ] && [ "$mid" = "$expected_mid" ] || exit 22; [ "$(systemctl is-active "$unit" 2>/dev/null)" = active ] || exit 23; pid=$(systemctl show "$unit" -p MainPID --value) || exit 24; [[ "$pid" =~ ^[1-9][0-9]*$ ]] && [ -r "/proc/$pid/cmdline" ] || exit 25; mapfile -d "" -t a < "/proc/$pid/cmdline"; dir=""; cfg=""; for ((i=0;i<${#a[@]};i++)); do case ${a[i]} in --pod-manifest-path=*) [ -z "$dir" ] || exit 26; dir=${a[i]#*=};; --pod-manifest-path) ((i++)); [ "$i" -lt "${#a[@]}" ] && [ -z "$dir" ] || exit 26; dir=${a[i]};; --config=*) [ -z "$cfg" ] || exit 27; cfg=${a[i]#*=};; --config) ((i++)); [ "$i" -lt "${#a[@]}" ] && [ -z "$cfg" ] || exit 27; cfg=${a[i]};; esac; done; if [ -z "$dir" ]; then [[ "$cfg" = /* ]] && [ -f "$cfg" ] && [ -r "$cfg" ] || exit 28; raw=$(grep -E "^[[:space:]]*staticPodPath:[[:space:]]*[^[:space:]#]+[[:space:]]*(#.*)?$" "$cfg"); rc=$?; [ "$rc" -eq 0 ] && [ "$(grep -Ec "^[[:space:]]*staticPodPath:[[:space:]]*[^[:space:]#]+[[:space:]]*(#.*)?$" "$cfg")" -eq 1 ] || exit 29; dir=${raw#*:}; dir=${dir%%#*}; dir=${dir//[[:space:]]/}; fi; [[ "$dir" = /* ]] || exit 30; path=$dir/$role.yaml; [ -f "$path" ] && [ -r "$path" ] || exit 31; stat -c "%n|%i|%s|%Y|%U:%G|%a" -- "$path"' "$EXPECTED_REMOTE_HOST" "$NODE_MACHINE_ID" "$KUBELET_UNIT" "$ROLE" 2>&1); RC=$?; MANIFEST_READY=false; unset MANIFEST_PATH; if [ "$RC" -eq 0 ]; then MANIFEST_PATH=${OUT%%|*}; MANIFEST_READY=true; printf 'MANIFEST_READY=true metadata=%s\n' "$OUT"; else printf 'manifest gate 실패 rc=%s detail=%s\n' "$RC" "$OUT" >&2; fi; unset OUT RC`

**kubelet journal과 pipeline RC:** `refresh_target || exit $?; [ "$REMOTE_READY" = true ] && [ "$WINDOW_READY" = true ] && [ "$MANIFEST_READY" = true ] || exit 1; run_remote 'expected=$1; expected_mid=$2; unit=$3; start=$4; end=$5; role=$6; path=$7; actual=$(hostname -f 2>/dev/null || hostname) || exit 20; mid=$(cat /etc/machine-id) || exit 21; [ "$actual" = "$expected" ] && [ "$mid" = "$expected_mid" ] && [ -f "$path" ] || exit 22; raw=$(sudo journalctl -u "$unit" --since "$start" --until "$end" --no-pager -n 500 2>&1); rc=$?; if [ "$rc" -ne 0 ]; then printf "journal 수집 실패 rc=%s\n" "$rc" >&2; exit "$rc"; elif match=$(grep -E -i -C 3 "$role|static pod|manifest|parse|yaml|permission denied|create|start|sandbox|runtime|x509|bind|failed" <<<"$raw"); then printf "%s\n" "$match"; else printf "%s\n" "필터 불일치: 정상 증거 아님"; tail -n 50 <<<"$raw"; fi' "$EXPECTED_REMOTE_HOST" "$NODE_MACHINE_ID" "$KUBELET_UNIT" "$START_RFC3339" "$END_RFC3339" "$ROLE" "$MANIFEST_PATH"`

### 2. active CRI endpoint·socket provider·exact container

**active endpoint 자동 등록:** `refresh_target || exit $?; [ "$REMOTE_READY" = true ] || exit 1; OUT=$(run_remote 'expected=$1; expected_mid=$2; unit=$3; actual=$(hostname -f 2>/dev/null || hostname) || exit 20; mid=$(cat /etc/machine-id) || exit 21; [ "$actual" = "$expected" ] && [ "$mid" = "$expected_mid" ] || exit 22; pid=$(systemctl show "$unit" -p MainPID --value) || exit 23; [[ "$pid" =~ ^[1-9][0-9]*$ ]] && [ -r "/proc/$pid/cmdline" ] && [ -r "/proc/$pid/stat" ] || exit 24; mapfile -d "" -t a < "/proc/$pid/cmdline"; ep=""; cfg=""; for ((i=0;i<${#a[@]};i++)); do case ${a[i]} in --container-runtime-endpoint=*) [ -z "$ep" ] || exit 25; ep=${a[i]#*=};; --container-runtime-endpoint) ((i++)); [ "$i" -lt "${#a[@]}" ] && [ -z "$ep" ] || exit 25; ep=${a[i]};; --config=*) [ -z "$cfg" ] || exit 26; cfg=${a[i]#*=};; --config) ((i++)); [ "$i" -lt "${#a[@]}" ] && [ -z "$cfg" ] || exit 26; cfg=${a[i]};; esac; done; if [ -z "$ep" ]; then [[ "$cfg" = /* ]] && [ -f "$cfg" ] && [ -r "$cfg" ] || exit 27; raw=$(grep -E "^[[:space:]]*containerRuntimeEndpoint:[[:space:]]*[^[:space:]#]+[[:space:]]*(#.*)?$" "$cfg"); rc=$?; [ "$rc" -eq 0 ] && [ "$(grep -Ec "^[[:space:]]*containerRuntimeEndpoint:[[:space:]]*[^[:space:]#]+[[:space:]]*(#.*)?$" "$cfg")" -eq 1 ] || exit 28; ep=${raw#*:}; ep=${ep%%#*}; ep=${ep//[[:space:]]/}; fi; [[ "$ep" = unix:///* ]] || exit 29; start=$(cut -d " " -f 22 "/proc/$pid/stat") || exit 30; printf "%s|%s|%s" "$ep" "$pid" "$start"' "$EXPECTED_REMOTE_HOST" "$NODE_MACHINE_ID" "$KUBELET_UNIT" 2>&1); RC=$?; ENDPOINT_READY=false; unset CRI_ENDPOINT KUBELET_PID KUBELET_START; if [ "$RC" -eq 0 ] && [[ "$OUT" = unix:///*\|[1-9]*\|[0-9]* ]]; then CRI_ENDPOINT=${OUT%%|*}; REST=${OUT#*|}; KUBELET_PID=${REST%%|*}; KUBELET_START=${REST#*|}; ENDPOINT_READY=true; printf 'ENDPOINT_READY=true endpoint=%s kubelet_pid=%s start_ticks=%s\n' "$CRI_ENDPOINT" "$KUBELET_PID" "$KUBELET_START"; else printf 'endpoint gate 실패 rc=%s detail=%s\n' "$RC" "$OUT" >&2; fi; unset OUT REST RC`

**CRI inspect, direct current gate:** `refresh_target || exit $?; [ "$ENDPOINT_READY" = true ] && [ -n "${MIRROR_UID:-}" ] && [ -n "${CONTAINER_ID:-}" ] || exit 1; run_remote 'expected=$1; expected_mid=$2; rpid=$(systemctl show "$runtime_unit" -p MainPID --value) || exit 28; [[ "$rpid" =~ ^[1-9][0-9]*$ ]] || exit 29; socket=${endpoint#unix://}; [ -S "$socket" ] || exit 30; listeners=$(sudo ss -xlpnH 2>&1); rc=$?; [ "$rc" -eq 0 ] || exit 31; line=$(grep -F -- "$socket" <<<"$listeners"); rc=$?; [ "$rc" -eq 0 ] && grep -Fq -- "pid=$rpid," <<<"$line" || { printf "runtime unit PID가 socket provider가 아님\n" >&2; exit 32; }; cid=${cid_full#*://}; raw=$(sudo crictl --runtime-endpoint "$endpoint" inspect "$cid" 2>&1); rc=$?; [ "$rc" -eq 0 ] || { printf "CRI inspect 실패 rc=%s\n" "$rc" >&2; exit "$rc"; }; got_uid=$(jq -er ".status.labels[\"io.kubernetes.pod.uid\"]" <<<"$raw") || exit 33; `crictl` 전에는 매번 `refresh_target`, remote machine identity, active runtime unit, Unix socket와 service MainPID의 listener 소유 관계를 직접 검사한다. endpoint 등록 뒤 kubelet이 재시작했으면 `ENDPOINT_READY`를 폐기하고 다시 등록한다.

## 변경·rollback·정상화

이 문서는 manifest edit/move/touch, component·kubelet·runtime restart, container 삭제 명령을 제공하지 않는다. 변경 owner는 실행 직전 fresh Node UID/machineID, mirror UID/RV/current containerID 또는 부재, manifest inode/mtime, UTC 증거, active endpoint·socket provider를 다시 확인하고 승인 ID·HA peer·etcd quorum·한 번에 변경할 instance 수·idempotence를 확인해야 한다. 검증된 rollback 원본·명령·trigger가 없으면 중단한다.

replacement 뒤에는 모든 UID/RV/containerID/path/endpoint/READY를 폐기하고 새 mirror와 manifest→kubelet→CRI 관계를 재등록한다. 정상화는 `실제 control-plane 기능 → component health/leader/quorum → mirror Ready·restart 안정 → CRI state → kubelet sync → manifest identity` 역순이며, 다른 node만 정상인 것으로 닫지 않는다.

## 증거·미검증·상위 문서

보존: Node UID/machineID·remote hostname, role, mirror UID/RV/current containerID, manifest metadata, UTC 창·결정적 오류, active endpoint 식별자와 socket provider PID, CRI labels, 승인·rollback·기능 결과. manifest 원문, token, kubeconfig, Secret, private key, 전체 journal은 저장하지 않는다. 배포판별 unit/config, runtime과 HA topology는 실제 환경 미검증이다.
