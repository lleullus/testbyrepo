# etcd에 NOSPACE alarm이 발생한 경우

## 입력값과 빠른 수집

이 문서는 kubeadm 계열 static Pod etcd를 대상으로 한다. 실행 hop은 `승인된 작업 PC/bastion의 Bash -> Kubernetes API의 current mirror Pod -> current Node -> 승인된 SSH host의 /etc/machine-id -> argv에서 확인한 client endpoint -> current etcd member -> data-dir mount/device`다. systemd 또는 managed control plane이면 Pod·host·endpoint를 추측하지 않고 제공자/etcd owner의 동등한 read-only 경로로 이관한다.

| 종류 | 값 | 등록·선택 기준 |
|---|---|---|
| 최초 입력 | `NS`, `ETCD_POD` | 승인 inventory의 namespace와 exact mirror Pod name |
| API 확인 자동값 | Pod UID/RV/mirror source, regular container/current containerID, Node UID/machineID, argv·TLS/data-dir | 모든 API와 단일 관계가 성공할 때만 등록 |
| 계산 후보값 | client endpoint 목록, argv hash·escaped regex | 현재 regular container argv에서 생성하며 아직 실행 대상이 아님 |
| 운영자 선택값 | `HOST`, exact `ENDPOINT`, UTC 증거 창, Prometheus target labels | inventory와 출력의 member/node 관계를 확인한 뒤 선택 |

API 실패나 재등록 전에는 target, host, member, filesystem, time, query, evidence, mutation, rollback, normalization READY를 먼저 폐기한다. 작업 PC 변수가 SSH에 자동 전달된다고 가정하지 않고 고정 remote script의 positional argument로만 전달한다. `eval`은 사용하지 않는다.

**Bash·도구 확인**

`TOOLS_READY=false; MISSING=''; for T in kubectl jq sed grep date mktemp sha256sum ssh awk; do command -v "$T" >/dev/null 2>&1 || MISSING="$MISSING $T"; done; if [ -n "${BASH_VERSION:-}" ] && [ -z "$MISSING" ]; then TOOLS_READY=true; printf 'TOOLS_READY=true bash=%s\n' "$BASH_VERSION"; else printf '중단: Bash 또는 도구 없음:%s\n' "$MISSING" >&2; fi`

**current mirror Pod·Node·argv 등록**

```bash
unset TARGET_READY HOST_READY ETCD_READY FS_READY TIME_READY QUERY_READY EVIDENCE_READY MUTATION_READY ROLLBACK_READY NORMALIZATION_READY POD_UID POD_RV POD_CREATED POD_OWNER MIRROR_SOURCE NODE NODE_UID NODE_MACHINE_ID ETCD_CONTAINER CONTAINER_KIND CONTAINER_ID ARGV_SHA ARGV_RE DATA_DIR CA_FILE CERT_FILE KEY_FILE HOST ENDPOINT REMOTE_MACHINE_ID MEMBER_ID START_RFC3339 END_RFC3339 JOB INSTANCE JOB_RE INSTANCE_RE
ENDPOINT_CANDIDATES=()
TARGET_READY=false
if [ "$INPUT_READY" != true ]; then
  printf '%s\n' '중단: INPUT_READY가 아니다.' >&2
elif POD_JSON="$(kubectl get pod "$ETCD_POD" -n "$NS" -o json)" && NODE="$(jq -r '.spec.nodeName // empty' <<<"$POD_JSON")" && [ -n "$NODE" ] && NODE_JSON="$(kubectl get node "$NODE" -o json)"; then
  mapfile -t CONTAINERS < <(jq -r '[.spec.containers[]|select(([.command[]?,.args[]?]|join(" "))|test("(^|/)etcd( |$)"))|.name]|unique[]' <<<"$POD_JSON")
  if [ "${#CONTAINERS[@]}" -ne 1 ]; then
    printf '중단: etcd regular container count=%s\n' "${#CONTAINERS[@]}" >&2
  else
    ETCD_CONTAINER="${CONTAINERS[0]}"
    CONTAINER_KIND=regular
    POD_UID="$(jq -r '.metadata.uid // empty' <<<"$POD_JSON")"
    POD_RV="$(jq -r '.metadata.resourceVersion // empty' <<<"$POD_JSON")"
    POD_CREATED="$(jq -r '.metadata.creationTimestamp // empty' <<<"$POD_JSON")"
    MIRROR_SOURCE="$(jq -r '.metadata.annotations["kubernetes.io/config.mirror"] // empty' <<<"$POD_JSON")"
    POD_OWNER="$(jq -r '[.metadata.ownerReferences[]?|"\(.kind)/\(.name)#\(.uid)"]|join(",")' <<<"$POD_JSON")"
    NODE_UID="$(jq -r '.metadata.uid // empty' <<<"$NODE_JSON")"
    NODE_MACHINE_ID="$(jq -r '.status.nodeInfo.machineID // empty' <<<"$NODE_JSON")"
    CONTAINER_ID="$(jq -r --arg c "$ETCD_CONTAINER" '.status.containerStatuses[]?|select(.name==$c and .state.running!=null)|.containerID // empty' <<<"$POD_JSON")"
    ARGV="$(jq -r --arg c "$ETCD_CONTAINER" '.spec.containers[]|select(.name==$c)|[.command[]?,.args[]?]|join(" ")' <<<"$POD_JSON")"
    ARGV_SHA="$(printf '%s' "$ARGV" | sha256sum | jq -Rr 'split(" ")[0]')"
    ARGV_RE="^$(printf '%s' "$ARGV" | sed 's/[][\\.^$*+?(){}|]/\\&/g')$"
    mapfile -t DATA_FLAGS < <(jq -r --arg c "$ETCD_CONTAINER" '.spec.containers[]|select(.name==$c)|.args[]?|select(startswith("--data-dir="))|sub("^--data-dir=";"")' <<<"$POD_JSON")
    mapfile -t CA_FLAGS < <(jq -r --arg c "$ETCD_CONTAINER" '.spec.containers[]|select(.name==$c)|.args[]?|select(startswith("--trusted-ca-file="))|sub("^--trusted-ca-file=";"")' <<<"$POD_JSON")
    mapfile -t CERT_FLAGS < <(jq -r --arg c "$ETCD_CONTAINER" '.spec.containers[]|select(.name==$c)|.args[]?|select(startswith("--cert-file="))|sub("^--cert-file=";"")' <<<"$POD_JSON")
    mapfile -t KEY_FLAGS < <(jq -r --arg c "$ETCD_CONTAINER" '.spec.containers[]|select(.name==$c)|.args[]?|select(startswith("--key-file="))|sub("^--key-file=";"")' <<<"$POD_JSON")
    mapfile -t URL_FLAGS < <(jq -r --arg c "$ETCD_CONTAINER" '.spec.containers[]|select(.name==$c)|.args[]?|select(startswith("--listen-client-urls="))|sub("^--listen-client-urls=";"")|split(",")[]' <<<"$POD_JSON")
    ENDPOINT_CANDIDATES=("${URL_FLAGS[@]}")
    if [ -z "$POD_UID" ] || [ -z "$POD_RV" ] || [ -z "$POD_CREATED" ] || { [ -z "$MIRROR_SOURCE" ] && [ -z "$POD_OWNER" ]; } || [ -z "$NODE_UID" ] || [ -z "$NODE_MACHINE_ID" ] || [ -z "$CONTAINER_ID" ] || [ "${#DATA_FLAGS[@]}" -ne 1 ] || [ "${#CA_FLAGS[@]}" -ne 1 ] || [ "${#CERT_FLAGS[@]}" -ne 1 ] || [ "${#KEY_FLAGS[@]}" -ne 1 ] || [ "${#ENDPOINT_CANDIDATES[@]}" -lt 1 ]; then
      ENDPOINT_CANDIDATES=()
      printf '%s\n' '중단: mirror/Node/container/argv 단일 관계 실패' >&2
    else
      DATA_DIR="${DATA_FLAGS[0]}"; CA_FILE="${CA_FLAGS[0]}"; CERT_FILE="${CERT_FLAGS[0]}"; KEY_FILE="${KEY_FLAGS[0]}"
      TARGET_READY=true
      export POD_UID POD_RV POD_CREATED POD_OWNER MIRROR_SOURCE NODE NODE_UID NODE_MACHINE_ID ETCD_CONTAINER CONTAINER_KIND CONTAINER_ID ARGV_SHA ARGV_RE DATA_DIR CA_FILE CERT_FILE KEY_FILE
      printf 'TARGET_READY=true pod=%s#%s rv=%s owner=%s mirror=%s node=%s#%s machineID=%s container=%s/%s#%s\n' "$ETCD_POD" "$POD_UID" "$POD_RV" "${POD_OWNER:--}" "${MIRROR_SOURCE:--}" "$NODE" "$NODE_UID" "$NODE_MACHINE_ID" "$CONTAINER_KIND" "$ETCD_CONTAINER" "$CONTAINER_ID"
      printf 'data-dir=%s endpoint-candidates=%s argv-sha=%s\n' "$DATA_DIR" "${ENDPOINT_CANDIDATES[*]}" "$ARGV_SHA"
    fi
  fi
else
  printf '%s\n' '중단: Pod/Node API 실패' >&2
fi
```

**SSH host·exact endpoint 선택과 remote identity**

`HOST='PASTE_APPROVED_SSH_HOST_HERE'; ENDPOINT='PASTE_EXACT_CLIENT_ENDPOINT_HERE'; HOST_READY=false; unset ETCD_READY FS_READY QUERY_READY EVIDENCE_READY MUTATION_READY ROLLBACK_READY NORMALIZATION_READY REMOTE_MACHINE_ID MEMBER_ID; if [ "$TARGET_READY" != true ]; then printf '%s\n' '중단: TARGET_READY가 아니다.' >&2; elif ! [[ "$HOST" =~ ^[A-Za-z0-9._:-]+$ ]] || ! printf '%s\n' "${ENDPOINT_CANDIDATES[@]}" | grep -Fxq -- "$ENDPOINT"; then printf '%s\n' '중단: host 형식 또는 endpoint exact match 실패' >&2; else REMOTE_MACHINE_ID="$(ssh -T -- "$HOST" 'set -eu; test -r /etc/machine-id; tr -d "\n" </etc/machine-id' 2>/dev/null)"; SSH_RC=$?; if [ "$SSH_RC" -eq 0 ] && [ "$REMOTE_MACHINE_ID" = "$NODE_MACHINE_ID" ]; then HOST_READY=true; export HOST ENDPOINT REMOTE_MACHINE_ID; printf 'HOST_READY=true host=%s node=%s#%s machineID=%s endpoint=%s\n' "$HOST" "$NODE" "$NODE_UID" "$REMOTE_MACHINE_ID" "$ENDPOINT"; else printf '중단: remote identity 불일치 rc=%s\n' "$SSH_RC" >&2; fi; fi`

**fresh identity 함수 등록**

```bash
invalidate_target(){ unset TARGET_READY HOST_READY ETCD_READY FS_READY TIME_READY QUERY_READY EVIDENCE_READY MUTATION_READY ROLLBACK_READY NORMALIZATION_READY HOST ENDPOINT REMOTE_MACHINE_ID MEMBER_ID START_RFC3339 END_RFC3339 START_EPOCH END_EPOCH JOB INSTANCE JOB_RE INSTANCE_RE; TARGET_READY=false; }
fresh_target(){ local p n uid rv node nid mid cid argv sha mirror owner; p="$(kubectl get pod "$ETCD_POD" -n "$NS" -o json)" && node="$(jq -r '.spec.nodeName // empty' <<<"$p")" && n="$(kubectl get node "$node" -o json)" || { invalidate_target; printf '%s\n' '중단: fresh Pod/Node API 실패' >&2; return 1; }; uid="$(jq -r '.metadata.uid // empty' <<<"$p")"; rv="$(jq -r '.metadata.resourceVersion // empty' <<<"$p")"; nid="$(jq -r '.metadata.uid // empty' <<<"$n")"; mid="$(jq -r '.status.nodeInfo.machineID // empty' <<<"$n")"; cid="$(jq -r --arg c "$ETCD_CONTAINER" '.status.containerStatuses[]?|select(.name==$c and .state.running!=null)|.containerID // empty' <<<"$p")"; argv="$(jq -r --arg c "$ETCD_CONTAINER" '.spec.containers[]|select(.name==$c)|[.command[]?,.args[]?]|join(" ")' <<<"$p")"; sha="$(printf '%s' "$argv"|sha256sum|jq -Rr 'split(" ")[0]')"; mirror="$(jq -r '.metadata.annotations["kubernetes.io/config.mirror"] // empty' <<<"$p")"; owner="$(jq -r '[.metadata.ownerReferences[]?|"\(.kind)/\(.name)#\(.uid)"]|join(",")' <<<"$p")"; if [ "$uid" = "$POD_UID" ] && [ "$rv" = "$POD_RV" ] && [ "$node" = "$NODE" ] && [ "$nid" = "$NODE_UID" ] && [ "$mid" = "$NODE_MACHINE_ID" ] && [ "$cid" = "$CONTAINER_ID" ] && [ "$sha" = "$ARGV_SHA" ] && [[ "$argv" =~ $ARGV_RE ]] && [ "$mirror" = "$MIRROR_SOURCE" ] && [ "$owner" = "$POD_OWNER" ]; then return 0; fi; invalidate_target; printf '%s\n' '중단: Pod/Node/container/argv lifecycle 변경, 전체 재등록' >&2; return 1; }
fresh_remote(){ local mid rc; [ "$HOST_READY" = true ] && fresh_target || return 1; mid="$(ssh -T -- "$HOST" 'set -eu; test -r /etc/machine-id; tr -d "\n" </etc/machine-id' 2>/dev/null)"; rc=$?; if [ "$rc" -eq 0 ] && [ "$mid" = "$NODE_MACHINE_ID" ]; then return 0; fi; HOST_READY=false; ETCD_READY=false; printf '%s\n' '중단: fresh remote /etc/machine-id 실패' >&2; return 1; }
fresh_member(){ local out id; [ "$ETCD_READY" = true ] && fresh_remote || return 1; out="$(ssh -T -- "$HOST" 'set -eu; e=$1; ca=$2; crt=$3; key=$4; sudo -- env ETCDCTL_API=3 etcdctl --endpoints="$e" --cacert="$ca" --cert="$crt" --key="$key" endpoint status -w json' sh "$ENDPOINT" "$CA_FILE" "$CERT_FILE" "$KEY_FILE")" || { ETCD_READY=false; return 1; }; id="$(jq -r 'if length==1 then .[0].Status.header.member_id // empty else empty end' <<<"$out")"; if [ -n "$id" ] && [ "$id" = "$MEMBER_ID" ]; then return 0; fi; ETCD_READY=false; printf '%s\n' '중단: current endpoint/member 관계 변경' >&2; return 1; }
```

## 진입 판단

| 구분 | 판단 기준 |
|---|---|
| 사용 | current `alarm list`에 `NOSPACE`, 또는 같은 member/UTC 창에 `mvcc: database space exceeded`가 직접 관측됨 |
| 적용 | current member ID, backend quota/size와 실제 data-dir mount/device를 연결할 수 있음 |
| 제외 | `CORRUPT`는 [[05. etcd에 CORRUPT alarm 또는 데이터 불일치가 의심되는 경우]], leader/quorum 상실은 [[02. etcd cluster에 leader가 없거나 quorum을 잃은 경우]], WAL/backend 지연은 [[03. etcd 요청·WAL fsync·backend commit 지연이 증가한 경우]] |

검색 문자열: `NOSPACE`, `mvcc: database space exceeded`, `quota-backend-bytes`, `etcd_mvcc_db_total_size_in_bytes`, `no space left on device`, `read-only`, `inode`, `compact`, `defrag`.

## 권한·보안·CRI 경계

`fresh_target && kubectl auth can-i get pods -n "$NS" && kubectl auth can-i get pods/log -n "$NS" && kubectl auth can-i get nodes`

`Forbidden`, SSH/TLS 파일 권한 실패와 빈 출력은 NOSPACE 증거가 아니다. RBAC를 확대하거나 TLS 검증을 끄지 않는다. CA/cert/key는 absolute path·regular readable file인지 원격에서 검사하지만 private key, Secret, token, 인증서 원문, audit body를 출력하지 않는다. 이 문서는 CRI를 사용하지 않는다. container lifecycle 오류는 active kubelet runtime endpoint와 socket provider를 검증하는 runtime 런북으로 이관한다.

## 관측별 진단 경로

| 지금 보이는 것 | 먼저 볼 것 | 다음 경계 |
|---|---|---|
| current member에 `NOSPACE` | alarm member ID, quota와 total/in-use size | backend quota·revision 보존 |
| backend quota 여유, host `ENOSPC` | data-dir mount의 block·inode·`ro` | node/storage |
| total은 크고 in-use는 낮음 | revision/compaction 정책과 member별 DB size | 승인된 compaction/defrag 검토 |
| `CORRUPT`도 있음 | CORRUPT member와 동일 revision hash | 무결성 런북 |

## current member·alarm 직접 확인

**원격 etcdctl/TLS preflight와 member 등록**

`ETCD_READY=false; unset FS_READY QUERY_READY EVIDENCE_READY MUTATION_READY ROLLBACK_READY NORMALIZATION_READY MEMBER_ID; if fresh_remote; then STATUS_JSON="$(ssh -T -- "$HOST" 'set -eu; e=$1; ca=$2; crt=$3; key=$4; command -v etcdctl >/dev/null; for f in "$ca" "$crt" "$key"; do case "$f" in /*) ;; *) exit 21;; esac; sudo -- test -f "$f"; sudo -- test -r "$f"; done; sudo -- env ETCDCTL_API=3 etcdctl version >/dev/null; sudo -- env ETCDCTL_API=3 etcdctl --endpoints="$e" --cacert="$ca" --cert="$crt" --key="$key" endpoint status -w json' sh "$ENDPOINT" "$CA_FILE" "$CERT_FILE" "$KEY_FILE")"; RC=$?; if [ "$RC" -eq 0 ]; then MEMBER_ID="$(jq -r 'if length==1 then .[0].Status.header.member_id // empty else empty end' <<<"$STATUS_JSON")"; if [ -n "$MEMBER_ID" ]; then ETCD_READY=true; export MEMBER_ID; printf 'ETCD_READY=true endpoint=%s memberID=%s\n' "$ENDPOINT" "$MEMBER_ID"; else printf '%s\n' '중단: endpoint status member 단일 해석 실패' >&2; fi; else printf '중단: remote preflight rc=%s\n' "$RC" >&2; fi; fi`

`if fresh_member; then ssh -T -- "$HOST" 'set -eu; e=$1; ca=$2; crt=$3; key=$4; sudo -- env ETCDCTL_API=3 etcdctl --endpoints="$e" --cacert="$ca" --cert="$crt" --key="$key" alarm list; sudo -- env ETCDCTL_API=3 etcdctl --endpoints="$e" --cacert="$ca" --cert="$crt" --key="$key" endpoint health --cluster; sudo -- env ETCDCTL_API=3 etcdctl --endpoints="$e" --cacert="$ca" --cert="$crt" --key="$key" endpoint status --cluster -w table; sudo -- env ETCDCTL_API=3 etcdctl --endpoints="$e" --cacert="$ca" --cert="$crt" --key="$key" member list -w table' sh "$ENDPOINT" "$CA_FILE" "$CERT_FILE" "$KEY_FILE"; fi`

producer인 `etcdctl`의 nonzero rc나 빈 table은 정상으로 해석하지 않는다. `alarm list`의 member ID를 등록한 `MEMBER_ID` 및 member list의 ID/name/peer/client URL과 대조한다. `CORRUPT`, leader 없음, voting quorum 미달이면 공간 변경 검토를 중단한다.

## data-dir filesystem gate

`FS_READY=false; if fresh_member; then ssh -T -- "$HOST" 'set -eu; d=$1; case "$d" in /*) ;; *) exit 21;; esac; sudo -- test -d "$d"; sudo -- findmnt -T "$d" -o TARGET,SOURCE,FSTYPE,OPTIONS; sudo -- df -h "$d"; sudo -- df -i "$d"; sudo -- stat -c "%d:%i %A %U %G %a %n" "$d"' sh "$DATA_DIR"; RC=$?; if [ "$RC" -eq 0 ]; then FS_READY=true; printf 'FS_READY=true memberID=%s data-dir=%s\n' "$MEMBER_ID" "$DATA_DIR"; else printf '중단: filesystem producer rc=%s\n' "$RC" >&2; fi; fi`

mount source, filesystem, `rw/ro`, block/inode 사용률과 data-dir device/inode를 같은 member/node에 연결한다. host filesystem 부족은 backend quota와 별개다. `FS_READY`는 공간 변경을 승인하지 않는다.

## canonical UTC 증거 창과 로그 rc

`START_RFC3339='PASTE_START_UTC_RFC3339_HERE'; END_RFC3339='PASTE_END_UTC_RFC3339_HERE'; TIME_READY=false; unset EVIDENCE_READY MUTATION_READY ROLLBACK_READY NORMALIZATION_READY; R='^[0-9]{4}-(0[1-9]|1[0-2])-([0-2][0-9]|3[01])T([01][0-9]|2[0-3]):[0-5][0-9]:[0-5][0-9]Z$'; if [[ "$START_RFC3339" =~ $R ]] && [[ "$END_RFC3339" =~ $R ]]; then S="$(date -u -d "$START_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null)"; SRC=$?; E="$(date -u -d "$END_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null)"; ERC=$?; START_EPOCH="$(date -u -d "$START_RFC3339" +%s 2>/dev/null)"; END_EPOCH="$(date -u -d "$END_RFC3339" +%s 2>/dev/null)"; if [ "$SRC" -eq 0 ] && [ "$ERC" -eq 0 ] && [ "$S" = "$START_RFC3339" ] && [ "$E" = "$END_RFC3339" ] && [ "$START_EPOCH" -lt "$END_EPOCH" ]; then TIME_READY=true; export START_RFC3339 END_RFC3339; printf 'TIME_READY=true window=%s..%s\n' "$START_RFC3339" "$END_RFC3339"; else printf '%s\n' '중단: UTC round-trip/start<end 실패' >&2; fi; else printf '%s\n' '중단: canonical UTC RFC3339 아님' >&2; fi`

`EVIDENCE_READY=false; if [ "$TIME_READY" = true ] && fresh_member; then RAW="$(mktemp)"; WIN="$(mktemp)"; kubectl logs "$ETCD_POD" -n "$NS" -c "$ETCD_CONTAINER" --timestamps --since-time="$START_RFC3339" >"$RAW"; PRODUCER_RC=$?; if [ "$PRODUCER_RC" -eq 0 ]; then awk -v start="$START_RFC3339" -v end="$END_RFC3339" '$1>=start && $1<=end' "$RAW" >"$WIN"; WINDOW_RC=$?; if [ "$WINDOW_RC" -eq 0 ]; then grep -E -i -C 3 'NOSPACE|database space exceeded|quota|no space left|read-only|inode|compact|defrag|corrupt|leader|error' "$WIN"; FILTER_RC=$?; if [ "$FILTER_RC" -eq 0 ]; then EVIDENCE_READY=true; printf 'EVIDENCE_READY=true producer_rc=%s window_rc=%s filter_rc=%s memberID=%s window=%s..%s\n' "$PRODUCER_RC" "$WINDOW_RC" "$FILTER_RC" "$MEMBER_ID" "$START_RFC3339" "$END_RFC3339"; elif [ "$FILTER_RC" -eq 1 ]; then printf 'filter_match=none producer_rc=%s window_rc=%s filter_rc=1\n' "$PRODUCER_RC" "$WINDOW_RC"; else printf '중단: log filter rc=%s\n' "$FILTER_RC" >&2; fi; else printf '중단: window filter rc=%s\n' "$WINDOW_RC" >&2; fi; else printf '중단: log producer rc=%s\n' "$PRODUCER_RC" >&2; fi; rm -f "$RAW" "$WIN"; fi`

filter rc `0`은 일치, `1`은 일치 없음, `>1`은 filter 오류다. 일치 없음은 오류 부재가 아니다. 민감정보가 보이면 보존을 중단하고 member ID·시각·오류 유형만 기록한다.

## 실행 가능한 Prometheus 쿼리

Prometheus target 화면에서 선택한 `ENDPOINT`의 current `MEMBER_ID`와 연결된 exact `job`·`instance`를 확인한 뒤 입력한다.

`JOB='PASTE_PROMETHEUS_ETCD_JOB_HERE'; INSTANCE='PASTE_PROMETHEUS_INSTANCE_FOR_SELECTED_MEMBER_HERE'; QUERY_READY=false; if fresh_member && [ -n "$JOB" ] && [ -n "$INSTANCE" ] && [[ "$JOB" != *$'\n'* ]] && [[ "$INSTANCE" != *$'\n'* ]]; then JOB_RE="$(printf '%s' "$JOB"|sed 's/[][\\.^$*+?(){}|]/\\&/g')"; INSTANCE_RE="$(printf '%s' "$INSTANCE"|sed 's/[][\\.^$*+?(){}|]/\\&/g')"; QUERY_READY=true; export JOB_RE INSTANCE_RE; printf 'QUERY_READY=true job=^%s$ instance=^%s$ memberID=%s\n' "$JOB_RE" "$INSTANCE_RE" "$MEMBER_ID"; else printf '%s\n' '중단: current member target label 미등록' >&2; fi`

`fresh_member && [ "$QUERY_READY" = true ] && printf 'max(etcd_mvcc_db_total_size_in_bytes{job=~"^%s$",instance=~"^%s$"})/max(etcd_server_quota_backend_bytes{job=~"^%s$",instance=~"^%s$"})\n' "$JOB_RE" "$INSTANCE_RE" "$JOB_RE" "$INSTANCE_RE"`

`fresh_member && [ "$QUERY_READY" = true ] && printf 'max(etcd_mvcc_db_total_size_in_use_in_bytes{job=~"^%s$",instance=~"^%s$"})/max(etcd_server_quota_backend_bytes{job=~"^%s$",instance=~"^%s$"})\n' "$JOB_RE" "$INSTANCE_RE" "$JOB_RE" "$INSTANCE_RE"`

`fresh_member && [ "$QUERY_READY" = true ] && printf 'increase(etcd_server_proposals_failed_total{job=~"^%s$",instance=~"^%s$"}[15m]) > 0\n' "$JOB_RE" "$INSTANCE_RE"`

완성 출력만 승인된 UI/API에 사용한다. HTTP status, Prometheus `status=success`, non-empty series를 각각 검사한다. 빈 결과는 0/정상이 아니라 metric 미지원·미수집·label/cluster/시간 오류·권한/API 실패 후보다.

## 원인 판정과 상태 변경 경계

| 직접 관계 | 판정 |
|---|---|
| current NOSPACE + total/in-use가 quota 근접 | backend quota/논리 사용량 경계 |
| current NOSPACE + total만 크고 in-use는 낮음 | 회수되지 않은 backend free space 후보 |
| host block/inode 100% 또는 `ro` | node/storage filesystem 경계 |
| CORRUPT 또는 quorum 불안정 | 공간 maintenance 중단, 해당 런북 이관 |

이 문서는 `alarm disarm`, compact, defrag, restart, member remove/add, data-dir 변경·삭제, snapshot restore 명령을 제공하지 않는다. 별도 mutation은 **각 실행 직전** fresh member/target, current alarm·quota·filesystem evidence, 승인 ID와 유효 window, 정확히 한 leader와 voting quorum, 검증된 snapshot source identity, 영향·멱등성·중단 조건, 실제 검증된 rollback/DR 절차를 다시 확인해야 한다. 이 조건 전에는 `EVIDENCE_READY`여도 `MUTATION_READY=false`, `ROLLBACK_READY=false`다.

static mirror/member replacement에는 selector를 억지 적용하지 않는다. 승인 membership의 member ID/peer URL, exact mirror Pod source, Node UID/machineID와 변경 이후 creationTimestamp로 replacement가 정확히 하나임을 확인한다. replacement 후 이름을 재사용하지 말고 모든 자동값·선택값·READY를 폐기해 처음부터 재등록한다.

## 정상화

정상화는 current membership의 모든 endpoint health -> current member ID/URL과 정확히 한 leader·진행하는 raft -> alarm 없음 -> backend quota/total/in-use와 data filesystem의 재상승 중단 -> current mirror Pod/Node/container -> API server `readyz` -> 승인된 실제 Kubernetes read/write 기능 순서로 확인한다. 쓰기 probe는 멱등성과 정리/rollback이 승인된 기존 제품 표면만 사용한다. 관찰 창 동안 NOSPACE·leader churn·storage timeout이 재발하지 않아야 한다. alarm 해제, Pod `Running`, endpoint 하나 성공, 빈 metric만으로 정상화하지 않는다.

`NORMALIZATION_READY=false; if fresh_member && [ "$FS_READY" = true ] && [ "$TIME_READY" = true ] && [ "$EVIDENCE_READY" = true ]; then printf '%s\n' '후속 수동 gate: 전체 endpoint/alarm/raft/filesystem/readyz/실제 기능과 재발 관찰을 모두 기록한 뒤에만 NORMALIZATION_READY=true로 승인 기록에 남긴다.'; else printf '%s\n' '중단: 정상화용 fresh evidence gate 실패' >&2; fi`
