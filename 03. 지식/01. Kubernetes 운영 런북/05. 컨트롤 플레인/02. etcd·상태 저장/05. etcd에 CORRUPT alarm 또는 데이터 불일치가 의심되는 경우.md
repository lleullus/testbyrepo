# etcd에 CORRUPT alarm 또는 데이터 불일치가 의심되는 경우

## 입력값과 빠른 수집

이 문서는 kubeadm 계열 static Pod etcd의 읽기 전용 무결성 판정을 다룬다. hop은 `승인된 작업 PC/bastion Bash -> current mirror Pod/Node -> /etc/machine-id가 일치하는 SSH host -> argv의 exact client endpoint -> 승인 membership의 전체 endpoint -> 같은 revision hash -> member data-dir mount/device`다. systemd·managed control plane이면 확인되지 않은 Pod, host, endpoint, TLS path를 만들지 않고 제공자/etcd owner의 동등한 integrity 경로로 이관한다.

| 종류 | 값 | 등록·선택 기준 |
|---|---|---|
| 최초 입력 | `NS`, `ETCD_POD` | 승인 inventory의 exact static mirror Pod |
| API 확인 자동값 | Pod UID/RV/mirror source, regular container/current containerID, Node UID/machineID, argv/TLS/data-dir | 전체 API와 단일 관계 성공 시 등록 |
| 계산 후보값 | client endpoint, argv hash·regex | argv에서 strict extraction하며 target은 아직 미확정 |
| 운영자 선택값 | SSH host, selected endpoint, 승인된 전체 endpoint CSV, common revision, UTC 창, Prometheus labels | current status/member list와 inventory를 대조한 뒤 선택 |

API 실패 또는 재등록 전에 target·host·member·cluster·revision·filesystem·time·query·evidence·mutation·rollback·normalization READY를 모두 폐기한다. 작업 PC 변수는 고정 remote script의 positional argument로 전달하며 `eval`과 agent forwarding을 사용하지 않는다.

**Bash·도구 확인**

`TOOLS_READY=false; MISSING=''; for T in kubectl jq sed grep date mktemp sha256sum ssh awk sort; do command -v "$T" >/dev/null 2>&1 || MISSING="$MISSING $T"; done; if [ -n "${BASH_VERSION:-}" ] && [ -z "$MISSING" ]; then TOOLS_READY=true; printf 'TOOLS_READY=true bash=%s\n' "$BASH_VERSION"; else printf '중단: Bash 또는 도구 없음:%s\n' "$MISSING" >&2; fi`

**current mirror Pod·Node·argv 등록**

```bash
unset TARGET_READY HOST_READY ETCD_READY CLUSTER_READY REVISION_READY FS_READY TIME_READY QUERY_READY EVIDENCE_READY MUTATION_READY ROLLBACK_READY NORMALIZATION_READY POD_UID POD_RV POD_CREATED POD_OWNER MIRROR_SOURCE NODE NODE_UID NODE_MACHINE_ID ETCD_CONTAINER CONTAINER_KIND CONTAINER_ID ARGV_SHA ARGV_RE DATA_DIR CA_FILE CERT_FILE KEY_FILE HOST ENDPOINT ENDPOINT_LIST ENDPOINT_LIST_CANON REMOTE_MACHINE_ID MEMBER_ID REVISION START_RFC3339 END_RFC3339 JOB INSTANCE JOB_RE INSTANCE_RE
ENDPOINT_CANDIDATES=()
TARGET_READY=false
if [ "$INPUT_READY" != true ]; then
  printf '%s\n' '중단: INPUT_READY가 아니다.' >&2
elif POD_JSON="$(kubectl get pod "$ETCD_POD" -n "$NS" -o json)" && NODE="$(jq -r '.spec.nodeName // empty' <<<"$POD_JSON")" && [ -n "$NODE" ] && NODE_JSON="$(kubectl get node "$NODE" -o json)"; then
  mapfile -t CONTAINERS < <(jq -r '[.spec.containers[]|select(([.command[]?,.args[]?]|join(" "))|test("(^|/)etcd( |$)"))|.name]|unique[]' <<<"$POD_JSON")
  if [ "${#CONTAINERS[@]}" -ne 1 ]; then
    printf '중단: etcd regular container count=%s\n' "${#CONTAINERS[@]}" >&2
  else
    ETCD_CONTAINER="${CONTAINERS[0]}"; CONTAINER_KIND=regular
    POD_UID="$(jq -r '.metadata.uid // empty' <<<"$POD_JSON")"; POD_RV="$(jq -r '.metadata.resourceVersion // empty' <<<"$POD_JSON")"; POD_CREATED="$(jq -r '.metadata.creationTimestamp // empty' <<<"$POD_JSON")"
    MIRROR_SOURCE="$(jq -r '.metadata.annotations["kubernetes.io/config.mirror"] // empty' <<<"$POD_JSON")"; POD_OWNER="$(jq -r '[.metadata.ownerReferences[]?|"\(.kind)/\(.name)#\(.uid)"]|join(",")' <<<"$POD_JSON")"
    NODE_UID="$(jq -r '.metadata.uid // empty' <<<"$NODE_JSON")"; NODE_MACHINE_ID="$(jq -r '.status.nodeInfo.machineID // empty' <<<"$NODE_JSON")"
    CONTAINER_ID="$(jq -r --arg c "$ETCD_CONTAINER" '.status.containerStatuses[]?|select(.name==$c and .state.running!=null)|.containerID // empty' <<<"$POD_JSON")"
    ARGV="$(jq -r --arg c "$ETCD_CONTAINER" '.spec.containers[]|select(.name==$c)|[.command[]?,.args[]?]|join(" ")' <<<"$POD_JSON")"; ARGV_SHA="$(printf '%s' "$ARGV"|sha256sum|jq -Rr 'split(" ")[0]')"; ARGV_RE="^$(printf '%s' "$ARGV"|sed 's/[][\\.^$*+?(){}|]/\\&/g')$"
    mapfile -t DATA_FLAGS < <(jq -r --arg c "$ETCD_CONTAINER" '.spec.containers[]|select(.name==$c)|.args[]?|select(startswith("--data-dir="))|sub("^--data-dir=";"")' <<<"$POD_JSON")
    mapfile -t CA_FLAGS < <(jq -r --arg c "$ETCD_CONTAINER" '.spec.containers[]|select(.name==$c)|.args[]?|select(startswith("--trusted-ca-file="))|sub("^--trusted-ca-file=";"")' <<<"$POD_JSON")
    mapfile -t CERT_FLAGS < <(jq -r --arg c "$ETCD_CONTAINER" '.spec.containers[]|select(.name==$c)|.args[]?|select(startswith("--cert-file="))|sub("^--cert-file=";"")' <<<"$POD_JSON")
    mapfile -t KEY_FLAGS < <(jq -r --arg c "$ETCD_CONTAINER" '.spec.containers[]|select(.name==$c)|.args[]?|select(startswith("--key-file="))|sub("^--key-file=";"")' <<<"$POD_JSON")
    mapfile -t URL_FLAGS < <(jq -r --arg c "$ETCD_CONTAINER" '.spec.containers[]|select(.name==$c)|.args[]?|select(startswith("--listen-client-urls="))|sub("^--listen-client-urls=";"")|split(",")[]' <<<"$POD_JSON")
    ENDPOINT_CANDIDATES=("${URL_FLAGS[@]}")
    if [ -z "$POD_UID" ] || [ -z "$POD_RV" ] || [ -z "$POD_CREATED" ] || { [ -z "$MIRROR_SOURCE" ] && [ -z "$POD_OWNER" ]; } || [ -z "$NODE_UID" ] || [ -z "$NODE_MACHINE_ID" ] || [ -z "$CONTAINER_ID" ] || [ "${#DATA_FLAGS[@]}" -ne 1 ] || [ "${#CA_FLAGS[@]}" -ne 1 ] || [ "${#CERT_FLAGS[@]}" -ne 1 ] || [ "${#KEY_FLAGS[@]}" -ne 1 ] || [ "${#ENDPOINT_CANDIDATES[@]}" -lt 1 ]; then
      ENDPOINT_CANDIDATES=(); printf '%s\n' '중단: mirror/Node/container/argv 단일 관계 실패' >&2
    else
      DATA_DIR="${DATA_FLAGS[0]}"; CA_FILE="${CA_FLAGS[0]}"; CERT_FILE="${CERT_FLAGS[0]}"; KEY_FILE="${KEY_FLAGS[0]}"; TARGET_READY=true
      export POD_UID POD_RV POD_CREATED POD_OWNER MIRROR_SOURCE NODE NODE_UID NODE_MACHINE_ID ETCD_CONTAINER CONTAINER_KIND CONTAINER_ID ARGV_SHA ARGV_RE DATA_DIR CA_FILE CERT_FILE KEY_FILE
      printf 'TARGET_READY=true pod=%s#%s rv=%s owner=%s mirror=%s node=%s#%s machineID=%s container=%s/%s#%s\n' "$ETCD_POD" "$POD_UID" "$POD_RV" "${POD_OWNER:--}" "${MIRROR_SOURCE:--}" "$NODE" "$NODE_UID" "$NODE_MACHINE_ID" "$CONTAINER_KIND" "$ETCD_CONTAINER" "$CONTAINER_ID"
      printf 'data-dir=%s endpoint-candidates=%s argv-sha=%s\n' "$DATA_DIR" "${ENDPOINT_CANDIDATES[*]}" "$ARGV_SHA"
    fi
  fi
else
  printf '%s\n' '중단: Pod/Node API 실패' >&2
fi
```

**fresh target·remote·member 함수**

```bash
invalidate_target(){ unset TARGET_READY HOST_READY ETCD_READY CLUSTER_READY REVISION_READY FS_READY TIME_READY QUERY_READY EVIDENCE_READY MUTATION_READY ROLLBACK_READY NORMALIZATION_READY HOST ENDPOINT ENDPOINT_LIST ENDPOINT_LIST_CANON REMOTE_MACHINE_ID MEMBER_ID REVISION START_RFC3339 END_RFC3339 JOB INSTANCE JOB_RE INSTANCE_RE; TARGET_READY=false; }
fresh_target(){ local p n uid rv node nid mid cid argv sha mirror owner; p="$(kubectl get pod "$ETCD_POD" -n "$NS" -o json)" && node="$(jq -r '.spec.nodeName // empty' <<<"$p")" && n="$(kubectl get node "$node" -o json)" || { invalidate_target; return 1; }; uid="$(jq -r '.metadata.uid // empty' <<<"$p")"; rv="$(jq -r '.metadata.resourceVersion // empty' <<<"$p")"; nid="$(jq -r '.metadata.uid // empty' <<<"$n")"; mid="$(jq -r '.status.nodeInfo.machineID // empty' <<<"$n")"; cid="$(jq -r --arg c "$ETCD_CONTAINER" '.status.containerStatuses[]?|select(.name==$c and .state.running!=null)|.containerID // empty' <<<"$p")"; argv="$(jq -r --arg c "$ETCD_CONTAINER" '.spec.containers[]|select(.name==$c)|[.command[]?,.args[]?]|join(" ")' <<<"$p")"; sha="$(printf '%s' "$argv"|sha256sum|jq -Rr 'split(" ")[0]')"; mirror="$(jq -r '.metadata.annotations["kubernetes.io/config.mirror"] // empty' <<<"$p")"; owner="$(jq -r '[.metadata.ownerReferences[]?|"\(.kind)/\(.name)#\(.uid)"]|join(",")' <<<"$p")"; if [ "$uid" = "$POD_UID" ] && [ "$rv" = "$POD_RV" ] && [ "$node" = "$NODE" ] && [ "$nid" = "$NODE_UID" ] && [ "$mid" = "$NODE_MACHINE_ID" ] && [ "$cid" = "$CONTAINER_ID" ] && [ "$sha" = "$ARGV_SHA" ] && [[ "$argv" =~ $ARGV_RE ]] && [ "$mirror" = "$MIRROR_SOURCE" ] && [ "$owner" = "$POD_OWNER" ]; then return 0; fi; invalidate_target; printf '%s\n' '중단: current lifecycle 변경, 전체 재등록' >&2; return 1; }
fresh_remote(){ local mid rc; [ "$HOST_READY" = true ] && fresh_target || return 1; mid="$(ssh -T -- "$HOST" 'set -eu; test -r /etc/machine-id; tr -d "\n" </etc/machine-id' 2>/dev/null)"; rc=$?; if [ "$rc" -eq 0 ] && [ "$mid" = "$NODE_MACHINE_ID" ]; then return 0; fi; HOST_READY=false; ETCD_READY=false; CLUSTER_READY=false; printf '%s\n' '중단: fresh remote identity 실패' >&2; return 1; }
fresh_member(){ local out id; [ "$ETCD_READY" = true ] && fresh_remote || return 1; out="$(ssh -T -- "$HOST" 'set -eu; e=$1; ca=$2; crt=$3; key=$4; sudo -- env ETCDCTL_API=3 etcdctl --endpoints="$e" --cacert="$ca" --cert="$crt" --key="$key" endpoint status -w json' sh "$ENDPOINT" "$CA_FILE" "$CERT_FILE" "$KEY_FILE")" || { ETCD_READY=false; CLUSTER_READY=false; return 1; }; id="$(jq -r 'if length==1 then .[0].Status.header.member_id // empty else empty end' <<<"$out")"; if [ -n "$id" ] && [ "$id" = "$MEMBER_ID" ]; then return 0; fi; ETCD_READY=false; CLUSTER_READY=false; printf '%s\n' '중단: endpoint/member 관계 변경' >&2; return 1; }
fresh_cluster(){ local json api; [ "$CLUSTER_READY" = true ] && fresh_member || return 1; json="$(ssh -T -- "$HOST" 'set -eu; e=$1; ca=$2; crt=$3; key=$4; sudo -- env ETCDCTL_API=3 etcdctl --endpoints="$e" --cacert="$ca" --cert="$crt" --key="$key" member list -w json' sh "$ENDPOINT" "$CA_FILE" "$CERT_FILE" "$KEY_FILE")" || { CLUSTER_READY=false; return 1; }; api="$(jq -r '[.members[]?.clientURLs[]?]|sort|join(",")' <<<"$json")"; if [ -n "$api" ] && [ "$api" = "$ENDPOINT_LIST_CANON" ]; then return 0; fi; CLUSTER_READY=false; REVISION_READY=false; printf '%s\n' '중단: current membership/clientURL 집합 변경' >&2; return 1; }
```

## 진입 판단

| 구분 | 판단 기준 |
|---|---|
| 사용 | current `CORRUPT` alarm, 같은 revision의 endpoint hash 불일치, 또는 member-local integrity/checksum/I/O 오류가 직접 관측됨 |
| 적용 | current membership, endpoint/member ID, same revision hash와 member data filesystem을 연결 가능 |
| 제외 | `NOSPACE`만 있으면 [[04. etcd에 NOSPACE alarm이 발생한 경우]], no leader/quorum은 [[02. etcd cluster에 leader가 없거나 quorum을 잃은 경우]], transport timeout만 있으면 peer/network 경로 |

검색 문자열: `CORRUPT`, `hash mismatch`, `hashkv`, `integrity`, `checksum`, `database file`, `I/O error`, `Input/output error`, `raft`, `peer`.

## 보안·권한·CRI 경계

`fresh_target && kubectl auth can-i get pods -n "$NS" && kubectl auth can-i get pods/log -n "$NS" && kubectl auth can-i get nodes`

RBAC/TLS/SSH 실패나 서로 다른 revision의 hash는 corruption 증거가 아니다. TLS 검증을 끄거나 권한을 확대하지 않는다. private key, Secret, token, certificate/snapshot 원문과 audit body를 출력하지 않는다. Audit은 승인된 reader가 API storage 오류의 timestamp/verb/objectRef/status만 본다. CRI는 사용하지 않으며 container lifecycle 장애는 active kubelet endpoint와 runtime socket provider를 검증하는 런북으로 이관한다.

## selected member와 승인 membership 등록

`ETCD_READY=false; unset CLUSTER_READY REVISION_READY FS_READY QUERY_READY EVIDENCE_READY MUTATION_READY ROLLBACK_READY NORMALIZATION_READY MEMBER_ID; if fresh_remote; then STATUS_JSON="$(ssh -T -- "$HOST" 'set -eu; e=$1; ca=$2; crt=$3; key=$4; command -v etcdctl >/dev/null; for f in "$ca" "$crt" "$key"; do case "$f" in /*) ;; *) exit 21;; esac; sudo -- test -f "$f"; sudo -- test -r "$f"; done; sudo -- env ETCDCTL_API=3 etcdctl version >/dev/null; sudo -- env ETCDCTL_API=3 etcdctl --endpoints="$e" --cacert="$ca" --cert="$crt" --key="$key" endpoint status -w json' sh "$ENDPOINT" "$CA_FILE" "$CERT_FILE" "$KEY_FILE")"; RC=$?; if [ "$RC" -eq 0 ]; then MEMBER_ID="$(jq -r 'if length==1 then .[0].Status.header.member_id // empty else empty end' <<<"$STATUS_JSON")"; if [ -n "$MEMBER_ID" ]; then ETCD_READY=true; export MEMBER_ID; printf 'ETCD_READY=true endpoint=%s memberID=%s\n' "$ENDPOINT" "$MEMBER_ID"; else printf '%s\n' '중단: member ID 해석 실패' >&2; fi; else printf '중단: preflight rc=%s\n' "$RC" >&2; fi; fi`

승인 inventory의 voting/learner 전체 client URL을 쉼표로 연결해 입력한다. URL 순서는 무관하지만 누락·추가·중복을 허용하지 않는다.

`ENDPOINT_LIST='PASTE_APPROVED_ETCD_CLIENT_ENDPOINT_CSV_HERE'; CLUSTER_READY=false; unset REVISION_READY FS_READY QUERY_READY EVIDENCE_READY MUTATION_READY ROLLBACK_READY NORMALIZATION_READY ENDPOINT_LIST_CANON REVISION; if fresh_member && [ -n "$ENDPOINT_LIST" ] && [[ "$ENDPOINT_LIST" != *[[:space:]]* ]]; then IFS=',' read -r -a APPROVED_ENDPOINTS <<<"$ENDPOINT_LIST"; if [ "${#APPROVED_ENDPOINTS[@]}" -lt 1 ] || ! printf '%s\n' "${APPROVED_ENDPOINTS[@]}" | grep -Fxq -- "$ENDPOINT"; then printf '%s\n' '중단: selected endpoint가 승인 목록에 없음' >&2; else ENDPOINT_LIST_CANON="$(printf '%s\n' "${APPROVED_ENDPOINTS[@]}" | sort -u | jq -Rsc 'split("\n")[:-1]|join(",")')"; MEMBER_JSON="$(ssh -T -- "$HOST" 'set -eu; e=$1; ca=$2; crt=$3; key=$4; sudo -- env ETCDCTL_API=3 etcdctl --endpoints="$e" --cacert="$ca" --cert="$crt" --key="$key" member list -w json' sh "$ENDPOINT" "$CA_FILE" "$CERT_FILE" "$KEY_FILE")"; RC=$?; API_LIST="$(jq -r '[.members[]?.clientURLs[]?]|sort|join(",")' <<<"$MEMBER_JSON")"; if [ "$RC" -eq 0 ] && [ "${#APPROVED_ENDPOINTS[@]}" -eq "$(printf '%s\n' "${APPROVED_ENDPOINTS[@]}" | sort -u | jq -Rsc 'split("\n")[:-1]|length')" ] && [ -n "$API_LIST" ] && [ "$API_LIST" = "$ENDPOINT_LIST_CANON" ]; then CLUSTER_READY=true; export ENDPOINT_LIST ENDPOINT_LIST_CANON; printf 'CLUSTER_READY=true selectedMember=%s endpoints=%s\n' "$MEMBER_ID" "$ENDPOINT_LIST_CANON"; else printf '중단: 승인 목록/current member clientURL 불일치 rc=%s\n' "$RC" >&2; fi; fi; else printf '%s\n' '중단: endpoint 목록 형식 또는 fresh member 실패' >&2; fi`

`if fresh_cluster; then ssh -T -- "$HOST" 'set -eu; list=$1; ca=$2; crt=$3; key=$4; sudo -- env ETCDCTL_API=3 etcdctl --endpoints="$list" --cacert="$ca" --cert="$crt" --key="$key" alarm list; sudo -- env ETCDCTL_API=3 etcdctl --endpoints="$list" --cacert="$ca" --cert="$crt" --key="$key" endpoint health; sudo -- env ETCDCTL_API=3 etcdctl --endpoints="$list" --cacert="$ca" --cert="$crt" --key="$key" endpoint status -w table' sh "$ENDPOINT_LIST_CANON" "$CA_FILE" "$CERT_FILE" "$KEY_FILE"; fi`

모든 endpoint의 producer rc, member ID, leader, raft term/index/applied, revision과 alarm을 기록한다. 빈 table·timeout은 hash 불일치가 아니라 수집 실패 또는 raft/transport 후보다. current membership과 정확히 한 leader, voting quorum을 확인하지 못하면 무결성 mutation을 금지한다.

## same revision hash gate

endpoint status에서 **모든 비교 member가 이미 적용한 양의 revision**을 선택한다. 다른 revision을 비교하지 않는다.

`REVISION='PASTE_COMMON_APPLIED_REVISION_HERE'; REVISION_READY=false; unset EVIDENCE_READY MUTATION_READY ROLLBACK_READY NORMALIZATION_READY; if fresh_cluster && [[ "$REVISION" =~ ^[1-9][0-9]*$ ]]; then STATUS_ALL="$(ssh -T -- "$HOST" 'set -eu; list=$1; ca=$2; crt=$3; key=$4; sudo -- env ETCDCTL_API=3 etcdctl --endpoints="$list" --cacert="$ca" --cert="$crt" --key="$key" endpoint status -w json' sh "$ENDPOINT_LIST_CANON" "$CA_FILE" "$CERT_FILE" "$KEY_FILE")"; RC=$?; BELOW="$(jq -r --argjson r "$REVISION" '[.[]?|select((.Status.header.revision // 0)<$r)]|length' <<<"$STATUS_ALL")"; COUNT="$(jq -r 'length' <<<"$STATUS_ALL")"; if [ "$RC" -eq 0 ] && [ "$COUNT" -eq "${#APPROVED_ENDPOINTS[@]}" ] && [ "$BELOW" -eq 0 ]; then REVISION_READY=true; export REVISION; printf 'REVISION_READY=true revision=%s endpoints=%s\n' "$REVISION" "$COUNT"; else printf '중단: status producer/current revision gate 실패 rc=%s count=%s below=%s\n' "$RC" "${COUNT:--}" "${BELOW:--}" >&2; fi; else printf '%s\n' '중단: common revision 또는 fresh cluster gate 실패' >&2; fi`

`if [ "$REVISION_READY" = true ] && fresh_cluster; then ssh -T -- "$HOST" 'set -eu; list=$1; ca=$2; crt=$3; key=$4; rev=$5; sudo -- env ETCDCTL_API=3 etcdctl --endpoints="$list" --cacert="$ca" --cert="$crt" --key="$key" endpoint hashkv --rev="$rev"' sh "$ENDPOINT_LIST_CANON" "$CA_FILE" "$CERT_FILE" "$KEY_FILE" "$REVISION"; RC=$?; printf 'hashkv_producer_rc=%s revision=%s\n' "$RC" "$REVISION"; fi`

producer rc `0`, 전체 endpoint 응답, 같은 revision과 member ID가 먼저다. 그 뒤 한 hash만 다르면 member-local 후보, 여러 hash이면 cluster-wide integrity 후보로 기록한다. compacted revision, timeout, 권한 오류를 hash mismatch로 해석하지 않는다.

## data-dir filesystem과 UTC 로그

`FS_READY=false; if [ "$REVISION_READY" = true ] && fresh_cluster; then ssh -T -- "$HOST" 'set -eu; d=$1; case "$d" in /*) ;; *) exit 21;; esac; sudo -- test -d "$d"; sudo -- findmnt -T "$d" -o TARGET,SOURCE,FSTYPE,OPTIONS; sudo -- df -h "$d"; sudo -- df -i "$d"; sudo -- stat -c "%d:%i %A %U %G %a %n" "$d"' sh "$DATA_DIR"; RC=$?; if [ "$RC" -eq 0 ]; then FS_READY=true; printf 'FS_READY=true memberID=%s data-dir=%s\n' "$MEMBER_ID" "$DATA_DIR"; else printf '중단: filesystem producer rc=%s\n' "$RC" >&2; fi; fi`

`START_RFC3339='PASTE_START_UTC_RFC3339_HERE'; END_RFC3339='PASTE_END_UTC_RFC3339_HERE'; TIME_READY=false; unset EVIDENCE_READY MUTATION_READY ROLLBACK_READY NORMALIZATION_READY; R='^[0-9]{4}-(0[1-9]|1[0-2])-([0-2][0-9]|3[01])T([01][0-9]|2[0-3]):[0-5][0-9]:[0-5][0-9]Z$'; if [[ "$START_RFC3339" =~ $R ]] && [[ "$END_RFC3339" =~ $R ]]; then S="$(date -u -d "$START_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null)"; SRC=$?; E="$(date -u -d "$END_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null)"; ERC=$?; SE="$(date -u -d "$START_RFC3339" +%s 2>/dev/null)"; EE="$(date -u -d "$END_RFC3339" +%s 2>/dev/null)"; if [ "$SRC" -eq 0 ] && [ "$ERC" -eq 0 ] && [ "$S" = "$START_RFC3339" ] && [ "$E" = "$END_RFC3339" ] && [ "$SE" -lt "$EE" ]; then TIME_READY=true; export START_RFC3339 END_RFC3339; printf 'TIME_READY=true window=%s..%s\n' "$START_RFC3339" "$END_RFC3339"; else printf '%s\n' '중단: UTC round-trip/start<end 실패' >&2; fi; else printf '%s\n' '중단: canonical UTC RFC3339 아님' >&2; fi`

`EVIDENCE_READY=false; if [ "$TIME_READY" = true ] && [ "$REVISION_READY" = true ] && fresh_cluster; then RAW="$(mktemp)"; WIN="$(mktemp)"; kubectl logs "$ETCD_POD" -n "$NS" -c "$ETCD_CONTAINER" --timestamps --since-time="$START_RFC3339" >"$RAW"; PRODUCER_RC=$?; if [ "$PRODUCER_RC" -eq 0 ]; then awk -v start="$START_RFC3339" -v end="$END_RFC3339" '$1>=start && $1<=end' "$RAW" >"$WIN"; WINDOW_RC=$?; if [ "$WINDOW_RC" -eq 0 ]; then grep -E -i -C 3 'CORRUPT|corrupt|hash mismatch|integrity|checksum|database file|I/O error|Input/output error|raft|peer|timeout|panic' "$WIN"; FILTER_RC=$?; if [ "$FILTER_RC" -eq 0 ]; then EVIDENCE_READY=true; printf 'EVIDENCE_READY=true producer_rc=%s window_rc=%s filter_rc=%s memberID=%s revision=%s\n' "$PRODUCER_RC" "$WINDOW_RC" "$FILTER_RC" "$MEMBER_ID" "$REVISION"; elif [ "$FILTER_RC" -eq 1 ]; then printf 'filter_match=none producer_rc=%s window_rc=%s filter_rc=1\n' "$PRODUCER_RC" "$WINDOW_RC"; else printf '중단: log filter rc=%s\n' "$FILTER_RC" >&2; fi; else printf '중단: window filter rc=%s\n' "$WINDOW_RC" >&2; fi; else printf '중단: log producer rc=%s\n' "$PRODUCER_RC" >&2; fi; rm -f "$RAW" "$WIN"; fi`

filter rc `1`은 일치 없음, `>1`은 filter 오류다. peer timeout만으로 corruption을 확정하지 않는다. 결정적 행은 current member ID, same revision hash와 증거 창에 연결한다.

## 실행 가능한 Prometheus 쿼리

Prometheus는 corruption을 직접 부정하거나 확정하지 않는다. selected current member와 연결된 exact labels만 가용성·leader·proposal 영향 보조 증거로 사용한다.

`JOB='PASTE_PROMETHEUS_ETCD_JOB_HERE'; INSTANCE='PASTE_PROMETHEUS_INSTANCE_FOR_SELECTED_MEMBER_HERE'; QUERY_READY=false; if fresh_cluster && [ -n "$JOB" ] && [ -n "$INSTANCE" ] && [[ "$JOB" != *$'\n'* ]] && [[ "$INSTANCE" != *$'\n'* ]]; then JOB_RE="$(printf '%s' "$JOB"|sed 's/[][\\.^$*+?(){}|]/\\&/g')"; INSTANCE_RE="$(printf '%s' "$INSTANCE"|sed 's/[][\\.^$*+?(){}|]/\\&/g')"; QUERY_READY=true; export JOB_RE INSTANCE_RE; printf 'QUERY_READY=true job=^%s$ instance=^%s$ memberID=%s\n' "$JOB_RE" "$INSTANCE_RE" "$MEMBER_ID"; else printf '%s\n' '중단: current member target label 미등록' >&2; fi`

`fresh_cluster && [ "$QUERY_READY" = true ] && printf 'up{job=~"^%s$",instance=~"^%s$"} == 0\n' "$JOB_RE" "$INSTANCE_RE"`

`fresh_cluster && [ "$QUERY_READY" = true ] && printf 'etcd_server_has_leader{job=~"^%s$",instance=~"^%s$"} == 0\n' "$JOB_RE" "$INSTANCE_RE"`

`fresh_cluster && [ "$QUERY_READY" = true ] && printf 'increase(etcd_server_proposals_failed_total{job=~"^%s$",instance=~"^%s$"}[15m]) > 0\n' "$JOB_RE" "$INSTANCE_RE"`

HTTP status, Prometheus `status=success`, non-empty series를 각각 검사한다. 빈 결과는 정상/0이 아니다.

## 상태 변경·replacement·정상화

이 문서는 alarm disarm, member stop/remove/add, restart, data-dir 조작, defrag, force-new-cluster, snapshot restore 명령을 제공하지 않는다. 별도 mutation은 **각 실행 직전** fresh target/member/membership/same-revision hash, 승인 ID·window, current leader와 voting quorum, 검증된 snapshot source cluster/member/revision identity, 영향·멱등성·중단 조건, 실제 검증된 rollback/DR 절차를 다시 확인한다. 어느 항목도 없으면 `MUTATION_READY=false`, `ROLLBACK_READY=false`다.

static mirror/member replacement는 selector가 아니라 승인 membership의 member ID/peer URL, exact mirror source, Node UID/machineID, 변경 이후 creationTimestamp와 단일 후보로 확인한다. replacement 뒤 기존 이름/UID/containerID/member ID/revision/hash를 재사용하지 않고 모든 값과 READY를 폐기해 전체 재등록한다.

정상화는 승인 membership exact match -> 모든 endpoint health -> 정확히 한 leader·voting quorum·진행하는 raft -> current alarm 없음 -> 새 common revision의 hash 일치 -> member data filesystem 안정 -> current mirror Pod/Node/container -> API server readyz -> 승인된 실제 Kubernetes read/write 기능 순서로 검증한다. 관찰 창 동안 integrity/I/O/leader churn이 재발하지 않아야 한다. alarm 해제, Pod Running, 이전 revision hash, endpoint 하나 또는 빈 metric만으로 닫지 않는다.

`NORMALIZATION_READY=false; if fresh_cluster && [ "$FS_READY" = true ] && [ "$TIME_READY" = true ] && [ "$EVIDENCE_READY" = true ]; then printf '%s\n' '후속 수동 gate: 새 common revision hash, 전체 endpoint/quorum, readyz, 실제 기능과 재발 관찰을 모두 기록한 뒤에만 NORMALIZATION_READY=true로 승인 기록에 남긴다.'; else printf '%s\n' '중단: 정상화용 fresh evidence gate 실패' >&2; fi`
