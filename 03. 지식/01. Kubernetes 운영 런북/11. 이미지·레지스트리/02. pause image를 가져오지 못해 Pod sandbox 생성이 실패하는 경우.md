# pause image를 가져오지 못해 Pod sandbox 생성이 실패하는 경우

## 입력값과 빠른 수집

연결 경로는 `작업 host의 kubectl -> API server -> Pod UID·Event -> Node`, `작업 host -> 승인된 SSH host -> active kubelet service -> kubelet이 실제 선택한 CRI endpoint -> runtime provider -> sandbox image registry`다. sandbox 생성 전에는 application container ID가 없을 수 있으며, 이를 조회 실패나 application image 장애로 바꾸어 해석하지 않는다.

| 종류 | 변수 | 출처와 gate |
|---|---|---|
| 최초 입력 | `NS`, `POD` | 거부 Event가 있는 exact Pod |
| API 자동값 | `POD_UID`, `POD_RV`, `OWNER_*`, `NODE`, `NODE_UID`, `NODE_RV`, `RUNTIME_VERSION`, `RUNTIME_CLASS`, `HOST_NETWORK`, `CONTAINER_ID` | Pod·Node API 호출이 모두 성공할 때만 등록 |
| 계산 후보값 | `POD_RE`, `PAUSE_RE`, `JOURNAL_RE`, `ENDPOINT_ARG_RE` | regex escape 결과, bounded 출력 뒤 사용 |
| 운영자 선택값 | `START_RFC3339`, `END_RFC3339`, `NODE_HOST`, unit 두 개, `CRI_ENDPOINT`, `PAUSE_IMAGE`, `REGISTRY_HOST` | Event·runtime journal·승인 inventory에서 확인 후 선택 |

Service identity는 외부 registry host, storage identity는 이 런북에서 `not-applicable`이다. imagefs가 직접 원인이면 storage 런북으로 이동한다.

refresh는 UID·RV·owner·containerID·node·host·runtime·service 관계·시간·argv regex와 downstream `READY`를 먼저 지운다. 어느 API 호출이라도 실패하면 이전 값으로 `true`가 남지 않는다.

**현재 identity guard**

`current_pause(){ local p n; [ "$AUTO_READY" = true ] || return 1; p="$(kubectl get pod "$POD" -n "$NS" -o json)" || return 1; n="$(kubectl get node "$NODE" -o json)" || return 1; jq -e --arg uid "$POD_UID" --arg rv "$POD_RV" --arg node "$NODE" '.metadata.uid==$uid and .metadata.resourceVersion==$rv and .spec.nodeName==$node' <<<"$p" >/dev/null && jq -e --arg uid "$NODE_UID" --arg rv "$NODE_RV" '.metadata.uid==$uid and .metadata.resourceVersion==$rv' <<<"$n" >/dev/null; }`

sandbox 생성 전 `CONTAINER_ID=not-created`도 lifecycle 상태다. owner·runtimeClass·hostNetwork·현재 containerID와 Node machine identity를 다시 확인하도록 guard를 강화한다.

## 진입 판단

| 구분 | 판단 기준 |
|---|---|
| 사용 | 같은 Pod UID의 `FailedCreatePodSandBox`·`RunPodSandbox` message가 sandbox/pause image pull과 `401/403/429/x509/timeout`을 함께 지목 |
| 적용 | Event→Node→active kubelet endpoint→runtime provider→exact pause image→registry 관계를 UTC 창으로 연결 가능 |
| 제외 | CNI/IPAM은 [[24. Pod 이벤트에 FailedCreatePodSandBox가 기록된 경우]], OCI/shim/cgroup은 [[04. RunPodSandbox가 runtime·OCI 오류로 실패하는 경우]], application image는 [[07. Pod STATUS가 ImagePullBackOff·ErrImagePull인 경우]] |

검색 문자열: `FailedCreatePodSandBox`, `RunPodSandbox`, `sandbox image`, `pause`, `unauthorized`, `429`, `x509`, `context deadline exceeded`.

## Event와 시간

`START_RFC3339='PASTE_START_RFC3339_HERE'; END_RFC3339='PASTE_END_RFC3339_HERE'; TIME_READY=false; RFC3339_RE='^[0-9]{4}-(0[1-9]|1[0-2])-([0-2][0-9]|3[01])T([01][0-9]|2[0-3]):[0-5][0-9]:[0-5][0-9]Z$'; if ! [[ "$START_RFC3339" =~ $RFC3339_RE ]] || ! [[ "$END_RFC3339" =~ $RFC3339_RE ]]; then printf '%s\n' '중단: canonical UTC RFC3339 형식이 아니다.' >&2; elif [ "$(date -u -d "$START_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null)" != "$START_RFC3339" ] || [ "$(date -u -d "$END_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null)" != "$END_RFC3339" ]; then printf '%s\n' '중단: date round-trip 실패' >&2; elif [ "$(date -u -d "$START_RFC3339" +%s)" -ge "$(date -u -d "$END_RFC3339" +%s)" ]; then printf '%s\n' '중단: 시간 순서 오류' >&2; elif ! current_pause; then AUTO_READY=false; printf '%s\n' '중단: identity 변경, refresh 필요' >&2; else TIME_READY=true; export START_RFC3339 END_RFC3339; printf 'TIME_READY=true start=%s end=%s podCreated=%s observed=%s\n' "$START_RFC3339" "$END_RFC3339" "$POD_CREATED" "$OBSERVED_AT"; fi`

`if [ "$TIME_READY" != true ] || ! current_pause; then AUTO_READY=false; EVIDENCE_READY=false; printf '%s\n' '중단: 현재 TIME/AUTO identity가 아니다.' >&2; elif kubectl get events -n "$NS" --field-selector "involvedObject.kind=Pod,involvedObject.name=$POD,involvedObject.uid=$POD_UID" --sort-by=.metadata.creationTimestamp -o custom-columns='EVENT-UID:.metadata.uid,OBJECT-UID:.involvedObject.uid,CREATED:.metadata.creationTimestamp,FIRST:.firstTimestamp,LAST:.lastTimestamp,EVENT-TIME:.eventTime,SERIES-LAST:.series.lastObservedTime,REASON:.reason,MESSAGE:.message'; then EVIDENCE_READY=true; else EVIDENCE_READY=false; printf '%s\n' '중단: Event API 실패' >&2; fi`

Event가 비면 성공이 아니다. Event TTL, 권한, 이름 재사용을 확인한다. object 생성, Event first/last/series와 journal 시각을 UTC로 정렬하고, pause image 언급이 없는 CNI·OCI 오류는 제외 경로로 보낸다.

## Linux host와 active CRI

`NODE_HOST='PASTE_APPROVED_NODE_HOST_HERE'; KUBELET_UNIT='PASTE_KUBELET_UNIT_HERE'; RUNTIME_UNIT='PASTE_RUNTIME_UNIT_HERE'; CRI_ENDPOINT='PASTE_CRI_ENDPOINT_HERE'; HOST_READY=false; CRI_READY=false; if [ "$TIME_READY" != true ] || ! current_pause; then AUTO_READY=false; printf '%s\n' '중단: 현재 identity가 아니다.' >&2; elif ! [[ "$NODE_HOST" =~ ^[A-Za-z0-9._-]+$ ]] || ! [[ "$KUBELET_UNIT" =~ ^[A-Za-z0-9_.@-]+\.service$ ]] || ! [[ "$RUNTIME_UNIT" =~ ^[A-Za-z0-9_.@-]+\.service$ ]] || ! [[ "$CRI_ENDPOINT" =~ ^unix:///[-A-Za-z0-9._/]+\.sock$ ]]; then printf '%s\n' '중단: host·unit·endpoint 형식 오류' >&2; else HOST_ID="$(ssh -- "$NODE_HOST" 'hostname --fqdn 2>/dev/null || hostname')" && ACTIVE="$(ssh -- "$NODE_HOST" 'systemctl is-active "$1" "$2"' sh "$KUBELET_UNIT" "$RUNTIME_UNIT")"; SSH_RC=$?; if [ "$SSH_RC" -ne 0 ] || [ -z "$HOST_ID" ] || [ "$ACTIVE" != $'active\nactive' ]; then printf '중단: Linux host/service 확인 실패 rc=%s\n' "$SSH_RC" >&2; else ENDPOINT_ESC="$(printf '%s' "$CRI_ENDPOINT" | sed 's/[][\\.^$*+?(){}|]/\\&/g')"; ENDPOINT_ARG_RE="(^|[[:space:];])--container-runtime-endpoint=${ENDPOINT_ESC}([[:space:];]|$)"; HOST_READY=true; export NODE_HOST HOST_ID KUBELET_UNIT RUNTIME_UNIT CRI_ENDPOINT ENDPOINT_ARG_RE; printf 'HOST_READY=true apiNode=%s sshHost=%s linuxHost=%s kubelet=%s runtime=%s endpoint=%s\n' "$NODE" "$NODE_HOST" "$HOST_ID" "$KUBELET_UNIT" "$RUNTIME_UNIT" "$CRI_ENDPOINT"; fi; fi`

`if [ "$HOST_READY" != true ] || ! current_pause; then AUTO_READY=false; CRI_READY=false; printf '%s\n' '중단: 현재 HOST/AUTO identity가 아니다.' >&2; else CRI_JSON="$(ssh -- "$NODE_HOST" 'set -eu; unit=$1; endpoint=$2; arg_re=$3; exec_start=$(systemctl show "$unit" -p ExecStart --value); count=$(printf "%s\n" "$exec_start" | grep -Eoc -- "$arg_re"); [ "$count" -eq 1 ]; sudo crictl --runtime-endpoint "$endpoint" version -o json' sh "$KUBELET_UNIT" "$CRI_ENDPOINT" "$ENDPOINT_ARG_RE")"; SSH_RC=$?; if [ "$SSH_RC" -ne 0 ]; then CRI_READY=false; printf '중단: kubelet endpoint exact match/CRI 실패 rc=%s\n' "$SSH_RC" >&2; elif CRI_NAME="$(jq -er '.runtimeName' <<<"$CRI_JSON")" && CRI_VERSION="$(jq -er '.runtimeVersion' <<<"$CRI_JSON")" && [ "$CRI_NAME" = "$RUNTIME_PROVIDER" ]; then CRI_READY=true; export CRI_NAME CRI_VERSION; printf 'CRI_READY=true endpoint=%s provider=%s version=%s\n' "$CRI_ENDPOINT" "$CRI_NAME" "$CRI_VERSION"; else CRI_READY=false; printf '중단: API runtime과 CRI provider 불일치 api=%s cri=%s\n' "$RUNTIME_PROVIDER" "${CRI_NAME:--}" >&2; fi; fi`

**원격 host·runtime socket provider 관계**

`HOST_IDENTITY_READY=false; RUNTIME_SOCKET_READY=false; EVIDENCE_READY=false; CHANGE_READY=false; NORMAL_READY=false; if [ "$CRI_READY" != true ] || ! current_pause_api; then AUTO_READY=false; CRI_READY=false; printf '%s\n' '중단: 현재 CRI/API identity가 아니다.' >&2; else REL="$(ssh -- "$NODE_HOST" 'set -eu; expected_mid=$1; unit=$2; endpoint=$3; actual_mid=$(cat /etc/machine-id); [ "$actual_mid" = "$expected_mid" ]; socket=${endpoint#unix://}; [ -S "$socket" ]; pid=$(systemctl show "$unit" -p MainPID --value); [ "$pid" -gt 1 ]; inode=$(stat -Lc %i "$socket"); sudo sh -c '\''for fd in /proc/$1/fd/*; do [ "$(readlink "$fd" 2>/dev/null)" = "socket:[$2]" ] && exit 0; done; exit 1'\'' sh "$pid" "$inode"; printf "machineID=%s mainPID=%s socket=%s inode=%s\n" "$actual_mid" "$pid" "$socket" "$inode"' sh "$NODE_MACHINE_ID" "$RUNTIME_UNIT" "$CRI_ENDPOINT")"; SSH_RC=$?; if [ "$SSH_RC" -eq 0 ]; then HOST_IDENTITY_READY=true; RUNTIME_SOCKET_READY=true; export HOST_IDENTITY_READY RUNTIME_SOCKET_READY; printf 'HOST_IDENTITY_READY=true RUNTIME_SOCKET_READY=true %s\n' "$REL"; else CRI_READY=false; printf '중단: remote machineID 또는 runtime socket owner 관계 실패 rc=%s\n' "$SSH_RC" >&2; fi; fi`

`current_pause_host(){ local out cri name; [ "$CRI_READY" = true ] && [ "$HOST_IDENTITY_READY" = true ] && [ "$RUNTIME_SOCKET_READY" = true ] && current_pause_api_v2 || return 1; out="$(ssh -- "$NODE_HOST" 'set -eu; expected_mid=$1; kubelet=$2; runtime=$3; endpoint=$4; arg_re=$5; [ "$(cat /etc/machine-id)" = "$expected_mid" ]; [ "$(systemctl is-active "$kubelet")" = active ]; [ "$(systemctl is-active "$runtime")" = active ]; exec_start=$(systemctl show "$kubelet" -p ExecStart --value); [ "$(printf "%s\n" "$exec_start" | grep -Eoc -- "$arg_re")" -eq 1 ]; socket=${endpoint#unix://}; [ -S "$socket" ]; pid=$(systemctl show "$runtime" -p MainPID --value); [ "$pid" -gt 1 ]; inode=$(stat -Lc %i "$socket"); sudo sh -c '\''for fd in /proc/$1/fd/*; do [ "$(readlink "$fd" 2>/dev/null)" = "socket:[$2]" ] && exit 0; done; exit 1'\'' sh "$pid" "$inode"; sudo crictl --runtime-endpoint "$endpoint" version -o json' sh "$NODE_MACHINE_ID" "$KUBELET_UNIT" "$RUNTIME_UNIT" "$CRI_ENDPOINT" "$ENDPOINT_ARG_RE")" || return 1; name="$(jq -er '.runtimeName' <<<"$out")" || return 1; [ "$name" = "$RUNTIME_PROVIDER" ]; }; current_pause(){ current_pause_host; }`

pause image journal·registry 명령은 위 두 READY까지 확인한 현재 cycle에서만 사용한다. runtime 재시작이나 socket inode 변경 뒤에는 이전 sandbox·journal 증거를 재사용하지 않는다.

active unit이 여러 개여도 kubelet argv의 strict exact endpoint와 일치한 provider만 이 Pod의 runtime 근거다. default socket 추측이나 다른 active runtime 로그 혼합을 금지한다.

## pause image와 journal

runtime journal 또는 승인된 provider 설정에서 실제 sandbox image를 확인한 후에만 입력한다. kubelet 기본값이나 `pause:latest`를 추측하지 않는다.

`PAUSE_IMAGE='PASTE_CONFIRMED_PAUSE_IMAGE_HERE'; REGISTRY_HOST='PASTE_REGISTRY_HOST_HERE'; PAUSE_READY=false; if [ "$CRI_READY" != true ] || ! current_pause; then AUTO_READY=false; printf '%s\n' '중단: 현재 CRI/AUTO identity가 아니다.' >&2; elif [ -z "$PAUSE_IMAGE" ] || ! [[ "$REGISTRY_HOST" =~ ^[A-Za-z0-9.-]+(:[0-9]{1,5})?$ ]]; then printf '%s\n' '중단: pause image/registry 확인값 오류' >&2; else PAUSE_RE="$(printf '%s' "$PAUSE_IMAGE" | sed 's/[][\\.^$*+?(){}|]/\\&/g')"; JOURNAL_RE="$POD_UID|$POD_RE|$PAUSE_RE|RunPodSandbox|sandbox|pause|pull|unauthorized|denied|401|403|429|x509|timeout|no such host"; PAUSE_READY=true; export PAUSE_IMAGE PAUSE_RE REGISTRY_HOST JOURNAL_RE; printf 'PAUSE_READY=true image=%s registryService=%s runtimeProvider=%s JOURNAL_RE=%s\n' "$PAUSE_IMAGE" "$REGISTRY_HOST" "$RUNTIME_PROVIDER" "$JOURNAL_RE"; fi`

`if [ "$PAUSE_READY" != true ] || [ "$TIME_READY" != true ] || ! current_pause; then AUTO_READY=false; EVIDENCE_READY=false; printf '%s\n' '중단: 현재 PAUSE/TIME/AUTO identity가 아니다.' >&2; else ssh -- "$NODE_HOST" 'sudo journalctl -u "$1" --since "$2" --until "$3" --no-pager' sh "$KUBELET_UNIT" "$START_RFC3339" "$END_RFC3339" | grep -E -i -C 3 -- "$JOURNAL_RE"; PS=("${PIPESTATUS[@]}"); printf 'pipeline ssh=%s grep=%s\n' "${PS[0]}" "${PS[1]}"; if [ "${PS[0]}" -ne 0 ]; then EVIDENCE_READY=false; elif [ "${PS[1]}" -eq 0 ]; then EVIDENCE_READY=true; elif [ "${PS[1]}" -eq 1 ]; then EVIDENCE_READY=false; printf '%s\n' '필터 결과 없음: 오류 부재가 아니다.' >&2; else EVIDENCE_READY=false; fi; fi`

**runtime journal과 pipeline status**

`if [ "$PAUSE_READY" != true ] || [ "$TIME_READY" != true ] || ! current_pause; then AUTO_READY=false; EVIDENCE_READY=false; printf '%s\n' '중단: 현재 PAUSE/TIME/AUTO identity가 아니다.' >&2; else ssh -- "$NODE_HOST" 'sudo journalctl -u "$1" --since "$2" --until "$3" --no-pager' sh "$RUNTIME_UNIT" "$START_RFC3339" "$END_RFC3339" | grep -E -i -C 3 -- "$JOURNAL_RE"; PS=("${PIPESTATUS[@]}"); printf 'pipeline ssh=%s grep=%s\n' "${PS[0]}" "${PS[1]}"; if [ "${PS[0]}" -ne 0 ]; then EVIDENCE_READY=false; elif [ "${PS[1]}" -eq 0 ]; then EVIDENCE_READY=true; elif [ "${PS[1]}" -eq 1 ]; then EVIDENCE_READY=false; printf '%s\n' '필터 결과 없음: unit·시간·보존 위치를 재확인한다.' >&2; else EVIDENCE_READY=false; fi; fi`

SSH는 node host만 local shell에서 선택하고, unit·time은 positional argument로 운반한다. `eval`, 원격 문자열 보간, credential 전달을 사용하지 않는다.

**Node에서 registry endpoint hop 확인**

`if [ "$PAUSE_READY" != true ] || ! current_pause; then AUTO_READY=false; printf '%s\n' '중단: 현재 PAUSE/AUTO identity가 아니다.' >&2; else ssh -- "$NODE_HOST" 'curl -sS -o /dev/null -w "http_code=%{http_code}\n" --max-time 10 "https://$1/v2/"' sh "$REGISTRY_HOST"; SSH_RC=$?; printf 'registry_probe_ssh=%s node=%s registry=%s\n' "$SSH_RC" "$NODE" "$REGISTRY_HOST"; [ "$SSH_RC" -eq 0 ] || printf '%s\n' 'probe 실패를 pause repository 부재로 확정하지 않는다.' >&2; fi`

`200/401/403/429`, DNS, TLS, timeout은 transport·공개 endpoint 범위의 증거다. pause repository pull 권한·manifest·architecture를 단독 보장하지 않는다. `CNI ADD`, IPAM, OCI, shim, cgroup, imagefs 오류가 먼저면 관련 런북으로 이동한다.

## Prometheus 보조 관측

`if [ "$AUTO_READY" != true ] || ! current_pause; then AUTO_READY=false; printf '%s\n' '중단: 현재 identity가 아니다.' >&2; else printf 'sum by(namespace,pod,uid,node)(kube_pod_status_phase{namespace="%s",pod=~"^%s$",uid="%s",phase="Pending"} * on(namespace,pod,uid) group_left(node) kube_pod_info{namespace="%s",pod=~"^%s$",uid="%s"})\n' "$NS" "$POD_RE" "$POD_UID" "$NS" "$POD_RE" "$POD_UID"; fi`

결과 부재는 정상화가 아니다. current UID의 `kube_pod_info`, kube-state-metrics target `up`, cluster·time range·label schema를 확인한다. `kubelet_run_podsandbox_errors_total`이 있더라도 pause image 원인은 표시하지 않으므로 Event와 exact CRI journal이 필수다.

## 변경과 정상화

진단은 읽기 전용이다. pause image, runtime config, mirror, credential 변경, runtime restart, sandbox 강제 제거와 Pod 반복 삭제를 실행하지 않는다.

별도 변경 절차의 `CHANGE_READY=true` 조건은 fresh UID/RV·owner·Node·Linux host·active kubelet endpoint·runtime provider·pause image·registry 관계, 같은 UTC 창의 직접 증거, node/runtime·registry·workload owner 승인과 변경 창, HA/quorum 최소 가용성, 재시도의 idempotence, 승인된 이전 config digest와 검증 가능한 rollback이다. replacement Pod·Node·sandbox가 생기면 이전 관계와 모든 `READY`를 폐기하고 새 UID/RV·containerID 또는 sandbox lifecycle·provider 관계를 재등록한다.

정상화는 `registry auth/quota/mirror -> exact CRI pause pull -> 새 sandbox identity -> CNI 완료 -> 새 Pod UID/owner/Node -> Ready -> Service endpoint -> 실제 요청` 순으로 확인한다. 승인된 관찰 창에서 같은 Event·journal 오류가 없고 실제 기능이 성공해야 한다. registry 응답, sandbox ID 하나, `Running`, metric 소멸만으로 닫지 않는다. rollback 뒤에도 같은 역순 검증을 반복한다.

민감정보 보호: Secret data, credential, token, private key, `WWW-Authenticate` 원문, 내부 주소, 전체 runtime config와 전체 journal은 출력·저장하지 않는다. 보존 대상은 UTC 시각, UID/RV, owner·Node·Linux host·endpoint·provider·pause image·registry의 비민감 관계, pipeline status, redacted 오류, 승인·rollback·실제 기능 결과다.
