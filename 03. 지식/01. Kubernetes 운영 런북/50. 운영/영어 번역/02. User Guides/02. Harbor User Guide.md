## 1. Accessing Harbor

Log in to the Harbor interface.

---

## 2. Image Push

1. In Harbor, select the target project.
2. Check the project's registry address (for example, `dcr.cloud.samsungds.net/<project>/<image>:<tag>`).
3. Build locally with Docker/Podman and push to the registry.

```bash
docker tag <local-image>:<tag> dcr.cloud.samsungds.net/<project>/<image>:<tag>
docker push dcr.cloud.samsungds.net/<project>/<image>:<tag>
```

---

## 3. Image Pull

### Using an Image in a Deployment

KubeSphere Dashboard → Project → **Application Workloads** → **Deployments** → **Create**

- **Container Image**: Enter `dcr.cloud.samsungds.net/<project>/<image>:<tag>`.

### Using an Image Secret

An Image Secret is required when the image belongs to a Private project.

1. **Configuration** → **Secrets** → **Create**
2. Under **Type**, select Image registry information.
3. Enter the registry address, account, and password.
4. In the Deployment, select and attach the Secret.
