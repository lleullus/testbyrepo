> [!summary] Summary
> Procedure for renewing API Server certificates in a KubeSphere cluster. Process the Master nodes one by one in sequence (ma01 → ma02 → ma03).

> [!warning] Important Notes
> - **Must proceed one by one in sequence**: confirm that Master 01 is operating normally before proceeding to Master 02, then proceed to Master 03.
> - **Backup is required**: back up the SSL directory and configuration files on all Master nodes before renewal.
> - **KubeSphere reconnection is required**: after certificate renewal, perform Member Cluster Unbind → Import again.

---

## Checklist

- [ ] **1. Backup Old Certificate Directory** — Confirm backups are complete on all Master nodes.
- [ ] **2. Renew Master Node 01 Certificates** — ma01 renewed and operating normally.
- [ ] **3. Renew Master Node 02 Certificates** — ma02 renewed and operating normally.
- [ ] **4. Renew Master Node 03 Certificates** — ma03 renewed and operating normally.
- [ ] **5. Update the Bastion kubeconfig** — Update kubeconfig for the root and dspaas accounts.
- [ ] **6. Re-join KubeSphere** — Unbind → Import → restart system pods.

---

## 1. Backup Old Certificate Directory

### 1-1. Back Up the SSL Directory (All Master Nodes)

**BASTION NODE**:

```bash
for host in ma01 ma02 ma03; do
  ssh $host mkdir -p /tmp/$(date +%Y%m%d)-apibackup
done

for host in ma01 ma02 ma03; do
  ssh $host sudo cp -rp /etc/kubernetes/ssl /tmp/$(date +%Y%m%d)-apibackup/
done
```

**Verify**:

```bash
for host in ma01 ma02 ma03; do
  ssh $host sudo ls -al /tmp/$(date +%Y%m%d)-apibackup/ssl
done
```

### 1-2. Back Up the Configuration Files (All Master Nodes)

**BASTION NODE**:

```bash
for host in ma01 ma02 ma03; do
  ssh $host sudo cp -rp /etc/kubernetes/admin.conf /tmp/$(date +%Y%m%d)-apibackup/
done

for host in ma01 ma02 ma03; do
  ssh $host sudo cp -rp /etc/kubernetes/scheduler.conf /tmp/$(date +%Y%m%d)-apibackup/
done

for host in ma01 ma02 ma03; do
  ssh $host sudo cp -rp /etc/kubernetes/controller-manager.conf /tmp/$(date +%Y%m%d)-apibackup/
done
```

**Verify**:

```bash
for host in ma01 ma02 ma03; do
  ssh $host ls -al /tmp/$(date +%Y%m%d)-apibackup/
done
```

## 2. Renew Master Node 01 Certificates

### 2-1. Renew the API Server 01 Certificate

**BASTION NODE**:

```bash
ssh ma01 sudo /usr/local/bin/kubeadm certs renew all
```

**Verify**:

```bash
ssh ma01 sudo /usr/local/bin/kubeadm certs check-expiration
```

### 2-2. Restart Static Pods (master01)

**BASTION NODE**:

```bash
ssh ma01 'sudo /usr/local/bin/crictl pods --namespace kube-system | grep -E "(kube-scheduler|kube-controller-manager|kube-apiserver)" | awk "{print \$1}" | xargs -r sudo /usr/local/bin/crictl rmp -f'
```

**Verify**:

```bash
ssh ma01 'sudo /usr/local/bin/crictl pods --namespace kube-system | grep -E "(kube-scheduler|kube-controller-manager|kube-apiserver)"'
```

### 2-3. Update the Master Node 01 kubeconfig

**BASTION NODE**:

```bash
ssh ma01 sudo cp /etc/kubernetes/admin.conf /root/.kube/config
```

**Verify**:

```bash
ssh ma01 sudo cat /root/.kube/config | grep client-certificate-data: | awk '{print $2}' | base64 -d | openssl x509 -noout -text | grep -i 'after'
```

### 2-4. Check Static Pod Status (master01)

**Check each Pod status**:

```bash
kubectl get pod -n kube-system | grep api | grep 01
kubectl get pod -n kube-system | grep controller-manager | grep 01
kubectl get pod -n kube-system | grep scheduler | grep 01
```

**Check Events**:

```bash
POD=$(kubectl get pods -n kube-system -o name \
  | grep "^pod/kube-apiserver-" \
  | grep "01$" \
  | head -n1); kubectl describe po -n kube-system "${POD#pod/}" | grep Events: -A10

POD=$(kubectl get pods -n kube-system -o name \
  | grep "^pod/kube-controller-manager" \
  | grep "01$" \
  | head -n1); kubectl describe po -n kube-system "${POD#pod/}" | grep Events: -A10

POD=$(kubectl get pods -n kube-system -o name \
  | grep "^pod/kube-scheduler" \
  | grep "01$" \
  | head -n1); kubectl describe po -n kube-system "${POD#pod/}" | grep Events: -A10
```

**Check API Server Health**:

```bash
# readyz
ssh ma01 curl -k https://localhost:6443/readyz?verbose

# livez
ssh ma01 curl -k https://localhost:6443/livez?verbose
```

> [!note] Confirm Before Proceeding
> Proceed to Master 02 only after all Pods on Master 01 are in the Running state and the API Server health check succeeds.

## 5. Update kubeconfig file (Bastion Node)

### 5-1. Update the Bastion Node Root Account kubeconfig

**BASTION NODE**:

```bash
ssh ma01 'sudo cp /etc/kubernetes/admin.conf /tmp/admin.conf && sudo chown $(whoami):$(whoami) /tmp/admin.conf'
scp ma01:/tmp/admin.conf /tmp/config
sudo cp /tmp/config /root/.kube/config
sudo ls -al /root/.kube/config
```

**Verify**:

```bash
sudo cat /root/.kube/config | grep client-certificate-data: | awk '{print $2}' | base64 -d | openssl x509 -noout -text | grep -i 'after'
```

### 5-2. Update the Bastion Node dspaas Account kubeconfig

**BASTION NODE**:

```bash
ssh ma01 sudo cat /etc/kubernetes/admin.conf > /app/dspaas/.kube/config
```

**Verify**:

```bash
cat /app/dspaas/.kube/config | grep client-certificate-data: | awk '{print $2}' | base64 -d | openssl x509 -noout -text | grep -i 'after'
```

## 6. Re-join KubeSphere

### 6-1. Member Cluster Unbind

1. Log in to the KubeSphere Console.
2. **Platform** → **Cluster Management** → select the Member Cluster to unbind.
3. In the left menu, go to **Cluster Settings** → **Basic Information** → **Unbind Cluster**, then click **Unbind**.
4. **Note**: Record the exact name and tag (they are required in the next step).
5. Check **"I understand the risks of this operation"** and execute Unbind.

### 6-2. Member Cluster Import

1. Click **Cluster Management** → **Add Cluster**.
2. Use the Cluster name and tag recorded during Unbind.
3. Copy and paste the contents of the kubeconfig file.
4. Click **Create**.

### 6-3. Restart KubeSphere System Pods

**BASTION NODE** (run on each Member Cluster):

```bash
kubectl rollout restart deploy -n kubesphere-system ks-apiserver ks-console ks-controller-manager
```

**Verify**:

```bash
kubectl get po -n kubesphere-system
```
