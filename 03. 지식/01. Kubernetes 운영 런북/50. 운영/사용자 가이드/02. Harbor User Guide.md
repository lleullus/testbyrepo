---

## 2. Image Push

1. Harbor 프로젝트에서 대상 프로젝트 선택
2. 프로젝트의 레지스트리 주소 확인 (예: `dcr.cloud.samsungds.net/<project>/<image>:<tag>`)
3. 로컬에서 Docker/Podman으로 빌드 후 레지스트리에 Push

```bash
docker tag <local-image>:<tag> dcr.cloud.samsungds.net/<project>/<image>:<tag>
docker push dcr.cloud.samsungds.net/<project>/<image>:<tag>
```

---

## 3. Image Pull

### Deployment에서 Image 사용

KubeSphere Dashboard → 프로젝트 → **Application Workloads** → **Deployments** → **Create**

- **Container Image**: `dcr.cloud.samsungds.net/<project>/<image>:<tag>` 입력

### Image Secret 사용

이미지가 Private 프로젝트인 경우 Image Secret이 필요하다.

1. **Configuration** → **Secrets** → **Create**
2. **Type**: Image registry information 선택
3. 레지스트리 주소, 계정, 비밀번호 입력
4. Deployment에서 Secret 연결
