## 1. DKS 리소스 사용 방법

**절차**: DKS Project 신청 → 보안그룹 생성 및 방화벽 개방 → Namespace 생성 (Workspace → Project → Resource Quota) → 사용자 안내

| 단계  | 활동                 | 비고                              |
| --- | ------------------ | ------------------------------- |
| 1   | DKS Project 신청서 제출 | Workspace/Project 1:1 매칭        |
| 2   | 보안그룹 생성            | 방화벽 규칙 설정                       |
| 3   | 방화벽 개방 신청          | DKS 운영팀 미직접 처리                  |
| 4   | Resource Quota 설정  | CPU/Memory/Storage 3종           |
| 5   | 사용자에게 안내           | 방화벽 개방 확인, KubeSphere 로그인 정보 제공 |

---

## 2. Harbor 권한 얻기

**절차**: SG1599 멤버십 확인 → 프로젝트 생성 → 10GB 쿼터 설정 → 멤버 추가

| 단계  | 활동                | 비고             |
| --- | ----------------- | -------------- |
| 1   | 사용자의 SG1599 소속 확인 | 보안그룹 멤버십 필수    |
| 2   | Harbor 프로젝트 생성    | 이미지 레지스트리 프로젝트 |
| 3   | 10GB 쿼터 설정        | 저장공간 할당        |
| 4   | 멤버 추가             | 프로젝트 접근 권한 부여  |

---

## 3. Namespace 축소 또는 삭제

### Namespace 리소스 축소
- Resource Quota를 조정하여 Namespace 리소스 축소

### Namespace 완전 삭제
- Workspace 삭제 시 Project 삭제 옵션 활성화
- Workspace 단위로 Namespace 및 Project 일괄 삭제

---

## 4. CLI 사용 방법 (kubectl)

**절차**: OS 계정 생성 → ConfigMap 복사 → `.kube/config` 적용

| 단계 | 활동 | 비고 |
|------|------|------|
| 1 | Bastion 서버에 OS 계정 생성 | AD 계정명과 동일 |
| 2 | CyberArk를 통한 Bastion 접근 | 권한 요청 필요 |
| 3 | ConfigMap에서 kubeconfig 복사 | `/home/.kube/config` 경로 |
| 4 | kubectl 명령어 실행 | KubeSphere Web UI 대체 |

## 5. 외부에서 애플리케이션 서비스 접근

**접근 방법**: `[application-name].ingress-cluster` 형식 사용

- 클러스터 Ingress 도메인을 DNS 서버에 VIP-B IP로 등록해야 함
- VIP-B 도메인을 통해 외부 접근 가능

---

## 6. DKS DevOps 사용

**현황**: DKS는 Docker 빌드 및 DevOps 기능을 지원하지 않음

**대안**:
- P-DEP 시스템 사용
- 사용자 자체 시스템에서 빌드 및 배포

---

## 7. Image 생성 및 Binary/Source 기반 Pod 배포

**Image 생성**: 사용자의 책임, DKS 운영팀 미지원

**지원 방식**:
- 외부/내부 네트워크에 이미 배포된 Image 사용 가능
- Docker, Podman 등으로 직접 빌드 후 레지스트리 Push 필요
- DKS 플랫폼 표준 CRI: **ContainerD** (Image 빌드 미지원, 관리/Pull-Push 완전 지원)

---

## 8. 로그인 오류 ("Wrong username or password")

**원인 및 해결**:

| 원인 | 확인 항목 |
|------|----------|
| AD 사용자 그룹 권한 | AD 그룹 멤버십 확인 |
| AD 비밀번호 | 비밀번호 재설정 필요 |
| 보안그룹 미소속 | **SG1599 보안그룹 멤버십 필수** |
