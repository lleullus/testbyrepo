## 3. Namespace

KubeSphere는 네임스페이스를 통해 서비스를 제공하며, 사용자에게 네임스페이스 내 애플리케이션 배포 권한을 부여한다.

- Workspace → Project → Namespace (1:1 매칭)
- Resource Quota로 CPU/Memory/Storage 제한
