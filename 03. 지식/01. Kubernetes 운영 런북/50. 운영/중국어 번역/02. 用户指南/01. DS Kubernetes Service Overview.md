> [!summary] 摘要
> DKS 通过 KubeSphere Web Console 提供 Kubernetes 服务。了解域名、访问信息和 Namespace 结构，并使用 AD 账户访问。

---

## 3. Namespace

KubeSphere 通过 Namespace 提供服务，并向用户授予在 Namespace 内部署应用程序的权限。

- Workspace → Project → Namespace (1:1 匹配)
- 使用 Resource Quota 限制 CPU/Memory/Storage
