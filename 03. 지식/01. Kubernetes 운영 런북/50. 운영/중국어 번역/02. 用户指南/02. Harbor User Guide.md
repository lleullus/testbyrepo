## 1. 访问 Harbor

登录 Harbor 界面。

---

## 2. 镜像推送

1. 在 Harbor 中选择目标项目
2. 确认项目的镜像仓库地址（例如：`dcr.cloud.samsungds.net/<project>/<image>:<tag>`）
3. 在本地使用 Docker/Podman 构建后推送到镜像仓库

```bash
docker tag <local-image>:<tag> dcr.cloud.samsungds.net/<project>/<image>:<tag>
docker push dcr.cloud.samsungds.net/<project>/<image>:<tag>
```

---

## 3. 镜像拉取

### 在 Deployment 中使用镜像

KubeSphere Dashboard → 项目 → **Application Workloads** → **Deployments** → **Create**

- **Container Image**：输入 `dcr.cloud.samsungds.net/<project>/<image>:<tag>`

### 使用镜像 Secret

如果镜像属于 Private 项目，则需要 Image Secret。

1. **Configuration** → **Secrets** → **Create**
2. **Type**：选择 Image registry information
3. 输入镜像仓库地址、账号和密码
4. 在 Deployment 中关联 Secret
