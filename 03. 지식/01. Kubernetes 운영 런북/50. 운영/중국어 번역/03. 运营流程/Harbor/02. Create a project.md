> [!summary] 摘要
> Harbor 项目创建分为 3 个步骤：向系统管理员申请 → 在 Harbor 中创建项目（Private + 10GB）→ 分配成员角色。

---

## 1. 申请流程

用户请求使用 Harbor 项目时，由系统管理员接收申请表并处理。

### 申请表格式

| 项目 | 内容 |
|------|------|
| **DKS Kubesphere Application Form** | Remarks |
| **User Information** | |
| - Department | Cloud Platform Group |
| - Requester | 申请人姓名 |
| - User account | Global AD 账号 |
| **Permission** | |
| - Permission | Admin 或 User（仅指定 1 名 Admin） |
| **DKS Information** | |
| - Cluster | 目标 Cluster（例如：dev-apps-pa01-tas） |
| - Project | 项目名称 |

### 示例

| AD 账号 | 角色 |
|---------|------|
| dj2.kim | Admin |
| dshl04829.id | User |
| dsml14311.id | User |
| dsml14312.id | User |
| dsml14313.id | User |

---

## 2. 创建 Harbor 项目

### 2-1. 登录 Harbor

登录 Harbor 界面。

### 2-2. 创建项目

1. 进入 **Projects** 菜单
2. 点击 **New Project**
3. 使用以下设置创建：

| 设置项 | 值 | 备注 |
|-----------|------|------|
| Project Name | 申请表中的项目名称 | |
| Access Level | **Private** | 禁止选择 Public |
| Storage Quota | **10 GB** | |

### 2-3. Access Level：Private 与 Public

| | Private | Public |
|---|---------|--------|
| 镜像拉取权限 | 仅项目成员可用 | 所有用户可用 |
| 安全性 | 高 | 低 |
| 使用范围 | 受限团队/项目 | 公开库 |

**设置为 Private 时**：只有项目成员拥有镜像拉取权限。设置为 Public 后，所有用户无需认证即可拉取镜像，因此出于安全考虑不建议这样设置。
