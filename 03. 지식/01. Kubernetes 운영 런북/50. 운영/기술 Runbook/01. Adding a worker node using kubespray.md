> [!summary] 요약
> Kubespray를 사용하여 클러스터에 새 워커 노드를 추가하는 6단계 절차이다. 사전 설정, inventory 편집, scale.yml 실행, 상태 확인, 배포 테스트, inventory 정리 순으로 진행된다.

---

## 사전 확인

- VM 접근 권한 확인
- NetApp Storage ACL 설정 확인

---

## 1. Node Pre-setting

Bastion Node 사전 설정 완료 후 Ansible을 통해 전체 클러스터 노드에 설정을 일괄 적용한다. (※ `-k` 옵션은 root 실행 시 각 노드 dspaas 사용자의 SSH password 입력)

| Phase | No. | 항목 | 확인/적용 | 비고 |
|-------|-----|------|-----------|------|
| **1. Node Pre-setting** | 1 | `dspaas` 사용자 그룹 확인 | ☐ | Bastion 수동 |
| | 2 | Bastion `/etc/hosts` 설정 | ☐ | Bastion 수동 |
| | 3 | SSH key pair 확인 | ☐ | Bastion 수동 |
| | 4 | sudoers wheel NOPASSWD | ☐ | Ansible |
| | 5 | SSH public-key 복사 | ☐ | Ansible |
| | 6 | YUM repository (Artifactory) | ☐ | Ansible |
| | 7 | 필수 패키지 설치 | ☐ | Ansible |
| | 8 | SWAP 비활성화 | ☐ | Ansible |
| | 9 | logrotate compress 설정 | ☐ | Ansible |
| | 10 | SECDS-ROOTCA CA Cert 배포 | ☐ | Ansible |
| | 11 | sysctl.conf ipv6 주석 처리 | ☐ | Ansible |
| | 12 | VM 리소스 확인 | ☐ | Ansible |
| **2. Edit Kubespray Inventory** | 1 | hosts.yaml 새 노드 정보 추가 | ☐ | `inventory/dks/hosts.yaml` |
| **3. Add a Node** | 1 | scale.yml 실행 | ☐ | `--limit xadkswkmp03,xadkswkmp04` |
| **4. Check Node Status** | 1 | 노드 Ready 상태 확인 | ☐ | `kubectl get nodes` |
| | 2 | containerd/커널 버전 확인 | ☐ | `kubectl get nodes -o wide` |
| | 3 | 시스템 Pod 상태 확인 | ☐ | `kubectl get pod -A -o wide` |
| **5. Deploy Test** | 1 | Deployment 테스트 | ☐ | checker pod |
| | 2 | PVC & Pod 배포 테스트 | ☐ | netapp SC |
| **6. Organize Inventory** | 1 | Inventory 파일 정리 | ☐ | XiAn_DKS 경로 |

### 3-1. scale.yml 실행

`--limit` 옵션으로 신규 노드만 제한하여 실행 (30분 이상 소요 가능)

## 5. 배포 테스트

### 5-1. Deployment 테스트

**테스트 yaml 생성**:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: checker-podselctor-test3
  labels:
    app: checker3
spec:
  replicas: 1
  selector:
    matchLabels:
      app: checker3
  template:
    metadata:
      labels:
        app: checker3
    spec:
      containers:
        - image: xa.dcr.dks.samsungds.net/dspaas-testrepo/checker:v5
          name: checker
          command: ['sh', '-c', 'sleep 365d']
      nodeSelector:
        kubernetes.io/os: linux
        kubernetes.io/hostname: xadkswkmp01  # 신규 추가 노드
```

**적용 및 확인**:

```bash
[dspaas@xadksbtmp01 ~ (prod-ds-ksp-member-xas:monitoring)]$ kc apply -f ./test_deploy.yaml
deployment.apps/checker-podselctor-test3 created

[dspaas@xadksbtmp01 ~ (prod-ds-ksp-member-xas:monitoring)]$ kc get pods -o wide
NAME                                                READY   STATUS    RESTARTS   AGE   IP           NODE             NOMINATED NODE   READINESS GATES
checker-podselctor-test3-977b76485-97wht            1/1     Running   0          9s    192.211.3.4  xadkswkmp01      <none>           <none>
```

### 5-2. PVC & Pod 배포 테스트

**StorageClass 확인**:

```bash
[dspaas@xadksbtmp01 ~ (prod-ds-ksp-member-xas:monitoring)]$ k get sc
NAME                               PROVISIONER               RECLAIMPOLICY   VOLUMEBINDINGMODE   ALLOWVOLUMEEXPANSION   AGE
xa-netapp-nfs-sc                   csi.trident.netapp.io     Delete          Immediate           true                   106d
```

> Xi'an 환경에서는 `xa-netapp-nfs-sc` 또는 `powerflexos-xfs-sc-300t-sp04`를 사용한다.

**PVC yaml 생성**:

```yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: test-netapp-deploy
spec:
  accessModes:
    - ReadWriteOnce
  resources:
    requests:
      storage: 16Gi
  storageClassName: xa-netapp-nfs-sc
```

```bash
[dspaas@xadksbtmp01 ~ (prod-ds-ksp-member-xas:monitoring)]$ kc apply -f ./netapp-test.yaml
persistentvolumeclaim/test-netapp-deploy created

[dspaas@xadksbtmp01 ~ (prod-ds-ksp-member-xas:monitoring)]$ kc get pvc
NAME                 STATUS   VOLUME           CAPACITY   ACCESS MODES   STORAGECLASS                       AGE
test-netapp-deploy   Bound    k8s-1dae9701d3   16Gi       RWO            xa-netapp-nfs-sc                  5s
```

**Pod yaml 생성**:

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: test-pvc-app
spec:
  volumes:
    - name: test-pvc
      persistentVolumeClaim:
        claimName: test-netapp-deploy
  containers:
    - image: xa.dcr.dks.samsungds.net/dspaas-testrepo/nginx:latest
      name: test-pvc-app
      volumeMounts:
        - name: test-pvc
          mountPath: "/pvc-test"
  nodeSelector:
    kubernetes.io/os: linux
    kubernetes.io/hostname: xadkswkmp01  # 신규 추가 노드
```

```bash
[dspaas@xadksbtmp01 ~ (prod-ds-ksp-member-xas:monitoring)]$ kc apply -f ./test_pvc_pod.yaml
pod/test-pvc-app created

[dspaas@xadksbtmp01 ~ (prod-ds-ksp-member-xas:monitoring)]$ kc get pods -o wide test-pvc-app
NAME           READY   STATUS    RESTARTS   AGE   IP           NODE             NOMINATED NODE   READINESS GATES
```
