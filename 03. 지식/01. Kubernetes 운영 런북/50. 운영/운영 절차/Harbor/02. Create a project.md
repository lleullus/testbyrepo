> [!summary] 요약
> Harbor 프로젝트 생성은 시스템 관리자 신청 → Harbor에서 프로젝트 생성 (Private + 10GB) → 멤버 역할 할당의 3단계로 진행된다.

---

## 1. 신청 절차

사용자가 Harbor 프로젝트 사용을 요청하면 시스템 관리자가 신청서를 받아 처리한다.

### 신청서 양식

| 항목 | 내용 |
|------|------|
| **DKS Kubesphere Application Form** | Remarks |
| **User Information** | |
| - Department | Cloud Platform Group |
| - Requester | 신청자 이름 |
| - User account | Global AD 계정 |
| **Permission** | |
| - Permission | Admin 또는 User (Admin 1명만 지정) |
| **DKS Information** | |
| - Cluster | 대상 Cluster (예: dev-apps-pa01-tas) |
| - Project | 프로젝트명 |

### 예시

| AD 계정 | 역할 |
|---------|------|
| dj2.kim | Admin |
| dshl04829.id | User |
| dsml14311.id | User |
| dsml14312.id | User |
| dsml14313.id | User |

---

## 2. Harbor 프로젝트 생성

### 2-1. Harbor 로그인

Harbor 인터페이스에 로그인한다.

### 2-2. 프로젝트 생성

1. **Projects** 메뉴로 이동
2. **New Project** 클릭
3. 다음 설정으로 생성:

| 설정 항목 | 값 | 비고 |
|-----------|------|------|
| Project Name | 신청서 프로젝트명 | |
| Access Level | **Private** | Public 선택 금지 |
| Storage Quota | **10 GB** | |

### 2-3. Access Level: Private vs Public

| | Private | Public |
|---|---------|--------|
| 이미지 풀 접근 | 프로젝트 멤버만 가능 | 모든 사용자 가능 |
| 보안 | 높음 | 낮음 |
| 사용 범위 | 제한된 팀/프로젝트 | 공개된 라이브러리 |

**Private 설정 시**: 프로젝트에 포함된 사용자에게만 이미지 풀 권한이 부여된다. Public으로 설정하면 인증 없이 모든 사용자가 이미지를 pull할 수 있으므로 보안상 권장되지 않는다.
