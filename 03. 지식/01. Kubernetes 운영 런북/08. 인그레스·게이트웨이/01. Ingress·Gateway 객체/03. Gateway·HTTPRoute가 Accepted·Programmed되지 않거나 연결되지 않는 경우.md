# Gateway·HTTPRoute가 Accepted·Programmed되지 않거나 연결되지 않는 경우

## 입력값과 빠른 수집

Gateway API는 Kubernetes 1.26 내장 API가 아니다. 먼저 설치된 CRD·discovery·served/storage version을 확인한다. 실행 경로는 `승인된 작업 PC/bastion의 같은 Bash → kubectl → API server → GatewayClass → Gateway listener → HTTPRoute parentRef/backendRef → Service → EndpointSlice → Pod`다. 기능 경로는 `같은 실행 host의 curl → Gateway address/listener → Route match/filter → Service/endpoint → application`이다. 이 문서는 SSH·node Linux·CRI 명령을 실행하지 않는다. 이관 시 SSH 인자는 positional argument로 넘기고 원격 host/machine identity를 node UID/providerID와 재검증하며 `eval`을 금지한다.

| 입력 종류 | 변수 | 출처와 gate |
|---|---|---|
| 최초 입력 | `NS`, `GW`, `ROUTE` | 같은 namespace의 exact Gateway·HTTPRoute 이름을 한 번 입력한다. cross-namespace parent는 자동 선택하지 않는다. |
| API 확인 자동값 | `GW_UID/RV/GEN`, `ROUTE_UID/RV/GEN`, class·listener·parent/backend·condition | discovery와 두 exact API 조회가 모두 성공한 경우만 등록한다. |
| 계산 후보값 | `GW_RE`, `ROUTE_RE` | escape 또는 객체 defaulting 후보이며 계약 확인 전 확정하지 않는다. |
| 운영자 선택값 | `START_RFC3339`, `END_RFC3339`, `CHECK_URL`, `CHECK_HOST` | 증거 창과 승인된 비민감 GET이다. |

`fresh_pair(){ FRESH_READY=false; [ "$AUTO_READY" = true ] || return 1; local gj rj gu gr ru rr; gj="$(kubectl get gateways.gateway.networking.k8s.io "$GW" -n "$NS" -o json)" || return 1; rj="$(kubectl get httproutes.gateway.networking.k8s.io "$ROUTE" -n "$NS" -o json)" || return 1; gu="$(jq -r '.metadata.uid' <<<"$gj")"; gr="$(jq -r '.metadata.resourceVersion' <<<"$gj")"; ru="$(jq -r '.metadata.uid' <<<"$rj")"; rr="$(jq -r '.metadata.resourceVersion' <<<"$rj")"; [ "$gu/$gr/$ru/$rr" = "$GW_UID/$GW_RV/$ROUTE_UID/$ROUTE_RV" ] || { printf '중단: Gateway/Route identity 또는 RV 변경, 재수집 필요\n' >&2; return 1; }; FRESH_READY=true; }`

## 진입 판단

| 구분 | 판단 기준 |
|---|---|
| 사용 | 설치 계약에 실제 존재하는 `Accepted=False`, `Programmed=False`, `ResolvedRefs=False`, `NoMatchingParent`가 현재 generation에 게시된 경우 |
| 적용 | CRD/discovery/version, class/listener/parent/backend와 status parent identity를 함께 대조할 수 있는 경우 |
| 제외 | condition이 설치 version에 없거나 Gateway API가 미설치면 실패로 만들지 않는다. Ingress 문제는 [[01. Ingress가 controller에 선택되지 않거나 ADDRESS가 갱신되지 않는 경우]]로 이동한다. |

검색 문자열: `Accepted`, `Programmed`, `ResolvedRefs`, `NoMatchingParent`, `RefNotPermitted`, `parentRefs`, `sectionName`, `allowedRoutes`, `backendRefs`.

## 관계와 condition 진단

**GatewayClass 관계**

`unset RELATION_READY CLASS_UID CLASS_RV CONTROLLER_NAME; RELATION_READY=false; fresh_pair || exit 1; if [ -z "$GW_CLASS" ]; then printf '%s\n' '중단: gatewayClassName이 비었다.' >&2; elif CJ="$(kubectl get gatewayclasses.gateway.networking.k8s.io "$GW_CLASS" -o json)"; then CLASS_UID="$(jq -r '.metadata.uid//empty' <<<"$CJ")"; CLASS_RV="$(jq -r '.metadata.resourceVersion//empty' <<<"$CJ")"; CONTROLLER_NAME="$(jq -r '.spec.controllerName//empty' <<<"$CJ")"; if [ -n "$CLASS_UID" ] && [ -n "$CLASS_RV" ] && [ -n "$CONTROLLER_NAME" ]; then RELATION_READY=true; export CLASS_UID CLASS_RV CONTROLLER_NAME; printf 'RELATION_READY=true Gateway=%s/%s -> GatewayClass=%s/%s -> controllerName=%s\n' "$GW" "$GW_UID" "$GW_CLASS" "$CLASS_UID" "$CONTROLLER_NAME"; jq -r '.status.conditions[]?|"class condition=\(.type)/\(.status) observed=\(.observedGeneration//"-") reason=\(.reason//"-")"' <<<"$CJ"; else printf '%s\n' '중단: GatewayClass identity/controller 불완전.' >&2; fi; else printf '%s\n' '중단: GatewayClass API 실패.' >&2; fi`

`fresh_gateway_relation(){ RELATION_FRESH_READY=false; fresh_pair || return 1; [ "$RELATION_READY" = true ] || return 1; local cj cu cr cc; cj="$(kubectl get gatewayclasses.gateway.networking.k8s.io "$GW_CLASS" -o json)" || return 1; cu="$(jq -r '.metadata.uid//empty' <<<"$cj")"; cr="$(jq -r '.metadata.resourceVersion//empty' <<<"$cj")"; cc="$(jq -r '.spec.controllerName//empty' <<<"$cj")"; [ "$cu/$cr/$cc" = "$CLASS_UID/$CLASS_RV/$CONTROLLER_NAME" ] || { printf '%s\n' '중단: GatewayClass UID/RV/controllerName 변경, 관계 재등록 필요.' >&2; return 1; }; RELATION_FRESH_READY=true; }`

**listener·parent·status의 현재 관계**

`fresh_gateway_relation || exit 1; if GJ="$(kubectl get gateways.gateway.networking.k8s.io "$GW" -n "$NS" -o json)" && RJ="$(kubectl get httproutes.gateway.networking.k8s.io "$ROUTE" -n "$NS" -o json)"; then jq -r '"=== Gateway status ===",(.status.conditions[]?|"condition=\(.type)/\(.status) observed=\(.observedGeneration//"-") reason=\(.reason//"-")"),(.status.listeners[]?|"listener=\(.name) attached=\(.attachedRoutes//0) conditions=\([.conditions[]?|"\(.type)/\(.status)/\(.reason)"]|join(","))")' <<<"$GJ" && jq -r '"=== HTTPRoute parents ===",(.status.parents[]?|"parent=\(.parentRef.namespace//"(route namespace)")/\(.parentRef.name)/\(.parentRef.sectionName//"-") controller=\(.controllerName) conditions=\([.conditions[]?|"\(.type)/\(.status)/\(.observedGeneration//"-")/\(.reason)"]|join(","))")' <<<"$RJ" || printf '%s\n' 'FILTER_ERROR: status JSON 파싱 실패.' >&2; else printf '%s\n' 'PRODUCER_ERROR: Gateway/HTTPRoute API 실패.' >&2; fi`

condition의 `observedGeneration`이 현재 generation과 다르면 최신 상태로 해석하지 않는다. `Accepted=True`는 attachment, `Programmed=True`는 해당 설치 계약이 정의한 program 상태만 보장하며 listener traffic·backend 기능을 보장하지 않는다.

**Service backend 관계**

`unset SERVICE SERVICE_UID SERVICE_RV BACKEND_PORT SERVICE_PORT_NAME TARGET_PORT; fresh_gateway_relation || exit 1; jq -e --arg gw "$GW" --arg ns "$NS" 'any(.[]?;((.group//"gateway.networking.k8s.io")=="gateway.networking.k8s.io") and ((.kind//"Gateway")=="Gateway") and .name==$gw and ((.namespace//$ns)==$ns))' <<<"$ROUTE_PARENTS" >/dev/null || { printf '%s\n' '중단: HTTPRoute parentRef가 현재 Gateway를 가리키지 않음.' >&2; exit 1; }; jq -e 'length==1 and ((.[0].group//"")=="") and ((.[0].kind//"Service")=="Service") and ((.[0].namespace//"")=="") and (.[0].port!=null)' <<<"$ROUTE_BACKENDS" >/dev/null || { printf '%s\n' '중단: 같은 namespace의 단일 Service backend가 아님. 자동 선택 금지.' >&2; exit 1; }; SERVICE="$(jq -r '.[0].name' <<<"$ROUTE_BACKENDS")"; BACKEND_PORT="$(jq -r '.[0].port' <<<"$ROUTE_BACKENDS")"; if SJ="$(kubectl get service "$SERVICE" -n "$NS" -o json)"; then SERVICE_UID="$(jq -r '.metadata.uid' <<<"$SJ")"; SERVICE_RV="$(jq -r '.metadata.resourceVersion' <<<"$SJ")"; PORTS="$(jq -c --argjson p "$BACKEND_PORT" '[.spec.ports[]?|select(.port==$p)]' <<<"$SJ")"; if [ "$(jq 'length' <<<"$PORTS")" -eq 1 ]; then SERVICE_PORT_NAME="$(jq -r '.[0].name//empty' <<<"$PORTS")"; TARGET_PORT="$(jq -r '.[0].targetPort' <<<"$PORTS")"; export SERVICE SERVICE_UID SERVICE_RV BACKEND_PORT SERVICE_PORT_NAME TARGET_PORT; printf 'Gateway=%s/%s <- Route=%s/%s -> Service=%s/%s port=%s:%s targetPort=%s\n' "$GW" "$GW_UID" "$ROUTE" "$ROUTE_UID" "$SERVICE" "$SERVICE_UID" "${SERVICE_PORT_NAME:--}" "$BACKEND_PORT" "$TARGET_PORT"; else printf '%s\n' '중단: backendRef port의 exact Service port가 하나가 아님.' >&2; exit 1; fi; else printf '%s\n' '중단: Service API 실패.' >&2; exit 1; fi`

`fresh_pair || exit 1; [ -n "${SERVICE_UID:-}" ] || { printf '%s\n' '중단: Service 관계 미등록.' >&2; exit 1; }; SJSON="$(kubectl get service "$SERVICE" -n "$NS" -o json)" || exit 1; [ "$(jq -r '.metadata.uid' <<<"$SJSON")/$(jq -r '.metadata.resourceVersion' <<<"$SJSON")" = "$SERVICE_UID/$SERVICE_RV" ] || { printf '%s\n' '중단: Service UID/RV 변경, 관계 재등록.' >&2; exit 1; }; SLICE_FILE="$(mktemp)" || exit 1; if kubectl get endpointslice -n "$NS" -l "kubernetes.io/service-name=$SERVICE" -o json >"$SLICE_FILE"; then if [ -n "$SERVICE_PORT_NAME" ]; then PORT_OK="$(jq --arg su "$SERVICE_UID" --arg pn "$SERVICE_PORT_NAME" '[.items[]|select(any(.metadata.ownerReferences[]?;.kind=="Service" and .uid==$su))|.ports[]?|select((.name//"")==$pn)]|length' "$SLICE_FILE")"; elif [[ "$TARGET_PORT" =~ ^[0-9]+$ ]]; then PORT_OK="$(jq --arg su "$SERVICE_UID" --argjson tp "$TARGET_PORT" '[.items[]|select(any(.metadata.ownerReferences[]?;.kind=="Service" and .uid==$su))|.ports[]?|select(.port==$tp)]|length' "$SLICE_FILE")"; else PORT_OK=0; fi; if [ "$PORT_OK" -gt 0 ] && OUT="$(jq -r --arg su "$SERVICE_UID" '[.items[]|select(any(.metadata.ownerReferences[]?;.kind=="Service" and .uid==$su))] as $owned|$owned[]|"slice=\(.metadata.name)/\(.metadata.uid) owner=\([.metadata.ownerReferences[]?|"\(.kind)/\(.name)/\(.uid)"]|join(",")) ports=\([.ports[]?|"\(.name//"-"):\(.port//0)"]|join(",")) targets=\([.endpoints[]?|"\(.targetRef.kind//"-")/\(.targetRef.name//"-")/\(.targetRef.uid//"-") node=\(.nodeName//"-") ready=\(.conditions.ready//false)"]|join(";"))"' "$SLICE_FILE")" && [ -n "$OUT" ]; then printf '%s\n' "$OUT"; else printf '%s\n' 'NO_MATCH: current Service UID 소유 EndpointSlice와 port 관계 없음.' >&2; fi; else printf '%s\n' 'PRODUCER_ERROR: EndpointSlice API 실패.' >&2; fi; rm -f "$SLICE_FILE"`

Pod container/containerID와 node 관계는 targetRef UID를 exact 조회한 뒤에만 사용한다. Endpoint ready나 선언 port는 process listener·application 정상 증거가 아니다. CRI는 active kubelet configuration에서 검증된 endpoint exact match와 runtime provider 관계가 확보된 node 런북에서만 사용한다.

## 시간 lifecycle과 Event

`START_RFC3339='PASTE_GATEWAY_EVIDENCE_START_UTC_HERE'; END_RFC3339='PASTE_GATEWAY_EVIDENCE_END_UTC_HERE'`

`TIME_READY=false; RX='^[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}Z$'; if [[ "$START_RFC3339" =~ $RX ]] && [[ "$END_RFC3339" =~ $RX ]] && [ "$(date -u -d "$START_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null)" = "$START_RFC3339" ] && [ "$(date -u -d "$END_RFC3339" '+%Y-%m-%dT%H:%M:%SZ' 2>/dev/null)" = "$END_RFC3339" ]; then START_EPOCH="$(date -u -d "$START_RFC3339" +%s)"; END_EPOCH="$(date -u -d "$END_RFC3339" +%s)"; GE="$(date -u -d "$GW_CREATED" +%s)"; RE="$(date -u -d "$ROUTE_CREATED" +%s)"; if [ "$START_EPOCH" -lt "$END_EPOCH" ] && [ "$GE" -le "$END_EPOCH" ] && [ "$RE" -le "$END_EPOCH" ] && [ "$END_EPOCH" -le "$(date -u +%s)" ]; then TIME_READY=true; export START_RFC3339 END_RFC3339 START_EPOCH END_EPOCH; printf 'TIME_READY=true %s..%s gateway-created=%s route-created=%s\n' "$START_RFC3339" "$END_RFC3339" "$GW_CREATED" "$ROUTE_CREATED"; else printf '%s\n' '중단: start<end/evidence lifecycle 실패.' >&2; fi; else printf '%s\n' '중단: canonical UTC RFC3339 regex/date roundtrip 실패.' >&2; fi`

`fresh_pair || exit 1; [ "$TIME_READY" = true ] || exit 1; EVENT_FILE="$(mktemp)" || exit 1; if kubectl get events -n "$NS" -o json >"$EVENT_FILE"; then if FILTERED="$(jq -r --arg gu "$GW_UID" --arg ru "$ROUTE_UID" --arg s "$START_RFC3339" --arg e "$END_RFC3339" '.items[]|select(.involvedObject.uid==$gu or .involvedObject.uid==$ru)|(.eventTime//.lastTimestamp//.metadata.creationTimestamp) as $t|select($t >= $s and $t <= $e)|"\($t) \(.involvedObject.kind)/\(.involvedObject.name) \(.type) \(.reason) \(.message|gsub("[[:cntrl:]]";" ")|.[0:300])"' "$EVENT_FILE")"; then if [ -n "$FILTERED" ]; then printf '%s\n' "$FILTERED"; else printf '%s\n' 'NO_MATCH: Event API 성공, UID·시간 창 일치 없음.' >&2; fi; else printf '%s\n' 'FILTER_ERROR: Event JSON/UID·시간 필터 실패.' >&2; fi; else printf '%s\n' 'PRODUCER_ERROR: Event API 실패.' >&2; fi; rm -f "$EVENT_FILE"`

producer/API 실패, 성공 후 no match, jq/filter 오류는 별개다. exact RBAC는 `gatewayclasses`, `gateways`, `httproutes`, `services`, `endpointslices`, `events` 각각의 verb·namespace/subresource로 `kubectl auth can-i`를 확인한다. audit owner에게는 exact UID와 UTC 창을 전달하고 audit 원문·credential을 수집하지 않는다.

## 관측 분기와 변경 경계

| 관측 | 직접 근거 | 다음 owner |
|---|---|---|
| GatewayClass 미수락 | current class UID/controllerName/condition | class/controller 설치 owner |
| listener `Accepted=False` | listener exact name/protocol/hostname/allowedRoutes/reason | Gateway owner |
| Gateway `Programmed=False` | current generation condition/address와 controller reconcile | controller/VIP owner |
| Route `NoMatchingParent` | parent namespace/name/section/port와 listener exact match | Route/Gateway owner |
| `ResolvedRefs=False` | backend group/kind/ns/name/port와 ReferenceGrant 설치 계약 | Route/Service owner |
| status 성공, 기능 실패 | running config→Service→EndpointSlice→backend→요청 | controller/L7 owner |

읽기 전용과 mutation을 분리한다. 별도 변경 절차는 fresh Gateway/Route/class/Service/EndpointSlice/Pod identity, 직접 증거, 승인 ID, window, tenant/listener 영향, quorum·가용 replica, 멱등성 key, 승인 원본, 중단 조건, 현재 UID에 결합한 rollback target을 실행 직전에 검증한다. 교체 객체는 parent/backend/controller/Pod/containerID/node 관계와 모든 READY gate를 재등록한다. CRD·ReferenceGrant·listener를 추측해 변경하지 않는다.

정상화는 `application 핵심 기능 → backend/EndpointSlice/Service → Route match·parent status → Gateway listener/address/condition → GatewayClass/controllerName → 현재 UID/RV` 순으로 역검증하고 동등한 관찰 창에서 재발이 없어야 한다. condition 하나나 HTTP 한 번으로 닫지 않는다.
