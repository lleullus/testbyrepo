# Pod STATUS가 OOMKilled인 경우

## 입력값과 빠른 수집

### 실행 계약

최초 입력·Kubernetes API는 승인된 작업 PC 또는 bastion의 **같은 Bash**에서 실행한다. `kubectl`, `jq`, `sed`, `grep`, `date`, `ssh`가 필수이며 도구 확인 실패 뒤에는 진행하지 않는다. node의 memory·journal·CRI·cgroup 명령은 작업 PC에서 실행하지 않고, 승인된 `NODE_HOST`와 Kubernetes node identity를 대조한 뒤 SSH remote command로 실행한다. Bash 변수가 node shell에 자동 공유된다고 가정하지 않는다.

연결 경로는 `실행 host → kubectl client/API server → node/kubelet → runtime·CRI → 대상 container cgroup/kernel → process/application`이다. API transport, SSH host, CRI endpoint/socket, cgroup mount와 application endpoint는 다른 hop·권한·protocol이다. 한 hop 성공은 다음 hop이나 실제 기능 정상을 보장하지 않는다.

| 구분 | 등록 값 | 출처·선택 기준 |
|---|---|---|
| 최초 입력 | `NS`, `POD` | 운영자가 승인된 namespace와 Pod 이름을 한 번 입력한다. |
| API 확인 자동값 | `POD_UID`, `NODE`, `PHASE`, `POD_CREATED`, `QOS`, `POD_RE`, `WORKLOAD_KIND`, `WORKLOAD_NAME`, `WORKLOAD_UID`, `WORKLOAD_SELECTOR`, `OLD_REQUEST`, `OLD_LIMIT` | Pod UID와 top-level owner chain, owner template API에서 등록한다. ReplicaSet은 변경 권한 owner가 아니다. |
| 계산 후보 | `END_JOURNAL`, `KUBELET_CONFIG_PATH`, `CRI_ID`, `CGROUP_IDENTIFIER`, `CGROUP_PATH` | 확인된 kubelet unit `ExecStart --config`, 현재 시각·확인된 CRI inspect·driver/mount 검증으로 계산한다. driver 또는 mount가 불명확하면 이관한다. |
| 운영자 선택값 | `CONTAINER`, `NODE_HOST`, `KUBELET_UNIT`, `START_JOURNAL`, `RUNTIME_UNIT`, `CRI_ENDPOINT`, `NEW_REQUEST`, `NEW_LIMIT`, `APPROVAL_ID`, `CHANGE_WINDOW_START`, `CHANGE_WINDOW_END`, `SERVICE`, `NEW_POD`, `FUNCTION_CHECK_ID`, `FUNCTION_CHECK_RESULT`, `FUNCTION_CHECK_START`, `FUNCTION_CHECK_END` | 세로 출력·승인 inventory·실제 node 구현·용량 계산을 확인한 뒤 선택한다. kubelet config path는 수동 입력하지 않으며, 기능 확인 값은 서비스 owner가 제공한 bounded check 결과만 사용한다. |

### API 자동 수집과 identity gate

**대상별 기본 정보 출력 — 아래 한 줄 전체를 복사**

`if [ "$INPUT_READY" != true ]; then printf '%s\n' '중단: INPUT_READY가 아니다.' >&2; elif POD_JSON="$(kubectl get pod "$POD" -n "$NS" -o json)" && jq -e '.metadata.uid and .metadata.name' >/dev/null <<<"$POD_JSON"; then jq -r '"=== 대상 Pod ===\n이름: \(.metadata.name)\nUID: \(.metadata.uid)\nNode: \(.spec.nodeName // "-")\nPhase: \(.status.phase // "-")\nQoS: \(.status.qosClass // "-")\n생성 시각: \(.metadata.creationTimestamp // "-")\nOwner: " + (([.metadata.ownerReferences[]? | select(.controller==true) | "\(.kind)/\(.name) UID=\(.uid)"] | join(", ")) // "-") + "\n" + ([.spec.containers[]? as $c | "Container: \($c.name)\n  상태: " + (([.status.containerStatuses[]? | select(.name==$c.name) | "current=\(.state | keys[0] // "-") last=\(.lastState.terminated.reason // "-") exit=\(.lastState.terminated.exitCode // "-") finished=\(.lastState.terminated.finishedAt // "-")"] | .[0]) // "status 없음"))] | join("\n"))' <<<"$POD_JSON"; else printf '%s\n' '중단: Pod API 또는 JSON 확인 실패. 빈 출력은 대상 없음·권한·API 오류를 구분한다.' >&2; fi`

raw command/args, Secret·token·개인정보는 출력하지 않는다. `exitCode=137`만으로 OOMKilled를 확정하지 않는다.

**최초 Pod 자동값 등록 — 아래 한 줄 전체를 복사**

`invalidate_pod_pipeline; unset AUTO_READY POD_UID NODE PHASE POD_CREATED QOS POD_RE; AUTO_READY=false; if [ "$INPUT_READY" != true ]; then printf '%s\n' '중단: INPUT_READY가 아니다.' >&2; elif POD_JSON="$(kubectl get pod "$POD" -n "$NS" -o json)" && POD_UID_TMP="$(jq -r '.metadata.uid // empty' <<<"$POD_JSON")" && NODE_TMP="$(jq -r '.spec.nodeName // empty' <<<"$POD_JSON")" && PHASE_TMP="$(jq -r '.status.phase // empty' <<<"$POD_JSON")" && POD_CREATED_TMP="$(jq -r '.metadata.creationTimestamp // empty' <<<"$POD_JSON")" && QOS_TMP="$(jq -r '.status.qosClass // empty' <<<"$POD_JSON")" && POD_RE_TMP="$(printf '%s' "$POD" | sed 's/[][\\.^$*+?(){}|]/\\&/g')"; then if [ -n "$POD_UID_TMP" ] && [ -n "$NODE_TMP" ] && [ -n "$PHASE_TMP" ]; then POD_UID="$POD_UID_TMP"; NODE="$NODE_TMP"; PHASE="$PHASE_TMP"; POD_CREATED="$POD_CREATED_TMP"; QOS="${QOS_TMP:--}"; POD_RE="^${POD_RE_TMP}$"; AUTO_READY=true; export NS POD POD_UID NODE PHASE POD_CREATED QOS POD_RE; printf 'AUTO_READY=true\nPod UID: %s\nNode: %s\nPhase: %s\nQoS: %s\n생성 시각: %s\nPod 정규식 후보: %s\n' "$POD_UID" "$NODE" "$PHASE" "$QOS" "$POD_CREATED" "$POD_RE"; else printf '%s\n' '중단: UID·node·phase가 비었다. 부분 등록값을 폐기했다.' >&2; fi; else printf '%s\n' '중단: API 자동값 등록 실패. 이전 값은 유효하지 않다.' >&2; fi`

**Pod UID 검증 helper 등록 — 같은 Bash에서 한 번 실행**

`verify_pod_identity(){ POD_IDENTITY_READY=false; unset POD_JSON CURRENT_POD_UID; if [ "$AUTO_READY" != true ]; then printf '%s\n' '중단: AUTO_READY가 아니다.' >&2; return 1; elif POD_JSON="$(kubectl get pod "$POD" -n "$NS" -o json)" && CURRENT_POD_UID="$(jq -r '.metadata.uid // empty' <<<"$POD_JSON")"; then if [ -z "$CURRENT_POD_UID" ] || [ "$CURRENT_POD_UID" != "$POD_UID" ]; then printf '중단: Pod UID mismatch initial=%s current=%s\n' "$POD_UID" "${CURRENT_POD_UID:--}" >&2; return 2; else POD_IDENTITY_READY=true; export POD_JSON CURRENT_POD_UID; printf 'POD_IDENTITY_READY=true pod=%s uid=%s\n' "$POD" "$CURRENT_POD_UID"; return 0; fi; else printf '%s\n' '중단: Pod 재조회 실패. 이전 JSON을 재사용하지 않는다.' >&2; return 1; fi; }`

`OWNER_CHAIN_READY=false;`

**selector 안전성 gate — matchExpressions는 지원하지 않으므로 아래 한 줄 전체를 복사**

`SELECTOR_SAFE_READY=false; if [ "$OWNER_CHAIN_RECHECK_READY" != true ]; then printf '%s\n' '중단: owner chain 재검증 gate가 아니다.' >&2; elif OWNER_SELECTOR_JSON="$(kubectl get "$WORKLOAD_KIND" "$WORKLOAD_NAME" -n "$NS" -o json)" && [ "$(jq -r '(.spec.selector.matchExpressions // []) | length' <<<"$OWNER_SELECTOR_JSON")" -eq 0 ]; then SELECTOR_SAFE_READY=true; export SELECTOR_SAFE_READY; printf 'SELECTOR_SAFE_READY=true owner=%s/%s selector=%s\n' "$WORKLOAD_KIND" "$WORKLOAD_NAME" "$WORKLOAD_SELECTOR"; else OWNER_CHAIN_READY=false; printf '%s\n' '중단: selector matchExpressions는 안전하게 해석하지 못해 변경 gate를 닫는다.' >&2; fi; if [ "$SELECTOR_SAFE_READY" = true ]; then OWNER_CHAIN_READY=true; fi`

ReplicaSet은 최상위 Deployment를 찾는 중간 객체다. chain이 끊기거나 top-level UID가 없으면 resource 변경을 하지 않는다.

**운영자 container 선택 및 OOM gate — 아래 한 줄 전체를 복사**

`CONTAINER='PASTE_CONTAINER_HERE'; SELECTION_READY=false; unset CONTAINER_ID_RAW CONTAINER_REASON EXIT_CODE FINISHED_AT; if verify_pod_identity && CONTAINER_REASON_TMP="$(jq -r --arg c "$CONTAINER" '[.status.containerStatuses[]? | select(.name==$c) | (.lastState.terminated.reason // .state.terminated.reason // "")][0] // empty' <<<"$POD_JSON")" && CONTAINER_ID_TMP="$(jq -r --arg c "$CONTAINER" '[.status.containerStatuses[]? | select(.name==$c) | (.lastState.terminated.containerID // .containerID // "")][0] // empty' <<<"$POD_JSON")" && EXIT_CODE_TMP="$(jq -r --arg c "$CONTAINER" '[.status.containerStatuses[]? | select(.name==$c) | (.lastState.terminated.exitCode // .state.terminated.exitCode // "")][0] // empty' <<<"$POD_JSON")" && FINISHED_AT_TMP="$(jq -r --arg c "$CONTAINER" '[.status.containerStatuses[]? | select(.name==$c) | (.lastState.terminated.finishedAt // .state.terminated.finishedAt // "")][0] // empty' <<<"$POD_JSON")"; then if [ "$CONTAINER_REASON_TMP" = OOMKilled ]; then CONTAINER_ID_RAW="$CONTAINER_ID_TMP"; CONTAINER_REASON="$CONTAINER_REASON_TMP"; EXIT_CODE="$EXIT_CODE_TMP"; FINISHED_AT="$FINISHED_AT_TMP"; SELECTION_READY=true; export CONTAINER CONTAINER_ID_RAW CONTAINER_REASON EXIT_CODE FINISHED_AT; printf 'SELECTION_READY=true\ncontainer=%s reason=%s exitCode=%s finishedAt=%s containerID=%s\n' "$CONTAINER" "$CONTAINER_REASON" "${EXIT_CODE:--}" "${FINISHED_AT:--}" "${CONTAINER_ID_RAW:--}"; else printf '중단: 선택 container reason이 OOMKilled가 아님 reason=%s\n' "${CONTAINER_REASON_TMP:--}" >&2; fi; else printf '%s\n' '중단: UID 검증·container 조회 실패. 임의 선택하지 않는다.' >&2; fi`

### 4. node memory와 kernel OOM

`Out of memory: Killed process`·`task_memcg`·cgroup path·finished 시각이 대상 container와 맞으면 kernel 보조 근거다. 다른 process가 victim이면 Pod 원인으로 단정하지 않고 node owner에게 이관한다. 로그 producer 실패·filter 빈 결과는 증거 공백으로 기록한다.

### 5. 대상 container cgroup 증거

systemd cgroup driver 식별자나 runtime `cgroupsPath` 문자열을 filesystem 절대경로로 직접 사용하지 않는다. kubelet driver, 실제 cgroup mount, runtime inspect 값을 각각 확인하고 실제 path로 해석되지 않으면 owner에게 이관한다.

**kubelet 실제 runtime endpoint exact-match — cgroup·CRI 명령 전에 아래 한 줄 전체를 복사**

## 관측 결과 해석

- `reason=OOMKilled`만 있고 cgroup·kubelet·kernel이 없거나 충돌하면 **OOMKilled만 확정, 세부 원인 미확정**이다.
- 대상 limit·cgroup event·finished 시각이 맞으면 container cgroup limit 초과 가능성을 기록한다.
- MemoryPressure·kubelet eviction·global kernel victim이 node와 맞으면 node memory pressure 가능성으로 기록한다.
- `exitCode=137`만 있으면 OOMKilled로 확정하지 않는다.

## 복구 전 gate와 승인된 상태 변경

limit 조정 전에는 Pod UID identity, OOM reason, metrics 한계, node pressure, kubelet/kernel, 실제 cgroup path/driver/mount, top-level owner UID, 용량 계산, 승인자와 rollback을 기록한다. ReplicaSet·Pod에는 `set resources`를 실행하지 않는다.

`RESOURCE_CHANGE_APPLIED=false; RESOURCE_CHANGE_START=''; if [ "$MEMORY_LIMIT_EVENT_READY" != true ] || [ "$MEMORY_RESOURCE_FORBIDDEN" = true ]; then RESOURCE_CHANGE_READY=false; printf '%s\n' '중단: resource 변경 직전 target cgroup memory limit·event direct evidence gate가 닫혔다.' >&2; elif [ "$RESOURCE_CHANGE_READY" != true ]; then printf '%s\n' '중단: RESOURCE_CHANGE_READY가 아니다.' >&2; else RESOURCE_CHANGE_ATTEMPT_START="$(date -u '+%Y-%m-%dT%H:%M:%SZ')"; if kubectl -n "$NS" set resources "$WORKLOAD_KIND/$WORKLOAD_NAME" -c "$CONTAINER" --requests=memory="$NEW_REQUEST" --limits=memory="$NEW_LIMIT"; then RESOURCE_CHANGE_APPLIED=true; RESOURCE_CHANGE_START="$RESOURCE_CHANGE_ATTEMPT_START"; export RESOURCE_CHANGE_APPLIED RESOURCE_CHANGE_START; printf 'RESOURCE_CHANGE_APPLIED=true owner=%s/%s uid=%s start=%s oldRequest=%s oldLimit=%s newRequest=%s newLimit=%s approval=%s\n' "$WORKLOAD_KIND" "$WORKLOAD_NAME" "$WORKLOAD_UID" "$RESOURCE_CHANGE_START" "$OLD_REQUEST" "$OLD_LIMIT" "$NEW_REQUEST" "$NEW_LIMIT" "$APPROVAL_ID"; else RESOURCE_CHANGE_ATTEMPT_START=''; RESOURCE_CHANGE_START=''; printf '%s\n' '중단: set resources 실패. RESOURCE_CHANGE_APPLIED=false이며 정상화로 진행하지 않는다.' >&2; fi; fi`

**resource 변경 후 rollout·observed generation gate — 새 Pod 선택 전에 아래 한 줄 전체를 복사**

`ROLLOUT_READY=false; if [ "$RESOURCE_CHANGE_APPLIED" != true ]; then printf '%s\n' '중단: 성공한 resource 변경이 아니다.' >&2; else ROLLOUT_RC=0; kubectl rollout status "$WORKLOAD_KIND/$WORKLOAD_NAME" -n "$NS" --timeout=5m || ROLLOUT_RC=$?; if [ "$ROLLOUT_RC" -ne 0 ]; then printf '중단: rollout status 실패 또는 timeout rc=%s. 즉시 rollback하지 않고 stop·owner 판단으로 이관한다.\n' "$ROLLOUT_RC" >&2; elif OWNER_STATUS_JSON="$(kubectl get "$WORKLOAD_KIND" "$WORKLOAD_NAME" -n "$NS" -o json)" && OWNER_GENERATION="$(jq -r '.metadata.generation // empty' <<<"$OWNER_STATUS_JSON")" && OBSERVED_GENERATION="$(jq -r '.status.observedGeneration // empty' <<<"$OWNER_STATUS_JSON")" && [ -n "$OWNER_GENERATION" ] && [ "$OWNER_GENERATION" = "$OBSERVED_GENERATION" ]; then ROLLOUT_READY=true; export ROLLOUT_READY OWNER_GENERATION OBSERVED_GENERATION; printf 'ROLLOUT_READY=true owner=%s/%s generation=%s observedGeneration=%s\n' "$WORKLOAD_KIND" "$WORKLOAD_NAME" "$OWNER_GENERATION" "$OBSERVED_GENERATION"; else printf '%s\n' '중단: rollout 성공 또는 observedGeneration 일치 확인 실패. 즉시 rollback하지 않고 stop·owner 판단으로 이관한다.' >&2; fi; fi`

`if [ "$ROLLOUT_READY" != true ]; then RESOURCE_CHANGE_APPLIED=false; POST_CHANGE_READY=false; printf '%s\n' '중단: rollout status·observedGeneration 성공 전 새 Pod를 선택하지 않는다.' >&2; fi`

## 정상화 검증

변경 후 selector·top-level owner UID·revision으로 새 Pod 후보와 UID를 등록한다. 기존 `POD_UID` mismatch는 변경 전 gate를 무효화하고, 변경 후에는 명시적으로 새 UID가 기존 UID와 다르며 top-level owner chain이 맞는지 확인한다.

**변경 후 새 Pod 후보 출력 — resource 변경 성공 뒤 아래 한 줄 전체를 복사**

`POST_CHANGE_READY=false; if [ "$RESOURCE_CHANGE_APPLIED" != true ] || [ "$WORKLOAD_SELECTOR" = - ]; then printf '%s\n' '중단: 성공한 resource 변경·selector gate가 아니다.' >&2; elif CANDIDATE_JSON="$(kubectl get pods -n "$NS" -l "$WORKLOAD_SELECTOR" -o json)" && jq -e '.items | type == "array"' >/dev/null <<<"$CANDIDATE_JSON"; then jq -r --arg old "$POD_UID" '[.items[] | select(.metadata.uid != $old) | "=== 새 후보 ===\nPod: \(.metadata.name)\nUID: \(.metadata.uid)\n생성 시각: \(.metadata.creationTimestamp)\nPhase: \(.status.phase // "-")\nOwner: \([.metadata.ownerReferences[]? | select(.controller==true) | "\(.kind)/\(.name) UID=\(.uid)"] | join(","))"] | if length == 0 then "후보 없음" else join("\n") end' <<<"$CANDIDATE_JSON"; POST_CHANGE_READY=true; export CANDIDATE_JSON; else printf '%s\n' '중단: selector 후보 API/schema 조회 실패. 이전 Pod UID를 재사용하지 않는다.' >&2; fi`

**새 Pod identity·top owner chain 등록 — 후보 확인 후 아래 한 줄 전체를 복사**

`NEW_POD='PASTE_NEW_POD_HERE'; NEW_POD_READY=false; if [ "$POST_CHANGE_READY" != true ] || [ "$RESOURCE_CHANGE_APPLIED" != true ] || [ -z "$RESOURCE_CHANGE_START" ]; then printf '%s\n' '중단: candidate·성공한 resource 변경·change start gate가 아니다.' >&2; elif CANDIDATE_JSON="$(kubectl get pods -n "$NS" -l "$WORKLOAD_SELECTOR" -o json)" && NEW_POD_JSON="$(kubectl get pod "$NEW_POD" -n "$NS" -o json)" && NEW_POD_UID="$(jq -r '.metadata.uid // empty' <<<"$NEW_POD_JSON")" && NEW_OWNER_KIND="$(jq -r '[.metadata.ownerReferences[]? | select(.controller==true)][0].kind // empty' <<<"$NEW_POD_JSON")" && NEW_OWNER_NAME="$(jq -r '[.metadata.ownerReferences[]? | select(.controller==true)][0].name // empty' <<<"$NEW_POD_JSON")" && NEW_OWNER_UID="$(jq -r '[.metadata.ownerReferences[]? | select(.controller==true)][0].uid // empty' <<<"$NEW_POD_JSON")"; then NEW_OWNER_GATE=false; if [ "$WORKLOAD_KIND" = deployment ] && [ "$NEW_OWNER_KIND" = ReplicaSet ] && [ -n "$NEW_OWNER_NAME" ] && [ -n "$NEW_OWNER_UID" ] && NEW_RS_JSON="$(kubectl get replicaset "$NEW_OWNER_NAME" -n "$NS" -o json)" && NEW_RS_UID="$(jq -r '.metadata.uid // empty' <<<"$NEW_RS_JSON")" && NEW_RS_TOP_KIND="$(jq -r '[.metadata.ownerReferences[]? | select(.controller==true)][0].kind // empty' <<<"$NEW_RS_JSON")" && NEW_RS_TOP_NAME="$(jq -r '[.metadata.ownerReferences[]? | select(.controller==true)][0].name // empty' <<<"$NEW_RS_JSON")" && NEW_RS_TOP_UID="$(jq -r '[.metadata.ownerReferences[]? | select(.controller==true)][0].uid // empty' <<<"$NEW_RS_JSON")"; then if [ "$NEW_RS_UID" = "$NEW_OWNER_UID" ] && [ "$NEW_RS_TOP_KIND" = Deployment ] && [ "$NEW_RS_TOP_NAME" = "$WORKLOAD_NAME" ] && [ "$NEW_RS_TOP_UID" = "$WORKLOAD_UID" ]; then NEW_OWNER_GATE=true; fi; elif { [ "$WORKLOAD_KIND" = statefulset ] || [ "$WORKLOAD_KIND" = daemonset ]; } && [ "$NEW_OWNER_KIND" = "$WORKLOAD_KIND" ] && [ "$NEW_OWNER_NAME" = "$WORKLOAD_NAME" ] && [ "$NEW_OWNER_UID" = "$WORKLOAD_UID" ]; then NEW_OWNER_GATE=true; fi; if [ "$NEW_OWNER_GATE" = true ] && [ -n "$NEW_POD_UID" ] && [ "$NEW_POD_UID" != "$POD_UID" ] && jq -e --arg pod "$NEW_POD" --arg uid "$NEW_POD_UID" --arg old "$POD_UID" --arg start "$RESOURCE_CHANGE_START" --arg end "$CHANGE_WINDOW_END" 'any(.items[]; .metadata.name==$pod and .metadata.uid==$uid and .metadata.uid != $old and (.metadata.creationTimestamp // "") >= $start and (.metadata.creationTimestamp // "") <= $end)' >/dev/null <<<"$CANDIDATE_JSON"; then NEW_POD_READY=true; export NEW_POD NEW_POD_UID NEW_OWNER_KIND NEW_OWNER_NAME NEW_OWNER_UID; printf 'NEW_POD_READY=true pod=%s uid=%s directOwner=%s/%s ownerUID=%s topOwner=%s/%s uid=%s changeWindow=%s..%s\n' "$NEW_POD" "$NEW_POD_UID" "$NEW_OWNER_KIND" "$NEW_OWNER_NAME" "$NEW_OWNER_UID" "$WORKLOAD_KIND" "$WORKLOAD_NAME" "$WORKLOAD_UID" "$RESOURCE_CHANGE_START" "$CHANGE_WINDOW_END"; else printf '%s\n' '중단: candidate membership·change-window·UID·owner kind별 chain gate 실패.' >&2; fi; else printf '%s\n' '중단: 새 Pod API/schema 조회 실패.' >&2; fi`

**변경 실패 시 이전 request/limit rollback — 아래 한 줄 전체를 복사**

`RESOURCE_ROLLBACK_APPLIED=false; if [ "$RESOURCE_CHANGE_APPLIED" != true ]; then printf '%s\n' 'rollback 생략: 성공한 resource 변경이 없다.'; elif [ "$NEW_POD_READY" = true ]; then printf '%s\n' 'rollback 생략: 새 Pod gate가 성공했다.'; elif [ "$CURRENT_OWNER_UID" != "$WORKLOAD_UID" ] || [ -z "$OLD_REQUEST" ] || [ -z "$OLD_LIMIT" ]; then printf '%s\n' '중단: 이전 request/limit 또는 owner UID가 없어 rollback하지 않는다.' >&2; elif kubectl -n "$NS" set resources "$WORKLOAD_KIND/$WORKLOAD_NAME" -c "$CONTAINER" --requests=memory="$OLD_REQUEST" --limits=memory="$OLD_LIMIT"; then RESOURCE_ROLLBACK_APPLIED=true; export RESOURCE_ROLLBACK_APPLIED; printf 'RESOURCE_ROLLBACK_APPLIED=true owner=%s/%s uid=%s request=%s limit=%s\n' "$WORKLOAD_KIND" "$WORKLOAD_NAME" "$WORKLOAD_UID" "$OLD_REQUEST" "$OLD_LIMIT"; else printf '%s\n' '중단: 이전 request/limit rollback 실패. 정상화로 진행하지 않는다.' >&2; fi`

**새 Pod·owner·기능 확인 — 아래 한 줄 전체를 복사**

`if [ "$NEW_POD_READY" != true ]; then printf '%s\n' '중단: NEW_POD_READY가 아니다.' >&2; elif NEW_STATUS="$(kubectl get pod "$NEW_POD" -n "$NS" -o json)" && [ "$(jq -r '.metadata.uid // empty' <<<"$NEW_STATUS")" = "$NEW_POD_UID" ] && kubectl get "$WORKLOAD_KIND" "$WORKLOAD_NAME" -n "$NS" && kubectl rollout status "$WORKLOAD_KIND/$WORKLOAD_NAME" -n "$NS" --timeout=5m; then printf '정상화 객체 gate: newPod=%s uid=%s topOwner=%s/%s uid=%s\n' "$NEW_POD" "$NEW_POD_UID" "$WORKLOAD_KIND" "$WORKLOAD_NAME" "$WORKLOAD_UID"; else printf '%s\n' '중단: 새 Pod UID·top owner·rollout 확인 실패.' >&2; fi`

`Running`, `Ready`, rollout status 또는 HTTP 200은 application listener·실제 요청·핵심 기능을 단독 보장하지 않는다. cgroup/kernel → kubelet eviction → node pressure → workload identity → Service endpoint → 실제 기능 순으로 역검증하고 OOMKilled·137·restart·새 Warning 재발을 관찰한다. Service 영향은 아래 Service·EndpointSlice 조회와 승인된 실제 요청으로 별도 검증한다.

**Service 영향 선택 및 EndpointSlice 확인 — 실제 Service가 있는 경우에만 아래 한 줄 전체를 복사**

`SERVICE='PASTE_SERVICE_HERE'; SERVICE_READY=false; if [ "$AUTO_READY" != true ]; then printf '%s\n' '중단: AUTO_READY가 아니다.' >&2; elif SERVICE_JSON="$(kubectl get service "$SERVICE" -n "$NS" -o json)" && ENDPOINTS_JSON="$(kubectl get endpointslice -n "$NS" -l "kubernetes.io/service-name=$SERVICE" -o json)"; then SERVICE_READY=true; export SERVICE; jq -r '"Service UID: " + (.metadata.uid // "-") + "\nselector: " + ((.spec.selector // {}) | to_entries | sort_by(.key) | map("\(.key)=\(.value)") | join(",") // "-")' <<<"$SERVICE_JSON"; jq -r 'if (.items|length)==0 then "EndpointSlice: 없음 (정상 endpoint로 해석하지 않음)" else .items[] | "EndpointSlice: \(.metadata.name) endpoints=\((.endpoints // [])|length)" end' <<<"$ENDPOINTS_JSON"; printf 'SERVICE_READY=true service=%s\n' "$SERVICE"; else printf '중단: Service 또는 EndpointSlice 조회 실패 service=%s\n' "$SERVICE" >&2; fi`

**owner-provided bounded function check — 아래 한 줄 전체를 복사**

실제 서비스 요청·핵심 기능의 자동화 정보가 이 런북에 없으므로 `FUNCTION_READY=false`가 안전 기본이다. `Running`, `Ready`, rollout, HTTP 200, Service 또는 EndpointSlice만으로 `FUNCTION_READY`를 열지 않는다. 서비스 owner가 bounded check의 식별자·pass 결과·UTC 시작/종료 시각을 제공하기 전에는 정상화하지 않는다.

`FUNCTION_CHECK_ID='PASTE_OWNER_FUNCTION_CHECK_ID_HERE'; FUNCTION_CHECK_RESULT='PASTE_OWNER_FUNCTION_CHECK_RESULT_HERE'; FUNCTION_CHECK_START='PASTE_OWNER_FUNCTION_CHECK_START_HERE'; FUNCTION_CHECK_END='PASTE_OWNER_FUNCTION_CHECK_END_HERE'; FUNCTION_READY=false; NORMALIZATION_READY=false; if [ "$NEW_POD_READY" != true ] || [ "$ROLLOUT_READY" != true ] || [ "$FUNCTION_CHECK_ID" = "PASTE"_"OWNER_FUNCTION_CHECK_ID_HERE" ] || [ "$FUNCTION_CHECK_RESULT" != pass ]; then printf '%s\n' '중단: 새 Pod·rollout 또는 owner-provided bounded function check gate가 아니다.' >&2; elif ! [[ "$FUNCTION_CHECK_START" =~ ^[0-9]{4}-[0-9]{2}-[0-9]{2}[[:space:]][0-9]{2}:[0-9]{2}:[0-9]{2}[[:space:]]UTC$ ]] || ! [[ "$FUNCTION_CHECK_END" =~ ^[0-9]{4}-[0-9]{2}-[0-9]{2}[[:space:]][0-9]{2}:[0-9]{2}:[0-9]{2}[[:space:]]UTC$ ]] || ! FUNCTION_CHECK_START_EPOCH="$(date -u -d "$FUNCTION_CHECK_START" +%s 2>/dev/null)" || ! FUNCTION_CHECK_END_EPOCH="$(date -u -d "$FUNCTION_CHECK_END" +%s 2>/dev/null)" || (( FUNCTION_CHECK_START_EPOCH >= FUNCTION_CHECK_END_EPOCH )); then printf '%s\n' '중단: owner function check의 bounded UTC window가 유효하지 않다.' >&2; else FUNCTION_READY=true; export FUNCTION_CHECK_ID FUNCTION_CHECK_RESULT FUNCTION_CHECK_START FUNCTION_CHECK_END FUNCTION_READY; printf 'FUNCTION_READY=true check=%s result=pass window=%s..%s\n' "$FUNCTION_CHECK_ID" "$FUNCTION_CHECK_START" "$FUNCTION_CHECK_END"; fi`

`NORMALIZATION_READY=false; if [ "$NEW_POD_READY" = true ] && [ "$ROLLOUT_READY" = true ] && [ "$FUNCTION_READY" = true ]; then NORMALIZATION_READY=true; export NORMALIZATION_READY; printf 'NORMALIZATION_READY=true\n'; else printf '%s\n' '중단: FUNCTION_READY=true 없이는 NORMALIZATION_READY를 열지 않는다.' >&2; fi`

## 증거 보존

최초·새 Pod UID, node와 verified `NODE_HOST` remote hostname/machineID, UTC 시각, top owner kind/name/UID/selector, container reason·ID, kubelet/kernel producer·filter rc, CRI info/inspect rc, cgroup driver·mount·path, resource 변경 승인·rollback·정상화 결과를 보존한다. raw command/args, Secret·token·개인키·개인정보와 전체 로그는 저장하지 않는다.

**OOM reason PromQL 생성 — 아래 한 줄 전체를 복사**

`if [ "$SELECTION_READY" != true ]; then printf '%s\n' '중단: SELECTION_READY가 아니다.' >&2; else QUERY="$(printf 'kube_pod_container_status_last_terminated_reason{namespace="%s",pod="%s",uid="%s",container="%s",reason="OOMKilled"}==1' "$NS" "$POD" "$POD_UID" "$CONTAINER")"; printf '%s\n' "$QUERY" | head -c 1000; printf '\n'; unset QUERY; fi`
