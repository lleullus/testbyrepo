# Xi'an 실제 업로드 산출물 목록

이 폴더는 우리가 검토하는 작업 문서가 아니라, 검수와 승인이 끝난 실제 외부 전달용 산출물만 보관한다.

## 사용 원칙

- 작업 중인 초안, 검토 메모, 개인 판단, 이전본은 이 폴더에 넣지 않는다.
- 산출물은 실제 전달 전에 문서 내용·링크·환경값·보안정보를 최종 확인한다.
- 인증서 본문, Secret, 토큰, 비밀번호, 개인키 등 민감정보는 게시·전달본에 포함하지 않는다.
- 실제값과 기준본이 확인되지 않은 문서는 `미착수`, `검수`, `보류` 상태로 두고 업로드 산출물로 취급하지 않는다.
- 원문과 작업 진행은 기존 `30. 구축 및 전환`, `50. 운영`, `35. 작업 관리`에서 관리한다.

## 업로드 전 확인

- [ ] 최종 문서 분류와 파일명이 `03~07` 전달 구조와 일치함
- [ ] 각 문서의 선행조건·실행절차·완료조건·오류 시 다음 조치가 확인됨
- [ ] Xi'an 환경의 hostname·IP·클러스터명·경로·버전이 기준본과 일치함
- [ ] SCS 설치파일의 기준본·수정본·폐기본 구분이 끝남
- [ ] 문서와 설치파일에 민감정보가 없음
- [ ] 내부 검토용 링크와 외부 전달용 링크를 구분함
- [ ] 실제 사용 확인 결과와 잔여 보류 항목이 반영됨
- [ ] 최종 검증자와 전달 승인자가 확인됨
