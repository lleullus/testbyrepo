# 为用户分配项目角色

> [!summary] 摘要
> 为已受邀加入 Workspace 的成员在 Project 级别分配角色的流程。可从 project-admin、project-operator、project-viewer 中选择 Role，并根据用户的申请信息进行分配。

---

## 邀请 Project 成员

**只有受邀加入 Workspace 的成员才能被指定为 project-admin。** 因此，必须先通过 02. 邀请新成员流程将用户邀请到 Workspace。

### 流程

1. 在左侧导航面板中点击 **Projects**
2. 点击要更改用户权限的 **Project 名称**
3. 点击 **Project Settings > Project Members > Invite**
4. **邀请用户**
   - 根据用户申请表中的 Permission 项（Admin/User）分配 Role（参考下面的 `[!note]` 权限映射）
5. 点击 **OK**

---

## 角色分配标准

| Role | 权限 | 申请表 Permission |
|------|------|-------------------|
| **project-admin** | 项目管理员 — 可创建/修改/删除资源、更改设置、邀请成员 | - |
| **project-operator** | 普通用户 — 可创建/修改/删除资源，不可更改设置 | Admin |
| **project-viewer** | 只读 — 只能查看资源，不可进行更改 | User |

---

> [!note] 权限映射参考
> 申请表中请求 "Admin" 权限的用户分配 `project-operator` 角色，请求 "User" 权限的用户分配 `project-viewer` 角色。
