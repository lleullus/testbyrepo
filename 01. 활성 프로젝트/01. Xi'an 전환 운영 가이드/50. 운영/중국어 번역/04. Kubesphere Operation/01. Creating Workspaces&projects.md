# 创建 Workspace 和 Project

> [!summary] 摘要
> KubeSphere Project 的创建按提交申请 → 确认登录 → 创建 Workspace → 创建 Project 的 4 个步骤进行。根据 DKS 政策，Workspace 和 Project 为 1:1 匹配。

---

## 1. 提交申请

系统管理员接收用户提交的 KubeSphere Project 使用申请。

在 KubeSphere 中，**Project** 表示 Kubernetes 的 **Namespace**。因此，用户必须通过 KubeSphere Project 提交 DKS Namespace 服务使用申请。

### 防火墙规则/端口开通申请（需事先提交）

DKS 运营团队不直接处理防火墙规则/端口开通申请，因此需要另行提前提交申请。

| All     | Harbor               | User IP | 109.156.22.53 | 80, 443 | TCP  | prd-harbor 直接 IP（无 LB，域名 `xa.dcr.dks.samsungds.net`） |

## 2. 确认登录记录

KubeSphere 在批准账户时要求用户的访问记录。因此，在创建 Project 之前，必须确认用户至少访问过一次 KubeSphere Web Dashboard。

### 步骤

1. 使用 Admin 账户登录 KubeSphere Web 控制台（Host Cluster）
2. 在顶部导航栏点击 **Workbench > Users** → 进入用户管理页面
3. 确认目标用户的登录记录
4. 如果没有登录记录，先要求用户访问 KubeSphere Web

---

## 3. 创建 Workspace

Workspace 是 Project 的逻辑单元，用于控制团队内对资源的访问并共享资源。

根据 DKS 政策，**Workspace 和 Project 为 1:1 匹配**。因此，在一个 Workspace 下创建一个 Project。

### 步骤

1. 点击 **Workspace > Create**
2. **Basic Information** 页面：
   - **Name**：`ws-[cluster]-[project]-[suffix]`
     - 所有字符使用小写
     - 示例：`ws-prd-apps-pa01-xas-myapp-prd`
   - **Administrator**：从下拉菜单选择 `admin(DKS)`
   - **Description**：输入申请人信息（AD 账户、部门、申请日期等）
3. **Cluster Settings** 页面：
   - 确认 Project 名称后分配 Cluster
   - `prd` 后缀 → `prd-apps-pa01-xas`（生产环境）
    - `dev` 后缀 → `dev-apps-pa01-xas`（开发环境）

   #### Cluster 信息

   | Namespace 后缀 | 用途        | Cluster 名称          | Ingress 域名                              |
   | -------------- | --------- | ---------------- | ----------------------------------------- |
   | OOO-prd        | Production | prd-apps-pa01-xas | *.xaprdpa01.apps.dks.samsungds.net        |
   | OOO-dev        | Development | dev-apps-pa01-xas | *.xadevpa01.apps.dks.samsungds.net        |

   > [!note] 权限映射参考
   > 如果申请表中申请了“admin”权限，则在 KubeSphere 中授予 `project-operator` 权限。如果申请了“user”权限，则授予 `project-viewer` 权限。

4. 点击 **Create**

---

## 4. 创建 Project

KubeSphere 的 Project 与 Kubernetes 的 Namespace 相同，为资源提供虚拟隔离。

### 步骤

1. 在 Workspace 中点击 **Projects > Create**
2. 输入 Project 名称后点击 **OK**
   - 可以添加别名（Alias）和说明（Description）
3. 在 **Projects** 列表中点击创建的 Project → 确认详细信息
