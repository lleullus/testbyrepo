## 2. 培训流程

### 检查清单

- [ ] 培训开始公告 — 创建聊天室并宣布培训开始 (CP-PaaS / DKS Operation)
- [ ] 培训前系统状态检查 — 通过 DKS 监控进行培训前系统检查 (DKS Operation)
- [ ] 系统检查 — 通过监控确认系统状态，并请求模拟故障 (DKS Operation)
- [ ] 模拟故障 — 使用 OS 命令将 `/` 分区填满至 100% (DS Cloud team)
- [ ] 检测故障 — 通过监控检测事件 (DKS Operation)
- [ ] 报告故障 — 报告故障状态 (DKS Operation)
- [ ] 召集故障响应团队 — 召集相关团队并创建聊天室 (CP Team)
- [ ] 发布当前状态 — 分享故障状态及恢复方法，并通知所有用户 (DKS Operation / CP Team)
- [ ] 检查影响 — 评估应用程序故障的影响程度 (Business units)
- [ ] 分析根本原因 — 分析根本原因（`/` 分区使用率 100%） (DKS Operation)
- [ ] 故障转移操作 — 确认根本原因后采取恢复措施（删除 `/var/log/message`） (DKS Operation)
- [ ] 检查集群状态 — 确认集群节点状态正常，并确认应用程序服务状态 (DKS Operation / Business units)
- [ ] 确认恢复 — 报告故障已恢复 (DKS Operation)
- [ ] 宣布培训结束 — 宣布培训结束 (CP Team)
