> DKS(DS Kubernetes Service) 资源申请、Harbor 权限、Namespace 管理、CLI 使用、外部访问、DevOps、镜像创建、登录等运营方面的常见问题

---

## 1. DKS 资源使用方法

**流程**：申请 DKS Project → 创建安全组并开放防火墙 → 创建 Namespace (Workspace → Project → Resource Quota) → 向用户说明

| 阶段  | 活动                 | 备注                              |
| --- | ------------------ | ------------------------------- |
| 1   | 提交 DKS Project 申请表 | Workspace/Project 1:1 匹配        |
| 2   | 创建安全组            | 设置防火墙规则                       |
| 3   | 申请开放防火墙          | DKS 运营团队不直接处理                  |
| 4   | 设置 Resource Quota  | CPU/Memory/Storage 3 种           |
| 5   | 向用户说明           | 确认防火墙开放，提供 KubeSphere 登录信息 |

---

## 2. 获取 Harbor 权限

**流程**：确认 SG1599 成员资格 → 创建项目 → 设置 10GB 配额 → 添加成员

| 阶段  | 活动                | 备注             |
| --- | ----------------- | -------------- |
| 1   | 确认用户所属 SG1599 | 必须具备安全组成员资格    |
| 2   | 创建 Harbor 项目    | 镜像仓库项目 |
| 3   | 设置 10GB 配额        | 分配存储空间        |
| 4   | 添加成员             | 授予项目访问权限  |

---

## 3. 缩减或删除 Namespace

### 缩减 Namespace 资源
- 调整 Resource Quota 以缩减 Namespace 资源

### 完全删除 Namespace
- 删除 Workspace 时启用删除 Project 选项
- 按 Workspace 单位批量删除 Namespace 和 Project

---

## 4. CLI 使用方法 (kubectl)

**流程**：创建 OS 账户 → 复制 ConfigMap → 应用 `.kube/config`

| 阶段 | 活动 | 备注 |
|------|------|------|
| 1 | 在 Bastion 服务器创建 OS 账户 | 与 AD 账户名相同 |
| 2 | 通过 CyberArk 访问 Bastion | 需要申请权限 |
| 3 | 从 ConfigMap 复制 kubeconfig | `/home/.kube/config` 路径 |
| 4 | 执行 kubectl 命令 | 替代 KubeSphere Web UI |

## 5. 从外部访问应用程序服务

**访问方法**：使用 `[application-name].ingress-cluster` 格式

- 必须在 DNS 服务器中将集群 Ingress 域名注册为 VIP-B IP
- 可通过 VIP-B 域名从外部访问

---

## 6. 使用 DKS DevOps

**现状**：DKS 不支持 Docker 构建及 DevOps 功能

**替代方案**：
- 使用 P-DEP 系统
- 在用户自有系统中构建和部署

---

## 7. 创建镜像及基于 Binary/Source 部署 Pod

**镜像创建**：由用户负责，DKS 运营团队不提供支持

**支持方式**：
- 可以使用已部署在外部/内部网络中的镜像
- 需要使用 Docker、Podman 等自行构建后推送到镜像仓库
- DKS 平台标准 CRI：**ContainerD**（不支持镜像构建，但完全支持镜像的管理及拉取/推送）

---

## 8. 登录错误 ("Wrong username or password")

**原因及解决方案**：

| 原因 | 检查项目 |
|------|----------|
| AD 用户组权限 | 确认 AD 组成员资格 |
| AD 密码 | 需要重置密码 |
| 未加入安全组 | **必须具备 SG1599 安全组成员资格** |
