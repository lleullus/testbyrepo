> [!summary] 摘要
> 使用 Kubespray 向集群添加新 worker 节点的 6 步流程。按预设置、编辑 inventory、执行 scale.yml、确认状态、部署测试、整理 inventory 的顺序进行。

---

## 事前确认

- 确认 VM 访问权限
- 确认 NetApp Storage ACL 设置

---

## 1. Node Pre-setting

完成 Bastion Node 预设置后，通过 Ansible 将设置批量应用到整个集群的所有节点。（※ `-k` 选项在以 root 身份执行时，需要输入各节点 dspaas 用户的 SSH 密码）

| Phase | No. | 项目 | 确认/应用 | 备注 |
|-------|-----|------|-----------|------|
| **1. Node Pre-setting** | 1 | 确认 `dspaas` 用户组 | ☐ | Bastion 手动 |
| | 2 | 设置 Bastion `/etc/hosts` | ☐ | Bastion 手动 |
| | 3 | 确认 SSH key pair | ☐ | Bastion 手动 |
| | 4 | sudoers wheel NOPASSWD | ☐ | Ansible |
| | 5 | 复制 SSH public-key | ☐ | Ansible |
| | 6 | YUM repository (Artifactory) | ☐ | Ansible |
| | 7 | 安装必需软件包 | ☐ | Ansible |
| | 8 | 禁用 SWAP | ☐ | Ansible |
| | 9 | 设置 logrotate compress | ☐ | Ansible |
| | 10 | 部署 SECDS-ROOTCA CA Cert | ☐ | Ansible |
| | 11 | 注释 sysctl.conf ipv6 | ☐ | Ansible |
| | 12 | 确认 VM 资源 | ☐ | Ansible |
| **2. 编辑 Kubespray Inventory** | 1 | 在 hosts.yaml 中添加新节点信息 | ☐ | `inventory/dks/hosts.yaml` |
| **3. 添加节点** | 1 | 执行 scale.yml | ☐ | `--limit xadkswkmp03,xadkswkmp04` |
| **4. 确认节点状态** | 1 | 确认节点 Ready 状态 | ☐ | `kubectl get nodes` |
| | 2 | 确认 containerd/内核版本 | ☐ | `kubectl get nodes -o wide` |
| | 3 | 确认系统 Pod 状态 | ☐ | `kubectl get pod -A -o wide` |
| **5. 部署测试** | 1 | Deployment 测试 | ☐ | checker pod |
| | 2 | PVC & Pod 部署测试 | ☐ | netapp SC |
| **6. 整理 Inventory** | 1 | 整理 Inventory 文件 | ☐ | XiAn_DKS 路径 |

## 3. 添加节点

### 3-1. 执行 scale.yml

使用 `--limit` 选项仅针对新节点执行（可能需要 30 分钟以上）

```bash
[dspaas@xadksbtmp01 20.kubespray-release-2.19 (prod-ds-ksp-member-xas:monitoring)]$ ansible-playbook -e @inventory/dks/dks_vars.yml -i inventory/dks/hosts.yaml --become --become-user=root scale.yml --limit "xadkswkmp03,xadkswkmp04"
```

## 5. 部署测试

### 5-1. Deployment 测试

**创建测试 yaml**：

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: checker-podselctor-test3
  labels:
    app: checker3
spec:
  replicas: 1
  selector:
    matchLabels:
      app: checker3
  template:
    metadata:
      labels:
        app: checker3
    spec:
      containers:
        - image: xa.dcr.dks.samsungds.net/dspaas-testrepo/checker:v5
          name: checker
          command: ['sh', '-c', 'sleep 365d']
      nodeSelector:
        kubernetes.io/os: linux
        kubernetes.io/hostname: xadkswkmp01  # 신규 추가 노드
```

**应用及确认**：

```bash
[dspaas@xadksbtmp01 ~ (prod-ds-ksp-member-xas:monitoring)]$ kc apply -f ./test_deploy.yaml

[dspaas@xadksbtmp01 ~ (prod-ds-ksp-member-xas:monitoring)]$ kc get pods -o wide
```

### 5-2. PVC & Pod 部署测试

**确认 StorageClass**：

```bash
[dspaas@xadksbtmp01 ~ (prod-ds-ksp-member-xas:monitoring)]$ k get sc
NAME                               PROVISIONER               RECLAIMPOLICY   VOLUMEBINDINGMODE   ALLOWVOLUMEEXPANSION   AGE
xa-netapp-nfs-sc                   csi.trident.netapp.io     Delete          Immediate           true                   106d
```

> 在 Xi'an 环境中使用 `xa-netapp-nfs-sc` 或 `powerflexos-xfs-sc-300t-sp04`。

**创建 PVC yaml**：

```yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: test-netapp-deploy
spec:
  accessModes:
    - ReadWriteOnce
  resources:
    requests:
      storage: 16Gi
  storageClassName: xa-netapp-nfs-sc
```

```bash
[dspaas@xadksbtmp01 ~ (prod-ds-ksp-member-xas:monitoring)]$ kc apply -f ./netapp-test.yaml
persistentvolumeclaim/test-netapp-deploy created

[dspaas@xadksbtmp01 ~ (prod-ds-ksp-member-xas:monitoring)]$ kc get pvc
NAME                 STATUS   VOLUME           CAPACITY   ACCESS MODES   STORAGECLASS                       AGE
test-netapp-deploy   Bound    k8s-1dae9701d3   16Gi       RWO            xa-netapp-nfs-sc                  5s
```

**创建 Pod yaml**：

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: test-pvc-app
spec:
  volumes:
    - name: test-pvc
      persistentVolumeClaim:
        claimName: test-netapp-deploy
  containers:
    - image: xa.dcr.dks.samsungds.net/dspaas-testrepo/nginx:latest
      name: test-pvc-app
      volumeMounts:
        - name: test-pvc
          mountPath: "/pvc-test"
  nodeSelector:
    kubernetes.io/os: linux
    kubernetes.io/hostname: xadkswkmp01  # 신규 추가 노드
```

```bash
[dspaas@xadksbtmp01 ~ (prod-ds-ksp-member-xas:monitoring)]$ kc apply -f ./test_pvc_pod.yaml
pod/test-pvc-app created

[dspaas@xadksbtmp01 ~ (prod-ds-ksp-member-xas:monitoring)]$ kc get pods -o wide test-pvc-app
NAME           READY   STATUS    RESTARTS   AGE   IP           NODE             NOMINATED NODE   READINESS GATES
test-pvc-app   1/1     Running   0          15s   192.211.3.5  xadkswkmp01      <none>           <none>
```
