## 2. Training Procedure

### 체크리스트

- [ ] Training start announcement — 채팅룸 생성 및 훈련 시작 공지 (CP-PaaS / DKS Operation)
- [ ] Pre-check system status — DKS 모니터링을 통한 사전 시스템 확인 (DKS Operation)
- [ ] System check — 모니터링을 통한 시스템 상태 확인, 장해 생성 요청 (DKS Operation)
- [ ] Create failure — OS 명령어로 `/` 파티션 100% 사용 (DS Cloud team)
- [ ] Detect the failure — 모니터링으로 이벤트 감지 (DKS Operation)
- [ ] Report failure — 장해 상태 보고 (DKS Operation)
- [ ] Call disability response team — 관련 팀 소집 및 채팅룸 생성 (CP Team)
- [ ] Current status announcement — 장해 상태 및 복구 방법 공유, 모든 사용자 공지 (DKS Operation / CP Team)
- [ ] Check impact — 애플리케이션 장해 영향도 확인 (Business units)
- [ ] Analyze root cause — 근본 원인 분석 (`/` 파티션 100% 사용) (DKS Operation)
- [ ] Failover action — 근본 원인 확인 후 복구 조치 (`/var/log/message` 삭제) (DKS Operation)
- [ ] Check cluster status — 클러스터 노드 상태 정상 확인, 애플리케이션 서비스 상태 확인 (DKS Operation / Business units)
- [ ] Confirm recovered — 장해 복구 보고 (DKS Operation)
- [ ] Announce training finish — 훈련 종료 공지 (CP Team)
