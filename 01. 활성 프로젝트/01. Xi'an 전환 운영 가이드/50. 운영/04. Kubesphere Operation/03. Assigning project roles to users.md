# Assigning project roles to users

> [!summary] 요약
> Workspace에 초대된 멤버에게 Project 레벨에서 역할을 부여하는 절차이다. Role은 project-admin, project-operator, project-viewer 중 선택하며, 사용자의 신청 정보에 따라 할당한다.

---

## Project 멤버 초대

**Workspace에 초대된 멤버만 project-admin으로 지정할 수 있다.** 따라서 먼저 02. Inviting a new member절차를 통해 Workspace에 사용자를 초대해야 한다.

### 절차

1. 왼쪽 네비게이션 패널에서 **Projects** 클릭
2. 사용자 권한을 변경할 **Project 이름 클릭**
3. **Project Settings > Project Members > Invite** 클릭
4. **사용자 초대**
   - 사용자 신청서의 Permission 항목(Admin/User) 기준으로 Role 할당 (아래 `[!note]` 권한 매핑 참고)
5. **OK** 클릭

---

## 역할 부여 기준

| Role | 권한 | 신청서 Permission |
|------|------|-------------------|
| **project-admin** | 프로젝트 관리자 — 리소스 생성/수정/삭제, 설정 변경, 멤버 초대 | - |
| **project-operator** | 일반 사용자 — 리소스 생성/수정/삭제 가능, 설정 변경 불가 | Admin |
| **project-viewer** | 조회 전용 — 리소스만 확인 가능, 변경 불가 | User |

---

> [!note] 권한 매핑 참고
> 신청서에서 "Admin" 권한을 요청한 사용자는 `project-operator`로, "User" 권한을 요청한 사용자는 `project-viewer`로 역할이 부여됩니다.
