# 해외 사업장 관련 DKS URL GSAMS 신청 가이드

## 이 문서의 용도

SCS, SAS 등 해외 사업장의 사용자 또는 서비스 담당자가 **해외 사업장에서 국내 GH/HS의 DKS 서비스 URL로 접속하기 위해 GSAMS 방화벽 신청서를 작성하고 상신하는 방법을 안내하는 문서**다.

## 적용 기준

보안그룹 안내에 따르면 GSAMS의 FQDN 메뉴는 접속 출발지가 국내인 신청으로 한정된다. 따라서 SCS, SAS 등 해외 사업장에서 국내 GH/HS의 DKS 서비스 URL로 접속하려는 경우에는 FQDN 메뉴로 신청하지 않고, **GSAMS 방화벽 신청서**를 아래 형식으로 작성해 상신한다.

## 1. 신청서 작성

GSAMS에서 방화벽 신청서를 열고 다음 값을 입력한다.

| 신청 항목 | 입력 방법 |
|---|---|
| 신청 제목 | 제목에 `[FQDN]` 명시 |
| 목적지 IP | `1.1.1.1` |
| Port | `80/443` |
| 상신 의견 | 실제로 접속해야 하는 DKS 서비스 URL 입력 |

`1.1.1.1`은 이 신청 방식에서 목적지 IP 항목에 입력하도록 안내된 값이다. 실제 접속 대상은 상신 의견에 기재하므로, IP나 `*` URL이 아닌 실제 개별 DKS 서비스 URL을 적는다.

## 2. 작성 예시

`<신청 목적>`과 `<DKS 서비스 URL>`을 실제 신청 내용으로 바꾼다.

```text
신청 제목: [FQDN] <신청 목적>
목적지 IP: 1.1.1.1
Port: 80/443
상신 의견:
접속이 필요한 URL: <DKS 서비스 URL>
```

## 3. 제출 전 확인

- 신청 제목에 `[FQDN]`이 포함되어 있는지 확인한다.
- 목적지 IP가 `1.1.1.1`, Port가 `80/443`으로 입력되어 있는지 확인한다.
- 상신 의견의 URL이 예시가 아니라 실제 접속해야 하는 DKS 서비스 URL인지 확인한다.

이 가이드는 해외 사업장에서 국내 GH/HS의 DKS 서비스 URL로 접속하기 위한 GSAMS 방화벽 신청서 작성 방법만 다룬다. 개별 서비스 URL의 유효성, 신청 승인 여부, 승인 후 통신 확인 방법은 이 가이드에서 정하지 않는다.
