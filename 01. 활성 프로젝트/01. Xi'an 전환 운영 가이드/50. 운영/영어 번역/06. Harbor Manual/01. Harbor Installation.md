> [!summary] Summary
> Harbor installation proceeds in five steps: install Docker 20.10.16 and docker-compose 1.27.4 -> download the offline installer from Nexus -> configure CA cert/koppy and harbor.yml -> run install.sh.

---

## 1. Prerequisites

The Harbor official website provides the offline installer (`harbor-offline-installer-v2.2.2.tgz`).

| Item | Version |
|------|------|
| Docker | 20.10.16 |
| docker-compose | 1.27.4 |

---

## 2. Preparation

### 2-1. Add the Docker yum repo

```bash
sudo cat <<EOF | sudo tee /etc/yum.repos.d/docker.repo
[Artifactory-docker]
async = 1
baseurl = http://repo.samsungds.net/artifactory/yum-docker-remote/8/x86_64/stable/
enabled = 1
gpgcheck = 0
name = Artifactory-docker
EOF
```

### 2-2. Install Docker & docker-compose

```bash
sudo yum install -y docker-ce-20.10.16 --nobest --allowerasing

wget http://nexus.adpaas.cloud.samsungds.net/repository/vulcanus/files/docker-compose -P ~
chmod +x ~/docker-compose
sudo mv ~/docker-compose /usr/local/bin/
```

### 2-3. Check the version and enable the service

```bash
docker -v
docker-compose -v
sudo systemctl enable docker --now
```

---

## 3. Harbor Download

Because this is an air-gapped environment, download the installer through HQ Nexus.

```bash
wget http://nexus.adpaas.cloud.samsungds.net/repository/paas-filerepo/harbor/harbor-offline-installer-v2.2.2.tgz -P ~
tar -zxvf harbor-offline-installer-v2.2.2.tgz
```

---

## 4. Install Configuration

### 4-1. Prepare the CA-signed certificate/key

Prepare a CA-signed certificate and `SECDS-2TROOTCA.crt`.

```bash
sudo mkdir -p /etc/docker/certs.d/xa.dcr.dks.samsungds.net:443
sudo cp xa.dcr.dks.samsungds.net.crt /etc/docker/certs.d/xa.dcr.dks.samsungds.net:443/xa.dcr.dks.samsungds.net.crt
sudo cp xa.dcr.dks.samsungds.net.key /etc/docker/certs.d/xa.dcr.dks.samsungds.net:443/xa.dcr.dks.samsungds.net.key
```

### 4-2. Update the CA certificate

```bash
wget http://nexus.adpaas.cloud.samsungds.net/repository/paas-filerepo/SECDS-2TROOTCA.crt -P /etc/pki/ca-trust/source/anchors
update-ca-trust extract
```

### 4-3. Edit harbor.yml

```bash
cd ~/harbor
cp harbor.yml.tmpl harbor.yml
vi ~/harbor/harbor.yml
```

### 4-4. Key harbor.yml settings

| Setting | Value | Notes |
|-----------|------|------|
| `hostname` | `xa.dcr.dks.samsungds.net` | Harbor domain (localhost/127.0.0.1 is prohibited) |
| `http.port` | `80` | Redirects to HTTPS |
| `https.port` | `443` | HTTPS port |
| `certificate` | `/etc/docker/certs.d/xa.dcr.dks.samsungds.net:443/xa.dcr.dks.samsungds.net.crt` | Certificate path |
| `private_key` | `/etc/docker/certs.d/xa.dcr.dks.samsungds.net:443/xa.dcr.dks.samsungds.net.key` | Key path |
| `data_volume` | `/harbordata` | Data storage path |

---

## 5. Install

Run the following command as the root account to install Harbor.

```bash
/app/dspaas/harbor/install.sh --with-chartmuseum --with-trivy
```

| Option | Description |
|------|------|
| `--with-chartmuseum` | Chartmuseum integration (Helm chart repository) |
| `--with-trivy` | Trivy integration (image vulnerability scanning) |
