> [!summary] Summary
> Harbor manages users by project and distinguishes permissions through two roles: ProjectAdmin and Developer.

---

## 1. Project Member Roles

Harbor adds users to a project and manages access permissions by assigning one of the following roles.

### Role Comparison

| Role | Read | Write | Member Management | Vulnerability Scanning | Description |
|------|------|------|-----------|-------------|------|
| **ProjectAdmin** | O | O | O | O | Automatically assigned when the project is created |
| **Developer** | O | O | X | O | Member role assigned manually |

### Recommended Role Assignment

| Position | Recommended Role |
|-----------|-----------|
| Project administrator | ProjectAdmin |
| General member | Developer |

---

## 2. Adding Members

### 2-1. Log in to Harbor

Log in to the Harbor interface.

### 2-2. Select a Project

1. Go to the **Projects** menu.
2. Select the project to which you want to add a member.

### 2-3. Add a User

1. Select the **Members** tab.
2. Click **+User**.
3. Enter the following information:

| Item | Input Format | Example |
|------|-----------|------|
| Name | `<user-name>` | `dj2.kim` |
| Role | **ProjectAdmin** or **Developer** | `ProjectAdmin` |

### Example

| User Name | Role |
|-------------|------|
| dj2.kim | ProjectAdmin |
| dshl04829.id | Developer |
| dsml14311.id | Developer |
| dsml14312.id | Developer |
| dsml14313.id | Developer |

---

## 3. Removing Members or Changing Roles

### 3-1. Remove a Member

1. Go to the project's **Members** tab.
2. Select the member to remove (multiple selections are allowed).
3. Click **Action**.
4. Select **Remove**.

### 3-2. Change a Role

1. Go to the project's **Members** tab.
2. Select the member whose role you want to change.
3. Click **Action**.
4. Select the new role (ProjectAdmin <-> Developer).
