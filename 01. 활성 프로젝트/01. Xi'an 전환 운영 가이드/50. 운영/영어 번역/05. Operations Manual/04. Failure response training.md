## 2. Training Procedure

### Checklist

- [ ] Training start announcement — Create a chat room and announce the start of training (CP-PaaS / DKS Operation)
- [ ] Pre-check system status — Perform a pre-training system check through DKS monitoring (DKS Operation)
- [ ] System check — Check system status through monitoring and request that a simulated failure be induced (DKS Operation)
- [ ] Create failure — Use OS commands to fill the `/` partition to 100% capacity (DS Cloud team)
- [ ] Detect the failure — Detect the event through monitoring (DKS Operation)
- [ ] Report failure — Report the failure status (DKS Operation)
- [ ] Call the incident response team — Convene the relevant teams and create a chat room (CP Team)
- [ ] Current status announcement — Share the failure status and recovery method, and notify all users (DKS Operation / CP Team)
- [ ] Check impact — Check the impact of the failure on applications (Business units)
- [ ] Analyze root cause — Analyze the root cause (`/` partition at 100% usage) (DKS Operation)
- [ ] Failover action — Take recovery action after confirming the root cause (delete `/var/log/message`) (DKS Operation)
- [ ] Check cluster status — Verify that the cluster node status is normal and check the application service status (DKS Operation / Business units)
- [ ] Confirm recovery — Report that the failure has been resolved (DKS Operation)
- [ ] Announce training finish — Announce the end of training (CP Team)
