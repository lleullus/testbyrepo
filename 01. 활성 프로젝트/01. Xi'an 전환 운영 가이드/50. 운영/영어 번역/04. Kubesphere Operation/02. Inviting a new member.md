# Inviting a new member

> [!summary] Summary
> This procedure invites a new user to a Workspace and grants the viewer role. Members can be added from Workspace Settings, and existing members can also have their roles changed or be removed from the Workspace.

---

## Invite a Workspace Member

KubeSphere requires the user's access history when approving a user account. Before creating the Project, invite the user to the Workspace.

### Procedure

1. Click **Workbench > Workspaces**
2. Select the **Workspace** to which the member will be added
3. Click **Workspace Settings > Workspace Members > Invite Member**
4. **Invite the user**
   - Role: Assign the **viewer** role
   - The viewer role allows users to view all resources within the Workspace
5. Click **OK** and confirm the newly invited member in the Workspace Members list

### Manage Existing Members

You can change an existing member's role or remove the member from the Workspace.

- **Change role**: Select the target member in Workspace Members → Edit
- **Remove**: Select the target member in Workspace Members → Remove

---

> [!note] Permission Mapping Reference
> A user who requests the "admin" permission in the request form is later assigned `project-operator` at the Project level, while a user who requests the "user" permission is assigned `project-viewer`. Workspace invitations initially use `viewer`.

---

## Role: viewer

| Item | Description |
|------|------|
| Permissions | View all resources within the Workspace |
| Restrictions | Cannot create, modify, or delete resources |
| Use | User onboarding and access history verification |
