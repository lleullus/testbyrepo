> [!summary] 요약
> Harbor는 프로젝트 단위로 사용자를 관리하며, ProjectAdmin과 Developer 두 가지 역할로 권한을 구분한다.

---

## 1. 프로젝트 멤버 역할

Harbor는 프로젝트에 사용자를 포함하고 다음 역할 중 하나를 할당하여 접근 권한을 관리한다.

### 역할 비교

| 역할 | 읽기 | 쓰기 | 멤버 관리 | 취약점 스캔 | 설명 |
|------|------|------|-----------|-------------|------|
| **ProjectAdmin** | O | O | O | O | 프로젝트 생성 시 자동 할당 |
| **Developer** | O | O | X | O | 멤버 역할 수동 할당 |

### 권장 역할 배정

| 직책 | 권장 역할 |
|------|-----------|
| 프로젝트 관리자 | ProjectAdmin |
| 일반 멤버 | Developer |

---

## 2. 멤버 추가

### 2-1. Harbor 로그인

Harbor 인터페이스에 로그인한다.

### 2-2. 프로젝트 선택

1. **Projects** 메뉴로 이동
2. 멤버를 추가할 프로젝트 선택

### 2-3. 사용자 추가

1. **Members** 탭 선택
2. **+User** 클릭
3. 다음 정보 입력:

| 항목 | 입력 형식 | 예시 |
|------|-----------|------|
| Name | `<user-name>` | `dj2.kim` |
| Role | **ProjectAdmin** 또는 **Developer** | `ProjectAdmin` |

### 예시

| 사용자 이름 | 역할 |
|-------------|------|
| dj2.kim | ProjectAdmin |
| dshl04829.id | Developer |
| dsml14311.id | Developer |
| dsml14312.id | Developer |
| dsml14313.id | Developer |

---

## 3. 멤버 제거 또는 역할 변경

### 3-1. 멤버 제거

1. 프로젝트의 **Members** 탭으로 이동
2. 제거할 멤버 선택 (다중 선택 가능)
3. **Action** 클릭
4. **Remove** 선택

### 3-2. 역할 변경

1. 프로젝트의 **Members** 탭으로 이동
2. 역할 변경할 멤버 선택
3. **Action** 클릭
4. 새로운 역할 선택 (ProjectAdmin ↔ Developer)
