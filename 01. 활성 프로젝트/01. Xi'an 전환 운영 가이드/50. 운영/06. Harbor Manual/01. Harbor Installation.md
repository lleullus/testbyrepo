> [!summary] 요약
> Harbor 설치: Docker 20.10.16 & docker-compose 1.27.4 설치 → Nexus에서 offline installer 다운로드 → CA cert/koppy 및 harbor.yml 설정 → install.sh 실행의 5단계로 진행된다.

---

## 1. Prerequisites

Harbor 공식 사이트에서 offline installer(`harbor-offline-installer-v2.2.2.tgz`)를 제공한다.

| 항목 | 버전 |
|------|------|
| Docker | 20.10.16 |
| docker-compose | 1.27.4 |

---

## 2. Preparation

### 2-1. Docker yum repo 추가

```bash
sudo cat <<EOF | sudo tee /etc/yum.repos.d/docker.repo
[Artifactory-docker]
async = 1
baseurl = http://repo.samsungds.net/artifactory/yum-docker-remote/8/x86_64/stable/
enabled = 1
gpgcheck = 0
name = Artifactory-docker
EOF
```

### 2-2. Docker & docker-compose 설치

```bash
sudo yum install -y docker-ce-20.10.16 --nobest --allowerasing

wget http://nexus.adpaas.cloud.samsungds.net/repository/vulcanus/files/docker-compose -P ~
chmod +x ~/docker-compose
sudo mv ~/docker-compose /usr/local/bin/
```

### 2-3. 버전 확인 및 서비스 활성화

```bash
docker -v
docker-compose -v
sudo systemctl enable docker --now
```

---

## 3. Harbor Download

에어갭 환경이므로 HQ Nexus를 통해 다운로드한다.

```bash
wget http://nexus.adpaas.cloud.samsungds.net/repository/paas-filerepo/harbor/harbor-offline-installer-v2.2.2.tgz -P ~
tar -zxvf harbor-offline-installer-v2.2.2.tgz
```

---

## 4. Install Configuration

### 4-1. CA 서명 인증서/키 준비

CA 서명 인증서와 `SECDS-2TROOTCA.crt`를 준비한다.

```bash
sudo mkdir -p /etc/docker/certs.d/xa.dcr.dks.samsungds.net:443
sudo cp xa.dcr.dks.samsungds.net.crt /etc/docker/certs.d/xa.dcr.dks.samsungds.net:443/xa.dcr.dks.samsungds.net.crt
sudo cp xa.dcr.dks.samsungds.net.key /etc/docker/certs.d/xa.dcr.dks.samsungds.net:443/xa.dcr.dks.samsungds.net.key
```

### 4-2. CA 인증서 업데이트

```bash
wget http://nexus.adpaas.cloud.samsungds.net/repository/paas-filerepo/SECDS-2TROOTCA.crt -P /etc/pki/ca-trust/source/anchors
update-ca-trust extract
```

### 4-3. harbor.yml 수정

```bash
cd ~/harbor
cp harbor.yml.tmpl harbor.yml
vi ~/harbor/harbor.yml
```

### 4-4. harbor.yml 주요 설정

| 설정 항목 | 값 | 비고 |
|-----------|------|------|
| `hostname` | `xa.dcr.dks.samsungds.net` | Harbor 도메인 (localhost/127.0.0.1 금지) |
| `http.port` | `80` | HTTPS로 리다이렉트 |
| `https.port` | `443` | HTTPS 포트 |
| `certificate` | `/etc/docker/certs.d/xa.dcr.dks.samsungds.net:443/xa.dcr.dks.samsungds.net.crt` | 인증서 경로 |
| `private_key` | `/etc/docker/certs.d/xa.dcr.dks.samsungds.net:443/xa.dcr.dks.samsungds.net.key` | 키 경로 |
| `data_volume` | `/harbordata` | 데이터 저장소 경로 |

---

## 5. Install

root 계정으로 다음 명령어를 실행하여 Harbor를 설치한다.

```bash
/app/dspaas/harbor/install.sh --with-chartmuseum --with-trivy
```

| 옵션 | 설명 |
|------|------|
| `--with-chartmuseum` | Chartmuseum 통합 (Helm 차트 저장소) |
| `--with-trivy` | Trivy 통합 (이미지 취약점 스캔) |
