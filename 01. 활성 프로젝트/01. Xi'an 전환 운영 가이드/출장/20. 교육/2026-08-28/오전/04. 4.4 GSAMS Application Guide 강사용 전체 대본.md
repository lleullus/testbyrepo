# 4.4 GSAMS Application Guide 강사용 전체 대본

> [!important] 사용 방법
> 이 대본은 **SCS·SAS 등 해외 사업장에서 국내 GH·HS의 DKS 서비스 URL에 접속하기 위해 GSAMS 신청서를 처음 작성하는 사용자**를 대상으로 한다. FQDN 메뉴와 방화벽 신청서를 혼동하지 않게 출발지부터 확인하고, 네 개 입력값을 실제 신청 예시로 연결한다.

## 0. 강사가 머릿속에 들고 갈 설명 공식

```text
어디에서 어디로 접속하는지 먼저 확인한다
→ 이 경우 사용할 신청 방식을 정한다
→ 각 입력값의 목적을 설명한다
→ 실제 URL을 넣은 신청 형태로 연결한다
→ 제출 전 네 항목을 다시 확인한다
```

## 0-1. 오늘 전체 한 줄

```text
해외 사업장에서 출발한다
→ 국내 GH·HS DKS URL에 접속하려 한다
→ GSAMS FQDN 메뉴를 사용하지 않는다
→ GSAMS 방화벽 신청서를 작성한다
→ 제목 [FQDN]
→ 목적지 IP 1.1.1.1
→ Port 80/443
→ 상신 의견에 실제 개별 DKS URL
```

---

# 1. 시작 — URL부터 입력하지 않고 출발지를 확인한다

> 오늘은 해외 사업장에서 국내 DKS 서비스 URL에 접속하기 위한 GSAMS 신청 방법을 보겠습니다.
>
> 먼저 사용자가 어디에 있고 접속 대상이 어디인지 확인해야 합니다.
>
> 사용자는 SCS, SAS 같은 해외 사업장에 있고, 접속 대상은 국내 GH 또는 HS의 DKS 서비스 URL입니다.
>
> **하지만**, GSAMS에서 FQDN이라는 이름의 메뉴가 보인다고 이 메뉴를 바로 사용하면 안 됩니다.

## 1.1 FQDN 메뉴를 사용하지 않는 이유

> 보안그룹 안내에 따르면 GSAMS의 FQDN 메뉴는 접속 출발지가 국내인 신청으로 한정됩니다.
>
> 이번 경우의 출발지는 해외 사업장입니다.
>
> **그래서**, FQDN 메뉴가 아니라 **GSAMS 방화벽 신청서**를 작성해 상신합니다.

```text
출발지 국내
→ GSAMS FQDN 메뉴 대상

출발지 해외 사업장
→ GSAMS 방화벽 신청서 작성
```

> 오늘 다루는 것은 두 번째 경우뿐입니다.

---

# 2. 신청서에는 네 가지 핵심값을 입력한다

> 방화벽 신청서를 열면 제목, 목적지 IP, Port와 상신 의견을 입력합니다.

| 신청 항목 | 입력 방법 |
|---|---|
| 신청 제목 | 제목에 `[FQDN]` 명시 |
| 목적지 IP | `1.1.1.1` |
| Port | `80/443` |
| 상신 의견 | 실제로 접속해야 하는 DKS 서비스 URL |

## 2.1 신청 제목

> 제목에는 `[FQDN]`을 명시합니다.
>
> 그 뒤에 실제 신청 목적을 적습니다.

```text
[FQDN] <신청 목적>
```

## 2.2 목적지 IP

> 목적지 IP에는 `1.1.1.1`을 입력합니다.
>
> 이 값은 해외 사업장 신청 방식에서 목적지 IP 항목에 입력하도록 안내된 값입니다.
>
> **하지만**, 이것이 실제 접속할 DKS 서비스의 주소라는 뜻은 아닙니다. 실제 접속 대상은 상신 의견에 URL로 적습니다.

## 2.3 Port

> Port에는 `80/443`을 입력합니다.

```text
80/443
```

## 2.4 상신 의견

> 상신 의견에는 실제로 접속해야 하는 개별 DKS 서비스 URL을 적습니다.
>
> 예시 Placeholder를 그대로 제출하지 않습니다.
>
> IP 주소나 `*` Wildcard URL도 적지 않습니다.

```text
접속이 필요한 URL: <실제 DKS 서비스 URL>
```

---

# 3. 신청서 한 장으로 연결한다

> 이제 네 항목을 실제 신청서 형태로 연결하겠습니다.
>
> `<신청 목적>`과 `<DKS 서비스 URL>`은 자신의 실제 신청 내용으로 바꿉니다.

```text
신청 제목: [FQDN] <신청 목적>
목적지 IP: 1.1.1.1
Port: 80/443
상신 의견:
접속이 필요한 URL: <DKS 서비스 URL>
```

> 이 예시에서 고정해 사용할 값은 제목의 `[FQDN]`, 목적지 IP `1.1.1.1`, Port `80/443`입니다.
>
> 신청 목적과 DKS 서비스 URL은 실제 요청마다 달라집니다.

```text
고정 형식
→ [FQDN]
→ 1.1.1.1
→ 80/443

실제 신청값
→ 신청 목적
→ 개별 DKS 서비스 URL
```

---

# 4. 제출 전에 잘못 적기 쉬운 부분을 확인한다

## 4.1 제목에서 [FQDN]을 빼지 않는다

> 신청 제목에 `[FQDN]`이 포함돼 있는지 확인합니다.

## 4.2 목적지 IP를 실제 서비스 IP로 바꾸지 않는다

> 이 신청 형식의 목적지 IP는 `1.1.1.1`입니다.
>
> 실제 접속 대상은 상신 의견에 URL로 적습니다.

## 4.3 Port를 확인한다

> Port가 `80/443`으로 입력돼 있는지 확인합니다.

## 4.4 실제 개별 URL을 적는다

> 상신 의견의 URL이 예시 Placeholder가 아닌지 확인합니다.
>
> IP나 `*` Pattern이 아니라 실제 접속해야 하는 개별 DKS 서비스 URL인지 확인합니다.

```text
제목 [FQDN]
+
목적지 IP 1.1.1.1
+
Port 80/443
+
상신 의견의 실제 개별 DKS URL
```

---

# 5. 이 가이드가 정하지 않는 범위를 구분한다

> 이 절차는 해외 사업장에서 국내 GH·HS의 DKS 서비스 URL로 접속하기 위한 GSAMS 방화벽 신청서 작성 방법만 다룹니다.
>
> 개별 서비스 URL이 실제로 유효한지는 이 가이드에서 확정하지 않습니다.
>
> 신청이 승인될지도 이 가이드에서 보장하지 않습니다.
>
> 승인 후 어떤 방법으로 통신을 확인할지도 이 가이드에서 정하지 않습니다.
>
> **따라서**, 여기서 완료할 작업은 안내된 형식으로 신청서를 정확히 작성하고 제출 전 입력값을 확인하는 것입니다.

---

# 6. 마무리 — 한 문장으로 다시 말한다

> 해외 사업장에서 국내 GH·HS DKS URL에 접속하려면 GSAMS FQDN 메뉴가 아니라 방화벽 신청서를 사용합니다.
>
> 제목에는 `[FQDN]`, 목적지 IP에는 `1.1.1.1`, Port에는 `80/443`을 입력합니다.
>
> 실제 접속 대상은 상신 의견에 개별 DKS 서비스 URL로 적습니다.
