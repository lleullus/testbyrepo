# KubeSphere Operation 운영자 실습 가이드 안내

> [!important] 이 폴더의 목적
> `50. 운영/04. Kubesphere Operation`의 원본 1.1~1.7 가이드는 그대로 보존한다. 이 폴더는 2026-08-26 Xi'an 현지 **운영자 6명 실습**에 바로 사용할 수 있도록 원본 절차를 최대한 유지하면서, 실제 실습 순서·완료 확인·현재 Xi'an 환경에서 필요한 보완사항만 반영한 교육용 사본이다.

## 1. 공통 진행 방식

모든 직접 실습 Step은 아래 순서로 진행한다.

```text
강사 설명·시연
→ 교육생 6명 동일 작업
→ 6/6 완료 확인
→ 다음 Step
```

- 6명은 서로 다른 교육용 Workspace/Project 이름을 사용한다.
- 6명에게 서로 다른 난이도나 Role을 배정하지 않는다.
- 실제 운영자가 반복 수행하는 Workspace/Project/Member/Role/Quota/kubectl 작업은 직접 실습한다.
- RBAC 권한표 자체는 설명으로 끝낸다.
- CA ConfigMap과 `ks-apiserver`는 현재 상태와 적용 구조를 조회·설명한다.

## 3. 이번 실습 공통 기준

- **실습 대상 Cluster**: `dev-apps-pa01-xas`
- Workspace/Project는 6명 모두 위 DEV Member에 생성한다.
- CPU·Memory·Storage Quota는 교육 시작 전에 하나의 실습값을 정하고 6명 모두 같은 값을 사용한다.
- StorageClass는 `scs-netapp-qtree-nfs-sc-delete`를 사용한다. 실습 시작 전에 `kubectl get sc`로 현재 상태만 한 번 확인한다.
- kubectl의 API Server는 `dev-apps-pa01-xas` VIP-A인 `109.156.25.72:6443`을 사용한다.
- 교육용 Workspace/Project와 실습 중 생성한 설정은 교육 종료 후 정리한다.

### 계정

- 교육생 AD 계정 6개
- Workspace 생성 등 운영 실습에 필요한 권한이 준비된 교육생별 운영 계정
- 각 교육생 VM/Bastion 접속 확인
- 04 Storage ResourceQuota와 06 사용자 kubeconfig ConfigMap 조회에 사용할 기존 운영 context가 각 교육생 환경에 준비되어 있고 `dev-apps-pa01-xas`를 가리키는지 확인
- 해당 운영 context에서 자기 교육용 Namespace의 ResourceQuota 생성·조회 및 `kubesphere-controls-system` ConfigMap 조회가 가능한지 확인
- kubectl 실습에 사용할 사용자별 kubeconfig 존재 여부 확인

### Naming Rule

6명 모두 **자기 AD 계정**을 기준으로 이름을 만든다. 교육용 날짜·별도 번호·`ksop` 접두사는 넣지 않는다.

AD 계정은 소문자로 사용하고 `.`은 `-`로 바꾼다.

```text
예: abcd1234.id

Project:   abcd1234-id-dev
Workspace: ws-dev-apps-pa01-xas-abcd1234-id-dev
```

각 교육생은 자기 실제 AD 계정으로 위 규칙을 적용한다. 실습 시작 전에 6명 이름이 서로 중복되지 않는지만 확인하고 수업 중 임의 변경하지 않는다.

## 4. 실습 종료 기준

교육생 6명 모두 다음을 완료하면 KubeSphere Operation 실습을 완료한 것으로 본다.

- Workspace 생성
- Project 생성 및 Namespace 확인
- Workspace Member 초대
- Project Member/Role 지정 (`project-operator`)
- Workspace/Project CPU·Memory Quota 설정
- Storage ResourceQuota 설정 및 조회
- 사용자별 kubectl context와 Project 접근 확인
- RBAC 계층 설명 이해
- CA ConfigMap과 `ks-apiserver` Mount 관계 확인
- 교육용 객체와 실습 중 생성한 설정 정리
