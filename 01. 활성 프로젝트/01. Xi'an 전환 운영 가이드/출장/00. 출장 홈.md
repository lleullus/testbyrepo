## 1. 이번 출장의 목적

```text
Kubernetes 사전 지식이 없는 교육생에게
Kubernetes 기초와 DKS 구조를 먼저 설명
→ 현재 운영 Manual을 사용자·운영자 관점에서 기술 전수
→ 신규 Member Cluster를 실제 환경에서 처음부터 구축
→ Storage·Monitoring·KubeSphere까지 검증
→ 이미 구축 완료된 기존 Host Cluster에 Join
→ Multi-Cluster 정상 상태 확인
→ 문서·증적·잔여 항목을 인계하고 철수
```

### 이번 신규 구축 대상

- 신규 Member Cluster
- 신규 Member VM·Bastion·Node Pre-setting
- Kubespray 기반 Kubernetes
- Storage Component
- Member custom Monitoring
- Member KubeSphere
- 기존 Host Join과 Multi-Cluster 연결

### 이번 신규 구축 대상이 아닌 것

- 기존 Xi'an Host Cluster 재설치
- 기존 Host KubeSphere 재구축
- 기존 PRD·DEV Member 재설치
- 9/4 신규 기술 작업

- VIP-A·VIP-B
- Pod·Service CIDR
- Domain
- context
- StorageClass
- Trident Backend·SVM·Data LIF
- Registry·Repository·Tag
- ETCD Endpoint
- Monitoring External Label
- Ingress Host
- 사용자 계정·Project·Quota
- Secret·Certificate Key 이름
- 동적 Pod·PV·Endpoint

## 11. 성공 상태의 의미를 확대하지 않는다

```text
Playbook Success ≠ Kubernetes Functional Success
Node Ready ≠ DKS Complete
PVC Bound ≠ Pod Mount
Pod Running ≠ Service HTTP Success
Secret Exists ≠ Workload Uses Secret
Prometheus Running ≠ Target UP
Grafana Opens ≠ Datasource Works
KubeSphere Opens ≠ Member Install Complete
Cluster Listed on Host ≠ Multi-Cluster Complete
```

각 일자 문서의 완료 기준과 Gate를 사용한다.

## 12. 민감정보

현재 출장 문서·교육자료·증적에 원문을 남기지 않는다.

- Password
- Token
- JWT
- kubeconfig 인증 데이터
- Private Key
- Secret Data
- ServiceAccount Token
- Join Credential

필요한 경우 이름·Type·Key 존재·Masking된 상태·승인된 관리 방식만 기록한다.
