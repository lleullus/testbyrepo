## Monitoring / DKS Prometheus Stack

Member Cluster의 DKS custom Prometheus stack은 KubeSphere 설치 전에 `monitoring` Namespace에 선행 배포합니다. 상세 절차는 [[30. 구축 및 전환/Member 클러스터/개요|05.2 Member Cluster 설치]]의 `5-2-1-1~5` 문서를 따릅니다.

| 항목 | dev-apps-pa01-xas 기준값 |
|------|------------------------|
| Monitoring Namespace | `monitoring` |
| Prometheus CR | `k8s` |
| Alertmanager CR | `main` |
| Prometheus retention | 목표 `30d` / 현장 확인 시 `14d`였음 → `30d`로 맞출 것 |
| Prometheus externalLabels.cluster | `dev-apps-pa01-xas` |
| Prometheus externalLabels.stage | 목표 `Dev` / 현장 확인 시 `dev`였음 |
| Prometheus/Alertmanager replicas | `3` (Infra 3대 기준) |
| Monitoring nodeSelector | `node-type=infra`, `kubernetes.io/os=linux` |
| Custom stack image base | `xa.dcr.dks.samsungds.net/dspaas-v1.22.10-a/prometheus/...` |
| Grafana PVC | `grafana-pvc`, `10Gi` Bound (`scs-netapp-qtree-nfs-sc-delete`) |
| Grafana datasource | `http://prometheus-k8s.monitoring.svc:9090` (`kubesphere-monitoring-system` 금지) |
| Prometheus Ingress | `prometheus.xadevpa01.apps.dks.samsungds.net` |
| Grafana Ingress | `grafana.xadevpa01.apps.dks.samsungds.net` |
| Alertmanager Ingress | `alertmanager.xadevpa01.apps.dks.samsungds.net` |
| etcd-certs Secret 키(현장) | `ca.pem`, `node-xadksmamd01.pem`, `node-xadksmamd01-key.pem` |
