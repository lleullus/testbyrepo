# Xi'an 전환 후속 작업 목록

설치 문서, 영문 매뉴얼, 설치 파일, 실제 사용성을 하나의 작업 흐름으로 추적한다. 문서 내용 자체는 각 원문 노트에서 관리하고, 이 문서에서는 작업 상태와 검수 결과만 관리한다.

## 작업 순서

1. 설치 문서의 기준 순서와 파일 구성을 확정한다.
2. 설치 파일을 검수하면서 설치 문서의 사실관계를 대조한다.
3. 운영·사용자 매뉴얼을 영문화하고 링크와 용어를 정리한다.
4. 실제 사용 시나리오로 설치 문서와 매뉴얼을 실행해 수정 항목을 확정한다.

## 상태 기준

- `미착수`: 아직 검토하지 않음
- `진행`: 작업 중
- `검수`: 결과 확인 또는 사용자 검증 대기
- `완료`: 결과와 증적이 확인됨
- `보류`: 범위·자료·결정이 없어 진행을 멈춤

## 3. 설치파일 검수

목표: SCS에서 제공한 설치 파일을 기준 문서와 대조해 실제 설치에 사용할 수 있는 기준본을 확정한다.

- [ ] SCS 설치 파일 전체 목록과 버전·수정일 확보 — 상태: `미착수`
- [ ] 파일별 용도와 적용 단계(`03. Cluster Setup`) 매핑
- [ ] 호스트명, IP, 클러스터명, 네임스페이스, 경로의 Xi'an 값 검수
- [ ] Kubernetes·Kubespray·KubeSphere·스토리지·Harbor 버전 및 호환성 검수
- [ ] 인증서·ConfigMap·Secret·StorageClass·레지스트리 관련 값 검수
- [ ] 실행 권한, 선행 파일, 환경변수, 외부 의존성 및 재실행 가능성 검수
- [ ] 민감정보 포함 여부 확인 및 공유용 파일에서 비밀값 제거
- [ ] 기준본·수정본·폐기본을 구분하고 최종 설치 파일 묶음 확정

검수 게이트: 파일만 전달받은 담당자가 대상 환경, 실행 순서, 필요한 사전조건과 예상 결과를 확인할 수 있어야 한다.

## 4. 실제 사용 확인

목표: 문서와 설치 파일이 실제 담당자의 작업 흐름에서 막힘없이 사용되는지 확인한다. 상세 범위와 참여자는 첫 실행 전에 결정한다.

- [ ] 실제 사용 확인 대상 결정: 설치 담당자, 운영 담당자, 사용자 중 선정
- [ ] 확인 방식 결정: 전체 리허설, 단계별 워크스루, 실제 운영 시나리오 중 선정
- [ ] 최소 시나리오 정의: 신규 설치, Host·Member 구성, 스토리지 확인, KubeSphere 사용자·프로젝트 운영, Harbor 프로젝트·사용자 운영
- [ ] 문서와 설치 파일만 제공한 상태에서 실행해 막힘·누락·오해 지점 기록
- [ ] 오류·재현조건·수정 대상 문서·필요 증적을 이슈로 등록
- [ ] 수정본으로 재실행하고 설치·운영·사용자 관점의 확인 결과 기록
- [ ] 최종 사용 가능 여부와 잔여 보류 항목 결정

검수 게이트: 실제 수행자가 별도 구두 설명 없이 핵심 시나리오를 완료하고, 실패 시 다음 조치를 찾을 수 있어야 한다.
