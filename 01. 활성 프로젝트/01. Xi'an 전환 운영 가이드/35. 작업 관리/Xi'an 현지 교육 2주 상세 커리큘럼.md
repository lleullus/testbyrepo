# Xi'an 현지 교육 2주 상세 커리큘럼

## 1. 과정 정의

| 항목 | 내용 |
|---|---|
| 전체 기간 | **P0 환경 준비 1일 + 기술 교육 10일**, 총 11일 |
| 일일 시간 | 통역 포함 6시간, `09:00~16:00` |
| 수강생 | 2명. 주 수강생은 실제 운영·판정·teach-back 담당 CKA·CKS 보유자, 보조 수강생은 증적 감사·교차검증·인시던트 타임라인 담당 |
| 목표 | Xi'an 실제값과 Multi-Cluster·외부 의존성 경계를 기준으로 구축 인수, 반복 운영, 사용자 요청, Daily Monitoring과 장애 초동을 교육생이 주도한다. |
| 과정 완료 의미 | 문서를 근거로 반복 관리·운영과 교대 인계를 주도할 준비를 확인한다. Full Installation Hands-on과 장기 실운영 보증은 별도 과정이다. |

일반 Kubernetes 개론, 시험 대비형 보안 설명, Kubespray 일반 설치 원리는 제외한다. Xi'an의 `VIP-A/B`, Host·Member, Project·Role·Quota, Harbor, Storage·ONTAP, Monitoring, 실제값 대조와 첫 단절 판단에 필요한 경우에만 해당 개념을 재호출한다.

### P0 - 환경 준비일

P0의 세부 접속·실제값·실습 게이트 절차와 6개 승인 조건은 [[Xi'an 현지 교육 1주 상세 커리큘럼#3. P0 - 환경 준비일|1주 상세 커리큘럼 P0]]와 동일하게 적용한다. P0는 기술 교육과 별도 1일이며, D1으로 접근 설정을 이월하지 않는다.

| 시간 | 핵심 작업 | 강사·주 수강생·보조 수강생 역할 | 완료 증거 |
|---|---|---|---|
| 09:00~10:30 | 역할, 계정, MFA, 방화벽, Host·PRD·DEV·Harbor·Monitoring UI 접속 | 강사는 경로 제시, 주 수강생은 운영 계정으로 접속, 보조 수강생은 권한·결과 기록 | UI 접근 확인표 |
| 10:45~12:00 | Bastion·조회용 kubectl, context·Namespace 확인 | 주 수강생은 조회 실행, 보조 수강생은 대상·출처 교차검증 | CLI 접근 확인표 |
| 13:00~14:20 | Domain, VIP-A/B, StorageClass, Monitoring URL, 정상 Workload 실제값 확인 | 강사는 카탈로그 대조, 주 수강생은 화면 확인, 보조 수강생은 시각 기록 | 실제값 기준표 |
| 14:35~16:00 | 자료·사례·변경 게이트·Blocker 확정 | 강사는 안전 경계, 주 수강생은 실습 가능 범위 확인, 보조 수강생은 Blocker 기록 | 실습 판정표·Blocker 목록 |

조건부 변경은 격리 대상, 최소 권한, 승인자, 허용 범위, 원복·정리, 성공·중단 기준의 6개 조건을 모두 통과할 때만 허용한다. 그 외에는 조회·증적 판정·워크스루로 대체한다.

## 6. Shadowing 개입 규칙과 금지 범위

강사는 다음 상황에서만 즉시 개입한다.

- 대상 Cluster·context·Namespace가 불명확한데 작업을 계속하는 경우
- Secret, Token, 개인키, kubeconfig 원문을 출력·기록하려는 경우
- 승인되지 않은 변경 명령을 실행하려는 경우
- Taylor 또는 다른 Cluster 값을 Xi'an에 적용하려는 경우
- 백업·정리·중단 기준 없이 변경하려는 경우
- 관찰 사실 없이 원인을 확정하고 외부 시스템 변경을 요청하려는 경우

전체 Cluster 재설치·Playbook 실행, Worker 변경, taint·label, Member Unbind·Import 재수행, Native API 외부 노출, 인증서 갱신, Namespace 삭제·복구, Monitoring 재적용, RBAC·Network·LB·ONTAP 정책 변경, 장애 재현, 민감정보 출력은 실제 수행하지 않는다.

## 7. 최종 산출물과 선택 기준

| 산출물 | 판정 기준 |
|---|---|
| 접근 확인표·실제값 기준표·Blocker 목록 | 시스템별 접속, 값의 출처·시각, 미확정 담당자가 있다. |
| 토폴로지·책임 경계도 | Host·Member, VIP-A/B, 외부 담당 조직을 구분한다. |
| 구축·Multi-Cluster 인수표 | Step 0~5 결과, Join, Monitoring 증거와 중단·에스컬레이션을 포함한다. |
| 사용자 요청 처리표 | 신청, Role, Quota, Harbor, 외부 요청과 완료 증거를 연결한다. |
| 정상 운영·Daily Monitoring 기록 | Image, Mount, Endpoint, Ingress, HTTP, Monitoring을 분리해 기록한다. |
| 인시던트 타임라인·교대 인계서 | 증상, 첫 단절, 반증, 금지 변경, 담당자와 다음 확인을 포함한다. |

2주안은 주 수강생이 실제 운영을 맡고, 교육 종료 전에 반복 요청·Daily Monitoring·장애 초동·교대 인계까지 주도하는 모습을 확인해야 할 때 선택한다. 전체 설치 반복과 장기 실운영 관찰은 포함하지 않는다.
