# 05.1 Host Cluster 설치

Host cluster는 다른 member cluster를 관리하는 **중앙 control plane** 역할을 수행합니다. Host cluster는 환경 전체에서 **1개만** 정의할 수 있으며, KubeSphere 설치 후 `cluster-configure.yaml` 의 `clusterRole` 값을 `host` 로 설정해야 합니다.

> [!info] 범위
> 이 문서는 DSPAAS 기준 `5-1-1. Kubesphere Install on Host Cluster`의 상위 인덱스입니다. 실제 절차는 같은 폴더의 하위 문서로 분리합니다.

### 사전 확인

- 대상 클러스터가 **Host cluster** 로 지정된 단일 클러스터인지 확인
- `kubesphere-installer.yaml` 및 `cluster-configure.yaml` 원본 파일 확보
- `cluster-configure.yaml` 내 `clusterRole: host` 반영 예정 여부 확인
- `kubectl` context가 대상 host cluster를 가리키는지 확인
- 설치 bundle 경로는 Xi'an 기준 `SCS_DKS_Kubernetes_Stack-v1.0/Kubesphere-v3.2.1/host` 사용

> [!warning] Host cluster 제약
> Host cluster는 한 환경에 하나만 둘 수 있습니다. 기존 Host cluster가 있는 상태에서 중복 지정하면 multi-cluster 운영 구성이 꼬일 수 있으므로 사전 확인이 필요합니다.
