## 1-2 用户及权限设置

确认 `dspaas` 用户的组和权限。在 Bastion 上，`dspaas` 必须属于 `wheel` 组，并且能够无需密码使用 sudo。

### 1-2-1 sudoers 文件编辑

使用 `visudo` 打开 `/etc/sudoers`，设置 `wheel` 组无需密码即可使用 sudo。使用 `visudo` 可以防止保存包含 sudoers 语法错误的文件。

> [!warning] sudoers 与 visudo
> 必须使用 `visudo` 编辑 sudoers。不要使用普通编辑器保存，并使用 `visudo -c` 和 `sudo -n true` 确认语法及实际权限。

```bash
visudo
visudo -c
su - dspaas
sudo -n true
echo $?
```

```text
# %wheel ALL=(ALL) ALL
%wheel ALL=(ALL) NOPASSWD: ALL
```

确认正常时，普通 `wheel` 权限行应处于注释状态，`NOPASSWD` 行应处于启用状态。如果返回值不是 `0`，请检查 `wheel` 成员关系、sudoers 配置以及是否已重新启动会话。

## 1-3 必需软件依赖安装

Kubespray 是基于 Python 的 Ansible 自动化工具。在安装 Kubespray 前，应在 Bastion 上准备 SCS 仓库、Python 3.8 和 Pip。

### 1-3-1 pip.conf 配置

配置 `/etc/pip.conf`，使 Pip 从 SCS Artifactory 下载软件包。

```bash
vi /etc/pip.conf
cat /etc/pip.conf
```

```ini
[global]
index-url=http://repo.samsungds.net:8081/artifactory/api/pypi/pypi/simple
trusted-host=repo.samsungds.net
```

> [!warning] 未确定的仓库拼写变体
> `repo.sungsamds.net:8081` 是原文中同时记录的拼写变体，但该值尚未确认。有效配置中不要使用它；已确认的 Pip index 使用 `http://repo.samsungds.net:8081/artifactory/api/pypi/pypi/simple`。

### 1-3-2 YUM 仓库文件更新

在 `/etc/yum.repos.d/` 中配置单独的仓库文件。原始截图包含 `Appstream`、`BaseOS`、`EPEL`、Kubernetes 以及 Docker 仓库文件。

> [!warning] 仓库异常及 base.repo 删除
> 删除 `base.repo` 前应取得运营批准并完成备份。以下 `rm base.repo` 是原文中的可能具有破坏性的命令，未经批准和备份不要执行。捕获的 Docker 仓库中的 `baseurl = http:// /artifactory/...` 是错误值。在向 SCS 确认 Docker 仓库值之前，不要将其用于有效配置，也不要编造缺失的值进行补充。

cd /etc/yum.repos.d/
rm base.repo
