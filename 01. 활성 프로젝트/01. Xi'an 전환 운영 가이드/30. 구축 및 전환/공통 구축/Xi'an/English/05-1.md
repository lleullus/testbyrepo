1. Apply `kubesphere-installer.yaml`
2. Apply `cluster-configure.yaml`

## 5-1-5. DKS Standard Workload Redeployment

The KubeSphere installer's nodeSelector/toleration may not be automatically propagated to all workloads created after installation. Because the Xi'an Host has no `system` node type, redeploy all of the target workloads below to `infra` nodes.

| Namespace | Target resources | Target node |
|---|---|---|
| `kubesphere-monitoring-system` | `alertmanager/main`, `prometheus/k8s`, `prometheus-operator`, `kube-state-metrics`, `notification-manager`, `notification-manager-operator` | `infra` |
| `kubesphere-controls-system` | `default-http-backend`, `kubectl-admin` | `infra` |
| `kubesphere-devops-system` | `devops-apiserver`, `devops-controller`, `devops-jenkins`, `s2ioperator`, `devops` CronJob | `infra` |
| `kubesphere-system` | `ks-apiserver`, `ks-console`, `ks-controller-manager`, `minio`, `tower`, `redis-ha-haproxy`, `openldap`, `redis-ha-server` | `infra` |

Because `common.redis.enabled: false` and `common.openldap.enabled: false`, `redis-ha-*` and `openldap` may not exist. Patch only resources that exist.

### Monitoring Namespace

### Create the Transformation File

The procedure below removes the existing `Sensor` group and recreates it, so it does not create duplicates. In each existing group, keep only `record` rules and remove `alert` rules.

```bash
cd ~/dks-prom-rules

python3 <<'PY'
import json
import subprocess
import sys

namespace = "kubesphere-monitoring-system"
name = "prometheus-k8s-rules"

raw = subprocess.check_output(
    ["kubectl", "get", "prometheusrule", name, "-n", namespace, "-o", "json"],
    text=True,
)
obj = json.loads(raw)

metadata = obj.setdefault("metadata", {})
for key in [
    "resourceVersion",
    "uid",
    "creationTimestamp",
    "generation",
    "managedFields",
    "selfLink",
]:
    metadata.pop(key, None)

kept_groups = []
for group in obj.get("spec", {}).get("groups") or []:
    if group.get("name") == "Sensor":
        continue
    record_rules = [rule for rule in group.get("rules") or [] if "record" in rule]
    if record_rules:
        kept_group = {
            "name": group.get("name"),
            "interval": group.get("interval"),
            "partial_response_strategy": group.get("partial_response_strategy"),
            "rules": record_rules,
        }
        kept_groups.append({key: value for key, value in kept_group.items() if value is not None})

kept_groups.append(
    {
        "name": "Sensor",
        "rules": [
            {
                "alert": "[Grade I Sensor] Pod Status Issue (Core)",
                "annotations": {
                    "description": "NameSpace: {{ $labels.namespace }} , Pod: {{ $labels.pod }}. Pod status is: {{ $labels.phase }}."
                },
                "expr": 'kube_pod_status_phase{phase!~"Succeeded|Running", namespace=~"kube.*|ingress.*"} != 0',
                "for": "5m",
                "labels": {
                    "cluster": "{{ $externalLabels.cluster }}",
                    "grade": "I",
                    "type": "Status",
                },
            },
            {
                "alert": "[Grade C Sensor] Node Status Issue (NotReady)",
                "annotations": {
                    "description": "Node: {{ $labels.node }} status is NotReady."
                },
                "expr": 'kube_node_status_condition{condition="Ready", status="true"} != 1',
                "for": "5m",
                "labels": {
                    "cluster": "{{ $externalLabels.cluster }}",
                },
            },
        ],
    }
)

obj["spec"]["groups"] = kept_groups
record_count = sum(1 for group in kept_groups for rule in group["rules"] if "record" in rule)
alert_count = sum(1 for group in kept_groups for rule in group["rules"] if "alert" in rule)
print(
    f"groups={len(kept_groups)} record_rules={record_count} alert_rules={alert_count}",
    file=sys.stderr,
)

try:
    import yaml

    with open("prometheus-k8s-rules.dks.yaml", "w", encoding="utf-8") as output:
        yaml.safe_dump(obj, output, sort_keys=False, allow_unicode=True)
    print("wrote prometheus-k8s-rules.dks.yaml")
except Exception:
    with open("prometheus-k8s-rules.dks.json", "w", encoding="utf-8") as output:
        json.dump(obj, output, ensure_ascii=False, indent=2)
    print("wrote prometheus-k8s-rules.dks.json (PyYAML unavailable)")
PY
```

```text
groups=<recorded after execution> record_rules=<recorded after execution> alert_rules=2
wrote prometheus-k8s-rules.dks.yaml
```
