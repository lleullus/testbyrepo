## 1-2 User and Permission Configuration

Check the group and permissions of the `dspaas` user. On the Bastion, `dspaas` must belong to the `wheel` group and be able to use sudo without a password.

### 1-2-1 Edit the sudoers File

Open `/etc/sudoers` with `visudo` and configure the `wheel` group to use sudo without a password. Using `visudo` prevents saving a file that contains sudoers syntax errors.

> [!warning] sudoers and visudo
> Always edit sudoers with `visudo`. Do not save it with a regular editor; use `visudo -c` and `sudo -n true` to verify the syntax and actual permissions.

```bash
visudo
visudo -c
su - dspaas
sudo -n true
echo $?
```

```text
# %wheel ALL=(ALL) ALL
%wheel ALL=(ALL) NOPASSWD: ALL
```

When verification succeeds, the regular `wheel` permission line must be commented out and the `NOPASSWD` line must be active. If the return value is not `0`, check `wheel` membership, the sudoers configuration, and whether the session has been restarted.
