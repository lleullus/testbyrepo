### 3-1-1. Prepare Ansible Configuration File

Set `host_key_checking` to `False` to disable the strict host key check. Ansible uses host key checking by default. This prevents server spoofing and man-in-the-middle attacks, but action or confirmation is required when the key in `known_hosts` changes after a server reinstallation or when a new host is not registered. To disable this behavior, modify `/etc/ansible/ansible.cfg` or `/.ansible/cfg`.

```bash
cd SCS_DKS_Kubernetes_Stack-v1.0/DKS-Kubespray-v2.19/
cat ansible.cfg | grep host_key
```

```bash
[dspaas@xadksbthm01 ~]$ cd SCS_DKS_Kubernetes_Stack-v1.0/DKS-Kubespray-v2.19/
```

## 3-2. Ansible Playbook Deployment

### 3-2-1. Deploy Ansible Playbook

Deploy Kubespray as an Ansible Playbook. Completion takes approximately 20 to 30 minutes, and the `--become` option is required to run the Playbook as root.

