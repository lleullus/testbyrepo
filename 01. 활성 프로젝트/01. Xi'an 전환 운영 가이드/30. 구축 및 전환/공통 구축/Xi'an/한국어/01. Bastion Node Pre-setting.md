## 1-1 Bastion 노드 구성

DKS는 클러스터마다 Bastion 노드 1대를 사용한다. Bastion은 해당 클러스터의 설치, 관리, 운영 실행 지점이다. 따라서 Bastion의 DNS, hosts, 사용자 권한, 소프트웨어 의존성, Kubespray 준비를 클러스터 설치 전에 완료한다.

### 1-1-1 Nameserver 파일 구성

SCS가 승인한 DNS 서버 정보를 `/etc/resolv.conf`에 적용한다.

```bash
vi /etc/resolv.conf
cat /etc/resolv.conf
```

```text
# Generated by NetworkManager
search samsungds.net
nameserver 109.150.175.95
nameserver 109.150.175.96
```

## 1-2 사용자 및 권한 설정

`dspaas` 사용자의 그룹과 권한을 확인한다. Bastion에서 `dspaas`가 `wheel` 그룹에 속하고 비밀번호 없이 sudo를 사용할 수 있어야 한다.

### 1-2-1 sudoers 파일 편집

`visudo`로 `/etc/sudoers`를 열고 `wheel` 그룹이 비밀번호 없이 sudo를 사용할 수 있도록 설정한다. `visudo`를 사용하면 sudoers 구문 오류가 있는 파일의 저장을 방지할 수 있다.

> [!warning] sudoers와 visudo
> sudoers는 반드시 `visudo`로 편집한다. 일반 편집기로 저장하지 말고, `visudo -c`와 `sudo -n true`로 구문과 실제 권한을 확인한다.

```bash
visudo
visudo -c
su - dspaas
sudo -n true
echo $?
```

```text
# %wheel ALL=(ALL) ALL
%wheel ALL=(ALL) NOPASSWD: ALL
```

정상 확인 시 일반 `wheel` 권한 줄은 주석 처리되어 있고 `NOPASSWD` 줄이 활성화되어 있어야 한다. 반환값이 `0`이 아니면 `wheel` 멤버십, sudoers 설정, 세션 재시작 여부를 확인한다.

## 1-3 필수 소프트웨어 의존성 설치

Kubespray는 Python 기반 Ansible 자동화 도구다. Kubespray 설치 전에 SCS 저장소, Python 3.8, Pip을 Bastion에 준비한다.

### 1-3-1 pip.conf 구성

`/etc/pip.conf`를 구성해 Pip이 SCS Artifactory에서 패키지를 다운로드하도록 한다.

```bash
vi /etc/pip.conf
cat /etc/pip.conf
```

```ini
[global]
index-url=http://repo.samsungds.net:8081/artifactory/api/pypi/pypi/simple
trusted-host=repo.samsungds.net
```

> [!warning] 미확정 저장소 철자 변형
> `repo.sungsamds.net:8081`은 원본에 함께 기록된 철자 변형이지만 확정되지 않은 값이다. 활성 설정에는 사용하지 않고, 확정된 Pip index는 `http://repo.samsungds.net:8081/artifactory/api/pypi/pypi/simple`을 사용한다.

### 1-3-2 YUM 저장소 파일 업데이트

`/etc/yum.repos.d/`에 개별 저장소 파일을 구성한다. 원본 캡처에는 `Appstream`, `BaseOS`, `EPEL`, Kubernetes 및 Docker 저장소 파일이 포함되어 있다.

> [!warning] 저장소 이상 및 base.repo 삭제
> `base.repo`를 삭제하기 전에 운영 승인을 받고 백업을 완료한다. 아래 `rm base.repo`는 원본의 파괴 가능 명령이므로 승인과 백업 전에는 실행하지 않는다. 캡처된 Docker 저장소의 `baseurl = http:// /artifactory/...`는 잘못된 값이다. SCS에 Docker 저장소 값을 확인하기 전 활성 설정으로 사용하지 않으며, 누락된 값을 만들어 보완하지 않는다.

```bash
cd /etc/yum.repos.d/
rm base.repo
vi Appstream.repo
vi Artifactory-docker.repo
vi BaseOS.repo
vi EPEL.repo
vi kubernetes.repo
ls
cat *
```

### 1-4-4 SSH 키 쌍 생성

각 노드에 배포할 SSH 공개키/개인키 쌍을 `dspaas` 계정으로 생성한다.

> [!warning] SSH 개인 키
> 개인키 내용은 이 문서나 실행 증적에 넣지 않는다. 원본 캡처에는 키 지문과 randomart만 있으며, 그 증적은 그대로 보존한다.

su - dspaas
ssh-keygen
ls -l ~/.ssh/id_rsa ~/.ssh/id_rsa.pub

### 1-4-6 Ansible 인벤토리 생성

```bash
su - dspaas
cd SCS_DKS_Kubernetes_Stack-v1.0
cd ansible/
vi inventory
cat inventory
```
