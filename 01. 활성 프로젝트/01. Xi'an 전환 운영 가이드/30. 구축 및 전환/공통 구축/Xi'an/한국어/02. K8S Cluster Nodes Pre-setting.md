이 문서는 Xi'an Host 클러스터 전환을 위한 K8S 클러스터 노드 사전 설정 절차입니다. 대상 클러스터는 `prd-host-pa01-xas`(`PRD-HOST-PA01-XAS`)입니다. Taylor 환경의 호스트명, IP 주소, VIP, DNS 값, 패키지 경로, 비밀번호, 스토리지 값을 이 절차에 복사해서는 안 됩니다.

아래 `참조 출력` 블록은 확정된 Xi'an Host 클러스터 인벤토리와 대상 구성을 기반으로 생성되었습니다. 이는 실행 증적이 아닙니다. Xi'an VM에서 명령어를 실행한 후 캡처한 출력으로 교체하십시오.

### 0-1. Xi'an 로드밸런서 구성 확인

현재 Xi'an Host 클러스터 로드밸런서 값은 다음과 같습니다.

| VIP | 주소 | 포트 | 백엔드 매핑 | 상태 확인 |
|---|---|---|---:|---|---|
| VIP-A | `109.156.25.43` | 6443 | `xadksmahm01`-`03` | TCP 6443 |
| VIP-B | `109.156.25.46` | 80 | Router 노드 -> 30080 | TCP 30080 |
| VIP-B | `109.156.25.46` | 443 | Router 노드 -> 30443 | TCP 30443 |

Xi'an Bastion 절차는 VIP-A를 아직 확인 필요로 표시하고 있으나, Host 클러스터 카탈로그에는 `109.156.25.43`로 기록되어 있습니다. 프로덕션에서 사용하기 전에 SCS에 API VIP를 확인하십시오.

```bash
curl -k -i https://109.156.25.43:6443/healthz

```


### 0-2. ETCD 파일시스템 및 VM 리소스 확인

노드 사전 설정을 적용하기 전에 VM 템플릿 마운트 지점을 확인하십시오. ETCD 노드는 승인된 `/var/lib/etcd` 설계가 필요하며, 현재 Xi'an 노드 테이블에는 나열된 모든 비-Bastion 역할에 대해 `/var/lib/containerd`가 기록되어 있습니다.

```bash
hostnamectl
lsblk -f
df -hT
findmnt /var/lib/containerd /var/lib/etcd
```

### 0-3. `dspaas` 계정 및 비밀번호 없는 sudo 확인

`dspaas` 계정은 Bastion과 모든 Kubernetes 노드에 존재해야 합니다. `wheel` 그룹에 속해야 하며 Kubespray 실행 중 비밀번호 없는 sudo를 사용할 수 있어야 합니다.

```bash
id dspaas
getent group wheel
sudo -n true
```

필요한 결과:

```text
uid=<dspaas-uid>(dspaas) gid=<dspaas-gid>(dspaas) groups=<dspaas-gid>(dspaas),10(wheel)
wheel:x:10:dspaas
```

UID, 기본 GID, SSH 자격 증명은 Xi'an 계정 값입니다. 이 문서나 실행 증적에 비밀번호를 기록하지 마십시오.

## 2-1. Ansible을 사용한 모든 노드 구성(bastion→all nodes)

### 2-1-1. sudoers 파일 편집

`dspaas` 사용자가 `wheel` 그룹에 속하므로, Kubespray를 실행하기 전에 모든 Xi'an Host 클러스터 노드에서 비밀번호 없는 sudo를 활성화하십시오.

```bash

ansible k8s,etcd -i inventory -m shell -a "cat /etc/sudoers | grep %wheel" -K -k -b
ansible k8s,etcd -i inventory -m lineinfile -a 'path=/etc/sudoers regexp="^%wheel\s+ALL=\(ALL\)\s+ALL" line="#%wheel ALL=(ALL) ALL" state=present' -K -k -b
ansible k8s,etcd -i inventory -m shell -a "cat /etc/sudoers | grep %wheel" -b
```

## 5. Xi'an Host 클러스터 전환 완료 상태

| 항목 | 상태 | 사유 |
|---|---|---|
| 클러스터 이름, 도메인, Pod/Service 네트워크 | 완료 | Xi'an 환경 준비 및 Host 클러스터 카탈로그에서 확인됨. |
| Host 노드 호스트명/IP 목록 | 카탈로그 확인됨 | 노드 테이블이 기록됨; 최종 SCS 인벤토리 승인이 아직 필요함. |
| Master 노드 개수 | 확인 필요 | 클러스터 개요는 4개로 표시되나, 노드 테이블, VIP-A 실서비스, 전체 개수는 3개로 나타남. |
| VIP-B `109.156.25.46` | 완료 | Host 클러스터 인그레스 VIP 및 Router 매핑이 기록됨. |
| VIP-A `109.156.25.43` | 확인 필요 | Host 클러스터 카탈로그에는 기록되었으나 Bastion 절차에 확정 사항으로 아직 반영되지 않음. |
| `/var/lib/etcd` 할당 | 확인 필요 | 카탈로그는 0으로 기록되어 있으나, Xi'an 사전 설정 절차는 ETCD 마운트가 필요함. |
| `dspaas` 계정 및 wheel sudo | 확인 필요 | 배포된 SCS VM에서 확인해야 함. |
| 리포지토리 엔드포인트 | 엔드포인트 확인됨, 경로 미정 | HQ Nexus/JFrog/Harbor 주소는 확인되었으나 정확한 리포지토리 경로는 기록되지 않음. |
| DKS 패키지 디렉터리 | 부분 확인됨 | Xi'an 문서에서 `SCS_DKS_Kubernetes_Stack-v1.0`이 사용됨; 패키지 URL과 체크섬은 실행 증적이 필요함. |
| Ansible 인벤토리 | 카탈로그 기반 | SCS가 최종 역할 할당과 Master 개수를 확정한 후 노드 테이블에서 채움. |
| 참조 출력 블록 | 실행 증적 아님 | 절차 실행 후 캡처한 Xi'an 명령어 출력으로 교체할 것. |

Xi'an Host 클러스터에 절차를 적용하기 전에 확인 필요 항목을 완료하십시오.
