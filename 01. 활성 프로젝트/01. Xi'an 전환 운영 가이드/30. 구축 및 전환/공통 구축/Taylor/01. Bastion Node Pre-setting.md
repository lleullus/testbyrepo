### 0-1. Alert exception request against Load Balancer

Request the alert exception against Load Balancer to DS Cloud Service Desk.

```text
To DS Cloud Service Desk

Cluster:
LB Virtual server name:
IP Address:
Period for exception
Start date/time:
End date/time:
```

Inform DS Cloud Service Desk in advance of work information to exclude broadcasts. If there are two or more broadcasts due to work without prior notice, LB VS service-down detection is excluded.

### 0-2. Verify VIP-A/B

Verify Load Balancers (VIP-A and VIP-B) routing traffic to Master and Router nodes by running a simple HTTP server as a backend on each node.

```bash
python3 -m http.server <backend_port_number>
curl http://<load_balancer_IP>:<port_number>
```

- VIP-A (`6443`): run the backend on Master nodes.
- VIP-B (`80`): run the backend on Router nodes.
- VIP-B (`443`): run the backend on Router nodes.

## 1-2. User and Permissions Setup

Confirm `dspaas` user group and permissions.

### 1-2-1. Confirm `dspaas` user group

The `dspaas` user is the administrator account. Confirm that it belongs to the `wheel` group.

```bash
cat /etc/group | grep wheel
```

Reference output:

```text
wheel:x:10:dspaas
```

### 1-2-2. Edit the sudoers file

Use `visudo` to allow the `wheel` group to use sudo without a password prompt.

```bash
visudo
```

```text
# %wheel ALL=(ALL) ALL
%wheel ALL=(ALL) NOPASSWD: ALL
```

Confirm the active configuration:

```bash
cat /etc/sudoers | grep wheel
```

The normal `%wheel ALL=(ALL) ALL` line is commented out and `%wheel ALL=(ALL) NOPASSWD: ALL` is active.

## 1-3. Install prerequisite software dependencies

Kubespray uses Ansible, an automation tool built on Python. Install Python and Pip on the Bastion Node before executing the Kubespray installer.

### 1-3-1. Configure `pip.conf` file

Configure JFrog Artifactory as the pip download target.

```bash
vi /etc/pip.conf
```

```ini
[global]
index-url=http://repo.samsungds.net:8081/artifactory/api/pypi/pypi/simple
trusted-host=repo.samsungds.net
```

### 1-3-2. Update YUM repository file

Define the individual repositories in `/etc/yum.repos.d/`.

```bash
cd /etc/yum.repos.d/
vi Appstream.repo
vi Artifactory-docker.repo
vi BaseOS.repo
vi EPEL.repo
vi kubernetes.repo
ls
cat *
```


### 1-3-3. Install Python

DKS uses Python 3.8 to install the required Kubespray modules with Pip.

```bash

cd /usr/bin

python -V
```

Offline instructions (Non-DKS): <https://github.com/kubernetes-sigs/kubespray/blob/master/docs/offline-environment.md>
