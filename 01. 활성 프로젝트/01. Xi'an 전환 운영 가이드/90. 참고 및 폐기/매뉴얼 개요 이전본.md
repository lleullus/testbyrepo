# Manual

## 목적

이 노트는 `매뉴얼/` 폴더를 묶어 보는 로컬 인덱스 허브다.
KubeSphere 운영 절차, 일반 운영 참고자료, Harbor 절차, DKS 사용자 가이드를 한곳에서 찾을 수 있게 연결한다.

> [!warning] 문서 권위
> `KubeSphere 운영/`은 실제 운영 절차에 가까운 문서군이다.
> `운영 절차/`, `Harbor 매뉴얼/`, `DKS 사용자 가이드/`는 참고용/초안 성격이 강하므로 Xi'an 전환 정보와 실제 운영 기준을 우선 확인한다.

## 구성 요약

- `KubeSphere 운영/`: Workspace, Project, 사용자, 권한, quota, kubectl 접근 등 KubeSphere 운영 절차를 모아둔 문서군
- `운영 절차/`: Kubespray, 노드 추가, 장애 대응, API 활용, 인증서 갱신 등 운영 참고자료
- `Harbor 매뉴얼/`: Harbor 설치, 프로젝트 생성, 사용자 관리 절차를 정리한 문서군
- `DKS 사용자 가이드/`: DKS/KubeSphere/Harbor를 사용하는 사람 기준의 가이드
