# Xi'an Cluster 상세

## 목적

이 노트는 `클러스터 상세/` 폴더의 로컬 인덱스 허브다.
클러스터별 상세 사실은 각 하위 노트에서 확인하고, 이 문서는 탐색과 연결만 담당한다.

- 폴더 범위: Xi'an 환경의 개별 클러스터별 상세 노트
- 상세 사실의 권한: 각 클러스터 하위 노트
