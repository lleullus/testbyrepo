# 기존 운영 가이드 국문 번역 및 저장소 최신화 가이드

## Index

초기 Xi'an DKS 인프라 가이드는 영문 및 중문 위주로 작성되었으며, 사내 저장소 URL(Nexus → 사내 Artifactory), Harbor 이미지 레지스트리 FQDN, Kubespray 패키지 경로 등이 과거 임시 경로로 표기되어 있었다. 본 문서는 이를 현행화(최신화)된 Xi'an 표준값으로 통합 정리하고, 운영자가 현장에서 바로 참조할 수 있는 국문 절차를 제공한다.

작업은 다음 순서로 진행한다.

1. **사내 YUM 저장소 (Artifactory) 설정 최신화 및 확인**
2. **Harbor 이미지 레지스트리 저장소 경로 최신화**
3. **Kubespray 및 배포 패키지 디렉터리 경로 현행화**
4. **오프라인 설치 바이너리 다운로드 경로 유효성 검증**
5. **Worker 노드 증설 시 최신 저장소 참조 실습 검증**

---

## 1. 사내 YUM 저장소 (Artifactory) 설정 최신화 및 확인

과거 가이드에 기재되었던 임시 Nexus 경로(nexus.adpaas.cloud.samsungds.net)는 폐기되었으며, 현재는 Xi'an 전용 사내 YUM 저장소 미러 또는 Artifactory를 사용한다.

### 1-1. Bastion 및 노드 YUM Repository 파일 확인

Bastion(xadksbtmp01) 및 Master/Worker 노드의 /etc/yum.repos.d/ 디렉터리 설정을 점검한다.

```console
[dspaas@xadksbtmp01 ~]$ ls -l /etc/yum.repos.d/
total 16
-rw-r--r--. 1 root root  820 Jun 19 04:00 dks-base.repo
-rw-r--r--. 1 root root  910 Jun 19 04:00 dks-docker.repo
-rw-r--r--. 1 root root  780 Jun 19 04:00 dks-kubernetes.repo

[dspaas@xadksbtmp01 ~]$ cat /etc/yum.repos.d/dks-base.repo
[dks-base]
name=DKS Base Repository
baseurl=http://repo.dks.samsungds.net/repository/centos-7-base/
enabled=1
gpgcheck=0
```

### 1-2. YUM 캐시 갱신 및 정상 조회 테스트


## 2. Harbor 이미지 레지스트리 저장소 경로 최신화

기존 영문 가이드 및 초기 테스트 환경에 사용되었던 dspaas-testrepo 또는 dks-test 네임스페이스는 공식 운영 네임스페이스로 변경되었다.

### 2-1. 최신 Harbor 이미지 경로 매핑

| 용도 | 과거 가이드 표기 | Xi'an 운영 최신 표준 경로 |
|---|---|---|
| **기본 Nginx 테스트 이미지** | xa.dcr.dks.samsungds.net/dspaas-testrepo/nginx:latest | xa.dcr.dks.samsungds.net/dspaas-v1.22.10-a/nginx:1.14.2 |
| **KubeSphere 인스톨러 이미지** | harbor.adpaas.cloud/... | xa.dcr.dks.samsungds.net/kubesphere/ks-installer:v3.3.0 |
| **Calico CNI 이미지** | calico/cni:v3.21.4 | xa.dcr.dks.samsungds.net/calico/cni:v3.21.4 |

### 2-2. 최신 경로 기반 Docker Tag 및 Push 검증


## 4. 오프라인 설치 바이너리 다운로드 경로 유효성 검증

폐쇄망 환경에서 신규 Worker 노드 설치 시 필요한 Docker 및 유틸리티 패키지가 사내 미러에서 정상 다운로드되는지 확인한다.

```console
[dspaas@xadksbtmp01 ~]$ curl -sk -o /dev/null -w "%{http_code}\n" http://repo.dks.samsungds.net/repository/files/docker-compose
200

[dspaas@xadksbtmp01 ~]$ curl -sk -o /dev/null -w "%{http_code}\n" http://repo.dks.samsungds.net/repository/files/harbor-offline-installer-v2.2.2.tgz
200
```

200 OK가 반환되어 정상 통신됨을 확인한다.
