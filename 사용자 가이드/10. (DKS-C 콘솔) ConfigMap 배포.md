# (DKS-C 콘솔) ConfigMap 배포

## ConfigMap 배포 하기

1. ConfigMap을 배포하고자 하는 Project > 클러스터를 선택합니다.
2. 메뉴에서 구성 > Config 맵을 선택 후 상단 타이틀 옆 `+` 버튼을 클릭합니다.
3. 에디터에서 항목에 맞게 입력한 후 적용을 클릭합니다.

| 필드 | 설명 |
|---|---|
| `metadata.name` | ConfigMap 이름 |
| `metadata.namespace` | ConfigMap 네임스페이스 |
| `data` | UTF-8 문자열. key-value 형식 |
| `binaryData` | 바이너리 데이터를 base64로 인코딩한 문자열. key-value 형식 |

- `data`, `binaryData` 필드 아래의 각 키는 영숫자 문자, `-`, `_` 또는 `.` 으로 구성되어야 합니다.
- `data` 에 저장된 키는 `binaryData` 필드의 키와 겹치지 않아야 합니다.

`data` 예시, `binaryData` 예시는 원문에서 접힘(펼치기) 영역이라 붙여넣기에 내용이 없다.

4. ConfigMap 생성을 완료하면, 해당 ConfigMap의 정보와 상태를 확인할 수 있습니다.
