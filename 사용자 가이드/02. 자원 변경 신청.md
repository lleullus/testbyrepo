# 자원 변경 신청

"콘솔관리 > 신청 관리 > 자원 변경 신청" 메뉴를 클릭합니다.

## Project 선택 Step

변경하고자 하는 Cluster가 있는 Project 명을 선택한 뒤 [다음] 버튼을 클릭합니다.

## 자원 정보 선택 Step

1. 변경할 Cluster를 선택하면 이전에 신청된 정보가 조회되어 보여집니다.
2. 조회된 내용을 확인 후 원하는 자원량을 다시 입력합니다.
3. 반영 일자를 입력하여, 변경이 처리되는 시간을 지정할 수 있습니다.
   - 입력된 시간에 클러스터 자원 변경이 발생하므로 운영중인 애플리케이션을 모니터링 하고 필요한 사전 작업을 진행하도록 합니다.
4. 정보가 모두 올바르게 기입되었다면 [다음] 버튼을 클릭합니다.

## 자원 변경 정보 확인 Step

자원 변경 정보 확인 Step에서는 신청한 데이터가 모두 올바른지 확인 합니다.

1. [임시저장] 버튼을 클릭하면 설정정보가 저장됩니다. (보관주기 7일)
   - 보관된 정보는 "신청관리 > 자원신청현황" 목록에서 확인할 수 있으며, 상세 정보화면에 진입하여 우측 상단 "Action 메뉴의 편집 버튼" 기능을 이용하여 재사용 가능합니다.
2. 수요조사 내역을 초과하여 신청할 경우 DKS의 담당자 합의가 결재 라인에 추가됨을 안내하는 메시지가 표시됩니다.
3. 모든 내용을 확인한 후 [신청] 버튼을 클릭하면 결재 상신 팝업이 오픈 됩니다.
   - 위에서 안내한 바와 같이 수요조사내역을 초과 할 경우 DKS 담당자가 결재라인에 합의로 추가 됩니다.
   - [등록] 버튼을 누를 경우 결재라인을 추가 할 수 있습니다.
   - 결재자 정보를 올바르게 선택하고, 상신의견을 입력한 후, "자원 산정근거 양식"을 작성하여 업로드 하면 [상신] 버튼을 클릭하여 자원 신청을 완료할 수 있습니다.

## 신청 완료 > 자원 신청 현황

신청이 완료되면 자원 신청 현황 목록으로 이동되며, 변경 신청한 내용이 가장 상단에 보여집니다. 신청 No를 클릭하여 자원 변경 정보를 확인할 수 있습니다.
