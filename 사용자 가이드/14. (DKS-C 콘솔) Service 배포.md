# (DKS-C 콘솔) Service 배포

> [!danger] 필수 확인 사항
> 서비스의 External IP와 NodePort는 정책상 사용이 불가합니다. External IP 설정 시 Node 통신 불가로 DKS2 서비스 이상 발생하니 절대 사용을 금합니다. (입력 금지)

## Service 배포 하기

1. Service를 배포하고자 하는 Project > 클러스터를 선택합니다.
2. 메뉴에서 네트워크 > 서비스를 선택 후 상단 타이틀 옆 `+` 버튼을 클릭합니다.
3. 에디터에서 항목에 맞게 입력한 후 적용을 클릭합니다.

| 필드 | 설명 |
|---|---|
| `metadata.name` | Service 이름 |
| `metadata.namespace` | Service 네임스페이스 |
| `spec.selector` | 대상 워크로드 labels |
| `spec.type` | Service 타입 |
| `spec.ports[].name` | 이름 |
| `spec.ports[].protocol` | 프로토콜 |
| `spec.ports[].port` | 서비스가 외부에서 받는 포트 |
| `spec.ports[].targetPort` | 포드 내부에서 실행 중인 앱 포트 |

### Service Type

| 타입 | 설명 |
|---|---|
| ClusterIP | 클러스터 내부에서만 접근 가능한 IP |
| NodePort | 모든 노드의 특정 포트를 열어 외부 접속 허용 (DKS2 사용불가) |
| LoadBalancer | VCF 로드밸런서와 연결 (DKS2콘솔 Ingress 배포 매뉴얼 참고) |
| ExternalName | 외부 도메인(예: google.com)을 서비스처럼 호출 (DKS2 사용불가) |

4. 서비스 생성을 완료하면, 해당 서비스의 정보와 상태를 확인할 수 있습니다.

> [!note] 18번 노트와의 관계
> 18번(LoadBalancer 구성) 예제 YAML은 `type: LoadBalancer` 서비스에 `nodePort: 30432`·`30306`을 적어 두었다. 이 노트의 "NodePort 사용 불가" 정책과 충돌해 보인다. 원문 그대로 옮겼으며 실제 적용 전 확인이 필요하다.
