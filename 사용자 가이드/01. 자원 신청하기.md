# 자원 신청하기

> 원문 머리글: (Cluster Service) 운영 가이드 · 영어페이지 번역 · 자원 신청하기

## Project 배부비율 변경

추후, DKS2 서비스를 제공하기 위해 필요한 총 금액(HW 비용 + SW 비용 + 운영 비용 등)을 각 사업부로 배부하여 비용 청구 예정입니다. 이 때 활용하기 위한 사업부 별 과금 비율 데이터입니다.

자세한 사항은 `DKS(DS Kubernetes Service) 비용은 어떻게 청구되나요? - DS WIKIPEDIA - DS Confluence (samsungds.net)` 를 참고 부탁드립니다.

1. "콘솔관리 > 신청 관리 > Project 설정" 메뉴를 클릭합니다.
2. 배부비율을 설정할 Project의 우측 끝 "메뉴" 아이콘을 클릭한 후 "배부비율변경" 메뉴를 선택합니다.
3. 부서 별 배부비율을 작성 및 확인 후 "확인" 버튼을 클릭합니다.

## 자원 등록 신청

"콘솔관리 > 신청 관리 > 자원 등록 신청" 메뉴를 클릭합니다.

### Project 선택 Step

Project 란 One Cloud (Cloud Service) 에서 생성하는 Project입니다.

- One Cloud (Cloud Service) 상에서의 Project 등록 방법은 `클라우드 프로젝트 참여 신청/승인 - DS Wikipedia - DS Confluence` 를 참고 부탁드립니다.
- Project의 AA 변경방법은 `One Cloud에서 AA 변경 어떻게 하나요? - DS WIKIPEDIA - DS Confluence (samsungds.net)` 를 참고 부탁드립니다.

1. Project선택 항목에서 자원등록 할 Project정보를 선택한다.
   - Project 추가가 필요한 경우 [Project생성 바로가기]를 클릭(One Cloud 페이지로 이동)하여 신규 Project를 생성할 수 있습니다.
2. Application Architecture를 확인합니다.
3. 신청가능 자원현황을 확인합니다.
4. 각 배부비율을 확인합니다.
   - 배부비율에서 [Project 설정버튼]을 클릭 시 신청관리 > Project 설정 화면으로 이동하여 배부비율을 설정할 수 있습니다.
5. 정보 확인 후 [다음] 버튼을 클릭.

### 자원 정보 입력 Step

자원 정보 입력 Step에서 등록할 자원 정보를 입력합니다.

1. 사용목적 선택시 목적별로 신청 가능한 자원 현황을 확인할 수 있습니다.
2. Cluster이름을 입력하고, OS / Cluster 버전을 선택합니다.
3. Cluster 사양은 기본으로 Small, Medium, Large 템플릿 중 선택이 가능합니다.
   - 선택한 템플릿을 기반으로 노드의 정보는 모두 사용자가 수정이 가능합니다.
     - 노드 그룹의 이름
     - 노드 개수
     - 컨테이너 볼륨의 용량
     - 노드의 사양
   - [노드 그룹추가]로 노드를 추가 할 수 있습니다.
4. RWO 용도의 Object Storage와 RWX 가능한 Object Strorage 용량을 선택합니다.
   - 크기는 직접 입력하거나, 셀렉트박스에서 선택해서 입력할 수 있습니다.
5. Application 규모에서는 서비스 중단 가능 시간, 필요 I/O, 네트워크 대역폭, 동시 접속자 수, 중요 등급을 입력합니다.
   - Application 규모는 신청하는 자원의 중요도 및 규모를 파악하기 위한 용도로 신청시 자원에 실질적인 영향을 미치는 값은 아닙니다.
6. [이전] 버튼을 클릭하면 이전 단계인 Project 선택 화면으로 돌아 갈 수 있습니다.
7. 입력한 정보를 확인하고 이상이 없으면 [다음] 버튼을 클릭하여 자원 신청 정보 확인 Step으로 이동합니다.

### 자원 신청 정보 확인 Step

자원 신청 정보 확인 Step에서는 신청한 데이터가 모두 올바른지 확인 합니다.

1. [임시저장] 버튼을 클릭하면 설정정보가 저장됩니다. (보관주기 7일)
   - 보관된 정보는 "신청관리 > 자원신청현황" 목록에서 확인할 수 있으며, 상세 정보화면에 진입하여 우측 상단 "Action 메뉴의 편집 버튼" 기능을 이용하여 재사용 가능합니다.
2. 수요조사 내역을 초과하여 신청할 경우 DKS의 담당자 합의가 결재 라인에 추가됨을 안내하는 메시지가 표시됩니다.
3. 모든 내용을 확인한 후 [신청] 버튼을 클릭하면 결재 상신 팝업이 오픈 됩니다.
   - 위에서 안내한 바와 같이 수요조사내역을 초과 할 경우 DKS 담당자가 결재라인에 합의로 추가 됩니다.
   - [등록] 버튼을 누를 경우 결재라인을 추가 할 수 있습니다.
   - 결재자 정보를 올바르게 선택하고, 상신의견을 입력한 후, "자원 산정근거 양식"을 작성하여 업로드 하면 [상신] 버튼을 클릭하여 자원 신청을 완료할 수 있습니다.

### 신청 완료 > 자원 신청 현황

신청이 완료되면 자원 신청 현황 목록으로 이동되며, 등록한 내용이 가장 상단에 보여집니다. 신청 No를 클릭하여 자원 신청 정보를 확인할 수 있습니다.

## Q&A Section

**Q. DKS2 콘솔 접속 주소가 어떻게 되나요?**
A. console.dks.samsungds.net 입니다.

**Q. DKS2 콘솔 접속 시 ID / PW가 뭔가요?**
A. AD 계정 ID / PW 입력 바랍니다.

**Q. DKS2 콘솔에 접속이 되지 않습니다.**
A. 아래 방화벽 오픈 사전 작업이 정상적으로 완료되었는지 확인 바랍니다. 방화벽 open 방법은 DS WIKIPEDIA - DS Cloud Kubernetes Service 가이드를 참고해주시기 바라며, 방화벽 open 신청 관련 문의는 GSAMS (http://gsams.samsungds.net)로 문의 바랍니다.

**Q. 방화벽 open 신청시 단방향인가요? 양방향인가요?**
A. 단방향으로 open하시면 정상적으로 접속 가능합니다.

**Q. 회의실에서 DKS2 Cluster로 접속할 수 있게 방화벽 open해 주실 수 있나요?**
A. 사용자 분들의 필요에 의한 방화벽 open 설정은 DKS2 운영팀에서 지원해드리지 않습니다. 필요한 경우 VDI를 통해 접속해주시거나 사용자분께서 GSAMS를 통해 방화벽 open 신청 부탁드립니다.

**Q. 신규 Cluster는 어떻게 신청하나요?**
A. "신청관리 > 자원 등록 신청" 메뉴를 통하여 신청 가능합니다.

**Q. Project는 어떻게 신청하나요?**
A. DKS2 콘솔은 One Cloud (cloud.onecloud.samsungds.net) 로부터 Project 정보를 연동하고 있습니다. Project와 관련된 내용은 One Cloud 부서로 문의 바랍니다. (OneCloud (Cloud service) S-VOC 바로가기)

**Q. Cluster 명을 변경하고 싶습니다.**
A. Cluster 명은 수정이 불가능합니다. 필요하시다면 기존 Cluster 삭제 후 새로운 Cluster를 생성하여야 하오니, 신중히 생각 후 이름을 지정 해 주세요.
