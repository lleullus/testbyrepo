# (DKS-C 콘솔) Secret으로 Image Registry 등록하기

## Secret으로 Image Registry 등록하기

1. 시크릿을 배포하고자 하는 Project > 클러스터를 선택합니다.
2. 메뉴에서 구성 > 시크릿을 선택 후 상단 타이틀 옆 `+` 버튼을 클릭합니다.
3. 에디터에서 항목에 맞게 입력한 후 적용을 클릭합니다.

| 필드 | 설명 |
|---|---|
| `metadata.name` | Secret 이름 |
| `metadata.namespace` | Secret 네임스페이스 |
| `type` | Secret 타입: `kubernetes.io/dockerconfigjson` |
| `data` | `.dockerconfigjson: <BASE64_ENCODED_JSON>` (repository 주소, repository 계정/비밀번호) |

아래의 `.dockerconfigjson` 데이터 만드는법 참고

### .dockerconfigjson 데이터 만드는 법

인증 정보를 포함한 json 데이터를 준비하고, 아래와 같이 형태로 준비된 JSON 문자열 전체를 Base64 인코딩하여 `.dockerconfigjson`에 넣어야 합니다.

JSON 형식의 인증 정보

```json
{
  "auths": {
    "<repository 주소>": {
      "username": "<repository 계정>",
      "password": "<repository 비밀번호>",
      "email": "<사용자 이메일: 생략 가능>",
      "auth": "BASE64_ENCODED_USER_PASS"
    }
  }
}
```

예제 (Json): username : `abc` 이고, password : `passwd123` 인 경우 `auth` 필드의 값은 `"username:password"` 와 같은 형태로 구성하여 Base64 인코딩 하여 넣습니다.

```text
abc:passwd123 => Base64 인코딩 => YWJjOnBhc3N3ZDEyMw==
```

아래에 최종 데이터 형태 샘플 참고

JSON 형식의 인증 정보

```json
{
  "auths": {
    "harbor.dks.samsungds.net": {
      "username": "abc",
      "password": "passwd123",
      "email": "dks@samsungds.net",
      "auth": "YWJjOnBhc3N3ZDEyMw=="
    }
  }
}
```

4. 생성된 시크릿 정보를 확인합니다.

## Q&A Section

**Q. Secret으로 image registry 등록 시 사내 공식 저장소 외에도 사용자가 구축한 private registry를 사용할 수 있나요?**
A. DKS에서 private registry 사용을 위해 DKS 클러스터 내에서 TLS 설정이 필요합니다. 현재 사내 공식 저장소의 경우 이미 TLS 설정이 완료되었기 때문에 사용이 가능하지만, 사용자가 직접 구축한 private registry의 경우 image pull 시에 에러가 발생할 수 있습니다.

현재 (2026년 04월 21일 기준) DKS 에 등록되어 있는 저장소 목록은 아래와 같습니다. (확인 필요)

- harbor.dks.samsungds.net
- artifact.samsungds.net
- repository.samsungds.net
