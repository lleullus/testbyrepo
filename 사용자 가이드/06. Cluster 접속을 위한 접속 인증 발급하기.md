# Cluster 접속을 위한 접속 인증 발급하기

## 접속 인증 발급하기

### 1. 메뉴 이동하기

접속 인증을 발급하려면, 왼쪽 하단의 콘솔 관리 메뉴를 클릭한 후, 운영관리 > 접속 인증 관리 메뉴를 클릭하여 이동합니다.

### 2. 접속 인증 발급하기

`+`(더하기) 버튼을 클릭하여, 접속 인증 발급 팝업 화면을 띄운 후, 사용 목적과 만료 기간 항목을 입력하신 후, 저장 버튼을 클릭하여 발급합니다.

- **사용 목적**: 접속 인증을 발급하여 사용하는 목적을 입력합니다.
- **만료 기간**: 접속 인증의 만료 기간은 아래와 같이 사용 목적에 맞게 30일, 90일, 120일, 180일, 1년 중 선택하여 발급하실 수 있습니다. (발급일로 부터 선택한 만료 기간을 가진 접속 인증이 생성됩니다.)

## 접속 인증 사용하기

### 1. Kubeconfig 다운로드하기

발급받은 접속 인증은 접속 인증 발급 목록의 Kubeconfig 다운로드 항목에서 다운로드 가능합니다. 다운로드시 클러스터 항목을 선택하면, 선택한 클러스터와 발급된 접속 인증으로 작성된 kubeconfig 파일로 다운로드 받을 수 있습니다.

Kubeconfig 다운로드는 본인이 발급한 접속 인증만 다운로드 가능합니다.

### 2. Kubeconfig 사용하기

다운로드된 파일은 kubeconfig 형식에 맞게 작성된 파일로 바로 사용이 가능합니다.

다운로드 파일 예시 kubeconfig 파일을 이용하여 kubectl 실행하기

## 이력 확인하기

### 1. 발급 이력 확인하기

먼저 왼쪽 하단의 콘솔 관리 메뉴를 클릭한 후, 운영관리 > 접속 인증 관리 메뉴를 클릭하여 이동합니다. 발급 이력 탭을 클릭하면 발급 이력 목록 화면으로 이동하고, 해당 목록에서 접속 인증의 발급 정보와 상태 등의 이력 정보를 확인할 수 있습니다.

### 2. 다운로드 이력 확인하기

먼저 왼쪽 하단의 콘솔 관리 메뉴를 클릭한 후, 운영관리 > 접속 인증관리 메뉴를 클릭하여 이동합니다. 다운로드 이력 탭을 클릭하면 다운로드 이력 목록 화면으로 이동하고, 해당 목록에서 접속 인증 다운로드 이력 정보를 확인할 수 있습니다.

## Q&A Section

**Q. Cluster 권한은 어떻게 되나요?**
A. Cluster 권한은 위의 절차에서 인증한 사용자의 권한을 갖습니다. 권한 변경이 필요한 경우 `해당 Cluster 멤버 권한 변경하기 - DS WIKIPEDIA - DS Confluence (samsungds.net)` 가이드를 참고하세요. → [[05. Cluster 멤버 권한 변경하기]]

**Q. P-DEP 연동을 위해 토큰이 필요합니다.**
A. 다운로드 받으신 kubeconfig 파일을 열면, `users.user.token` 정보를 통해 P-DEP 연동을 위한 토큰 정보를 확인하실 수 있습니다.
