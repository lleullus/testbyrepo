# Cluster 접속을 위한 장기 Token 발급

> [!warning] 지원 중단 안내
> 해당 가이드의 VOC 요청을 통한 장기 토큰 발급은 더 이상 지원하지 않습니다. 콘솔에서 접속 인증 발급 기능이 추가되어 이제부터는 해당 기능을 통하여 발급하실 수 있으며, 사용하는 방법은 기존과 동일합니다. 발급하는 방법은 `Cluster 접속을 위한 접속 인증 발급하기`를 참고하시기 바랍니다. → [[06. Cluster 접속을 위한 접속 인증 발급하기]]
>
> ※ 기존에 발급된 토큰은 그대로 사용가능합니다.

## 개요

해당 가이드는 P-DEP과 같은 시스템 연동시 클러스터 접속을 위해 필요한 장기(long-lived) Token 발급 방법에 대해 기술합니다. 발급되는 장기(long-lived) Token의 만료시간은 발급일로부터 1년입니다.

## (사전준비) kubelogin Plugin 설치 (로컬)

이미 설치하신 분은 해당 절차는 건너뛰고 진행하시면 됩니다.

### kubelogin Plugin 설치 (로컬)

#### chocolatey 설치 [Software Management for Windows]

kubelogin을 설치하기 위해 먼저 관리툴인 chocolatey를 설치하여 줍니다.

- https://docs.chocolatey.org/en-us/choco/setup/

Install with PowerShell.exe

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
```

#### kubelogin Plugin 설치 [Kubernetes OpenID Connect (OIDC) authentication]

Chocolatey를 사용하여 kubelogin Plugin을 설치하여 줍니다.

- https://community.chocolatey.org/packages/kubelogin
- https://github.com/int128/kubelogin

To install Kubelogin (CLI), run the following command from the command line or from PowerShell

```powershell

```

## 1. kube-login를 통한 OIDC 인증 access-token 발급

### 1) access-token 발급

`--oidc-use-access-token` 옵션을 추가하여 access-token 발급

```bash
## 실행
$ kubectl oidc-login get-token --oidc-issuer-url=https://keycloak.dks.samsungds.net/realms/DKS --oidc-client-id=kube-login --oidc-use-access-token
```

### 2) OIDC 인증 화면 [브라우저]

OIDC 인증을 위해 브라우저가 실행되어 인증화면으로 이동합니다. 인증이 성공하면 인증 성공 화면으로 리다이렉트 됩니다.

### 3) 응답값 확인

응답값 중 token 항목을 복사합니다.

```bash
$ kubectl oidc-login get-token --oidc-issuer-url=https://keycloak.dks.samsungds.net/realms/DKS --oidc-client-id=kube-login --oidc-use-access-token
```

## 2. Cluster 접속을 위한 장기 Token 발급 요청

### Token 발급 요청

위에서 복사한 token 정보를 첨부하여 `VOC 등록 - DS Cloud VOC`를 통해 발급 요청해주시기 바랍니다. token 정보 첨부시에는 아래와 같이 반드시 민감정보 체크를 하여 요청 부탁드립니다.

## 3. 발급받은 장기 Token을 이용하여 kubeconfig 생성

### kubeconfig 파일 생성 [로컬]

발급받은 Token을 이용하여 접속할 kubeconfig 파일을 작성합니다.

1. `clusters[*].cluster.server`의 `<클러스터명>`을 꼭 수정해주세요.
2. `users[*].user.token`의 `<발급받은 토큰>`을 발급받은 token으로 수정해주세요.

`kubeconfig-token`

```yaml
apiVersion: v1
clusters:
- cluster:
    server: https://cluster.dks.samsungds.net/clusters/<클러스터명> # 클러스터명 수정을 해주세요.
    insecure-skip-tls-verify: true
  name: kubernetes
contexts:
- context:
    cluster: kubernetes
    user: kube-token
  name: kube-token
current-context: kube-token
kind: Config
preferences: {}
users:
- name: kube-token
  user:
    # token is the bearer token for authentication to the kubernetes cluster
    token: <발급받은 token> # 발급받은 token으로 수정해주세요
```
