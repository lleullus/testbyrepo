# Cluster 멤버 권한 변경하기

## 멤버 목록

DKS2 콘솔의 프로젝트 및 Cluster의 멤버 목록은 One Cloud 에서 해당 프로젝트에 Assign된 멤버 목록과 동일합니다.

## 멤버 권한 관리

"콘솔관리 탭 > 운영관리 > 권한관리" 메뉴를 클릭합니다.

메뉴에 진입하면 상단에 "Cluster" 탭과 "멤버 관리" 탭이 존재합니다.

- Cluster 탭에서 Cluster 멤버 권한을 변경할 수 있습니다.
- 멤버관리 탭에서는 DKS2 콘솔의 멤버 권한을 변경할 수 있습니다.

Cluster 탭이 기본으로 선택되며, 선택되어져 있는 Cluster의 상세 정보가 보여집니다.

- 클러스터 이름
- 클러스터 대표 관리자 정보
- CPU / Memory, RWO Storage, RWX Stroage 정보

### 권한을 변경할 Cluster 선택

권한을 변경할 클러스터를 선택 할 때마다, 선택한 클러스터의 정보로 바뀌어 보여지게 됩니다. Project내의 전체 구성원 정보도 함께 보여집니다.

### Cluster를 선택하여 권한 할당

1. 권한을 변경할 클러스터를 선택합니다.
2. 전체 구성원 중에 권한을 변경할 사용자를 선택합니다. (필요에 따라 전체 선택)
3. 사용자를 선택하면 "우측 > 권한부여" 섹션에 사용자가 보여지게 되며, 권한을 부여할 수 있게 됩니다.
4. "권한" 버튼을 클릭하면, 부여 가능한 권한 중 하나를 선택해서 권한을 부여할 수 있습니다.

> [!note]
> - One Cloud 에서 사용자 정보가 I/F 되어 DKS2 사용자로 등록될때 기본적으로 `dks-cluster` 권한이 자동 부여 되어 있습니다.
> - 자동으로 부여되는 권한에 대한 정책은 DKS2 콘솔 운영 정책에 따라 변경될 수 있습니다.

5. 대표관리자는 1명만 선택할 수 있으며 Radio 버튼을 클릭하여 변경할 수 잇습니다.
6. 취소 아이콘을 클릭하면 편집 대상에서 제외 됩니다.
7. 모든 권한에 대한 설정이 완료되면 [저장] 버튼을 클릭하여 편집 내용을 반영합니다.

## Cluster 권한 목록

현재 제공되는 Cluster 권한에 대한 안내 입니다.

> [!note]
> 권한에 대한 정책은 DKS2 콘솔 운영 정책에 따라 업데이트 됩니다.

1. "콘솔관리 탭 > 운영관리 > Role 관리" 메뉴를 클릭합니다.
2. Role 관리 목록에서 "권한 종류"가 CLUSTER 인 Role이 Cluter 권한 입니다.
3. "Role 명" 을 클릭하면 Role(권한)에 대한 상세 정보를 확인할 수 있습니다.

## Q&A Section

**Q. Project에 멤버로 추가 했는데, 권한 관리 메뉴에서 사용자가 보이지 않아요**
A. Project에 멤버로 추가되었더라도 해당 멤버가 최소 1회 이상 DKS2 콘솔에 접속 하여야만 DKS2 콘솔의 멤버로 추가됩니다.
