# Cluster 접속을 위한 Kubeconfig 생성

## 1. kubelogin Plugin 설치 (로컬)

### chocolatey 설치 [Software Management for Windows]

kubelogin을 설치하기 위해 먼저 관리툴인 chocolatey를 설치하여 줍니다.

- https://docs.chocolatey.org/en-us/choco/setup/

Install with PowerShell.exe

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
```

### kubelogin Plugin 설치 [Kubernetes OpenID Connect (OIDC) authentication]

Chocolatey를 사용하여 kubelogin Plugin을 설치하여 줍니다.

- https://community.chocolatey.org/packages/kubelogin
- https://github.com/int128/kubelogin

To install Kubelogin (CLI), run the following command from the command line or from PowerShell

```powershell
choco install kubelogin
```

## 2. kubeconfig 파일 생성 [로컬]

OIDC로 접속할 kubeconfig 파일을 작성합니다. `clusters[*].cluster.server`의 `<클러스터명>`을 꼭 수정해주세요.

`kubeconfig-oidc`

```yaml
apiVersion: v1
clusters:
- cluster:
    server: https://cluster.dks.samsungds.net/clusters/<클러스터명> # 클러스터명 수정을 해주세요.
  name: kubernetes
contexts:
- context:
    cluster: kubernetes
    user: kube-login
  name: kube-login
current-context: kube-login
kind: Config
preferences: {}
users:
- name: kube-login
  user:
    exec:
      apiVersion: client.authentication.k8s.io/v1
      command: kubectl
      args:
      - oidc-login
      - get-token
      - --oidc-issuer-url=https://keycloak.dks.samsungds.net/realms/DKS
      - --oidc-client-id=kube-login
      interactiveMode: IfAvailable
```

## 3. kubelogin Plugin 실행 (로컬)

### 실행

Install with PowerShell.exe

```powershell
kubectl --kubeconfig=kubeconfig-oidc get no
```

### OIDC 인증

OIDC 인증 화면 [브라우저]: OIDC 인증을 위해 브라우저가 실행되어 인증화면으로 이동합니다. 인증이 성공하면 인증 성공 화면으로 리다이렉트 됩니다.

1. kubectl 설치 후 XML 에러 발생 (`syntax error near unexpected token '<'`)
   - 원인: 다운로드 URL 오류로 HTML 파일이 저장된 경우
   - 해결: 최신 버전 재확인 후 다시 다운로드
2. oidc-login 명령어 오류 (`error: unknown command "oidc-login"`)
   - 원인: kubelogin 심볼릭 링크 설정 누락
   - 해결: `sudo ln -s /usr/local/bin/kubelogin /usr/local/bin/kubectl-oidc_login` 실행
