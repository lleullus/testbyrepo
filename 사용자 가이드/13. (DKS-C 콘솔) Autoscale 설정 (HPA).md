# (DKS-C 콘솔) Autoscale 설정 (HPA)

HPA(Horizontal Pod Autoscaler)는 CPU, 메모리 등의 리소스 사용량에 따라 포드(Pod)의 개수를 자동으로 늘리거나 줄여주는 기능입니다. 따라서 Metrics Server가 (클러스터 신청 시 기본 제공) 정상 구동 중이어야 하며, Deployment 설정에 `resources.requests`가 정의되어 있어야 합니다.

## HPA (Horizontal Pod Autoscaler) 구성 하기

1. HPA를 설정하고자 하는 Project > 클러스터를 선택합니다.
2. Deployment 배포를 참고하여 Deployment를 생성합니다.
3. 메뉴에서 구성 > 수평 자동 확장(HPA)을 선택 후 상단 타이틀 옆 `+` 버튼을 클릭합니다.
4. 에디터에서 항목에 맞게 입력한 후 적용을 클릭합니다.

| 필드 | 설명 |
|---|---|
| `metadata.name` | HPA 이름 |
| `spec.scaleTargetRef` | 어떤 대상을 늘릴지 지정 (`apiVersion`, `kind`, `name`) |
| `spec.minReplicas` | 최소 복제 Pod 수 |
| `spec.maxReplicas` | 최대 복제 Pod 수 |
| `spec.metrics[].type` | metric 타입: Resource, Pods, Object, External (원문 표기 `spec.mectics[].type`) |
| `spec.metrics[].resource` | `name`: cpu / memory, `target.type`: Utilization / AverageValue, `target.averageUtilization`, `target.averageValue` |

### Resource Target Type

- **Utilization** (사용률, %): 컨테이너의 requests 값 대비 현재 몇 %를 쓰고 있는지 계산합니다.
- **AverageValue** (평균 절대값): 전체 포드의 리소스 사용량 평균값을 기준으로 합니다.

5. 생성된 HPA 정보를 확인합니다.
