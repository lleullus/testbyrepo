# (DKS-C 콘솔) PVC 배포

## PVC 배포 하기

1. PVC를 배포하고자 하는 Project > 클러스터를 선택합니다.
2. 메뉴에서 스토리지 > 퍼시스턴트 볼륨 클레임을 선택 후 상단 타이틀 옆 `+` 버튼을 클릭합니다.
3. 에디터에서 항목에 맞게 입력한 후 적용을 클릭합니다.

| 필드 | 설명 |
|---|---|
| `metadata.name` | PVC 이름 |
| `metadata.namespace` | PVC 네임스페이스 |
| `spec.storageClassName` | 스토리지 클래스 이름 |
| `spec.accessModes` | Access Mode 이름 |
| `spec.resources.requests.storage` | Volume 용량 |

### Storage Class

| Storage Class | 유형 | Reclaim | Access Mode | 용량 범위 |
|---|---|---|---|---|
| `vks-pf-storage-policy-data` | Block | Delete | RWO, RWOP | 1 Mi ~ 62 Ti |
| `netapp-nfs` | NAS | Delete | RWX, ROX | 20 Mi ~ 100 Ti |

※ 최대용량은 스토리지 사용 현황에 따라 제한될 수 있습니다.

### Access Mode

| Access Mode | 설명 |
|---|---|
| ReadWriteOnce (RWO) | 단일 노드에서 읽기, 쓰기 가능 (단일 노드 내 다수의 POD에서 읽기, 쓰기 가능) |
| ReadWriteMany (RWX) | 다수의 노드에서 읽기, 쓰기 가능 |
| ReadOnlyMany (ROX) | 다수의 노드에서 읽기만 가능 |
| ReadWriteOncePod (RWOP) | 단일 파드에서 읽기, 쓰기 가능 (단일 파드 마운트 보장) |

> [!note] 원문 표기
> 원문은 Storage Class 표가 평문으로 이어져 있어 열 구분을 복원했다. `netapp-nfs`가 RWO를 지원하는지는 표에 없지만, 아래 Q&A는 "NAS는 RWO, RWX 용도의 PVC 생성이 가능"하다고 적고 있다. 표의 `RWX, ROX` 열과 Q&A가 다르다.

4. PVC 생성을 완료하면, 해당 PVC의 정보와 상태를 확인할 수 있습니다.

## Q&A Section

**Q. PVC는 어떻게 배포하나요?**
A. 스토리지 > 퍼시스턴트 볼륨 클레임 경로로 접근하여 `+` 버튼을 클릭하신 후 안내에 따라 진행해 주세요.

**Q. PV 데이터를 다른 Cluster로 이관하고 싶습니다.**
A. 현재 DKS2는 Cluster 간 PV 데이터를 이관에 대한 지원을 하지 않습니다.

**Q. Storage Class Name을 어떻게 확인할 수 있나요?**
A. 위의 3번 항목에 있는 Storage Class 두 가지를 사용할 수 있습니다. 스토리지 > 스토리지 클래스 목록에서도 확인 가능합니다.

**Q. Storage Class를 추가할 수 있나요?**
A. Storage Class는 추가로 제공해드리지 않습니다.

**Q. Storage Class는 Cluster 수준에서 관리되나요?**
A. Storage Class는 Cluster 수준에서 관리되는 resource로 Cluster 관리자가 관리합니다. DKS2의 경우 DKS 운영팀입니다.

**Q. PVC 생성 시 403 Forbidden 에러가 발생하며 PVC가 생성되지 않습니다.**
A. PVC는 Cluster의 Storage Quota 내에서 생성 가능하며, 할당량을 초과하는 PVC 생성 시도 시 해당 에러 메시지가 발생할 수 있습니다. DKS2의 경우 Block Storage/ NAS 유형 별로 Storage Quota가 구분되어 있으며, Block Storage는 RWO 용도의 PVC 생성만 가능하고 NAS는 RWO, RWX 용도의 PVC 생성이 가능합니다. 각 유형 별 Storage Quota 확인 부탁드립니다.
