# DKS2 Cluster에 멤버 추가 방법

DKS2의 Cluster 멤버 목록은 One Cloud에서 해당 프로젝트에 Assign된 멤버 목록과 동일합니다. DKS2의 Cluster에 새로운 멤버 추가를 위해서는, One Cloud에 접속하여 Project 멤버를 추가 하여야 합니다.

> [!note]
> - DKS2는 One Cloud의 프로젝트 정보를 주기적으로 I/F 받아 멤버를 관리하며, One Cloud Project에 멤버 추가 후 I/F 되기까지 최대 20분 가량 소요될 수 있습니다.
> - I/F어 프로젝트에 추가되는 사용자는 프로젝트내의 클러스터 사용권한을 자동으로 획득하게 됩니다. (+ DKS2 콘솔의 사용자 권한도 자동 획득)

## One Cloud 에서 프로젝트 멤버 추가

좌측 LNB 메뉴 > My > My Dashboard > 클라우드 관리 항목의 프로젝트 > 추가 하고자하는 프로젝트의 나사 아이콘 클릭 > 프로젝트 설정 화면으로 이동

자세한 방법은 아래 One Cloud의 클라우드 프로젝트 참여 시청/승인 가이드 링크를 참고해주시기 바랍니다.

`클라우드 프로젝트 참여 신청/승인 - DS Wikipedia - DS Confluence`

## Q&A Section

**Q. Project에 멤버로 추가 했는데, 권한 관리 메뉴에서 사용자가 보이지 않아요**
A. Project에 멤버로 추가되었더라도 해당 멤버가 최소 1회 이상 DKS2 콘솔에 접속 하여야만 DKS2 콘솔의 멤버로 추가됩니다.
