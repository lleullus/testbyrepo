# 자원 삭제 신청

"콘솔관리 > 신청 관리 > 자원 삭제 신청" 메뉴를 클릭합니다.

## Project 선택 Step

변경하고자 하는 Cluster가 있는 Project 명을 선택한 뒤 [다음] 버튼을 클릭합니다.

## 자원 정보 선택 Step

삭제 대상 Cluster를 선택하면 이전에 신청된 정보가 조회되어 보여집니다. 조회된 내용을 확인 후 이상이 없으면 [다음] 버튼을 클릭합니다.

## 자원 삭제 정보 확인 Step

자원 삭제 정보 확인 Step에서는 삭제하려는 Cluster 정보를 확인할 수 있습니다.

1. [임시저장] 버튼을 클릭하면 설정정보가 저장됩니다. (보관주기 7일)
   - 보관된 정보는 "신청관리 > 자원신청현황" 목록에서 확인할 수 있으며, 상세 정보화면에 진입하여 우측 상단 "Action 메뉴의 편집 버튼" 기능을 이용하여 재사용 가능합니다.
2. 결재 완료 시 신청한 자원은 모두 바로 삭제되며, 복구가 불가능함을 안내하는 메시지가 노출됩니다.
3. 모든 내용을 확인한 후 [신청] 버튼을 클릭하면 결재 상신 팝업이 오픈 됩니다.
   - [등록] 버튼을 누를 경우 결재라인을 추가 할 수 있습니다.
   - 결재자 정보를 올바르게 선택하고, 상신의견을 입력한 후, [상신] 버튼을 클릭하여 자원 삭제 신청을 완료할 수 있습니다.

## 신청 완료 > 자원 삭제 신청 현황

신청이 완료되면 자원 신청 현황 목록으로 이동되며, 삭제 신청한 내용이 가장 상단에 보여집니다. 신청 No를 클릭하여 자원 삭제 정보를 확인할 수 있습니다.

## 완료 메일 수신

결재 완료 후 삭제 처리가 모두 완료되면, 삭제 완료 메일을 수신합니다.
