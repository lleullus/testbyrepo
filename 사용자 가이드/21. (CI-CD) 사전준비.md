# (CI/CD) 사전준비

CI/CD 를 이용해 소스 빌드와 배포를 하기 위해선 Git 소스 정보, Container 이미지를 upload 할 registry 그리고 배포할 클러스터와 Namespace 가 필요 합니다.

## K8s 리소스를 배포할 클러스터 & Namespace 준비

Kubernetes 리소스를 배포 하기 위해선 사전에 배포할 클러스터와 Namespace 가 생성되어 있어야 합니다. 프로젝트 하위에 자원들이 할당되기 때문에 당연히 프로젝트도 존재 해야 합니다.

### 클러스터 등록

클러스터가 존재하지 않는다면 콘솔관리 탭 > 신청관리 > 자원등록신청 에서 클러스터 자원을 신청하세요. 자세한 정보는 가이드 문서(자원 신청하기 가이드 문서)를 참고하세요. → [[01. 자원 신청하기]]

### Namespace 등록

CI/CD 배포시 클러스터와 네임스페이스를 선택해야 합니다. 배포하려고 하는 namespace 가 존재 하지 않는다면 클러스터 관리 탭 > 클러스터 > 네임스페이스 에서 namespace 를 생성할 수 있습니다.

## 등록된 registry 확인

DKS 프로젝트내에 클러스터가 생성될 때 해당 프로젝트에서 사용할 이미지 registry는 자동으로 생성되어 할당이 됩니다. 클러스터가 생성된 후에 할당된 registry 가 존재하는지 메뉴에서 확인이 필요 합니다.

레지스트리 관리 메뉴에서는 등록된 레지스트리 확인, 레지스트리 정보수정 및 등록된 이미지 확인과 삭제가 가능합니다.

앱배포 파이프라인 탭 > 설정 > 레지스트리 관리 메뉴에서 등록된 레지스트리가 존재 하는지 확인 합니다. (레지스트리가 존재하지 않는 경우 DKS 운영에 문의 주세요)

※ 레지스트리에 Image를 Push하는 방법은 별도 Guide를 참고하세요. `Image Push. - DS Wikipedia - DS Confluence`

- 레지스트리 목록
- 레지스트리 상세
- 레지스트리 수정
- 이미지 관리: 이미지 관리 탭은 등록된 이미지를 확인하고 삭제할 수 있는 기능을 제공합니다.

(각 항목의 원문 스크린샷은 붙여넣기에 없음)

## 소스 Repository 등록

사용자가 개발한 소스를 이용해 소스 빌드 및 Container 이미지 빌드를 하기 위해선 개발한 소스가 있는 소스 repository를 등록해야 합니다. 등록된 repository 만 CI/CD에서 사용할 수 있습니다.

사설 인증서 사용할 경우,

- SSL Verification : ON
- Use Self-Signed Certificate : ON
- CA Certificate : 필수값 입니다.

앱배포 파이프라인 탭 > 설정 > 레포지토리 관리 메뉴로 이동합니다.

### 레포지토리 목록

목록에서 추가 아이콘을 통해 repository 추가할 수 있고, 항목을 선택해 일괄 삭제도 가능합니다.

### 레포지토리 추가

목록에서 추가 아이콘을 입력하여 레포지토리를 추가할 수 있습니다. 모든 정보를 입력하면 [연결 확인] 버튼을 클릭하여 입력된 정보를 검증합니다. [연결 확인] 을 통과하면 [저장] 버튼이 활성화 되어 입력된 내용을 저장할 수 있습니다.

### 레포지토리 정보

해당 내용은 사내 DS Github를 기준으로 작성되었습니다.

- **엔드포인트**: 브라우저에서 대상 Git 레포지토리로 이동하여 복사 버튼을 클릭하여 복사한 후, 엔드포인트에 붙여넣기하여 입력합니다.
- **Public 유형 레포지토리 여부 확인**: 브라우저에서 대상 Git 레포지토리로 이동하여 확인하실 수 있습니다.
- **Internal & Private 유형 레포지토리 여부 확인**: 브라우저에서 대상 Git 레포지토리로 이동하여 확인하실 수 있습니다.
- **사용자 이름**: 인증 및 권한을 가진 사용자 ID를 입력합니다. 더 자세한 내용은 `[GitHub] User 계정 생성 가이드`를 참고하세요.
- **Personal Access Token**: 발급한 Personal Access Token(PAT)를 입력합니다. 더 자세한 내용은 `[GitHub] Personal Access Token 발급 가이드`를 참고하세요.
- **CA Certificate**: 해당 Git 엔드포인트에 필요한 인증서를 입력합니다. 인증서는 `[GitHub] "인증서 적용 가이드"`에서 제공합니다. 인증서 파일을 메모장으로 열어 처음부터(`-----BEGIN CERTIFICATE-----`) 끝까지(`-----END CERTIFICATE-----`) 전체 내용을 복사하여 입력합니다.

## 기타 준비 사항

CI/CD를 통해 이미지 빌드를 하기 위해선 Dockerfile 이 필요하고, Kubernetes 클러스터에 배포를 위해선 배포 Yaml 파일이 필요 합니다.

### Dockerfile

소스 레포지토리에 Dockerfile 을 upload 하고 CI/CD 설정시 Dockerfile을 선택해서 사용하거나 내용을 직접 입력하여 사용할 수 있습니다.

### Yaml 파일

소스 레포지토리에 yaml 파일들을 upload 하고 CI/CD 설정시 해당 레포지토리의 경로를 선택해서 사용하거나 내용을 직접 입력하여 사용할 수 있습니다.
