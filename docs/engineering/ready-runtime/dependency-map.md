# Current IIS dependency map

Dated records in this directory describe historical versions only.

## Contract producers and consumers

Thesis → exact bound Scope → Plan/Assurance Baseline → authorized implementation/self-check → source and execution binding → native gates/direct observations → independent Production Heuristic Probe lanes → structural closure → Main's conditional status-only record.

Thesis/Scope own meaning. Planner owns methods and the predeclared evidence/attack denominator. Implementer owns authorized delta and reproducible handoff. Existing project tools and observation owners produce actual readbacks. Probers find bounded counterexamples, not every-Acceptance approvals. Main preserves terminal results and checks currentness/attribution/settlement/request coverage, without adding a final semantic judge.

The shared data contract is `iis-workflow/references/assurance.md`; the helper is `iis-workflow/tools/assurance.py`. Direct observation failure, stale evidence, missing started work and unknown effect settlement block independently of no-finding labels. Scope recording belongs to iis-workflow, never a deleted role directory.

## Executable helpers

- `scope-shaper/tools/validate_scope.py` and `iis_path_contract.py`: canonical structure/path/bound-source checks; reused by assurance validation.
- `iis-workflow/tools/assurance.py`: baseline validation, clean committed source and execution identity, native foreground command capture, evidence closure and read-only status-delta check.
- `companion-skills/repository-investigation/tools/`: immutable investigation artifact preparation/validation.
- `scripts/sync_installed_iis.py`: immutable packaging and optional OMP/Codex links; no role execution.
- `observatory/`: conservative read-only project state.
- `repo-snapshot/`: independent Git snapshot utility, not automatically called by sealing.
- `evaluation/`: disposable fixtures, standalone prompt preparation, historical label scorer and offline causal-trace scorer. No model/agent runner or production completion credential.

No controller, scheduler, registry, database or host authentication is introduced. Runtime identity, actual role source loading and behavior remain distinct from source/install identity.

## Installation boundary

Packaging stays protocol 4 / iis-skills. Candidate validation uses current required/retired topology; installed integrity uses that release's own manifest and managed links. A new candidate can replace old v4 without treating old role files as corrupt. Rollback restores old managed links and installed inspection remains valid. User-owned entries/history remain protected. Historical v3 usage still requires its matching host source.

Operating activation needs current authority and affected work/effect settlement. Installation does not restart clients or prove loaded identity. Independent Observatory sync targets Codex only and is not required for OMP delivery.
