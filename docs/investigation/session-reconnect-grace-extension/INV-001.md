## Current System Model

### Entry And Execution Flow

1. 클라이언트(모바일 브라우저)가 네트워크 순단 또는 화면 슬립으로 연결이 끊기면 `protocol.c:811`의 `session_start_expiry(session)`가 호출됩니다.
2. `session_start_expiry`는 `session_grace_ms()`를 호출하여 밀리초 단위 유예 시간을 산출합니다.
3. `session_grace_ms()`는 `TTYD_RECONNECT_GRACE` 환경변수를 확인하며, 부재 시 기본값 `SESSION_GRACE_DEFAULT_MS` (기본 6시간 = 21,600,000 ms)를 반환합니다.
4. libuv 타이머 `uv_timer_start(timer, session_expire_cb, grace_ms, 0)`가 가동됩니다.
5. 유예 시간 내 클라이언트가 동일한 `resumeId`로 재접속하면 `attach_process()` -> `session_cancel_expiry()`가 타이머를 중단하고 세션을 복원합니다.
6. 유예 시간이 경과하면 `session_expire_cb()`가 호출되어 `pty_kill(process, sig)`로 자식 프로세스를 정리하고 세션 리스트에서 해제합니다.

### State, Data And Lifecycle Ownership

- **세션 상태 소유자**: `protocol.c`의 `session_list` 연결 리스트 및 `struct tty_session` 내 `expiry_timer` 포인터.
- **타이머 수명 소유자**: libuv 이벤트 루프(`server->loop`).
- **프로세스 수명 소유자**: ttyd 데몬이 fork/pty로 생성한 PID이며, 타이머 만료 또는 명시적 종료 시에만 kill 시그널을 발송함.

### Configuration And Extension Boundaries

- `SESSION_GRACE_MAX_SECONDS`: `src/protocol.c:21`에 정의된 상한선 매크로. 현재 `(6 * 60 * 60)`.
- `SESSION_GRACE_DEFAULT_MS`: `(SESSION_GRACE_MAX_SECONDS * 1000ULL)`.
- `TTYD_RECONNECT_GRACE`: 초 단위 문자열 환경변수. 1 이상 `SESSION_GRACE_MAX_SECONDS` 이하의 정수만 허용되며, 범위를 벗어나면 기본값으로 폴백됨.

### Observable Results And Readbacks

- 관측 로그 (`~/.local/state/webterm/ttyd.log`):
  - 단절 시: `N: detached resumable process, pid: <pid>`
  - 복구 시: `N: WS /ws - 127.0.0.1, clients: <n>` 및 세션 재연결
  - 만료 시: `N: resume grace expired, killing process, pid: <pid>`
