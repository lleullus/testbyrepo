# 계정 내보내기 통합의 첫 경로

상태: 기획 보조 (비권위)
권위: 없음. 이 문서는 Spec 이전의 경로 정리용이며 구현 범위를 승인하지 않는다.

## 목적

여러 서비스에 흩어진 계정 내보내기 기능을 장기적으로 통합할 수 있는 첫 구현 경로를 정한다.

## 테스트 사용자 제공 사실

- 기존 단일 서비스에는 JSON 내보내기 경로가 있다.
- 기존 통합 테스트로 이전 요청과 새 요청의 동일 결과를 검증할 수 있다.

## 검토 후보

- 후보 A: 기존 단일 서비스의 JSON 내보내기 한 경로만 새 공통 요청 형식에 연결한다.
- 후보 B: 여러 서비스를 같은 변경에서 통합한다.
- 후보 C: CSV와 UI까지 함께 포함한다.

## 채택된 결정

- 테스트 사용자는 후보 A만 첫 구현 범위로 채택했다.
- 이전 요청과 새 공통 요청은 기존 통합 테스트에서 동일 결과를 보여야 한다.

## 알려진 의존성

- 기존 단일 서비스 JSON 내보내기 경로
- 이전 요청과 새 공통 요청을 비교하는 기존 통합 테스트

## 명시적 제외

- 다른 서비스
- CSV
- UI
- 데이터 삭제

## Open Questions

첫 구현 범위에 대한 미해결 제품 결정은 없다. 다른 서비스의 후속 통합 순서는 이후 별도 기획 범위다.
