# 승인된 UI/UX 참조: 빈 설정 화면 정보 계층

Status: approved
Owner: 테스트 사용자
Authority: 사용자 승인된 빈 설정 화면 UI Ticket의 참조 문서

## 채택된 결정

설정이 비어 있는 화면에서는 안내문을 먼저 보여주고, 그 뒤에 단일 주요 설정 버튼을 보여준다.

## 적용 범위

- 빈 설정 화면
- 좁은 화면과 넓은 화면

## Non-Goals

- 다른 화면 변경
- prototype code 또는 variant switcher를 제품 UI로 승격

## 검토 근거

테스트 사용자가 실제 390x844와 1440x1000 browser render를 검토한 뒤 이 결정을 명시적으로 채택했다. 비교 기록은 비권위 `PROTOTYPE-NOTE.md`에 있으며 이 문서만 채택된 UI/UX 결정을 전달한다.
