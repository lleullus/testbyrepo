# 빈 설정 화면의 안내문 우선 정보 계층

Status: approved
Owner: 테스트 사용자

## Problem

설정이 비어 있는 화면에서 안내문과 주요 설정 버튼의 우선순위가 정해지지 않았다.

## Desired Outcome

좁은 화면과 넓은 화면의 빈 설정 화면에서 안내문이 먼저 보이고, 그 뒤에 단일 주요 설정 버튼이 보인다.

## Requirements

- 빈 설정 화면에서 안내문을 주요 설정 버튼보다 먼저 보여준다.
- 안내문 뒤에는 단일 주요 설정 버튼을 보여준다.
- 좁은 화면과 넓은 화면 모두에서 같은 정보 계층을 유지한다.
- 채택된 후보 B만 반영한다.

## Non-Goals

- 다른 화면 변경
- 빈 설정 화면 외 상태의 UI 변경
- prototype code 또는 variant switcher의 제품 구현

## Implementation Constraints

- 승인된 UI/UX 참조의 안내문 우선과 단일 주요 버튼 결정을 따른다.
- 변경 범위는 빈 설정 화면과 좁은/넓은 화면의 해당 표현으로 한정한다.

## Verification Expectations

- 좁은 390x844와 넓은 1440x1000에서 빈 설정 화면을 수동 검토해 안내문이 먼저 보이는지 확인한다.
- 같은 화면에서 단일 주요 설정 버튼이 안내문 뒤에 보이는지 확인한다.
- 변경 검토로 다른 화면이 범위에 포함되지 않았는지 확인한다.

## UI / UX

사용자가 채택한 후보 B: 빈 설정 화면에서 안내문을 먼저 보이고 그 뒤에 단일 주요 설정 버튼을 보인다. 승인된 참조는 `UX-REFERENCE.md`다.
