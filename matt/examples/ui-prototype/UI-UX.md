# 예시: 승인된 UI/UX 결정

Status: approved
Owner: 예시 planning owner
Scope: 대상 화면의 정보와 단일 주요 행동의 rendered ordering 및 narrow/wide viewport 보존

이 문서는 가상의 UI 질문에 대해 사용자가 채택한 결정의 승인된 참조다. prototype 검토 결과가 아니라, 사용자의 채택과 이 문서의 승인 상태가 권위다.

## Approved Decisions

- 대상 화면에서는 필요한 정보를 먼저 제시하고, 그 다음 하나의 주요 행동을 제시한다.
- narrow와 wide viewport 모두 같은 정보-행동 ordering을 유지한다.
- semantic reading order와 keyboard focus order도 같은 ordering을 보존한다.

## Out Of Scope

- 새로운 loading, error, success, 또는 permission state
- 이 ordering을 넘는 화면 구성, 문구, 또는 상호작용 결정
