> 안녕하세요. DKS 운영팀 입니다.
> DKS 콘솔에서 LoadBalancer 생성 방법 가이드 드리겠습니다.
> DKS 콘솔에서 네트워크
> 서비스 로 UI 접근하신 후 + 버튼을 누르셔서 yaml 내용을 작성하시면 됩니다.
> ```yaml
> apiVersion: v1
> kind: Service
> metadata:
> name: postgres-test-svc
> namespace: test-contour
> spec:
> type: LoadBalancer
> ports:
> - port: 9876
> targetPort: 5432
> selector:
> app: postgresql
> ```
> yaml은 위와 같이 작성해주시면 됩니다.
> name, namespace 등은 적절하게 작성해주시면 되며
> spec.selector : 요청을 수신할 pod에 작성하신 metadata.label과 동일하게 작성해주시면 됩니다.
> spec.ports.port : client가 요청을 보낼 port를 작성해주시면 됩니다.
> spec.ports.targetPort : pod가 open하고 있는 port를 동일하게 작성해주시면 됩니다.

**DKS 운영(dksmgmt.sec)/Cloud Solution그룹(AI센터)** · [게시됨] · 등록일: 2026-08-03 15:26:51
> 안녕하세요. DKS 운영팀 입니다.
> DKS-N 에서는 Namespace 단위로 제공해드리고 있기 때문에
> Namespace의 resource quota 를 DKS 운영팀에서 관리합니다.
> DKS-N의 resource quota는 두 개가 생성되어 있는데요.
> 하나는 cpu, memory 할당량을 위한 것이고
> 다른 하나는 storage 할당량을 위한 것 입니다.
> 반면 DKS-C 에서는 Cluster 단위로 제공해드리고 있기 때문에
> DKS에서는 운영 목적으로 사용되는 일부 namespace 를 제외하고
> 나머지 Namespace 들의 resource quota 를 관리하지 않습니다.
> DKS-C에서 보고 계시는 resource quota는 Cluster의 관리자 분께서 생성하신 것으로 보이며
> Cluster 관리자 분에게 문의주셔야 할 것 같습니다.
> 감사합니다.
