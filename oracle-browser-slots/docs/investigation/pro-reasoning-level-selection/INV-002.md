## Current System Model

### Entry And Execution Flow

1. CLI는 `high`, `extra-high`, `pro`를 수용한다. `high`는 legacy storage 값 `extended`, `extra-high`는 `heavy`, `pro`는 별도 literal로 parse된다.
2. Browser config는 이를 canonical `BrowserReasoningIntent`인 `high`, `extra-high`, `pro`로 복원한다.
3. Managed capability는 슬롯 1, 2, 10을 maximum `pro`, 슬롯 3, 4, 5를 maximum `high`로 모델링한다.
4. Strict controller는 live top-level slider에서 canonical rank 2, 3, 4를 목표로 native CDP mouse input을 수행한다.
5. Controller는 live label/position과 model identity를 재확인하고, Pro에서는 max position 및 닫힌 `6 Pro` pill도 확인한다.
6. 검증된 evidence가 아니면 `src/browser/index.ts`가 prompt 제출을 차단한다.
7. Wrapper는 Stock 실행 전 candidate slots를 결정한다. 여기서 High만 3, 4, 5를 포함하고 먼저 배치한다.

### State, Data And Lifecycle Ownership

- ChatGPT DOM: 현재 가능한 option set과 selected position.
- Stock browser controller: requested intent에 대응하는 UI action 및 positive verification.
- Stock session metadata: requested/resolved/status/verified/turn/attempt evidence.
- Wrapper JobRunner: model/reasoning token의 managed slot eligibility와 ordering.
- Wrapper lifecycle/session namespace: slot assignment, origin, conversation, submission/completion; actual reasoning selection을 대체하지 않음.

### Configuration And Extension Boundaries

- Canonical selection identities는 `high`, `extra-high`, `pro`로 이미 존재한다.
- Legacy aliases `extended`, `heavy`는 각각 `high`, `extra-high`로 귀결된다.
- Wrapper는 `high|extended`와 `extra-high|heavy|pro`를 서로 다른 slot class로 분기한다.
- Followup은 부모 원 슬롯을 바꾸지 않으므로 High가 슬롯 3, 4, 5에서 시작되면 이후 Pro/Extra High override가 다른 Pro slot로 이동할 수 없다.

### Observable Results And Readbacks

- Slot 1 live option IDs: `bucket:2:extended` High, `bucket:6:max` Extra High, `bucket:3:standard` Pro.
- Slots 1, 2, 10 모두 slider `aria-valuemin=0`, `aria-valuemax=4`, 단일 slider, 5 ticks, current `Pro, 5 of 5.`를 보였다.
- 세 슬롯 모두 nested Pro submenu, secondary slider, 별도 internal mode selector가 없었다.
- Stock metadata는 exact canonical requested/resolved intent와 `verified`를 제공한다.
- Wrapper readback은 compatible candidate tuple과 assignment/rejection을 제공한다.
