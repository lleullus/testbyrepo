## Current System Model

### Entry And Execution Flow

`run`은 argv validation과 mapped/caller URL injection 후 slot을 claim한다. `submit`은 allocator가 slot을 선택한 뒤 동일 mapping을 적용한다. 두 경로 모두 submission-capable이고 destination URL이 있으면 `execute_claimed`가 `_prepare_strict_destination`을 Popen보다 먼저 호출한다. Exact target이 없으면 wrapper가 `Target.createTarget(destination_url)`을 호출하고 `/json/list`의 target URL, websocket `location.href`, page readiness, composer, login을 확인한다. 성공한 readback URL은 `--browser-tab`으로 stock Oracle에 pin된다.

### State, Data And Lifecycle Ownership

`Settings.from_env`가 URL·port·profile/state 경로를 소유한다. Slot JSON은 prepared, occupancy, last lifecycle outcome을 소유하지만 exact target identity를 저장하지 않는다. Existing ready Chrome은 prepare에서 재사용되며 navigation하지 않는다. Live exact destination은 strict CDP target/readback이 소유한다.

### Configuration And Extension Boundaries

Request caller URL이 slot mapping보다 우선한다. Slot mapping은 선택 slot의 run/submit argv로 주입된다. Legacy global URL은 fresh launcher에만 사용된다. Followup은 parent origin slot/conversation을 사용하고 mapping injection과 strict destination을 끈다. Sessionless control은 strict target 준비를 건너뛴다.

### Observable Results And Readbacks

현재 persisted `pre_submit_failed` record의 정확한 오류 문구는 `strict destination readback URL이 변경되었습니다: about:blank`다. 이 문구는 `cdp.py:527-531`에서만 생성되며 target websocket의 `location.href` mismatch를 뜻한다. `runner.py:375-378`상 Popen은 이 검사 뒤이므로 stock Oracle child와 prompt submission은 시작되지 않았다.

## Alternate, Legacy And Bypass Paths

- `prepare`: fresh Chrome에만 mapped URL을 launcher argument로 사용하고 existing CDP는 navigation하지 않는다. Strict destination 증거가 아니다.
- `followup`: origin slot과 stable parent conversation을 authority로 사용하고 strict destination을 명시적으로 끈다. 새 mapped workspace navigation의 workaround가 아니다.
- Sessionless flags: strict target을 만들지 않고 prompt를 제출하지 않는다.
- Mapping/caller URL 없는 request: strict destination 없이 stock behavior를 사용하므로 current regression 범위 밖이지만 exact workspace authority도 없다.
- Direct stock Oracle: wrapper를 우회해 자체 target create/navigation 또는 existing-tab attach를 수행하므로 managed slot lifecycle/readback과 동일한 제품 경로가 아니다.
