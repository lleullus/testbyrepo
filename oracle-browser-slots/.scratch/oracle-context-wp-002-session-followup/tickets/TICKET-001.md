## Goal

현재 OpenCode 대화의 최근 재개 가능한 Oracle Browser 세션을 안전하게 선택하고, 원 슬롯의 같은 ChatGPT conversation에서 후속 질문과 응답을 이어 간 뒤 자식 세션 lineage로 확인할 수 있게 한다.

## Acceptance Criteria

- 세션 ID가 없는 팔로우업 요청은 현재 OpenCode 대화가 만든 종료된 Oracle Browser 세션 중 안정적인 ChatGPT 대화 식별 정보와 관리되는 원 슬롯·로그인 프로필을 확인할 수 있는 가장 최근 세션을 부모로 선택한다.
- 완료·오류·취소 또는 보관 여부는 그 자체로 자동 후보를 제외하지 않으며, 실행 중이거나 대화 식별 정보 또는 관리되는 원 슬롯을 확인할 수 없는 세션은 제외한다.
- 사용자가 세션 ID를 명시하면 자동 후보보다 우선하며, 해당 세션이 재개 자격을 충족하지 않으면 다른 세션으로 대체하지 않고 실패한다.
- 재개 가능한 자동 부모가 없으면 새 ChatGPT 대화를 만들거나 프롬프트를 제출하지 않고 이유와 명시 세션 지정 방법을 보여 주며 실패한다.
- 후속 요청은 부모의 원 슬롯·로그인 프로필에 자동 고정하고 다른 슬롯으로 대체하지 않는다.
- 원 슬롯이 점유 중이면 자동 만료 없이 해당 슬롯만 기다리고 호출자가 취소할 수 있으며, 슬롯이 해제되면 원 슬롯에서 실행한다.
- 원 슬롯이 미준비 또는 사용 불가이면 다른 슬롯으로 전환하거나 계속 기다리지 않고 복구 안내와 함께 실패한다.
- 후속 질문과 응답은 부모와 동일한 ChatGPT conversation에 추가되며 새 ChatGPT 대화를 만들지 않는다.
- 각 후속 실행은 부모 기록을 덮어쓰지 않는 새 Oracle 자식 세션을 만들고, 다음 암시적 팔로우업은 최신 재개 가능한 자식 세션을 부모로 선택한다.
- 자식 세션에서는 부모 선택 방식, 부모·자식 세션 ID, 원 슬롯, 동일 conversation ID/URL, 프롬프트 제출 결과, 응답 완료 상태와 후속 응답을 기존 세션 조회 흐름으로 다시 확인할 수 있다.
- 일반 새 Oracle 요청과 슬롯 준비·상태·점유, 기존 세션 조회의 범위 밖 관찰 가능한 동작은 변경되지 않는다.

## Scope

- 현재 OpenCode 대화의 암시적 최근 부모 선택과 사용자가 명시한 Oracle Browser 부모 세션 선택
- 부모의 원 슬롯 점유 대기, 취소, 사용 불가 실패 및 같은 ChatGPT conversation의 후속 질문·응답 수명주기
- 부모와 자식 Oracle 세션의 lineage 및 기존 세션 조회를 통한 후속 결과 확인
- 일반 새 요청과 기존 슬롯·세션 동작의 보존

## Non-Goals

- 단일 ZIP 첨부 또는 첨부 용량 정책 변경
- API 엔진 응답 이어가기
- 저장된 Oracle 세션과 무관한 임의 ChatGPT URL 재개
- 최초 호출 안에서 미리 정한 여러 후속 질문의 자동 제출
- 원 슬롯을 사용할 수 없을 때 다른 로그인 프로필의 슬롯으로 대체
- 재개 가능한 부모가 없을 때 일반 새 대화로 자동 전환

## Blockers

None

## Verification

- 현재 OpenCode 대화가 여러 Oracle Browser 세션을 만든 대표 흐름에서 세션 ID 없는 팔로우업이 가장 최근의 재개 가능한 세션을 선택하고, 명시 ID가 있으면 해당 세션을 우선하는지 확인한다.
- 완료·오류·취소·보관, 실행 중, 대화 식별 정보 부재, 원 슬롯 부재 상태를 대표하는 세션에서 후보 자격과 부적격 실패가 Acceptance Criteria와 일치하는지 확인한다.
- 자동 부모가 없는 요청과 부적격 세션을 명시한 요청이 새 대화 생성이나 프롬프트 제출 없이 이유와 사용자 조치를 보여 주는지 확인한다.
- 원 슬롯이 점유된 상태에서 다른 빈 슬롯을 사용하지 않고 기다린 뒤 원 슬롯에서 실행되는지, 대기 중 취소가 가능한지 확인한다.
- 원 슬롯이 미준비 또는 사용 불가인 상태에서 다른 슬롯으로 전환하거나 계속 기다리지 않고 복구 안내와 함께 실패하는지 확인한다.
- 성공한 실제 Oracle Browser 팔로우업에서 부모와 자식의 conversation ID/URL이 같고 후속 질문과 응답이 기존 ChatGPT conversation에 추가되며 새 대화가 만들어지지 않는지 확인한다.
- 자식 세션을 다시 읽어 선택 방식, 부모·자식 세션 ID, 원 슬롯, 동일 conversation ID/URL, 프롬프트 제출 결과, 응답 완료 상태와 후속 응답을 확인한다.
- 연속 팔로우업이 최신 재개 가능한 자식 세션을 부모로 선택하고 같은 ChatGPT conversation chain을 유지하는지 확인한다.
- 일반 새 Oracle 요청과 슬롯 준비·상태·점유 및 기존 세션 조회의 범위 밖 관찰 가능한 결과가 유지되는지 확인한다.
