# Xi'an 전환 허브

## 목적

현재 `01. 활성 프로젝트/01. Xi'an 전환 운영 가이드` 문서군은 Taylor 인프라 구축 내용을 기반으로 작성되어 있다.
이 허브는 Xi'an 환경 정보를 누적하고, 정보 축적이 충분한 시점에 기존 문서를 Xi'an 기준으로 치환하는 작업을 안내한다.

## 현재 상태

| 항목 | 내용 |
|------|------|
| 기존 문서 기반 | Taylor |
| 목표 기준 | Xi'an |
| Xi'an 정보 축적 상태 | prd-host-pa01-xas, prd-apps-pa01-xas, dev-apps-pa01-xas, prd-harbor-xas 수집완료 |
| 플레이스홀더 설계 | 미시작 |
| 문서 치환 | 미시작 |

## Taylor 기반 문서의 Xi'an 치환 범위

기존 20개 문서에서 Xi'an 정보로 교체될 부분:

- Cluster 명칭 및 IP 대역
- 도메인 패턴 (Ingress, Harbor, KubeSphere Dashboard)
- 노드 구성 및 명명 규칙
- StorageClass 및 NetApp 구성
- 방화벽 개방 대상 IP/포트
- Harbor 레지스트리 주소 및 CA 인증서
- Bastion 서버 정보
- 보안그룹 및 AD 그룹

## Xi'an 정보 축적 프로토콜

### 1단계: 수집 (현재)

- `클러스터 상세/`에 Xi'an 관련 사실 직접 기록
- 아직 확정된 정보가 없으면 `Unknown` 섹션에 기록
- 출처와 날짜를 명시

### 2단계: 플레이스홀더 설계

- Xi'an 정보가 안정화된 카테고리별 플레이스홀더 정의
- 기존 20개 문서에 Taylor 값 → 플레이스홀더 치환

### 3단계: 치환 초안 생성 및 검수

- 플레이스홀더 기반 문서 초안 생성
- Governor 검수
- 사용자 검토 후 확정
