> [!summary] 요약
> 오케스트레이터가 태스크를 MVP 단위로 분할하고, 구현/검증 서브에이전트가 한 팀으로 동작하며, 모든 MVP가 완료된 후 오케스트레이터가 직접 최종 검수하는 **Builder Mode Orchestrate** 워크플로우의 전체 구조.

## 3계층 구조

```text
┌──────────────────────────────────────────────────────────┐
│                   Orchestrator (본인)                      │
│  MVP 분할 → 할당 → 분기 판정 → 최종 검수                    │
├──────────────────────────────────────────────────────────┤
│              Implementation Subagent                      │
│  MVP 범위 내 구현 → R1-R12 적용 → 완료 보고                │
├──────────────────────────────────────────────────────────┤
│              Verification Subagent(s)                      │
│  검증 계획 → 범위/품질/증거 확인 → 통과/수정 필요           │
└──────────────────────────────────────────────────────────┘
```
