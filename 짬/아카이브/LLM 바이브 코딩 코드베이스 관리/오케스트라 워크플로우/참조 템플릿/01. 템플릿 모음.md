## MVP Assignment Packet

### DDD-Lumin 대상 MVP

```yaml
mvp_assignment:
  id: MVP1
  goal: ""
  allowed_files:
    - ""
  excluded_scope:
    - ""

  ddd:
    packet_mode: strict
    scope_packet_ref: runtime-record | docs/scope-packets/MVP1.yml
    covered_artifacts:
      - kind: value_object
        name: Money
    ssot_decision: create_local_only
    boundary_constraints:
      forbidden_imports:
        - domain -> infrastructure
      public_surface_change_allowed: false

  lumin:
    tool_mode: tool-only
    full_baseline_path: .audit/manifest.json
    prewrite_required: true
    prewrite_advisory_path: .audit/pre-write-advisory.latest.json
    postwrite_required: true
    expected_postwrite_path: .audit/post-write-delta.latest.json
    exact_matches:
      - src/payments/domain/currency-amount.ts#CurrencyAmount
    advisory_cues: []
    limitations: []

  implementation_rules:
    - Do not write outside allowed_files.
    - Do not create hidden covered artifacts.
    - Do not expand public surface.
    - Do not add forbidden dependency.
    - Do not run Lumin or generate/refresh DDD-Lumin evidence.
    - Stop and report blocked if new scope or new evidence is needed.

  required_report:
    - actual files changed
    - tests run
    - DDD Scope Packet compliance
    - Lumin evidence handling
    - deviations from plan
    - blocked issues if any
```

## Verification Assignment Packet

```yaml
verification_assignment:
  mvp_id: MVP1
  expected_result_prefix: "통과 / 수정 필요"
  required_report:
    - verification result
    - material findings with evidence
    - non-material suggestions, if any
    - DDD-Lumin evidence review, if applicable

  verify:
    scope:
       - actual changes within allowed_files
       - excluded scope not touched
    completion_report:
       - Initial Plan Summary exists
       - Plan depth valid
       - Reuse and Duplicate Check complete
       - R1-R12 Rule Map complete, no blank
       - actual changes match plan + deviations
    ddd:
      - packet mode correct
      - strict/minimal decision justified
      - ssot_check matches evidence
      - module_boundary_check matches imports/exports
    lumin:
      - pre-write exists if required
      - post-write exists if pre-write used
      - exact matches not hidden
      - evidence limitations not treated as absence
      - post-write blockers not ignored
      - verifier did not run Lumin or generate evidence
    code_quality:
      - apply subagent inspection standards
```

## Lumin Pre-write Intent

```json
{
  "mode": "pre-write",
  "root": ".",
  "output": ".audit",
  "intentJson": "{\"names\":[],\"shapes\":[],\"files\":[],\"dependencies\":[],\"plannedTypeEscapes\":[]}"
}
```

### intent 규칙

```yaml
intent:
  names:
    - 새 symbol/type/helper/function/class/DTO 이름
  shapes:
    - name: 새 reusable shape 또는 API/event/schema/table 이름
      fields:
        - field_or_property_name
  files:
    - 생성/수정/이동/삭제 예정 파일
  dependencies:
    - from: 생성/수정 예정 파일 경로
      specifier: 새 import/module/package specifier (파일경로 아님)
  plannedTypeEscapes:
    - any/as unknown as/type ignore 등 계획된 escape
```

> [!warning] dependency validation
> - `specifier` 사용, `to` 사용 금지
> - `specifier`는 `.py`, `.ts` 등 파일 확장자로 끝나면 안 됨
> - Python: `src/crawler/parser.py` → `src.crawler.parser`

## Scope Packet

```yaml
scope_packet:
  mvp_id: MVP1
  mode: minimal | strict
  allowed_files:
    - ""
  excluded_scope:
    - ""

  authority_check:
    active_authority_confirmed: true | false
    notes: ""

  ssot_check:
    creates_or_changes_covered_artifact: true | false
    searched_existing: true | false
    lumin_evidence_required: true | false
    matched_existing_artifact: null
    decision: reuse_existing | create_local_only | create_ssot_candidate | blocked_duplicate | not_applicable
    reason: ""

  module_boundary_check:
    layers_touched: []
    public_surface_changed: true | false
    dependency_direction_changed: true | false
    unmapped_write_paths: []
    forbidden_dependencies: []

  evidence_profile:
    lumin:
      available: true | false
      baseline_full_path: null
      prewrite_required: true | false
      prewrite_path: null
      postwrite_required: true | false
      postwrite_path: null
      limitations: []
```

## Implementation Completion Report

```md
## Implementation Completion Report
1. Initial Plan Summary (MVP ID, Plan depth, Goal, Excluded scope)
2. Reuse and Duplicate Check (inspected, matched candidates, decision)
3. R1-R12 Rule Map (12개 각각 active/n-a/blocked-risk)
4. Actual Changes (files changed, summary)
5. Deviations from Initial Plan
6. Tests Run (command, result)
7. DDD-Lumin Delta (Scope Packet ref, pre/post-write handling)
8. Blocked Issues
```
